# CDISC临床数据标准化

先确认研究方案、采集表、原始数据、受控术语版本、目标监管场景和计划采用的 SDTMIG 或 ADaMIG 版本。标准化不是简单改列名；每个变量必须能追溯到采集来源、派生逻辑和分析目的。

SDTM 阶段先建立域、变量角色、受控术语、时间变量和受试者键；ADaM 阶段从分析终点和统计计划反推分析数据，保留可追溯派生。未知、未采集、未执行和不适用必须使用正确语义，不能统一填成空值或零。

需要设计映射表、验证和交付包时读取[SDTM与ADaM执行规范](references/SDTM与ADaM执行规范.md)。交付映射规格、数据集、define 元数据、审阅者指南、受控术语版本、验证问题和处置记录。

正式申报材料需要由熟悉目标监管机构和具体标准版本的专业人员复核；本 Skill 不能替代合规签署。
