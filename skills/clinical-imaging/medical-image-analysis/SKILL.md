# 医学影像数据准备与质量检查

建立患者—检查—序列—标签清单，记录模态、设备、协议、spacing、方向、尺寸和标签来源。DICOM 去标识或 BIDS 整理属于各自专门流程，本 Skill 从可分析副本开始。

先按患者确定训练、验证和测试划分，再估计强度归一化、采样和增强参数。同患者的多期影像、切片或派生 mask 不得跨集合。重采样影像与标签使用不同插值，并保留原始空间信息。

查看强度范围、视野、目标占比、空/孤立标签、左右翻转、截断和采集批次。增强必须符合解剖和任务，例如方向有临床含义时不能任意翻转。

交付数据质量画像、排除/修复清单、预处理配置和划分表。发现标签与影像错位、身份冲突或严重泄漏时，应先停止建模。
