# 细胞划痕面积与闭合率分析

将原始划痕图像或已有测量转换成可核验的面积结果，并在配对成立时计算闭合率。这个入口专门处理划痕区域、时间点配对和批量运行；细胞计数、一般强度定量及临床伤口照片不按本流程处理。

## 执行能力与边界

本 Skill 提供方法选择、执行与审查约定，当前未附带经验证的专用分割程序或 ImageJ 宏，未完成 Upstream 端到端运行验收。不能把加载 Skill 当成软件已安装、脚本已验证或故障已修复。

先检查当前环境和用户已有脚本、ROI、mask、测量表；可复用的结果从对应阶段继续。优先使用接口和版本可核实、适用于当前图像的现成批处理入口。用户明确指定 ImageJ/Fiji 时保留其工具选择；不可用时说明缺失，不静默换成 Python 并声称是 ImageJ 结果。用户仅要求测面积时，可依据环境选择 ImageJ 宏或 Python 图像处理方法，并记录实际实现。

如必须编写适配代码，只生成一份可复用的批处理实现，保存在用户分析工作区；检查输入、失败退出、覆盖保护和日志后，先完成小样本验证。不得逐张重新写代码，不以空白输出或合成演示冒充真实分析。没有可用图像或可执行路径时交付输入检查与具体阻塞原因。

## 从文件确认测量对象

读取图片尺寸、通道、位深、像素标定、帧数和现有元数据。建立文件清单，识别重复、损坏、多页 TIFF、时间序列、拼版、截图、文字及比例尺；不得默认仅处理第一帧，或将拼版当成一个视野。保留原图，分析副本与结果写入独立目录。

目标是有效分析区域内尚未被细胞覆盖的划痕区域。先确认有效区域、边界与游离细胞处理约定；区分“沿两侧边界包围的间隙面积”和“扣除间隙内细胞后的无细胞面积”，不得混用。文字、比例尺、图像外黑边不计入区域。不能把最亮区域或最大连通域直接等同于划痕。

可从文件核实的事实自行读取；仅在影响分析时，用普通语言补问无法核实的事实，例如“哪些照片属于同一个培养孔的前后时间点？”、“哪些孔来自独立重复实验？”。不让用户选择阈值、算法和命令参数。文件名只能形成配对候选，不能独自证明配对关系。

只有单张图也能测面积；缺少分组不阻止单图测量。缺少标定时报告像素面积，不能凭放大倍数猜测 μm²。若依据比例尺标定，记录端点、标注长度及图像缩放关系，并核验横纵像素尺寸。

## 先核验，再批量执行

1. 按成像方式、分辨率、光照及批次检查代表图，包含难处理图和接近闭合的时间点。单张输入直接作为试跑样本；不因样本少跳过叠加检查。
2. 根据细胞与空白区的亮度、纹理和边界选择方法。预处理、阈值、形态学操作及 ROI 都要记录依据；避免填洞或平滑抹去残余间隙。不得默认所有图适用同一亮度阈值，也不在简单方法可用时无依据地下载模型或训练模型。
3. 将 mask 和边界叠加到原图，核对细胞层内部空隙、碎屑、脱落细胞、阴影及视野边缘。检查面积是否处于有效区域范围内；全空或全满 mask 均须复核，不能自动认定完全闭合或全部是划痕。
4. 代表图通过后，在条件可比的批次内固定处理规则，批量运行同一实现。自动逐图估计参数可以使用，但估计规则必须预先固定和记录。不能为了预期差异逐图调参；必要的人工 ROI 修正应保留原始与修正版本及理由。
5. 每张图生成质控叠加和处理状态，浏览批量缩略图，重点复核异常和极端面积。无法确定边界的图标为需复核；不能一边猜测，一边交付确定的生物学结论。

## 配对与计算

- 像素面积为划痕 mask 内像素数；物理面积为像素数 × 横向像素尺寸 × 纵向像素尺寸，单位写为 μm² 等实际标定单位。
- 面积占比为划痕面积 / 有效分析区域面积 × 100%；输出有效区域面积及其定义，不能将面积占比称为闭合率。
- 对同一培养孔、同一可比较视野和一致分析区域，闭合率为 `(A0 − At) / A0 × 100%`，其中 `A0` 是有依据的初始时间点面积。时间点单位明确，不强行把最早文件解释为 0 h。
- 前后视野不一致、裁剪不同或标定不同且无法建立可比区域时，仍可报告各自面积，但不直接计算配对闭合率。配准或共同 ROI 必须有图像证据，记录变换和裁剪；不得通过改变 ROI 制造闭合。
- `A0 = 0` 时闭合率无定义；基线缺失或失败时闭合率为空并写原因，不能填零。`At = 0` 仅在核验后认定闭合；负闭合率应保留并检查划痕扩大、细胞脱落或测量问题，不截断为零。
- 多个视野是孔内观测，多个时间点是重复测量；组间推断需明确独立实验单位和汇总规则，不把视野数当生物学重复数。缺少重复信息时报告描述性结果，不强行做显著性检验。

划痕闭合可能同时受迁移、增殖、细胞死亡和脱落影响，不能仅凭面积下降断言迁移机制或因果关系。保留阴性、矛盾及不确定结果。

## 防止长时间失败循环

环境与依赖集中检查一次。记录环境准备、试跑、批处理和导出的各阶段耗时；用试跑速度和图片数量估计后续耗时，不承诺固定的“几十张几分钟”。长任务报告已完成数量、当前阶段与具体阻塞，不只说“正在处理”。

每次失败记录命令、退出码、错误摘要和受影响输入，先判断是环境、格式、内存还是分割质量问题。同一根因只做一次有依据的修复；修复后仍复现就停止原路径。仅在存在适用且已验证的替代路径时切换一次，并记录方法变化；替代路径仍失败则停止并交付诊断。不重复安装同一依赖，不用原命令无限重试，不因分割难看就重装环境。

执行前依据试跑设定单文件及批次超时；有持续进展的长任务和无进展的卡死分别处理。终止仅针对本次启动的进程，保留已完成结果。单个坏文件可以隔离后继续其余文件；普遍环境错误或代表图分割不适用时停止整批。批量部分失败必须在总状态中体现，不能返回全成功。

恢复运行前核对输入摘要、实现版本和参数；三者一致才复用已完成结果，否则新建运行目录。禁止覆盖原图或静默覆盖旧结果。

## 可检查的交付

结果保存在用户分析目录，科研原图、缓存和分析结果不写入插件仓库。每次交付：

- 文件清单与逐图结果 CSV：唯一图像/帧 ID、来源文件、孔/视野/时间点（未知留空）、有效区域面积、划痕像素面积、物理面积及单位（未标定留空）、面积占比、方法、参数引用和质控状态。
- 配对成立时另交配对表与闭合率，包含基线 ID、当前图 ID、`A0`、`At`、时间及单位、计算状态与无效原因，保证能追溯到逐图表。
- 每图 mask、ROI 或轮廓，以及带图像 ID 的原图叠加；明确 mask 编码及坐标系。另存绘图标注，不将标注后的图片重新输入测量。
- 运行记录：输入摘要、软件及脚本版本、实际命令、参数与选择依据、标定来源、开始结束时间、阶段耗时、成功/需复核/失败数量及异常清单。失败数值为空，真实零值保留。
- 有真实数据且适合汇总时，交付面积或闭合率图、作图数据与图注。正式图默认同时提供可编辑 PDF、SVG 和高清 PNG；底层显微照片保留原始栅格属性，不能声称照片变成了矢量图。检查单位、字体、布局、独立重复数和误差区间含义，默认关闭背景网格。

最终用普通语言说明测了多少、哪些通过核验、哪些仍需复核、是否具备闭合率与组间比较条件。若仅完成方案、代码编写或部分执行，明确该状态，不能以生成文件数量代替分析成功。
