# Cell Painting细胞形态特征提取（nf-core/cellpainting）

## 识别数据与研究目标

从交付文件与报告中识别高内涵显微图像、plate/well/site/channel 映射、CellProfiler 配置和处理条件，核对通道与成像批次。

## 方法选择

按 cellprofiler_mode 区分 assay_development 的照明/单视野 QC 与 analysis 的完整特征提取及 CytoTable 转换。

先核对 [版本约定](references/流程约定.json)。

| 核对项 | 固定范围 |
|---|---|
| 上游版本 | `dev`；`6849844d1f7c841578a89caa5101d9537e7fa023` |
| 上游维护 | 开发版本；按当前代码实际实现的范围使用 |
| 本地运行 | 未进行真实分析运行；不能据本 Skill 文件声称实跑通过 |
| 引擎声明 | `!>=25.10.4`；还需核验 Java、容器和 profile |

## 根据数据确定参数

从通道、照明、细胞大小和板布局选择校正及分割设置，先在代表性视野检查边界；以独立孔或实验单位比较特征，不能用细胞数夸大生物重复。

| 决策与配置 | 处理要求 |
|---|---|
| 事实与缺口 | 先读现有文件和报告；不能据文件名猜实验类型、参考或样本关系；只补问无法核实且会改变分析的背景 |
| 参数来源 | 区分协议必需设置、数据估计、方法默认和研究选择；说明实际取值及理由，不要求用户填写专业参数 |
| 可执行配置 | 仅把已支持的选择映射为当前版本的原生字段；不支持的步骤另行交接，不虚构开关 |
| 阈值复核 | 默认值先评估适用性；依据质控、对照及敏感性检查调整，不能按显著结果数量调参 |

## 质控与解释

检查照明校正、分割、图像失焦、边缘效应及 plate 批次，抽查对象和形态特征。

比较处理条件时，以独立孔或实际实验单位组织重复，不能把同一孔内的大量细胞当作独立生物学重复。保留空白、阴性与阳性对照的空间分布，识别板边和加样顺序造成的系统偏差。展示异常特征时回到对应原始视野核验，区分细胞数量变化与单细胞形态变化。

交付实际模式的 QC、形态特征及 Parquet 等产物；开发模式不承诺全量特征表，形态相似不直接证明相同药物机制。
