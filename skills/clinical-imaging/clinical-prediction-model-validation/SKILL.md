# 临床预测模型验证

先写清预测对象、预测时点、结局时间窗和模型实际输入。预测时点之后才产生的信息属于泄漏，即使它在数据表中很方便。

## 验证层次

1. 在与开发流程隔离的数据上重现特征处理和预测。
2. 按结局类型评价区分度，同时给出校准截距、斜率和校准图。
3. 在预定阈值上报告敏感度、特异度、预测值或临床决策曲线。
4. 分中心、时间、人群和关键亚组检查可迁移性；必要时区分重新校准与重新训练。

处理删失、竞争风险和缺失时应与目标用途一致。交付验证队列流转、指标及区间、错误案例、校准和净获益。外部 AUC 尚可但校准失败时，不能宣称模型已可直接部署。
