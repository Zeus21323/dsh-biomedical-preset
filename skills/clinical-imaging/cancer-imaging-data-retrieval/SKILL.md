# 癌症影像公共数据检索

把研究需求转成癌种、影像模态、解剖部位、患者/检查数量、分割或临床注释、文件格式和使用许可等条件。优先在 NCI Imaging Data Commons（IDC）等提供稳定标识和队列元数据的资源中检索，先筛 collection 与 cohort，再展开到 patient、study 和 series。

同一患者可能有多个检查、重建和派生对象；统计时分别报告患者数、study 数和 series 数，不能把序列数当作独立样本量。需要标注时，核对 DICOM SEG、RTSTRUCT 或其他派生对象与原影像的引用关系，并确认标注适用的时间点和序列。

下载前保存数据源、稳定标识、完整查询条件和访问日期，估算文件量并检查许可、受控访问及再分发限制。交付候选队列、纳排理由、患者与序列清单、标注覆盖、重复检查处理规则和数据缺口；公共可下载不等于可以忽略其使用条款。
