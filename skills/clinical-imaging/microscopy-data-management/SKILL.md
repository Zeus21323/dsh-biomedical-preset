# 显微影像数据管理

先确定影像层级、用户权限、元数据规范和操作是读取、导入、注释、共享还是导出。使用 OMERO 等影像管理平台时，写操作前列出服务器、project/dataset、对象 ID 和预期变化，避免按模糊名称批量修改。

导入时保留原始文件之间的关系，以及通道、时间、z、像素尺寸和采集条件；大图或金字塔格式需先确认服务端支持。ROI、表格和标签使用稳定对象 ID 关联，受控词表与自由文本分开，并记录标注者、版本和坐标系。

批量任务先在一个测试对象上验证创建、链接、权限和重复执行行为。中途失败时保存已完成 ID 和失败原因，不直接全量重跑造成重复导入。交付对象清单、层级关系、元数据/注释 schema、权限设置、成功与失败项；导出时分别说明原始像素、渲染图、ROI 和元数据是否齐全。
