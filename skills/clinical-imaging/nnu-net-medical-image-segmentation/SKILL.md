# nnU-Net医学影像分割

输入需要配对影像与标签、明确标签值、模态顺序和患者级 ID。先检查方向、spacing、尺寸、空标签和影像—标签对齐，再建立 nnU-Net 数据集说明。

让 nnU-Net 规划决定常规重采样和网络配置；只有在数据或任务有明确理由时覆盖。fold 必须按患者划分，多时间点或双侧器官不能跨训练与验证。训练后比较 folds，并在独立测试集运行推理。

评价 Dice 之外的 Hausdorff/表面距离、病灶召回和体积误差，按器官大小、设备和中心分层。失败病例要查看原图与 mask，而不是只平均指标。

交付数据集配置、训练计划、模型 checkpoint、测试指标、推理结果和失败案例。此 Skill 用于 nnU-Net 分割；自定义分类/检测模型应走一般影像模型开发流程。
