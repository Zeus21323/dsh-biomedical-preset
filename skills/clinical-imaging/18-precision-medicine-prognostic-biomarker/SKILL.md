# 多组学生物标志物发现

首先定义标志物用途、样本取得时间和验证终点。诊断、预后与治疗反应标志物不能共用模糊标签。

按患者而非测量值划分发现、调参与验证数据。各组学先独立完成质量控制和批次检查，再按样本 ID 与采样时间对齐；缺少某个组学的样本不能被静默删除。所有归一化、特征筛选和超参数选择只能在训练折内完成。

从简单单组学基线开始，再评价多组学融合是否带来稳定增益。检查特征选择频率、相关特征替代、平台批次、类别不平衡和外部队列可测性。

交付候选特征、测量方法、效应与模型性能、选择稳定性和独立验证结果。没有技术与外部验证的候选应称为探索性发现。
