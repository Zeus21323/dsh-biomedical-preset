# 神经影像与电生理分析

先区分模态、任务设计、采样频率、事件标记、受试者重复和目标推断。BIDS 负责数据组织，但不会自动完成 fMRI 或 EEG 的信号处理；本 Skill 承接实际分析，原始目录整理仍由 BIDS Skill 负责。

fMRI 需要检查头动、畸变、配准、平滑、时序和混杂回归，再设计一级和组水平模型。EEG/电生理需要检查参考、滤波、工频、坏道、伪迹、事件同步和试次数，再选择 ERP、频谱、时频、连接性或尖峰分析。滤波和去伪迹参数必须与目标频段和事件时长相容。

需要选择预处理和统计路线时读取[模态流程与质控](references/模态流程与质控.md)。交付逐受试者质控、排除规则、预处理记录、一级效应、组水平效应、多重比较和可复现参数。

大量时间点、体素、电极或试次不等于大量独立受试者。最终统计必须尊重受试者和实验设计层级，避免把技术重复当作生物重复。
