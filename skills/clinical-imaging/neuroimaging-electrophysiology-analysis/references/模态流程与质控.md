# 模态流程与质控

## fMRI

- 核实任务事件、TR、切片时序和场图或反向相位编码；
- 报告 framewise displacement、离群体积和剔除规则；
- 配准必须通过叠加图人工检查；
- 混杂回归、滤波和平滑顺序应固定并记录；
- 一级模型保留对比和方差，组水平以受试者为单位；
- 全脑推断说明多重比较和搜索空间。

## EEG 与电生理

- 记录采样率、参考电极、硬件滤波和事件时钟；
- 滤波截止、阶数和相位特性不能省略；
- 坏道、眼动、肌电和工频处理保留前后证据；
- ERP 报告基线和有效试次数；
- 频谱与时频分析报告窗长、步长和归一化；
- 连接性分析检查体积传导或共同参考影响。

跨模态联合分析前，先完成各模态独立质控和受试者对齐。
