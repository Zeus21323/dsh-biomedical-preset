# 细胞衰老与SASP证据分析

## 先排除相似状态

需要细胞或组织背景、诱导方式、时间点、增殖、损伤、溶酶体、形态、转录/蛋白与分泌数据，以及阳阴性和干预对照。先区分静止、终末分化、凋亡、一般应激和炎症，不能从单个 marker 开始定论。

## 建立证据矩阵

1. **持续生长停滞**：EdU/Ki-67、细胞周期恢复和撤除刺激后的可逆性。
2. **损伤与结构改变**：DNA损伤灶、Lamin B1、细胞/核形态等，注明是否为该模型预期。
3. **溶酶体与常用标志**：SA-β-gal、p16、p21 等分别记录；任何一项都不是通用必要充分条件。
4. **SASP**：同时查看多个分泌因子和蛋白证据，并排查免疫浸润或急性炎症。
5. **因果干预**：清除、抑制或逆转实验是否改变目标表型；仅有相关数据时降低结论等级。

bulk 或组织样本要估计细胞组成，单细胞分析则检查目标群是否有足够供体和正交信号。不同诱导类型可具有不同 SASP 和标志组合。

## 结论分级与交付

分别给出“存在衰老相关标志”“多证据支持细胞衰老”“干预支持其驱动表型”三个等级，列出反证、替代解释和最小补充实验。SASP 高或 p16 高不能单独证明衰老细胞增加。
