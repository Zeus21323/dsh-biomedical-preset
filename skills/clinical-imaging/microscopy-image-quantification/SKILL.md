# 生物显微图像处理与定量

划痕实验的空白面积、时间点配对与闭合率任务，转入同插件的[细胞划痕面积与闭合率分析](../细胞划痕面积与闭合率分析/SKILL.md)，不在此重复建立流程。

确认像素尺寸、通道、位深、曝光、z/time 结构和独立实验单位。处理原始强度图时避免保存覆盖原件，并记录任何背景扣除、平场和反卷积。

用阴性/阳性视野确定阈值或分割规则，再冻结参数批量运行。强度比较需排除饱和并保持曝光可比；对象形态统计要说明边界对象、粘连和小碎片处理。

随机抽取每个批次、条件和质量极端视野进行 mask 叠加检查。CellProfiler/ImageJ 导出还需核对图像—对象关系、单位和对象 ID。

交付每图像/对象结果、参数、质控叠加和组间汇总。统计比较以独立培养、动物或患者为单位，不以视野和细胞数制造伪重复。
