# FHIR与EHR数据互操作

先确认目标 FHIR 版本、实施指南、服务端能力声明、认证方式、允许用途和数据最小化范围。FHIR 是交换结构，不会自动解决源 EHR 的字段质量、患者身份、术语不一致和临床时间语义。

从真实用例反推资源：患者、就诊、观察、诊断、用药、标本和基因组报告应使用各自资源及引用关系。编码优先使用实施指南要求的术语，并同时保留源代码。搜索、分页、版本和删除语义必须按服务端 CapabilityStatement 执行，不能假设所有服务器支持相同参数。

需要设计资源映射、检索和验证时读取[资源映射与安全边界](references/资源映射与安全边界.md)。交付用例、资源关系、字段映射、术语表、示例请求、校验结果和无法互操作的字段。

不得把真实患者数据放入示例、日志或测试。访问生产 EHR、写入资源或扩大查询范围都需要独立授权。
