# 三维医学影像配准与重采样

明确 fixed、moving、目标坐标系和配准目的是同一患者多模态、纵向随访还是群体模板。先检查 origin、spacing、direction 和物理覆盖，不能只比较数组尺寸。

由任务选择刚体、仿射或形变模型，设置适合模态的相似性度量和多分辨率策略。保存变换方向；将 moving 重采样到 fixed 时不要误用逆变换。

连续强度影像可用线性/B 样条插值，标签、mask 和离散概率不得使用会产生新类别的插值。用叠加图、解剖标志点、Jacobian 和目标配准误差检查结果，防止形变折叠。

交付变换、重采样影像、参数、定量/可视化 QC 和失败样本。配准失败时停止下游特征提取，而不是用强形变掩盖不一致。
