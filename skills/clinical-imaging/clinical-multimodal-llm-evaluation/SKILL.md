# 临床多模态LLM评估

先固定任务、输入模态、目标用户和允许模型回答的范围。报告生成、视觉问答和病例推理使用不同评价集，训练资料中出现的病例不能进入测试。

自动文本相似指标只作辅助。临床评价应覆盖病灶存在与位置、大小/变化、否定信息、遗漏、无图依据的幻觉、建议是否越界和不确定性表达。由合格评审者盲评，并记录分歧与裁决。

测试集应包含正常、罕见、低质量、设备变化、矛盾文本和域外输入。比较没有图像的文本基线，判断模型是否真正使用视觉信息。

交付逐项错误分类、严重度、患者/检查级指标、亚组结果和典型失败。模型生成内容在验证和治理完成前不能直接进入临床记录或面向患者。
