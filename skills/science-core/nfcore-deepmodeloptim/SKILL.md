# 生物训练数据增强与模型评估（nf-core/deepmodeloptim）

## 识别数据与研究目标

从交付文件与报告中识别任务数据、数据配置、模型接口、初始权重和预处理配置，确认训练/验证/测试划分及优化目标。

## 方法选择

按固定版本的拆分、输入变换、模型检查、调参和评估路径优化训练数据；所有增强和选择仅使用允许的训练信息。

先核对 [版本约定](references/流程约定.json)。

| 核对项 | 固定范围 |
|---|---|
| 上游版本 | `dev`；`ee174c24395fb1f96f047844b49e4f00469857c6` |
| 上游维护 | 开发版本；按当前代码实际实现的范围使用 |
| 本地运行 | 未进行真实分析运行；不能据本 Skill 文件声称实跑通过 |
| 引擎声明 | `!>=24.04.2`；还需核验 Java、容器和 profile |

## 根据数据确定参数

按患者、样本来源或实验批次划分训练与评估集，依任务损失和算力确定搜索空间；增强强度只在训练折中选择，测试集不能用于挑参数。

| 决策与配置 | 处理要求 |
|---|---|
| 事实与缺口 | 先读现有文件和报告；不能据文件名猜实验类型、参考或样本关系；只补问无法核实且会改变分析的背景 |
| 参数来源 | 区分协议必需设置、数据估计、方法默认和研究选择；说明实际取值及理由，不要求用户填写专业参数 |
| 可执行配置 | 仅把已支持的选择映射为当前版本的原生字段；不支持的步骤另行交接，不虚构开关 |
| 阈值复核 | 默认值先评估适用性；依据质控、对照及敏感性检查调整，不能按显著结果数量调参 |

| 资料 | 使用时机 |
|---|---|
| [参数模式.json](references/参数模式.json) | 编写 params.json 时核对字段、类型、枚举及条件约束 |

仅在已授权且配置齐备时运行。

```bash
nextflow run nf-core/deepmodeloptim -r ee174c24395fb1f96f047844b49e4f00469857c6 -params-file params.json
```

模式文件的许可见 [LICENSE](LICENSE)。

## 质控与解释

检查数据变换是否保留标签语义、测试集泄漏、随机波动和模型适配，比较增强前后在独立测试上的表现。

交付数据变换、训练/评价配置及结果；增强提高特定基准表现不代表对所有生物任务有效，也不承诺自动训练基础模型。
