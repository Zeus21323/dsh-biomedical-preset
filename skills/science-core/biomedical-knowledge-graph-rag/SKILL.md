# 生物医学知识图谱与RAG

## 先确定知识边界

列出允许进入系统的资料、更新时间、实体类型和关系方向。例如“药物—靶点”与“靶点—药物”可以互查，但证据和语义不能混成一个无方向关系。基因、疾病、药物优先保存稳定标识和同义词，不能只依赖显示名称。

## 构建与检索

1. 对文档保留标题、版本、章节或记录 ID，分块不能切断表格行、定义或证据上下文。
2. 对实体做物种、基因组版本和数据库命名消歧；关系同时记录证据出处和证据类型。
3. 先用关键词/过滤条件缩小范围，再做向量召回和重排；需要精确字段时直接查询结构化数据。
4. 回答时把原文事实、跨证据综合和模型推断分开，并让每个关键判断能定位到记录或段落。

## 评估

准备同义词、否定描述、冲突证据和“资料中没有答案”的问题。分别检查召回、实体链接、引用正确性和拒答，不能只评价文字是否流畅。
