# 分析参考资源构建（nf-core/references）

## 识别数据与研究目标

从任务与样本背景判断目标物种、组装与注释发布版、所需索引类型和原始资源位置；核对资源许可、体积及使用的软件版本。

## 方法选择

选择此版本实际提供的参考构建路径，将 FASTA、注释和索引生成过程绑定；不同用途的参考集合分别命名，避免被同名缓存覆盖。

先核对 [版本约定](references/流程约定.json)。

| 核对项 | 固定范围 |
|---|---|
| 上游版本 | `0.1`；`3ab25b0cdadc6a5440405ef20118e09e5f82dfa4` |
| 上游维护 | 未归档；使用这里固定的源码，不自动跟随新版本 |
| 本地运行 | 未进行真实分析运行；不能据本 Skill 文件声称实跑通过 |
| 引擎声明 | `!>=24.10.1`；还需核验 Java、容器和 profile |

## 根据数据确定参数

从物种、测序读长、目标比对器和参考组装确定资源组合与索引配置；注释和序列必须匹配，不能以索引已存在作为正确性的依据。

| 决策与配置 | 处理要求 |
|---|---|
| 事实与缺口 | 先读现有文件和报告；不能据文件名猜实验类型、参考或样本关系；只补问无法核实且会改变分析的背景 |
| 参数来源 | 区分协议必需设置、数据估计、方法默认和研究选择；说明实际取值及理由，不要求用户填写专业参数 |
| 可执行配置 | 仅把已支持的选择映射为当前版本的原生字段；不支持的步骤另行交接，不虚构开关 |
| 阈值复核 | 默认值先评估适用性；依据质控、对照及敏感性检查调整，不能按显著结果数量调参 |

| 资料 | 使用时机 |
|---|---|
| [参数模式.json](references/参数模式.json) | 编写 params.json 时核对字段、类型、枚举及条件约束 |
| [输入模式-1.json](references/输入模式-1.json) | 准备 input 对应的样本表或输入文件时读取 |

仅在已授权且配置齐备时运行。

```bash
nextflow run nf-core/references -r 3ab25b0cdadc6a5440405ef20118e09e5f82dfa4 -params-file params.json
```

模式文件的许可见 [LICENSE](LICENSE)。

## 质控与解释

检查 contig 命名、序列和注释对应关系、索引完整性与构建工具版本；不能用文件存在代替索引可读性检查。

输出参考文件、索引、来源和构建说明；资源构建成功不代表它适合所有建库技术或变异调用模式。
