# 配色、无网格与多面板
默认白底，关闭背景major/minor网格。保留有科学含义的零线、比值1线、阈值、参考对角线、区间、比例尺和网络边。不能删除所有线对象。
类别用稳定离散色；顺序/连续用感知有序色阶；有中心的双向量用发散色阶；周期用循环色阶；缺失和真实零区分。互补或对称只是候选，检查数据语义、明度、背景、灰度/色觉区分，必要时辅以符号。双变量配色需二维图例。
共享色条须同单位、变换、范围和中心；同对象跨图颜色和次序固定，不同指标不强求共享轴。实际物理尺寸由内容和期刊决定，类别数/留白比例不是万能阈值。

## 用户参考配色的统一应用

以用户2026-09-23提供的截图为风格参考，使用本Skill的 `assets/scientific_palettes.tsv`。这是候选色板，不是期刊规定，也未认证对所有色觉条件可辨。只采用明确可读的HEX；被遮挡或色块与文字冲突者不猜测。蓝白粉的白色中心和中性色为本地语义设计；组合/插值不是对原文献色图的复刻。

| 色板 | 用途与默认选择 |
|---|---|
| categorical_clear | 2–5类的分组图与热图注释：青、朱红、深蓝、杏、灰蓝 |
| categorical_soft | 两组的大面积填充：蓝绿、粉色；小散点和细线不用作默认 |
| categorical_strong | 两组的细线或小散点：深青、赭橙；用点形或线型增加可辨性 |
| blue_white_pink | 有真实中心的双向数据；低值蓝、高值粉，中心白，必须保留单位与范围 |
| blue_sequential | 单向连续量，浅蓝至深青；不能用于无序类别 |
| schematic_soft | 示意图区域/实体填充：浅蓝、蓝、粉、浅黄、紫；不直接当统计色阶 |
| neutral | 依次为文字、背景、其他类别、缺失值、未显著候选色；后三者必须通过标签/图例区分 |

默认白底深灰文字。机制图浅色可作为区域填充，但文字、箭头与边界需可辨；借用配色不等于照搬原图布局、结论或装饰。统计图不自动增加渐变阴影或三维效果。

## 项目颜色映射优先于单图自动选择

开始一组图时，智能体读取完整元数据，按科学语义确定变量与全部类别，创建用户分析目录中的 `project_colors.tsv`，包含 `variable/category/color` 三列。同一变量各类别使用唯一六位HEX。同一类别在PCA、箱线图、热图注释等跨图固定；不按当前出现顺序重新选色。不同变量可以使用同色，但图例必须明确变量。

已有项目映射优先使用，不因更换图形而换色；显式局部颜色与项目映射冲突则停止。新增类别时保留旧映射，审阅后扩展为新版本，记录来源，不覆盖旧文件。类别超过候选色板容量时不循环复用，不为配色擅自合并生物学类别；按目标选择扩展可辨色或分面。

没有项目映射的单图可按上表自动选候选，但运行记录必须标记figure_only，不能宣称跨图一致。后续组成多图时先建立完整项目映射，不把只有局部类别的导出表误当全项目映射。

## R/Python使用同一来源

Python入口通过 `scripts/scientific_colors.py` 读取色板；配置 `palette` 选择分类候选，`continuous_palette`选择对应连续候选，`color_registry`指向上述项目TSV（相对配置文件解析）。通用绘图器用 `color_variable` 指定变量，默认取group配置指定的列名；表达热图按annotations各字段匹配变量。项目映射须覆盖实际类别，允许包含当前未显示的类别。保持旧颜色时必须提供项目映射。

显式 `colors` / `annotation_colors` 仍可使用，接受六位HEX；允许全项目类别的超集但不能缺失实际类别或重复颜色。两种Python入口导出 `resolved_colors.tsv`、项目映射原件（若提供）、色板和映射指纹及最终连续色板名。

R在原分析脚本中source `scripts/scientific_colors.R`，使用相同TSV，不转到Python：

```r
# skill_dir与analysis_dir由已核实的安装路径和分析目录提供。
source(file.path(skill_dir, "scripts", "scientific_colors.R"))
group_colors <- figure_colors(file.path(analysis_dir, "project_colors.tsv"),
                             "group", unique(as.character(sample_metadata$group)))
# ggplot2中把group_colors作为命名values传给手动color/fill标度；
# pheatmap/ComplexHeatmap中将其作为对应分组变量的命名颜色映射。
heatmap_stops <- figure_palette(file.path(skill_dir, "assets", "scientific_palettes.tsv"),
                              "blue_white_pink", "diverging")
# 根据真实上下限与零点构造连续映射，不将三个颜色离散分配给连续数值。
```

R适配文件只读取/校验并返回颜色，不渲染、不覆盖文件。原R流程须把实际使用映射、范围、透明度和依赖版本写入其运行记录，并实际渲染验收。未运行R时必须说明未验证，Python通过不能替代。

## 颜色验收

按最终物理尺寸检查小点、细线、填充、文字和图例。浅填充配足够清晰的轮廓；散点/线图用形状、线型或直接标注辅助，不只靠颜色。检查透明度叠加、相邻类别、灰度和适用的色觉模拟；未做色觉模拟不得宣称色盲友好。色板可读不证明统计解释正确。

连续色阶检查数值方向、中心、范围、单位和明度变化；同指标跨面板用统一映射；共享色阶不同数据范围不能偷偷归一化。缺失不填零、不同含义不共用含糊图例。保存色板只是风格来源，出图后的可辨性验收仍必需。
