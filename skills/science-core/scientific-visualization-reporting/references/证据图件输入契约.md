# 证据图件：实际数据到可编辑交付

## 运行与输入

Python 3.12+、NumPy、Matplotlib；在隔离环境准备依赖。输入为真实结果CSV或TSV，每行含明确的比较/实体/样本身份，列名唯一，无静默丢弃和聚合。脚本只绘图，不执行差异检验、重采样、显著性星号或机制判断。

从本Skill目录运行：

```bash
python scripts/render_evidence_figure.py --config figure.json --out-dir figures/figure1
```

由代理填写配置，用户无需了解字段。相对table路径从配置文件目录解析，输出必须为新目录。示例用于说明契约，不包含实际结果：

```json
{
  "table": "effect_estimates.tsv",
  "kind": "point",
  "x": "comparison",
  "y": "estimate",
  "lower": "lower",
  "upper": "upper",
  "interval_method": "根据本次实际分析填写区间水平、算法与独立重采样单位",
  "title": "Estimated effects",
  "show_title": true,
  "xlabel": "Comparison",
  "ylabel": "Effect estimate",
  "question": "这些对比的效应方向和不确定性如何？",
  "caption": "根据实际样本数、模型、协变量、多重检验和限制撰写完整图注。",
  "unit": "独立供体；各对比样本数见关联的结果表",
  "source": "分析运行记录及结果表中的比较标识",
  "selection": "展示所有预先定义的主要对比",
  "evidence_level": "association",
  "width_mm": 180,
  "height_mm": 110,
  "dpi": 400,
  "font": "DejaVu Sans"
}
```

没有经过计算的区间就省略lower/upper/interval_method，明确是描述性点估计。`evidence_level` 为 descriptive/association/prediction/experimental，后者只是图注分类而非脚本认证。`title` 对正式图件不是必填；论文级默认 `show_title: false`，只有显式 `show_title: true` 才将标题放入面板。空数据、非有限值、重复热图坐标、缺列及区间倒置均停止。

## 图形选择与额外字段

- point：x是比较名，y是已计算估计；可加lower、upper列，必须说明区间方法；每行一个比较，不自动分组拟合。
- heatmap：x、y是两个类别轴，value是数值列；signed=true使用以零对称的色标。表达热图转到[专用输入契约](论文级表达热图规范.md)，本入口拒绝row_scale、gene_label及聚类字段，避免接受后忽略；通用热图不要求基因注释或行标准化。sample_order可指定完整且唯一的列顺序；默认不显示标题。未提供单元格需显式allow_missing=true，以灰色显示，不填零。重复单元格先明确统计聚合方式，不让绘图器猜测。
- scatter：x、y为数值，可用group列区分不超过8组。空间坐标需equal_aspect=true；保持单位和坐标方向，不能只靠散点替代必要的组织底图/比例尺。
- line：x、y为数值，按每组真实横坐标排序；同组不能有重复x。拟时间、序列位置与实际时间分别标注。
- 可加reference_line数值；width_mm/height_mm设实际版面尺寸。中文标签须指定已安装且覆盖字符的字体；缺字时停止，不交付方框文字。

## 输出与共用规则

输出figure.pdf/svg/png、原表副本、figure_manifest.json、caption.md与resolved_colors.tsv。source/selection/unit/caption来自实际分析记录，evidence_level只是声明，不是统计或因果认证。该适配器不自动核实自由文本图注，按[通用验收](有效性与布局验收.md)核对。

导出按[统一交付](三格式导出与交付.md)。配色按[共享配色规范](配色无网格与多面板规范.md)：palette指定分类候选，continuous_palette指定连续候选；color_registry指定项目TSV，color_variable指定变量（默认group列名），colors须与项目映射一致。记录颜色来源指纹；无项目映射只保证单图。
