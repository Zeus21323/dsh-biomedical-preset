# 科研证据评估

先把待判断的主张写成一句可检验的话，再确定需要哪类证据支持它。疾病相关、预测能力、治疗效果和作用机制不能用同一套证据替代。

## 逐项判断

1. 研究对象和比较是否真正对应主张，样本如何进入研究？
2. 暴露、干预和结局如何测量，评价者是否知道分组？
3. 是否存在未处理的混杂、选择、缺失、多重检验或数据泄漏？
4. 报告的是效应大小与不确定性，还是只强调显著性？
5. 结果是否在独立样本、不同实验体系或正交方法中复现？

把支持、冲突和缺失证据放在同一张证据表中，注明研究设计、适用人群和主要偏倚。结论使用“支持到什么程度”的语言；期刊名、数据库收录或单个 P 值都不能充当质量评级。
