# 负对照与假阳性校准（NullOmics方向）

## 触发与选择

“随机分组也显著”“结果太漂亮是真的吗”“审稿人要负对照”且有独立单位数值时进入。毕业愿望、阴性结果不是改阈值或随机种子的理由。区分标签对照、生物阴性、技术空白、随机特征和模型输入不变性；当前计算是标签置换均值差。

## 输入与执行

python scripts/run_null_controls.py --config /外部目录/null.json --out-dir /外部目录/null-001

配置：table，groups=[对照,病例]，design，permutations（99–100000），seed（0–2^32−1），可选alpha默认0.05。表列unit,group,feature,value；unit是独立供体/样本，不是细胞；unit×feature唯一，矩阵完整。不隐式删缺失或补零。

- independent：保持组数，在全部独立单位置换。
- blocked：另有block列，每块同时含两组，只在块内交换。统计量仍为总体两组均值差，不调整协变量，不能替代复杂分层模型。
- paired：每block恰好两个不同unit、一位对照一位病例；统计量配对差均值，对内交换标签。

可选known_null_features须为唯一预先确定特征列表，配known_null_reason外部依据；不能按最终p值选阴性集合。没有可信零假设集合就不估计假阳性比例。

## 校准与限制

双侧绝对均值差，以(至少同样极端的置换次数+1)/(B+1)计算Monte Carlo p，BH覆盖全部预设特征。B限制p精度，正式多重检验需据目标调整，99次不是通用标准。BH须满足适用依赖条件；自适应选择、重要混杂、重复纵向等应另选验证过的模型。

permutation_results.tsv保留效应/p/q；null_max_abs_effect.tsv保留最大绝对效应分布。不同量纲时最大值图不能统一比较生物效应。已知零特征原始p拒绝比例不是FDR，也不保证跨数据校准。

模型问题转“机器学习训练与评估”，每次置换内部重做筛选、预处理、训练和调参。本脚本不证明模型无泄漏；表达/长度匹配随机基因集未实现，不能冒称完成。
方法依据：[SciPy permutation_test](https://docs.scipy.org/doc/scipy/reference/generated/scipy.stats.permutation_test.html)。不是已建成的NullOmics跨组学数据库。

## 代理负责准备、执行和复核

用户不需要写JSON或命令。先读取文件与元数据，确认问题、独立统计单位、对比和出处；只用普通话补问确实无法核实且改变设计的事实。只有疾病/基因/毕业愿望时先回公共研究设计；缺输入交付缺口清单，不用模拟数据冒充结果。

代理在用户指定的仓库外目录创建配置。所有配置必填question（实际问题）、parameter_reason（参数与设计依据）、evidence_notes（来源、已核验事实与不确定性）；可选font为覆盖图中文字的已安装字体。参数不得由显著性倒推。路径相对配置文件解析。CSV/TSV为UTF-8、唯一表头，TSV以.tsv结尾；保留原始数据，不自行覆盖。每次指定新输出目录。

Python 3.11+，依赖numpy、pandas、scipy、matplotlib。代理在隔离环境准备并记录版本，不要求新手安装。各适配器自包含，无跨Skill脚本依赖，不需要根目录packages。输入1GB保护上限不等于内存保证；失败非零退出，已有输出目录则留下失败记录，不把残留产物视作成功。

交付完整TSV、summary.json、run_record.json、report.md、可编辑PDF/SVG、400 dpi PNG和图注。作图数据来自对应完整结果表；图的截取规则必须说明。配置、输入/输出哈希、版本和状态均留痕。脚本摘要不等于科学论文：代理需据真实数字补写观察、样本量、效应/区间、阴性/冲突、替代解释、证据等级和下一步，关联具体表行和图件。描述性模式不能声称显著。

打开PNG或渲染PDF，按最终版面检查缺字、截断、图例、颜色、单位、比例、方向和区间；重要发现回查输入。分辨率不是论文质量保证。原始记录保持“需视觉与科学复核”状态；复核可另存review.md，不篡改运行记录。结果、缓存、测试数据和日志只放仓库外。本地适配器不代表后台数据库或未实现的论文方法已完成。
