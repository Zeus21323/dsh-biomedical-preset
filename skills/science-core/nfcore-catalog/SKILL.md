# 从交付数据选择分析流程

## 接住不清楚数据的请求

接受“这是公司发给我的文件，样本是肿瘤组织，帮我看看能做什么”这类起点。先检查用户已提供或已授权访问的文件与报告，不要求用户先说出实验缩写、流程名称、参考版本或技术阈值。知道样本来自哪里不等于知道测了什么；肿瘤、血液、粪便均可能对应不同实验。

数据不明时先读 [数据识别与分析决策](references/数据识别与分析决策.md)。用 [交付目录初查](scripts/inspect_delivery.py) 读取目录与有限文件头，取得文件格式和下一步检查线索：

```bash
python scripts/inspect_delivery.py --path '用户提供的交付目录' --max-files 200
```

脚本只读且不联网，不解包、不执行交付文件，输出不包含测序序列或表格数据行。它辨识容器和文件格式，不能独立确认测序实验、物种、分组、数据质量合格或分析可行性。目录截断、格式未知与读取错误都必须继续处理。按需要使用实际可用的格式工具读取元数据；不要把有限抽样说成完整校验。

## 从证据形成研究起点

核对交付说明、建库报告、样本表、原始文件和已有结果，区分观察事实、支持的推断与尚未确认的信息。识别已经完成的处理，能复用计数或有效结果时从相应阶段继续。

用户还没有具体问题时，结合数据和样本背景解释可回答的问题与限制，给出有依据的分析方向。检查数据、基础质控和整理可先推进；会改变科学比较的分组、配对、结局或实验单位若无法从材料确认，用日常语言补问。不要用文件名猜病例对照，更不能代用户发明研究假设、样本重复或期望结论。

例如“这些是同一个人的治疗前后，还是不同人的样本？”比要求填写设计矩阵更合适。链方向、截断长度、细胞质控阈值等技术判断由系统依据证据承担。

## 匹配实际可用的方法

在数据类型、处理阶段和目标足以约束候选后，使用 [目录查询](scripts/catalog.py) 检索 [流程目录](references/流程目录.json)。目录查询是关键词检索，不是自动判别实验类型或证明方法适配的算法。宽泛文件名或一句未知数据描述搜不到时，先完成数据理解，不直接运行排名第一的候选。

```bash
python scripts/catalog.py search '扩增子' --limit 8
python scripts/catalog.py search --domain '单细胞' --limit 20
python scripts/catalog.py show nf-core/rnaseq
```

脚本以本 Skill 为工作目录运行，或使用已发现的脚本位置。`show` 接受官方名、短名或稳定 Skill ID；显式指定的方法也要核查兼容性。`total_matches` 大于返回条数时提高 `--limit`。`skill_location` 只提示仓库位置，不表示对应插件已加载；使用当前环境实际可发现的能力。

| 选择依据 | 实际决策 |
|---|---|
| 实验与处理阶段 | 区分原始读段、比对、计数、变异、质谱或图像；FASTQ 后缀不能判定 RNA-seq |
| 研究问题与设计 | 目标输出、分组、重复和对照支持什么推断，是否需要组合预处理与下游任务 |
| 方法适配 | 核验协议、平台、物种、输入及真实实现；必要时选择仓库已有其他分析能力 |
| 版本与计算条件 | 比较可用版本、参数接口、参考与环境；不能静默更新固定源码 |
| 维护与实现状态 | 归档方案适合有依据的复现需求；新项目优先比较受支持且适配的方法 |

无需让用户从 152 个流程中自行挑选。系统给出推荐路径及理由，只有科学目的尚有实质分歧时让用户选择研究方向。不能为了使用 nf-core 强行套用不适配的流程。

默认目录包含归档项用于查找。`--active-only` 仅过滤归档状态，不表示正式发布、已安装或已实跑。`genomeskim` 与 `mitodetect` 固定源码仅读段 QC，`liverctanalysis` 无 CT 实现；不能将它们推荐成完整的相应分析。

## 自主准备参数并复核

读取选中 Skill 的具体参数判断、固定版本约定和相关输入模式。系统准备样本表、参考及配置；先依据实验协议和实际数据确定科学选择，再映射到该版本支持的字段。JSON Schema 的合法值和默认值只说明接口接受什么，不能证明适合此样本。

参数来源区分为实验必需设置、从数据估计、经核验的方法默认与研究设计选择。对会影响结论的值记录依据、暂定条件及复核方法；数据不足时先做必要的预检，不能捏造参考、建库协议或样本关系。按代表性样本与对照检查过滤损失和敏感性，再决定全量设置；不得以更多显著结果为调参目标。

当用户已要求开展分析且必要条件齐备，继续准备和执行授权范围内的工作，不再要求用户确认工具名或每个技术参数。缺少决定性实验事实时暂停依赖该事实的步骤，并继续能独立完成的数据检查。上传、公开提交或覆盖删除不因自动选流程而获得额外授权。

## 用用户理解的方式交付

先说“这批数据是什么、现在能回答什么、建议如何做、还缺什么”，再按需要展示工具细节。交付实际输入关系、参数理由与产物解释，明确哪些工作已经完成、哪些只是准备。所有本批流程仍未完成真实数据运行验证；文件存在、参数通过格式检查与分析成功是不同的事实。
