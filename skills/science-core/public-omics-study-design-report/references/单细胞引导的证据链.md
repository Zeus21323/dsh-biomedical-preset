# 单细胞引导的证据链

## 选择分支

| 问题 | 适合的起点 | 后续数据的作用 |
| --- | --- | --- |
| 哪类细胞、何种状态与疾病有关 | 匹配组织的单细胞或单核数据 | 独立供体验证细胞状态，bulk 检验人群关联，空间定位 |
| 患者预后或治疗响应能否预测 | 有终点和合理事件数的患者队列 | 外部队列检验泛化，单细胞解释信号来源 |
| 候选基因是否具有遗传或功能支持 | 对应遗传、蛋白或扰动数据 | 表达和单细胞定位提供上下文 |
| 缺少合适单细胞数据 | 可直接回答问题的其他数据 | 将细胞机制列为证据缺口，允许完成有限结论 |

把检索顺序、计算依赖和文章呈现顺序分别记录。单细胞放在正文前部，可以帮助解释组织构成；只有它实际参与候选产生时才称为发现起点。用 bulk 模型筛选出的基因回看同一单细胞数据，属于后续解释，不能声称新的独立验证。

## 可复用的案例模式

以下模式来自用户提供的“单细胞案例1”和“单细胞案例2”的任务结构，经抽象用于研究设计；原文是案例材料，数据编号、样本量、阈值与结论均需在具体项目重新核验，不作为已验证事实。

- **预后模式**：单细胞提出细胞相关候选，带随访的 bulk 队列发现或训练，独立临床队列验证，回到单细胞解释候选来源；需要真实治疗响应数据才能进一步验证疗效预测。
- **疾病标志物模式**：单细胞提出相关细胞状态，疾病与对照 bulk 数据检验候选，独立数据检查方向和效应，按具体机制问题选择功能或空间支持。

复用的是数据职责，不复制“交集 → 多算法筛选 → 免疫 → ceRNA → 药物”的固定菜单。PPI 中心性或多个算法同意不等于机制确认；没有拟时序假设、谱系依据和适当采样时不强行进行轨迹分析。

## 单细胞作为发现起点的前提

检查每组独立供体、供体与条件映射、原始 counts、批次与配对、目标细胞在各供体的覆盖。一个供体产生大量细胞仍只有一个独立供体；缺乏独立重复时，数据可作描述性定位，不能据此做群体差异推断。

细胞类型内的疾病对比采用能反映生物学重复的方法，例如按供体和细胞类型汇总 counts 后使用 pseudobulk 模型，或适配的混合效应模型。配对和重复测量进入设计。细胞簇 marker 筛选与疾病组间推断目的不同；不能将忽略供体的细胞级 Wilcoxon 检验直接用作人群结论。批次整合的嵌入适合注释和可视化，不自动消除推断模型的供体依赖。

供体数是否充分应结合效应、变异、稀有细胞覆盖和问题判断，不给统一最低数。少供体数据的候选需报告稳定性和外部复现需求。线粒体比例、基因数等 QC 阈值应适配组织、平台与细胞类型；病例与批次完全混杂时不能依靠整合算法恢复可识别的疾病效应。

## 防止循环论证

用某基因集打分后按高低分筛选差异基因，会因分组定义产生相关性。记录参与打分的基因、背景和覆盖，避免把同一矩阵上同一基因集的高低差异当作机制验证。外部基因集也要保留版本、来源、基因映射和核心/扩展成员定义。

检验跨数据集信号时，同时考虑方向、效应大小、测量覆盖和细胞组成。组织整体变化可能由细胞比例改变导致，不必与某细胞类型内变化同向。硬交集可能遗漏稀有细胞或平台未覆盖的基因；如采用交集，报告每层可检测背景和阈值敏感性。

不为获得非空交集、显著 KM 曲线或某个 AUC 不断改变分析方法。必要的方法变更记录原因、时间和影响，区分预先规定与探索性调整。

## 结论等级

表达定位支持“在哪类细胞表达”；差异与相关支持“与某状态相关”；通讯及轨迹输出支持“计算推断的候选关系”；独立队列复现增强可重复性。机制因果还需合适的扰动或其他因果证据。药物数据库匹配、细胞系 IC50 及响应评分不等于观察到患者疗效。

供体层推断依据可参阅原始方法研究：[Confronting false discoveries in single-cell differential expression](https://www.nature.com/articles/s41467-021-25960-2) 与 [A practical solution to pseudoreplication bias in single-cell studies](https://www.nature.com/articles/s41467-021-21038-1)。二者具体方法比较并不完全一致，共同要求是建模生物学重复之间的变异。
