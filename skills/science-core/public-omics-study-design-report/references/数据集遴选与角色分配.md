# 数据集遴选与角色分配

## 从问题定义可用性

先把“疾病相关”拆成可核验条件。皮肤与溃疡边缘、原发与转移、治疗前与治疗后、健康与邻近正常组织不能只因名称相近就视为同一对照。病例定义、取样时间、临床终点及时间起点决定数据能回答哪个问题。

按角色检查必要信息，缺失字段记为未知并说明后果：

| 角色 | 必须检查 | 不满足时 |
| --- | --- | --- |
| 细胞定位 | 目标组织、捕获细胞类型、注释依据、供体映射、数据层 | 缺供体时仅作描述，不能承担疾病组间推断 |
| 发现 | 合理对照、独立重复、对比可估计、原始计数或适用表达矩阵 | 降为假设生成或排除 |
| 训练 | 终点、事件数、协变量、测量平台、缺失模式 | 无随访或事件状态不做预后建模 |
| 外部验证 | 独立队列、目标人群与终点、可测特征、冻结模型适用性 | 独立性未证实则标为待核验 |
| 机制扩展 | 对应细胞或模型系统、实际测量层、与核心主张的关系 | 仅保留数据库注释或计算预测等级 |

独立供体数、样本数、文库数、切片数、细胞数分别记录。原始数据库总数、满足当前条件的子集数、质控后的分析数也分别记录，避免复制论文中的数字作为实际纳入量。

## 检索与元数据记录

1. 保存来源库、真实执行的查询式、过滤条件、访问日期、总命中数、获取数及是否截断。候选由用户给定时也记录来源和筛选范围。
2. 从研究级记录进入样本级信息，核实物种、组织、技术、处理方式、分组、配对和供体。用官方 accession 追踪条目，论文仅作为关联证据。
3. 检查下载文件清单、可用数据层、参考版本、探针或基因 ID、许可与访问限制。矩阵和样本表可用不代表 FASTQ 一定公开，也不必为仅需矩阵的任务下载全部原始数据。
4. 预先固定硬性条件；软性偏好比较样本代表性、独立重复、批次可分辨性、元数据完整度和复用成本。可明确给权重，但不提供跨任务通用评分。
5. 排除与暂缓决定都附理由。新近发布可作为偏好，不能替代研究设计适配性；多数据集数量本身不是证据强度。

## 队列关系与可迁移性

联合 accession、论文、项目号、供体或样本映射识别 GEO SuperSeries/SubSeries、不同平台重复测量及数据重发布。不同 accession 不能直接证明独立。样本来源不明标为未知，不能默认独立。

单细胞供体在 bulk 验证中再次出现时，不可声称完全外部独立。来自同一队列的表达、突变、浸润和药物预测可提供不同解释角度，但不是四个独立队列。

跨物种、移植模型、人源化皮肤或细胞系可提供模型支持。核实测量对象、参考注释、物种来源和同源映射；不能直接称为人类临床外部验证。不同疾病亚型合并需明确研究对象，并检查亚型与分组混杂、分层和敏感性分析。

bulk RNA-seq 计数、芯片强度、TPM 与单细胞计数各自采用适配方法。冻结跨平台特征映射及预处理规则，在验证集重新优化阈值或筛选基因会改变“外部验证”的含义。不同终点或组织只有在明确提出可迁移假设时才可作补充，不强行合并矩阵。

## 最小充分组合

根据需要覆盖的主张选择组合。例如细胞机制课题可以选择一个匹配的单细胞发现集、一个人群关联集和一个独立复现集；预后课题优先保证训练与独立随访验证，单细胞作为定位支持。是否增加空间、蛋白或扰动数据取决于尚未回答的问题，不固定要求三组，也不自动附加全部分析模块。
