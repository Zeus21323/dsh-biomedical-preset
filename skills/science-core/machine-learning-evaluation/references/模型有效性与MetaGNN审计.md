# 模型有效性与MetaGNN审计

## 来源和适用情境

[预印本](https://doi.org/10.64898/2026.09.02.748315)；[作者仓库](https://github.com/thiptanawat/MetaGNN-Framework)。论文是失效自审计，不是新的可靠高性能代谢预测方法。训练指标可由输入阈值构造的标签、反应身份记忆、全零特征或随机推理波动产生；高分本身不能证明患者特异的代谢信息。

不要求新手知道“泄漏”。“模型太准”“病人换了结果不变”“能不能写论文”“验证集失败”均可进入检查；但只有疾病名或科研目标时先做设计，不强制大型审计。

## 输入契约和已实现检查

`audit_reaction_scores.py` 需要Python 3.12+、NumPy及不含object/pickle的NPZ：

| 数组 | 形状和含义 |
| --- | --- |
| patients / reactions | 一维唯一字符串ID，分别为P与R |
| features | P×R，真正输入模型的反应特征摘要；不能拿未送入模型的原始矩阵冒充 |
| labels | P×R，完整0/1标签；缺失需先按预先定义的可评估子集处理并记录 |
| predictions | P×R，按相同身份顺序排列的真实输出 |
| zero_predictions / permuted_predictions | 可选P×R；模型在明确对照输入下实际重推理结果，缺少则记未检查 |
| thresholds | 可选R；从标签生成代码确认的阈值，检查features>=threshold是否重现标签 |

所有数组须来自相同模型、数据/实体顺序与固定推理设置。NPZ仅带一套身份轴，脚本无法证明各数组原本已对齐，导出时必须按ID关联并保存来源。多维原始特征不能随意压成单值掩盖问题；改查原张量并说明本脚本不覆盖的维度。

```bash
python scripts/audit_reaction_scores.py --input audit_inputs.npz --out-dir audit-01
```

输出audit.json、metrics.tsv和report.md。实现全零/患者不变输入、患者不变标签、输出变异、已有置零/置乱对照差异，以及原始输入基线的描述性AUROC；同分按平均秩计算，单类别时指标为空，不强填0.5。不训练、不调用MetaGNN、不生成对照预测、不提供患者层置信区间。

## 需额外证据的审计

追踪标签生成代码、样本/反应切分和所有预处理拟合边界；患者切分不一定消除反应身份记忆。重训练的标签置乱与推理时输入置乱是不同检查。已知随机标签生成机制才按其确切生成器和种子重放，不尝试搜索种子然后当作机制证明。不同模型或输入的随机前向比较须控制dropout设置、种子和重复次数，区分抽样噪声与患者信号。

外部真值缺失时不能认证真实生物活性。表达阈值标签只能评估该规则的重现，不能认证代谢通量；跨平台验证应记录平台差异、特征覆盖与标签独立性。

## 图和解读

metrics.tsv可直接作真实/原始输入/无信号对照的点图，图注写pooled patient–reaction descriptive AUROC，不能把P×R当独立患者数。无区间数据不画误差线。进一步提供患者间输出变化和输入–输出关系图时保留真实患者ID映射，输出PDF/SVG、高清PNG、数据与图注并预览。

报告逐项列出检查、数据依据、发现、影响和未完成项；未触发规则不等于模型可靠。重要负面结果需保留，不能只展示最高AUROC。
