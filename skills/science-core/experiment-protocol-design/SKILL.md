# 生物医学实验设计

## 零技术背景的研究起点

不要让用户先选软件或填写专业参数。先读取已给资料、数据与报告，用普通语言确认无法获知的研究事实：想研究谁、比较什么、有没有现成数据或实验条件、时间与资源限制。仅有“某疾病+某基因+想毕业”时，先给可证伪的问题、可行证据和主要缺口，不承诺文章级别、发表或毕业。

希望用公开数据、暂时没有实验数据，或需要判断公开数据路线是否可行时，衔接可用的“公共组学多数据集研究设计与证据报告”，读取其研究问题分流参考。需要新增实验则继续本入口。需要单次结果复核时直接进入对应专业任务，不强制重新设计整个研究。

触发研究设计不等于启动全量计算。解释为什么需要某项证据，只在研究问题、实际数据和用户授权相符时调用具体分析；不用分析数量充当文章创新性。

## 从实验单位开始

明确真正接受处理并独立产生信息的单位是患者、动物、培养皿还是细胞系批次。多个孔、视野或技术重复不能冒充更多生物学重复。

围绕一个主要终点写出可证伪假设、最小有意义效应和观测时间。安排阴性、阳性、载体/溶剂及批次对照；处理分配随机化，能够盲法时同时说明谁被盲。

样本量依据主要比较、预期变异、效应和脱落计算。资源不足时缩小问题或提高测量质量，不靠增加终点碰显著性。

最终提供分组与样本表、随机化/盲法办法、采样顺序、主要统计比较、质控节点和失败判据。重点检查处理是否与板位、日期、操作者或测序批次完全重合。
