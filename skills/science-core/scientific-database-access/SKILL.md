# 生物医学数据库检索

## 先做实体消歧

确认名称对应的物种、稳定 ID、基因组版本、转录本或化合物结构。一个基因符号、rsID 或药物商品名可能在不同版本中指向不同对象，查询前先列出歧义。

选择最直接支持问题的数据库，记录数据库版本或访问日期、查询字段和过滤条件。坐标查询明确 0/1 基、闭合区间及 contig 命名；跨库映射保留原 ID 和映射状态。

结果中区分数据库直接返回、多个数据库的一致结论和自己的解释。对冲突记录并列展示发布日期、证据类型和版本，不强行合并。

交付规范化结果表、查询条件、未命中/多重命中和冲突说明。数据库“收录”只能证明有记录，不能单独证明功能、因果或临床有效性。
