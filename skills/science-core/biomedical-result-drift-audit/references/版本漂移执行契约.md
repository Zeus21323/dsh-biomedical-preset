# 版本漂移执行契约（BioDataDrift方向）

## 先明确变化

“以前显著现在没了”“更新注释后排名变了”“换数据库要重跑吗”且有两版资源或结果时进入。只有一次失败先查原方法。核对ID、效应单位、方向、过滤及检验家族；混合更新只能作描述性变化，不能归因于单一数据库。

## 两个实际模式

执行：python scripts/audit_result_drift.py --config /外部目录/drift.json --out-dir /外部目录/drift-001

配置增加mode、versions={"old":{"reference":"旧版"},"new":{"reference":"新版"}}，可选alpha默认0.05，须预先说明。

compare：old_results/new_results为表，列id,estimate,padj；ID唯一、数值有限、padj在[0,1]。计算完整外连接、效应差、平均并列排名差、方向及阈值变化；缺失不填零。两版versions项可各含64位小写十六进制input_sha256/code_sha256/parameters_sha256/environment_sha256；四项一致只说明提交记录声称控制了条件，不独立证明远程重运行或因果归因。

ora：foreground/background为唯一gene列表，前景是背景真子集；old_mapping/new_mapping为唯一term,gene对。固定前景、背景和实现，用超几何上尾概率实际重算两版ORA，再逐版对有背景成员的全部term做BH。estimate为前景命中比例，不是有符号效应。不会默默删除背景外前景；映射中的背景外成员不参与检验。

两版term集合不同意味着BH家族也不同，须同时报告p、padj、term_size，不能把所有q值变化归因于一个基因映射。

## 输出与边界

old_results/new_results/drift.tsv保留全表，图展示共有项数值和排名。阈值跨越不是生物学反转。回查核心主张、基因覆盖、术语变化，再决定报告如何更新。非ORA上游由原专业Skill分别真实执行后进入compare。

本实现不定时监控数据库，不重跑所有算法，不是已部署BioDataDrift平台。定时任务必须另有用户授权和产品调度。
方法依据：[SciPy hypergeom](https://docs.scipy.org/doc/scipy/reference/generated/scipy.stats.hypergeom.html)。

## 代理负责准备、执行和复核

用户不需要写JSON或命令。先读取文件与元数据，确认问题、独立统计单位、对比和出处；只用普通话补问确实无法核实且改变设计的事实。只有疾病/基因/毕业愿望时先回公共研究设计；缺输入交付缺口清单，不用模拟数据冒充结果。

代理在用户指定的仓库外目录创建配置。所有配置必填question（实际问题）、parameter_reason（参数与设计依据）、evidence_notes（来源、已核验事实与不确定性）；可选font为覆盖图中文字的已安装字体。参数不得由显著性倒推。路径相对配置文件解析。CSV/TSV为UTF-8、唯一表头，TSV以.tsv结尾；保留原始数据，不自行覆盖。每次指定新输出目录。

Python 3.11+，依赖numpy、pandas、scipy、matplotlib。代理在隔离环境准备并记录版本，不要求新手安装。各适配器自包含，无跨Skill脚本依赖，不需要根目录packages。输入1GB保护上限不等于内存保证；失败非零退出，已有输出目录则留下失败记录，不把残留产物视作成功。

交付完整TSV、summary.json、run_record.json、report.md、可编辑PDF/SVG、400 dpi PNG和图注。作图数据来自对应完整结果表；图的截取规则必须说明。配置、输入/输出哈希、版本和状态均留痕。脚本摘要不等于科学论文：代理需据真实数字补写观察、样本量、效应/区间、阴性/冲突、替代解释、证据等级和下一步，关联具体表行和图件。描述性模式不能声称显著。

打开PNG或渲染PDF，按最终版面检查缺字、截断、图例、颜色、单位、比例、方向和区间；重要发现回查输入。分辨率不是论文质量保证。原始记录保持“需视觉与科学复核”状态；复核可另存review.md，不篡改运行记录。结果、缓存、测试数据和日志只放仓库外。本地适配器不代表后台数据库或未实现的论文方法已完成。
