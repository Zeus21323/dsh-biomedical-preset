# 科研问题与假设设计

先判断用户关心的是描述现象、预测结果、估计干预效果还是解释机制。这四类问题需要不同数据和证据，不应混写成一个宽泛目标。

把问题具体到研究对象、比较、暴露/干预、结果和时间窗。因果问题画出主要变量和可能混杂；机制问题写出至少一个能区分竞争解释的实验结果。

每个候选假设都回答：

- 什么观测会支持它？
- 什么观测会反驳它？
- 当前数据是否能测到这些观测？
- 最关键的替代解释是什么？
- 最小可行研究能减少哪项不确定性？

输出一个主要问题、可检验假设、观测预测、关键混杂、所需数据和停止条件。不要把“寻找任何相关基因”当成假设，也不要把探索结果事后写成预先预测。

## 候选假设排序

需要生成多个候选时，先从已知证据、数据异常或机制缺口分别提出候选，再按新颖性、可证伪性、数据可得性、实验成本和潜在影响排序。每个候选必须给出支持预测、反驳预测、最小实验、阳性/阴性对照和主要替代解释；无法设计反驳结果的陈述不作为假设交付。
