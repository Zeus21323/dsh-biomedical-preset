# ctDNA 低频突变检测

1. 明确面板、UMI、血细胞对照、输入量、独立分子深度和经验证检测限。
2. 使用共识读段或平台适配模型检测候选，并以正常人群面板估计位点特异噪声。
3. 过滤链、方向、读段位置、末端和氧化损伤偏倚，检查局部比对与同源区域。
4. 用配对白细胞识别CHIP和胚系来源；重点候选采用正交或重复样本复核。
5. 输出分子支持数、VAF、背景错误率、置信等级和阴性可解释范围。

低于检测限的信号不得报告为确定阳性；没有白细胞对照时必须突出CHIP混淆风险。
