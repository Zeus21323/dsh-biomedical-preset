# RAD-seq限制性位点关联测序变异分析（nf-core/radseq）

## 识别数据与研究目标

从交付文件与报告中识别 RAD/ddRAD reads、酶切和条形码设计、样本群体及参考情况；确认文库和位点定义的一致性。

## 方法选择

根据此版本的拆分、位点构建或参考比对路径生成可比 SNP 集，明确等位基因脱落与重复位点处理。

先核对 [版本约定](references/流程约定.json)。

| 核对项 | 固定范围 |
|---|---|
| 上游版本 | `dev`；`d3d80e6b5a68544caa4fe7652238220d55d17e63` |
| 上游维护 | 开发版本；按当前代码实际实现的范围使用 |
| 本地运行 | 未进行真实分析运行；不能据本 Skill 文件声称实跑通过 |
| 引擎声明 | `!>=21.10.3`；还需核验 Java、容器和 profile |

## 根据数据确定参数

从酶切设计、个体深度与位点缺失分布选择聚类和保留条件；评估等位基因脱落及重复位点，避免严格缺失过滤造成群体选择偏差。

| 决策与配置 | 处理要求 |
|---|---|
| 事实与缺口 | 先读现有文件和报告；不能据文件名猜实验类型、参考或样本关系；只补问无法核实且会改变分析的背景 |
| 参数来源 | 区分协议必需设置、数据估计、方法默认和研究选择；说明实际取值及理由，不要求用户填写专业参数 |
| 可执行配置 | 仅把已支持的选择映射为当前版本的原生字段；不支持的步骤另行交接，不虚构开关 |
| 阈值复核 | 默认值先评估适用性；依据质控、对照及敏感性检查调整，不能按显著结果数量调参 |

| 资料 | 使用时机 |
|---|---|
| [参数模式.json](references/参数模式.json) | 编写 params.json 时核对字段、类型、枚举及条件约束 |
| [输入模式-1.json](references/输入模式-1.json) | 准备 input 对应的样本表或输入文件时读取 |

仅在已授权且配置齐备时运行。

```bash
nextflow run nf-core/radseq -r d3d80e6b5a68544caa4fe7652238220d55d17e63 -params-file params.json
```

模式文件的许可见 [LICENSE](LICENSE)。

## 质控与解释

评估位点覆盖、缺失率、深度异常和群体间差异性缺失，过滤时记录对各群体样本的影响。

交付变异及样本/位点 QC；限制性位点偏倚和非随机缺失会影响群体参数，不能当作均匀 WGS 数据解释。
