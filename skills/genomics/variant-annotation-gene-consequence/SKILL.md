# 变异功能注释

输入 VCF 应先完成参考核对、规范化和多等位处理。选择 VEP、SnpEff 或 ANNOVAR 时，固定基因组构建、基因注释发布版和外部数据库版本。

## 转录本规则

说明采用 MANE Select、canonical、所有转录本还是项目指定转录本。一个变异可同时是不同转录本的错义、内含子或剪接变异，不能只保留最严重后果而丢失上下文。

附加群体频率、临床记录或预测分数时，按标准化等位基因匹配并记录未命中。抽查复杂 Indel、多等位位点、剪接边界和基因重叠区域。

交付注释 VCF/表、字段字典、数据库版本、转录本选择规则、未注释与多重映射记录。功能后果是注释，不等于致病性结论。
