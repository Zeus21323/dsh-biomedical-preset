# PacBio长读长变异预处理与分析（nf-core/pacvar）

## 识别数据与研究目标

区分 PacBio WGS 与 PureTarget 输入，收集 HiFi 数据、参考、目标区域及样本关系，核对具体技术版本。

## 方法选择

按本版本的 WGS/靶向模式选择预处理和变异路径，避免把靶向区域配置用于全基因组或忽略特定重复位点要求。

先核对 [版本约定](references/流程约定.json)。

| 核对项 | 固定范围 |
|---|---|
| 上游版本 | `1.1.0`；`20364830237171928c79e59651142460379d1459` |
| 上游维护 | 未归档；使用这里固定的源码，不自动跟随新版本 |
| 本地运行 | 未进行真实分析运行；不能据本 Skill 文件声称实跑通过 |
| 引擎声明 | `!>=25.10.4`；还需核验 Java、容器和 profile |

## 根据数据确定参数

根据实际 WGS 或靶向协议、目标区域和覆盖选择模型与过滤；重复位点和一般小变异分别检查证据，不共用一个深度门槛。

| 决策与配置 | 处理要求 |
|---|---|
| 事实与缺口 | 先读现有文件和报告；不能据文件名猜实验类型、参考或样本关系；只补问无法核实且会改变分析的背景 |
| 参数来源 | 区分协议必需设置、数据估计、方法默认和研究选择；说明实际取值及理由，不要求用户填写专业参数 |
| 可执行配置 | 仅把已支持的选择映射为当前版本的原生字段；不支持的步骤另行交接，不虚构开关 |
| 阈值复核 | 默认值先评估适用性；依据质控、对照及敏感性检查调整，不能按显著结果数量调参 |

| 资料 | 使用时机 |
|---|---|
| [参数模式.json](references/参数模式.json) | 编写 params.json 时核对字段、类型、枚举及条件约束 |
| [输入模式-1.json](references/输入模式-1.json) | 准备 input 对应的样本表或输入文件时读取 |

仅在已授权且配置齐备时运行。

```bash
nextflow run nf-core/pacvar -r 20364830237171928c79e59651142460379d1459 -params-file params.json
```

模式文件的许可见 [LICENSE](LICENSE)。

## 质控与解释

评估读段质量、比对、目标覆盖和各类变异支持，分别记录难比对区域及模式未覆盖的变异类别。

交付支持模式下的比对和变异结果及 QC；对串联重复或其他特殊位点解释须依据实际输出与技术验证。
