# 癌症变异注释与优先级解释（nf-core/variantprioritization）

## 识别数据与研究目标

检查已有规范化的体细胞或胚系 VCF、参考、样本元数据及可用拷贝数，明确 PCGR 或 CPSR 分析目标。

## 方法选择

按本版本要求分别组织 PCGR 体细胞解释和 CPSR 癌症易感注释，保持转录本、频率和证据库版本。

先核对 [版本约定](references/流程约定.json)。

| 核对项 | 固定范围 |
|---|---|
| 上游版本 | `1.0.0`；`8ba629c53dbdb65057c85a3b0a76a7eb2e8688ef` |
| 上游维护 | 未归档；使用这里固定的源码，不自动跟随新版本 |
| 本地运行 | 未进行真实分析运行；不能据本 Skill 文件声称实跑通过 |
| 引擎声明 | `!>=25.10.0`；还需核验 Java、容器和 profile |

## 根据数据确定参数

按变异来源、肿瘤类型、频率和证据等级选择注释范围，分别处理体细胞与胚系问题；过滤条件和证据数据库版本写明，研究排序不能直接当临床用药决定。

| 决策与配置 | 处理要求 |
|---|---|
| 事实与缺口 | 先读现有文件和报告；不能据文件名猜实验类型、参考或样本关系；只补问无法核实且会改变分析的背景 |
| 参数来源 | 区分协议必需设置、数据估计、方法默认和研究选择；说明实际取值及理由，不要求用户填写专业参数 |
| 可执行配置 | 仅把已支持的选择映射为当前版本的原生字段；不支持的步骤另行交接，不虚构开关 |
| 阈值复核 | 默认值先评估适用性；依据质控、对照及敏感性检查调整，不能按显著结果数量调参 |

| 资料 | 使用时机 |
|---|---|
| [参数模式.json](references/参数模式.json) | 编写 params.json 时核对字段、类型、枚举及条件约束 |
| [输入模式-1.json](references/输入模式-1.json) | 准备 input 对应的样本表或输入文件时读取 |

仅在已授权且配置齐备时运行。

```bash
nextflow run nf-core/variantprioritization -r 8ba629c53dbdb65057c85a3b0a76a7eb2e8688ef -params-file params.json
```

模式文件的许可见 [LICENSE](LICENSE)。

## 质控与解释

检查变异表示、基因映射、VAF/CNV 语义及证据来源，区分致病性、驱动性和药物证据层级。

交付结构化注释与候选报告；数据库关联不能自动转为诊断或处方，所有临床结论需专业复核。
