# GWAS荟萃与跨祖源分析

## 明确整合目标

“这几篇能合起来发文章吗”“中国人和欧洲人结果为什么不同”先检查性状定义、单位、祖源、版本和参与队列。不要把不同发布版本的相同样本当独立研究。共享对照/样本重叠未知时说明风险，不因数据集名字不同就当独立。用户确认生物问题，不需要挑meta算法。

读取[荟萃操作与图件](references/荟萃操作与图件.md)。`scripts/meta_fixed.py`仅对已协调、同尺度且独立研究做固定效应逆方差合并，输出研究数、效应、SE、Q和I²；非独立研究或跨祖源异质性分析按METAL/MR-MEGA等专门原生流程处理，不冒充已封装。

分析后直接生成位点森林图、全量曼哈顿/QQ及研究间异质性检查；展示所有预设研究，不只显示方向一致者。合并增强精度，不消除共同偏倚。为复现而选择验证数据必须独立于发现数据，不反复挑最显著发布版本。
