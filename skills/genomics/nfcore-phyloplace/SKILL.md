# 系统发育定位（nf-core/phyloplace）

## 识别数据与研究目标

从交付文件与报告中识别查询序列、参考多序列比对、参考树和相容的进化模型，确认查询与参考的同源区域。

## 方法选择

依据 EPA-NG 等该版本支持的方法将查询放置到固定参考树，区分系统发育定位与重新推断整棵树。

先核对 [版本约定](references/流程约定.json)。

| 核对项 | 固定范围 |
|---|---|
| 上游版本 | `2.1.0`；`441e351e2703329c04ddb494cefcdd017a48b9f1` |
| 上游维护 | 未归档；使用这里固定的源码，不自动跟随新版本 |
| 本地运行 | 未进行真实分析运行；不能据本 Skill 文件声称实跑通过 |
| 引擎声明 | `!>=25.10.4`；还需核验 Java、容器和 profile |

## 根据数据确定参数

先检查同源区域覆盖与参考树代表性，再选择比对和定位置信条件；多个相近放置保留不确定性，不能强行给每条序列唯一物种标签。

| 决策与配置 | 处理要求 |
|---|---|
| 事实与缺口 | 先读现有文件和报告；不能据文件名猜实验类型、参考或样本关系；只补问无法核实且会改变分析的背景 |
| 参数来源 | 区分协议必需设置、数据估计、方法默认和研究选择；说明实际取值及理由，不要求用户填写专业参数 |
| 可执行配置 | 仅把已支持的选择映射为当前版本的原生字段；不支持的步骤另行交接，不虚构开关 |
| 阈值复核 | 默认值先评估适用性；依据质控、对照及敏感性检查调整，不能按显著结果数量调参 |

| 资料 | 使用时机 |
|---|---|
| [参数模式.json](references/参数模式.json) | 编写 params.json 时核对字段、类型、枚举及条件约束 |
| [输入模式-1.json](references/输入模式-1.json) | 准备 phyloplace_input 对应的样本表或输入文件时读取 |
| [输入模式-2.json](references/输入模式-2.json) | 准备 phylosearch_input 对应的样本表或输入文件时读取 |

仅在已授权且配置齐备时运行。

```bash
nextflow run nf-core/phyloplace -r 441e351e2703329c04ddb494cefcdd017a48b9f1 -params-file params.json
```

模式文件的许可见 [LICENSE](LICENSE)。

## 质控与解释

检查查询比对覆盖、参考代表性、多个候选放置及权重分布，避免把参考库缺失类群强行归类。

交付定位结果、支持权重和解释；最优放置只是给定参考树下的相对证据，不自动构成物种或传播关系判定。
