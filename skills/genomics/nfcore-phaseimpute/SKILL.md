# 基因型分相与填充（nf-core/phaseimpute）

## 识别数据与研究目标

从交付文件与报告中识别目标基因型、参考面板、遗传图谱和组装版本，检查群体匹配、等位基因方向和样本性别信息。

## 方法选择

按本版本后端先做基因型协调再分相/填充，严格处理 strand ambiguity、重复位点和染色体拆分。

先核对 [版本约定](references/流程约定.json)。

## 根据数据确定参数

根据祖源、基因组版本和参考面板匹配度确定协调与填充配置；按频率层检查填充质量，低质量位点不能因研究需要而直接视为实测。

| 决策与配置 | 处理要求 |
|---|---|
| 事实与缺口 | 先读现有文件和报告；不能据文件名猜实验类型、参考或样本关系；只补问无法核实且会改变分析的背景 |
| 参数来源 | 区分协议必需设置、数据估计、方法默认和研究选择；说明实际取值及理由，不要求用户填写专业参数 |
| 可执行配置 | 仅把已支持的选择映射为当前版本的原生字段；不支持的步骤另行交接，不虚构开关 |
| 阈值复核 | 默认值先评估适用性；依据质控、对照及敏感性检查调整，不能按显著结果数量调参 |

## 质控与解释

检查填充质量、MAF 分层表现、面板重叠与重组边界，保留剂量及概率信息而非只输出硬调用。

交付分相/填充结果和过滤依据；低质量填充位点不能与直接测得高质量基因型等同。
