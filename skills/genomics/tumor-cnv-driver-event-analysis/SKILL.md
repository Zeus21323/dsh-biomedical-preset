# 肿瘤拷贝数变异与驱动事件

1. 明确平台、是否配对正常、捕获区、肿瘤纯度和样本质量。
2. 联合深度与等位基因频率估计分段、绝对拷贝数、纯度和倍性。
3. 检查全基因组加倍、亚克隆事件、基线漂移和FFPE噪声。
4. 队列中识别复发扩增/缺失时纳入臂级背景、峰宽和多重检验，再定位候选驱动基因。
5. 输出分段、基因级CNV、纯度倍性、复发峰和不确定区间。

面板数据对全基因组CNV能力有限；广泛染色体事件不能只按单基因放大解释。
