# 基因组污染检测

明确预期物种、样本来源和可能污染途径，并同时检查阴性对照和同批次样本。只看一个分类器的物种名容易把近缘序列误判为污染。

读段层可用分类或比对评估污染比例；组装层结合 contig 的覆盖、GC、长度、分类和与宿主序列的连接关系判断。试剂组污染常在多批样本低丰度重复出现，样本混合则会影响等位比例或物种组成。

数据库名称和版本必须报告；低复杂度、保守基因与近缘物种命中需复核。删除 contig 前确认它不是质粒、线粒体、共生体或真实水平转移序列。

输出候选污染、证据、出现批次、保留/移除建议及处理前后统计。
