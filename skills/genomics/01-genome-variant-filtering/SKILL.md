# 变异过滤与质量校准

先保留原始质量字段和调用器 FILTER，不在规范化前覆盖。过滤方案由测序类型、调用器、队列规模和用途决定。

- 样本量和可信训练资源足够时，可用 VQSR；检查 tranche、训练集重叠和模型分布。
- 小队列或特殊物种更适合预先定义的硬过滤；SNV 与 Indel 使用各自指标。
- 低深度、低等位平衡或链偏倚应留下明确 FILTER 标签，研究阶段通常比直接删除更可追查。

比较过滤前后的数量、Ti/Tv、质量分布、已知位点保留、家系错误和等位频率。阈值不得根据“显著位点是否留下”事后调整。

输出带 FILTER 的 VCF、规则或模型版本、每条规则命中数和前后 QC。
