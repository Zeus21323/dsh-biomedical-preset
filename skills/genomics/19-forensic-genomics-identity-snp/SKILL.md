# 身份SNP

该 Skill 是“法医基因组学 → SNP分析 → 身份SNP”的规范任务入口。当前保留并追溯了 1 条历史 Skill 或方法实现；它们不再作为彼此竞争的顶层入口。

## 工作流程

1. 明确样本、数据类型、研究设计、参考版本、期望产物和不可改变的约束。
2. 用任务、算法、软件或数据库关键词检索 `references/来源追溯.jsonl`，只选择与当前请求相关的实现。
3. 读取相应 `references/方法实现/` 中的 `实现说明.md`、脚本和参考资料；不要批量加载无关实现。
4. 根据适用数据、假设、规模、许可、依赖和验证状态选择方法，同任务的不同算法不得仅按名称合并。
5. 执行与风险相称的输入检查、质量控制和结果验证；临床或医疗结论必须保留专业审核边界。
6. 输出所用方法、版本、关键参数、证据来源、失败项、限制和可复现路径。

## 实现查询

```bash
rg -n '<任务、算法、软件或数据库关键词>' references/来源追溯.jsonl
```

`references/实现索引.md` 适合人工浏览；`references/来源追溯.jsonl` 是逐条机器可读账本。历史实现中的旧路径、旧工具声明和示例参数仅代表迁移来源，必须以当前环境和实际版本为准。
