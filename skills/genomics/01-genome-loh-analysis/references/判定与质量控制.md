# 判定与质量控制

## 数据要求

| 数据 | 主要信号 | 关键限制 |
|---|---|---|
| SNP 芯片 | LRR、BAF、长纯合区 | 探针密度和批次影响分段 |
| WES | 深度、杂合位点 BAF | 捕获不均匀，区段边界较粗 |
| WGS | 深度、BAF、断点 | 成本较高但全基因组覆盖更完整 |
| 肿瘤-正常 | 肿瘤与正常联合 BAF、纯度、倍性 | 正常污染和亚克隆会稀释信号 |
| 家系 | 相位、亲子传递、IBD | 样本关系错误会造成根本性误判 |

## 最低报告字段

- 样本、参考基因组、染色体、起止坐标和区段长度；
- 总拷贝数与次要等位基因拷贝数；
- 区段内可用杂合位点数和 BAF 偏离；
- 是否跨越低可比对区、着丝粒或组装缺口；
- 肿瘤样本的纯度、倍性模型和克隆性；
- 胚系场景中的亲本来源或 UPD 证据。

## 常见误判

- 把长纯合区直接称为缺失；
- 忽略群体近交背景；
- 在无匹配正常的肿瘤中把胚系纯合区称为体细胞 LOH；
- 在低纯度肿瘤中使用固定 BAF 阈值；
- 混用不同参考版本的位点和区段。
