# 杂合性缺失与拷贝中性LOH分析

先区分研究对象：胚系或家系数据关注单亲二体、近亲和嵌合；肿瘤数据关注等位基因特异拷贝数、纯度和倍性。LOH 表示杂合性丢失，不等同于拷贝数缺失；总拷贝数接近二但次要等位基因拷贝数为零时，才支持拷贝中性 LOH。

根据数据选择证据。SNP 芯片使用 LRR 与 BAF；WES/WGS 使用覆盖度、杂合 SNP 的 BAF 和分段拷贝数；家系分析还应使用亲子传递和相位信息。先统一参考版本、样本身份和正常对照，再进行分段，不能只凭连续纯合位点下结论。

涉及阈值、工具选择和结果字段时读取[判定与质量控制](references/判定与质量控制.md)。交付区段坐标、长度、总拷贝数、次要等位基因拷贝数、支持位点数、可信度和可能机制；对着丝粒、低可比对区和低覆盖区单独标记。

不能从没有等位基因信息的粗粒度拷贝数结果可靠地区分缺失性 LOH 与拷贝中性 LOH。临床或家系解释需要结合亲缘、表型和独立验证。
