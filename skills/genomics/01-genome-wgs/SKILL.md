# 短读长WGS分析

这是从 FASTQ 到胚系小变异的串联任务。开始前锁定参考 FASTA、known-sites、样本关系、预期覆盖和目标交付。

复杂队列需要选择调用器或排查联合分型时，读取 [方法细节](references/方法细节.md)。

## 主流程

原始质量检查 → BWA-MEM2 比对与 read group → 重复标记 → 必要的 BQSR → GATK/DeepVariant 单样本调用 → 队列联合分型 → 过滤与功能注释。

每一阶段使用同一参考和 contig 集。队列联合分型前逐一核对样本与 gVCF；性染色体和非二倍体区域使用合适倍性。

交付分析就绪 BAM/CRAM、gVCF/VCF、样本身份与污染检查、覆盖、Ti/Tv、杂合度和批次诊断。未覆盖或低可调用区域应单列，不能把“无记录”解释为纯合参考。
