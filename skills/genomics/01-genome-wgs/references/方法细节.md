# 短读长 WGS 方法细节

仅在需要选择调用器、联合分型或排查队列质控时读取本文件。

## 固定一次的资源

- 参考 FASTA、索引、序列字典、known-sites 与注释必须来自同一构建和 contig 命名体系。
- 样本 read group 至少包含稳定的样本、文库、平台与 lane 信息。
- 输入、参考和主要输出保留校验和；资源变更意味着新的分析批次。

## 方法选择

| 场景 | 建议路线 | 关键约束 |
| --- | --- | --- |
| 单样本研究性小变异 | BWA-MEM2 + DeepVariant 或 GATK | 不把单样本阈值直接迁移到队列 |
| 多样本队列 | 每样本 gVCF + 联合分型 | 样本与 gVCF 清单逐一对账 |
| 家系 | 联合分型后检查孟德尔错误 | 先验证家系角色与样本身份 |
| 低深度队列 | 剂量/似然感知流程 | 不把低置信硬基因型当确定值 |

覆盖、均一性、重复、插入片段、污染、样本一致性、Ti/Tv、杂合度和批次必须联合检查。
