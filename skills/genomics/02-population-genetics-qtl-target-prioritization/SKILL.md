# 分子QTL与药物靶点因果优先排序

## 先帮助用户定义能检验的主张

“这个基因能不能做靶点”“导师让我解释这个蛋白”先查疾病、组织、分子层级和已有效应证据，区分表达相关、风险代理、靶点作用方向和药效。只有选题时给数据检索与证据方案；已有QTL/GWAS时再判断cis工具与共定位可行性，不承诺成药或论文。

读取[分子证据操作](references/分子证据操作.md)。该入口整合正式结果与注释，不独立重写MR和coloc；可用专业入口先产生结果，不可用则按规范导入用户现成结果。使用 `scripts/assemble_target_evidence.py`校验并输出证据矩阵及本地HTML；每条证据必须有来源和方向/限制。脚本不自动评分、不生成因果结论。

矩阵直接用于论文证据表，按照参考中的图件步骤输出方向/区间森林图与支持/冲突/缺失证据图。来源相关的证据不重复计权；遗传终身代理不能直接外推给药剂量、治疗时机、组织特异性或安全性。最终交付优先级理由和能够反驳假设的验证实验，不用“已证明致病靶点”替代假设。
