# 分子QTL与靶点证据链

## 操作

1. 明确疾病、组织/细胞、基因/蛋白ID、目标干预方向及研究阶段；没有数据先检索官方QTL/GWAS元数据，记录许可和完整性。
2. 为cis区域确定边界、坐标、QTL测量平台和工具规则。检查蛋白改变是否影响抗体/适配体结合、转录本/异构体、组织代表性。
3. 用独立或LD感知MR估计器；相关cis SNP不能假装独立。记录单位、条件工具强度、样本重叠及选择偏倚。
4. 同一区域完整统计做共定位，多信号分别比较；失败或低信息与反对共享不同。
5. [SMR/HEIDI](https://yanglab.westlake.edu.cn/software/smr/)可作为独立整合分支：准备GWAS摘要、BESD/ESD QTL和匹配参考，核对安装版--bfile、--gwas-summary、--beqtl-summary、--out及HEIDI参数。HEIDI不显著不证明表达中介。
6. 加入组织、编码变异、扰动/实验、成药性及跨表型关联证据，按来源归组避免重复计数。

## 证据表与实际交付

输入TSV必需列为target,question,outcome,tissue,exposure,unit,evidence_type,result,direction,direction_target,source,source_group,limitation。question写清这一行支持或反对的具体命题；组织、暴露、单位、结局不适用/未报告时明确填写not_applicable/not_reported并解释，不能猜测。result为support/conflict/inconclusive/not_available；direction为increase/decrease/unclear/not_applicable，direction_target必须说明变化的是“疾病中的表达量”还是“每单位遗传预测蛋白升高所对应的疾病风险”等，二者不得混为一谈。source为论文/数据库版本/结果文件的可追溯定位，source_group标识共用队列/数据来源，避免重复计数。脚本保留全部附加列，如beta,se,PP.H4、平台和转录本，不静默丢失上下文。运行：
`python scripts/assemble_target_evidence.py --input evidence.tsv --out evidence_new`
脚本拒绝空字段/非法类别，输出证据TSV和本地HTML，HTML转义文本，不加载外网。它不分析MR、不打总分，也不自动判断优先级。

从矩阵画离散颜色证据热图（缺失灰、冲突有符号），MR/共定位真实数值另画效应森林/区域图，不用证据计数冒充效应。PDF/SVG与600dpi PNG同时输出，含每项证据来源和冲突的图注。没有真实统计仅可交付明确标为研究设计的示意图，不能画拟真散点。

报告为每个候选写优先/暂缓理由、作用方向、关键反证、独立验证实验、替代解释。遗传支持、细胞实验和临床药效不同层级；PheWAS信号不能直接判定用药副作用。结论不承诺临床应用或发表。
