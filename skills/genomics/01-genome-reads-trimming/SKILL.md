# 测序读段修剪

修剪必须由原始质控或文库结构驱动。先确认真实接头、单双端、UMI/条码位置和下游分析对读长的要求。

用 fastp、cutadapt 或 Trim Galore 时设置接头与最短保留长度；UMI、扩增子引物和小 RNA 使用各自流程，不能当普通接头处理。不要仅因为末端质量略降就固定截去若干碱基。

比较处理前后：

- 读段和碱基保留比例；
- 长度分布与配对同步；
- 接头残留和每碱基质量；
- 下游比对或 k-mer 指标是否改善。

输出修剪后 FASTQ、完整参数、丢弃原因和前后 QC。若修剪显著缩短读段但不改善下游，应保留原始数据并重新评估规则。
