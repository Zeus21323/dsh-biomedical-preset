# 参数与质控

## 必需输入

- 坐标排序并建立索引的肿瘤 BAM/CRAM；CRAM 还必须提供完全匹配的参考序列。
- 参考 FASTA 及其 `.fai`、序列字典。
- BAM read group 中的样本名，必须与 `--tumor-sample` 一致。
- 建议提供同平台、同建库和同捕获区域正常样本建立的 PoN。
- 建议提供与研究人群和参考版本匹配的胚系等位基因频率资源。

## 核心流程

1. 用 Mutect2 肿瘤单样本模式生成未过滤 VCF 和 F1R2 方向计数。
2. 有 PoN 和胚系资源时同时传入；资源版本不同不得强行使用。
3. 在独立的正常样本集合上建立 PoN，不能用当前肿瘤样本代替。
4. 估计污染并把污染表交给 FilterMutectCalls。
5. 检查方向偏倚模型、测序深度、等位基因深度和过滤标签。
6. 对重要低频候选回看 BAM，并设计正交验证。

## 解释边界

- 没有匹配正常样本时，罕见胚系变异仍可能混入结果。
- PoN 主要清除平台和批次伪影，不能证明候选是体细胞来源。
- 公共胚系频率缺失不代表变异一定为体细胞。
- FFPE、低纯度和极低 VAF 场景应单独报告检测限和假阴性风险。
