# 肿瘤单样本体细胞变异检测

先确认样本确实没有可用的匹配正常对照，并记录测序类型、参考基因组、肿瘤类型、肿瘤纯度估计、建库方式和捕获区域。若能获得匹配正常样本，应转用肿瘤—正常配对流程；单样本模式的胚系污染和测序伪影风险更高，不能把全部候选直接视为体细胞变异。

优先采用肿瘤单样本调用、正常样本面板（PoN）、群体胚系资源和污染估计组成的流程。调用前检查 read group、重复标记、碱基质量校正、参考 contig 和样本名；调用后进行模型过滤、方向偏倚与污染过滤，并根据捕获区域、测序深度和最低可检出 VAF 评估阴性结果。

需要生成可复现命令时，先阅读[参数与质控](references/参数与质控.md)，再运行 `scripts/run_tumor_only_mutect2.sh`。该脚本负责参数检查和命令编排，不会替代 PoN、胚系资源或人工审查；用 `--dry-run` 可在没有 GATK 时审查命令。维护脚本时运行 `scripts/test_run_tumor_only_mutect2.sh`。

交付原始候选、过滤后 VCF、过滤原因统计、可检出范围、疑似胚系标记和人工复核清单。结论必须使用“候选体细胞变异”，除非已有正交验证或可靠的配对证据。
