# cfDNA 预处理与 UMI 共识

1. 核对样本类型、采血管、处理时间、建库方案、UMI结构、面板和阴性对照。
2. 检查接头、读长、插入片段和污染，再按建库结构提取UMI并校正测序错误。
3. 以位置、方向和UMI聚类形成家族，明确最小家族大小、单链或双链共识规则。
4. 统计原始深度、独立分子深度、家族大小、共识产率和各替换类型背景噪声。
5. 输出共识BAM、分子级QC、失败样本和检测限相关参数。

高原始深度不等于高独立分子深度；过度合并UMI会吞掉真实低频变异。
