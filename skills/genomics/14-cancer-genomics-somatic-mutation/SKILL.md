# 肿瘤—正常配对体细胞变异检测

1. 核对肿瘤与正常样本身份、肿瘤类型、纯度、参考版本、捕获区和UMI情况。
2. 评估覆盖、污染、交叉样本、FFPE损伤和正常样本肿瘤污染。
3. 使用配对体细胞调用流程并引入正常人群面板与种系资源，保留过滤原因。
4. 对低频候选检查双链/UMI支持、链偏倚、方向偏倚和局部比对。
5. 输出规范化VCF、可调用区域、QC、过滤统计和人工复核候选。

肿瘤纯度和拷贝数会改变VAF；低于检测限的阴性结果不能解释为不存在变异。
