# 系统发育树构建与评估

用户要求根树操作、分化时间或物种树时，先读取[树操作、物种树与分化时间](references/树操作、物种树与分化时间.md)，不得把普通枝长当作时间。

先确认序列确为同源，并区分基因树、核心基因组树和物种树问题。多序列比对后检查错配、大片缺失、饱和和重组；修剪规则应保留。

依据数据选择替换模型、分区和最大似然或贝叶斯方法。外群要足够近以可靠比对，又能提供根；根的位置不能靠绘图软件随意指定。

bootstrap 或后验概率衡量给定模型下的分支支持，不代表该分支无条件正确。比较不同比对、模型、重组处理和基因集合的拓扑稳定性。

交付原始/修剪比对、树文件、模型、外群、支持度和冲突分支。不要把枝长直接解释成时间，除非另有时钟模型和校准。
