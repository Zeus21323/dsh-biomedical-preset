# FASTQ质量评估

先确认文件是否压缩完整、单双端是否成对、测序平台和预期读长。质控对象是原始读段；不要先修剪再把结果称为“原始质量”。

使用 FastQC 或等价统计查看每碱基质量、N 比例、序列长度、接头、GC、重复和过度代表序列。判读时结合平台：短读长末端下降常见，扩增子或小 RNA 的重复/碱基组成也不服从普通 WGS 预期。

需要给出决定，而不只是转交 HTML：

- 接头信号明确且会影响比对或定量：建议针对实际接头修剪。
- 仅末端轻微降质：先评估下游工具容忍度，避免无理由截短。
- 个别样本整体偏离同批次：检查上样、lane、污染和样本身份。

输出逐样本异常、影响范围、是否需要修剪或重测，以及用于判断的关键图。
