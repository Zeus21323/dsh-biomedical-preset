# ctDNA 肿瘤分数估计

1. 确认是否有肿瘤组织和白细胞对照、可用变异、拷贝数分辨率及输入DNA量。
2. 变异法需校正局部拷贝数、克隆性和分子深度；CNV法需评估非整倍体与噪声基线。
3. 排除CHIP、胚系和明显测序伪影，比较多标记联合与最高VAF估计。
4. 用模拟、稀释或已验证样本给出检测下限和置信区间。
5. 输出肿瘤分数、方法、纳入标记、区间和失败原因。

不同方法估计的“肿瘤分数”定义可能不同；低肿瘤负荷时应报告区间而非虚假精确值。
