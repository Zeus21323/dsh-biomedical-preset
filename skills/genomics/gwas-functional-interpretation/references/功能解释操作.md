# 按证据类型进行功能解释

完整GWAS可做考虑LD的基因聚合、基因集/组织分析；独立候选列表只能做明确背景的过度代表分析；可信集可结合PIP加权注释。先说明背景是实际检测基因/变异而不是随意全基因组。样本库选择、基因长度、LD、注释重叠与MHC可能驱动富集。

## 操作路径

1. 固定build、基因坐标/边界、注释和基因集版本。
2. [MAGMA官方](https://ctg.cncr.nl/software/magma)：先以--annotate、--snp-loc、--gene-loc建立注释，再--bfile、--pval（含实际N设置）、--gene-annot做基因关联；--gene-results与--set-annot做基因集。实际列和covariate参数以安装版手册核验；当前Skill不提供自造magma wrapper。
3. 组织/细胞注释富集可按[LDSC分层说明](https://github.com/bulik/ldsc/wiki/Partitioned-Heritability)准备LD score注释和回归协变量，报告baseline模型和共线性；不能将未控制背景的注释P解释为细胞特异。
4. 基因列表富集记录全集、实际可映射集及丢失ID，校正全部测试集；重复通路按解释归组，不以任意剪枝隐藏冲突。
5. 比较合理边界、移除特殊强LD区和不同版本的敏感性，记录预设/探索区别。

## 图和严谨解释

结果后直接输出基因/通路点图、组织热图、leading genes表。颜色表示校正P时标明，大小表示基因数或比例时给分母；不要让巨大基因集看起来等同巨大效应。PDF/SVG、高清PNG和完整背景/结果表同时导出。富集提供关联分布证据，不证明每个基因致病；同一GWAS衍生多个富集不算多次独立验证。源头：[MAGMA 2015](https://doi.org/10.1371/journal.pcbi.1004219)。
