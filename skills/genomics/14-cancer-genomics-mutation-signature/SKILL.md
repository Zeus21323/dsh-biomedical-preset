# 肿瘤突变特征分析

1. 确认变异调用一致、参考上下文正确，并检查每个样本可用突变数是否足够。
2. 根据样本量选择已知特征拟合或从队列提取新特征，避免在稀疏样本中过拟合。
3. 比较重建误差、余弦相似度、暴露稳定性和相近特征可辨识度。
4. 用自助法或重复拟合给出暴露不确定性，并结合癌种、治疗和生物机制解释。
5. 输出特征暴露、重建质量、置信范围和不能区分的特征组。

突变特征提示过程关联，不可单凭相似度确定具体暴露或临床因果。
