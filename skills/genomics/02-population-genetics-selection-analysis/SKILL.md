# 自然选择信号分析

若样本来自环境梯度、地理网格或多个相关群体，先读取[景观基因组学与物种界定](references/景观基因组学与物种界定.md)，先分离空间结构、环境关联与物种边界问题。

依据时间尺度和数据条件选统计量：iHS/XP-EHH 依赖相位和单倍型，FST/PBS 比较群体分化，SFS 方法需要祖先等位基因和人口史背景。

每个统计量在合适的频率、重组和群体范围内标准化。候选阈值优先来自匹配的基因组背景或中性模拟，而不是跨研究照搬。长程 LD、背景选择、瓶颈和局部低重组都可产生类似信号。

整合不同原理证据，并检查相位、样本量、祖先状态、基因组可比性和注释密度。交付候选区域、统计量、经验/模拟分位、重叠基因和人口史敏感性。极端统计量是选择候选，不等于已证明适应机制。
