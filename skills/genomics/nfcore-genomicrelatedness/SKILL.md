# 低覆盖基因组亲缘关系估计（nf-core/genomicrelatedness）

## 识别数据与研究目标

从交付文件与报告中识别低覆盖全基因组数据、参考、样本身份和群体背景；明确是否涉及近亲、重复样本或未知个体识别。

## 方法选择

使用该版本适配低覆盖数据的亲缘估计路径，核对基因型似然或其他原生输入，避免把不确定低深度硬调用当作高质量基因型。

先核对 [版本约定](references/流程约定.json)。

| 核对项 | 固定范围 |
|---|---|
| 上游版本 | `dev`；`2484e643de827050d2b6a10b150223cf9ec5c9e6` |
| 上游维护 | 开发版本；按当前代码实际实现的范围使用 |
| 本地运行 | 未进行真实分析运行；不能据本 Skill 文件声称实跑通过 |
| 引擎声明 | `!>=25.10.4`；还需核验 Java、容器和 profile |

## 根据数据确定参数

根据实际覆盖、群体背景和可用位点选择似然与过滤条件；用估计不确定性区分可判定和待确认关系，低深度硬调用不作为可靠真值。

| 决策与配置 | 处理要求 |
|---|---|
| 事实与缺口 | 先读现有文件和报告；不能据文件名猜实验类型、参考或样本关系；只补问无法核实且会改变分析的背景 |
| 参数来源 | 区分协议必需设置、数据估计、方法默认和研究选择；说明实际取值及理由，不要求用户填写专业参数 |
| 可执行配置 | 仅把已支持的选择映射为当前版本的原生字段；不支持的步骤另行交接，不虚构开关 |
| 阈值复核 | 默认值先评估适用性；依据质控、对照及敏感性检查调整，不能按显著结果数量调参 |

| 资料 | 使用时机 |

nextflow run nf-core/genomicrelatedness -r 2484e643de827050d2b6a10b150223cf9ec5c9e6 -params-file params.json

## 质控与解释

检查共享位点数、污染、批次与祖源差异，评估低深度下亲缘类别的可分辨性。

交付亲缘矩阵和不确定性；边界样本不能凭单一估计值确定家系关系或个人身份。
