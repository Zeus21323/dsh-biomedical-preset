# 细胞外囊泡RNA分析（nf-core/evexplorer）

## 识别数据与研究目标

从交付文件与报告中识别 EV RNA 数据、分离与建库方法、平台、参考和分组，记录低输入及污染控制。

## 方法选择

按本版本支持的 nextflex、comboSeq、ONT 等路径处理 QC、表达区域和差异分析，先核实具体协议兼容性。

先核对 [版本约定](references/流程约定.json)。

| 核对项 | 固定范围 |
|---|---|
| 上游版本 | `dev`；`b06c9114853b9370cec6c4f6c0c9c44550ed5125` |
| 上游维护 | 开发版本；按当前代码实际实现的范围使用 |
| 本地运行 | 未进行真实分析运行；不能据本 Skill 文件声称实跑通过 |
| 引擎声明 | `!>=23.04.0`；还需核验 Java、容器和 profile |

## 根据数据确定参数

由分离方法、建库协议、读段长度及污染对照选择处理和计数；低复杂度与外源 RNA 背景分别评估，不能靠宽松过滤将污染转成囊泡标记。

| 决策与配置 | 处理要求 |
|---|---|
| 事实与缺口 | 先读现有文件和报告；不能据文件名猜实验类型、参考或样本关系；只补问无法核实且会改变分析的背景 |
| 参数来源 | 区分协议必需设置、数据估计、方法默认和研究选择；说明实际取值及理由，不要求用户填写专业参数 |
| 可执行配置 | 仅把已支持的选择映射为当前版本的原生字段；不支持的步骤另行交接，不虚构开关 |
| 阈值复核 | 默认值先评估适用性；依据质控、对照及敏感性检查调整，不能按显著结果数量调参 |

| 资料 | 使用时机 |
|---|---|
| [参数模式.json](references/参数模式.json) | 编写 params.json 时核对字段、类型、枚举及条件约束 |
| [输入模式-1.json](references/输入模式-1.json) | 准备 input 对应的样本表或输入文件时读取 |

仅在已授权且配置齐备时运行。

```bash
nextflow run nf-core/evexplorer -r b06c9114853b9370cec6c4f6c0c9c44550ed5125 -params-file params.json
```

模式文件的许可见 [LICENSE](LICENSE)。

## 质控与解释

关注低复杂度、rRNA、接头、非囊泡 RNA 污染及文库大小差异，检查表达区域与注释的对应。

交付 EV RNA 表达与 QC 及支持的比较结果；RNA 信号不能单独证明来自特定细胞或具有囊泡介导功能。
