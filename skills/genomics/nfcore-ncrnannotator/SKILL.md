# 基因组非编码RNA注释（nf-core/ncrnannotator）

## 识别数据与研究目标

从交付文件与报告中识别基因组序列、物种背景和所需的 RNA 家族库版本，明确是否已有重复和编码基因注释。

## 方法选择

依据 Infernal 及上游支持的步骤搜索 ncRNA 家族，核对模型阈值、片段化匹配与重叠结果的处理。

先核对 [版本约定](references/流程约定.json)。

| 核对项 | 固定范围 |
|---|---|
| 上游版本 | `dev`；`7b3c4e5685da83e53590c2c514368be3fcaac189` |
| 上游维护 | 开发版本；按当前代码实际实现的范围使用 |
| 本地运行 | 未进行真实分析运行；不能据本 Skill 文件声称实跑通过 |
| 引擎声明 | `!>=25.04.0`；还需核验 Java、容器和 profile |

## 根据数据确定参数

依据物种距离、家族模型的校准信息和片段化程度选择报告条件；检查重叠与重复区域中的候选，不用统一打分替代各模型的适用阈值。

| 决策与配置 | 处理要求 |
|---|---|
| 事实与缺口 | 先读现有文件和报告；不能据文件名猜实验类型、参考或样本关系；只补问无法核实且会改变分析的背景 |
| 参数来源 | 区分协议必需设置、数据估计、方法默认和研究选择；说明实际取值及理由，不要求用户填写专业参数 |
| 可执行配置 | 仅把已支持的选择映射为当前版本的原生字段；不支持的步骤另行交接，不虚构开关 |
| 阈值复核 | 默认值先评估适用性；依据质控、对照及敏感性检查调整，不能按显著结果数量调参 |

| 资料 | 使用时机 |
|---|---|
| [参数模式.json](references/参数模式.json) | 编写 params.json 时核对字段、类型、枚举及条件约束 |

仅在已授权且配置齐备时运行。

```bash
nextflow run nf-core/ncrnannotator -r 7b3c4e5685da83e53590c2c514368be3fcaac189 -params-file params.json
```

模式文件的许可见 [LICENSE](LICENSE)。

## 质控与解释

检查覆盖、匹配得分、链方向、重复区域和同家族重复命中，避免把弱片段匹配全部视为完整功能 RNA。

输出 ncRNA 坐标、家族归属与匹配证据；模型相似性不代表转录表达或功能已被实验确认。
