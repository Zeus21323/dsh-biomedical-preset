# 肿瘤变异图谱可视化

1. 统一样本、基因、变异分类和临床注释，记录多变异合并优先级。
2. 明确样本排序依据，分开展示突变、CNV、融合和缺失数据。
3. 频率分母使用可调用且经过质控的样本，不把未测当作野生型。
4. 共现/互斥分析校正突变负荷、肿瘤类型和多重检验。
5. 输出绘图输入表、排序规则、矢量图和完整图注。

图中的高频不等于驱动性；队列构成和检测面板差异必须随图说明。
