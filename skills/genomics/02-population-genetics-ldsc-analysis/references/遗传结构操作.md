# 遗传结构的操作分支

先核对全量汇总、祖源、N、病例比例、疾病群体患病率来源和样本重叠。仅显著位点/候选基因不能做全基因组LDSC；极低遗传力时遗传相关可能不稳定。参考LD score、权重、变异集合和注释版本相配，不默认用欧洲参考套全部队列。

## 原生命令

按[LDSC官方说明](https://github.com/bulik/ldsc/wiki/Heritability-and-Genetic-Correlation)使用其兼容环境，在用户目录运行：
`python munge_sumstats.py --sumstats input.tsv --N actual_N --out munged`
actual_N是智能体替换的实际值，逐SNP N存在时按原生字段使用，不以总人数混代有效N。再：
`python ldsc.py --h2 munged.sumstats.gz --ref-ld-chr ref_prefix --w-ld-chr weight_prefix --out h2`
遗传相关用--rg配置两个或多个预处理文件，参数按版本核对。二分类先区分observed与liability尺度，报告患病率和抽样比例假设；不把病例比例当群体患病率。

Genomic SEM按[官方源码/教程](https://github.com/GenomicSEM/GenomicSEM)执行munge/ldsc及usermodel等安装版接口，保存遗传协方差S、采样协方差V、模型语法、识别条件和拟合。共享样本不能把V非对角线设0；负方差或近奇异不能静默截断以取得拟合。用户问共同因素时先提出有解释的模型和反证，不让新手选SEM参数。

## 图、结果与扩展

实际结果直接画h²区间森林、rg及其不确定性热图、SEM路径图；rg越界/不稳定不裁成[-1,1]伪装有效。图注含尺度、祖源、N口径、参考版本、区间与校正。向量图+高清PNG+底层矩阵一起交付；有条件时查看删除单性状对模型的敏感性。分层LDSC用于注释富集、不是TWAS或基因因果；全局rg不能定位共享变异。源头：[LDSC 2015](https://doi.org/10.1038/ng.3211)。
