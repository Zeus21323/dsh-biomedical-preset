# GWAS图件与下一步

读取标准全量结果，至少CHR POS P；有极小P时提供MLOG10P替代。从本Skill目录运行：
`python scripts/plot_gwas.py --input sumstats.tsv.gz --out figures_new --title "Trait association" --threshold 5e-8`
阈值是常见单表型常变异示例，按实际检验族调整；不是所有研究统一阈值。脚本要求Python matplotlib/numpy，输出PDF/SVG/600dpi PNG、底层全量作图表、图注和图片清单；目录不得已存在。脚本不抽样计算QQ，不能仅传显著位点。

## 先诊断后标注

1. 查看样本流程、表型分布、PCA及批次着色；这些从QC结果生成，当前GWAS图脚本不伪造。
2. 看全量QQ（全部有效检验）、按MAF/MAC分层QQ及适用时LDSC； λ来自多基因与混杂的混合，不能机械除以λ。
3. 看曼哈顿：染色体异常、极端孤峰、位点密度；标注独立区域，不把每个显著SNP当独立发现。
4. 对候选区域从完整结果提取窗口，按匹配参考LD对lead SNP着色；基因注释使用明确build与版本。可用[GWASLab区域与全局绘图](https://cloufield.github.io/gwaslab/Visualization/)，没有LD时明确不着色，不填假LD。
5. 回查lead的MAC、INFO、缺失/批次、模型收敛；分组效应比较显示区间及异质性，不能比较两侧是否显著代替交互检验。

所有图打开查看裁切、字体、图例、坐标和统计一致性；密集点可栅格化、轴可明示断轴，不隐去不喜欢的结果。图注补充N、祖源、模型、协变量、阈值、完整数据来源。交互图只改变显示；筛点后不静默重算主结果。

## 扩展决策

- “这块真正哪个变异”：条件分析/精细定位，输入区域全量和带符号LD。
- “究竟哪个基因”：位点到基因证据，不能只取最近基因。
- “表达/蛋白是否相同信号”：共定位与QTL整合。
- “是不是因果”：先确定暴露/结局及工具条件，再考虑MR。
- “多队列怎样合并”：荟萃/跨祖源，先查重叠和单位。
- “很多罕见突变”：基因/区域掩码检验，不按常见变异单SNP流水线硬跑。
- “预测谁会得病”：PRS需要独立目标队列与评估，不由显著位点直接形成临床预测。
- “共同遗传背景”：LDSC/Genomic SEM；遗传相关不等于因果。
- “细胞/通路机制”：功能富集/TWAS，保留相关与机制假设区别。

报告依次写研究对象与实际N、模型/QC、效应及区间、校准、技术排查、复现、替代解释和限制。结果显著不证明因果基因；阴性可能是精度不足，不按发表目标更改阈值。
