# GWAS 方法细节

仅在需要选择 GLM、LMM、SPA/Firth 或解释整体膨胀时读取本文件。

| 数据条件 | 首选思路 | 原因 |
| --- | --- | --- |
| 无近亲、PC 足以描述结构 | PLINK2 GLM | 简单透明，易诊断 |
| 存在亲缘或细微结构 | GEMMA、BOLT-LMM；或 REGENIE | 前两者为混合模型；REGENIE使用两步全基因组预测控制结构 |
| 二分类极不平衡、低 MAC | SAIGE 或带 SPA/Firth 的 REGENIE | 普通检验尾部可能失准 |
| 生物样本库、多性状 | REGENIE 两步法 | 计算可扩展并使用 LOCO |

表型、病例定义和协变量在看结果前固定。效应等位基因、频率、样本量和版本写入汇总统计。QQ 图只显示现象；不能看到 λ>1 就机械做 genomic control。
