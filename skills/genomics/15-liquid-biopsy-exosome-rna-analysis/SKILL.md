# 细胞外囊泡 RNA 分析

1. 核对EV分离方法、体液类型、溶血指标、RNA提取、建库类型和外源对照。
2. 评估读长、接头二聚体、rRNA、miRNA或其他RNA组成及低复杂度。
3. 使用与短RNA或总RNA相符的比对和定量方法，处理多重比对与异构体。
4. 差异分析控制批次、输入量、溶血和细胞污染，候选标志物用嵌套验证。
5. 输出RNA丰度、EV/污染质控、差异结果和候选验证方案。

细胞外囊泡RNA结论取决于分离纯度；不能把共分离脂蛋白或细胞碎片信号默认为EV来源，也不能在缺少亚型证据时将全部EV称为外泌体。
