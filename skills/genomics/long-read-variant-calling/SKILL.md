# 长读长变异检测

先区分 HiFi 与 ONT，并记录 chemistry、basecalling 模型、覆盖、参考、样本或家系关系。小变异和结构变异使用各自适配的调用器与质量口径。

## 分析重点

- SNV/Indel：关注同聚物、低复杂区和平台系统误差，保留不可调用区域。
- SV：统一断点和类型后做队列重新分型，保留跨断点读段与局部组装。
- 分相：说明使用读段、家系还是参考面板，并报告相位块长度与 switch error 的可评估信息。
- 复杂区域：着丝粒、串联重复和高同源基因需单独复核，不能套常规阈值。

关键候选结合读段、覆盖、等位比例、家系分离和另一调用器验证。输出小变异 VCF、SV VCF、相位块、证据图及困难区域；不同平台的质量分不能直接比较。
