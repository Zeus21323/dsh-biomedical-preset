# 环状DNA与ecDNA候选识别（nf-core/circdna）

## 识别数据与研究目标

明确 Circle-seq、WGS 或 ATAC-seq 数据、参考、样本与对照，区分实验富集与普通覆盖数据。

## 方法选择

选择与本版本输入模式相符的环状 DNA 检测路径，保留断点、拷贝支持和调用器差异。

先核对 [版本约定](references/流程约定.json)。

| 核对项 | 固定范围 |
|---|---|
| 上游版本 | `1.1.0`；`8e0e14c84f90c94d975c2bac6bde8e5a1d5bc8ab` |
| 上游维护 | 未归档；使用这里固定的源码，不自动跟随新版本 |
| 本地运行 | 未进行真实分析运行；不能据本 Skill 文件声称实跑通过 |
| 引擎声明 | `!>=23.04.0`；还需核验 Java、容器和 profile |

## 根据数据确定参数

按建库富集方式、断点支持和背景覆盖选择检测条件；不同模式的支持度不可直接比较，线性重复或拷贝扩增不能单独证明环化。

| 决策与配置 | 处理要求 |
|---|---|
| 事实与缺口 | 先读现有文件和报告；不能据文件名猜实验类型、参考或样本关系；只补问无法核实且会改变分析的背景 |
| 参数来源 | 区分协议必需设置、数据估计、方法默认和研究选择；说明实际取值及理由，不要求用户填写专业参数 |
| 可执行配置 | 仅把已支持的选择映射为当前版本的原生字段；不支持的步骤另行交接，不虚构开关 |
| 阈值复核 | 默认值先评估适用性；依据质控、对照及敏感性检查调整，不能按显著结果数量调参 |

| 资料 | 使用时机 |
|---|---|
| [参数模式.json](references/参数模式.json) | 编写 params.json 时核对字段、类型、枚举及条件约束 |

仅在已授权且配置齐备时运行。

```bash
nextflow run nf-core/circdna -r 8e0e14c84f90c94d975c2bac6bde8e5a1d5bc8ab -params-file params.json
```

模式文件的许可见 [LICENSE](LICENSE)。

## 质控与解释

检查跨断点读段、重复、线性扩增、比对歧义和实验背景，避免仅凭高覆盖认定闭环。

交付环状 DNA 候选及证据；ecDNA 结构和功能需要进一步实验/结构验证，不能将所有候选视为癌症驱动。
