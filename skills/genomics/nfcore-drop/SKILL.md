# 罕见病RNA异常表达与剪接筛查（nf-core/drop）

## 识别数据与研究目标

从交付文件与报告中识别适用的 RNA-seq/比对或计数数据、参考队列、组织信息、基因型和样本元数据，明确可用于异常检测的背景。

## 方法选择

按本版本支持的异常表达、剪接或单等位表达模块建立参考分布，防止把组织差异与技术批次误作异常。

先核对 [版本约定](references/流程约定.json)。

| 核对项 | 固定范围 |
|---|---|
| 上游版本 | `1.0.0`；`20388350d242746f8e799b28c3ae80421627b077` |
| 上游维护 | 未归档；使用这里固定的源码，不自动跟随新版本 |
| 本地运行 | 未进行真实分析运行；不能据本 Skill 文件声称实跑通过 |
| 引擎声明 | `!>=25.10.0`；还需核验 Java、容器和 profile |

## 根据数据确定参数

按组织、批次、参考样本数量及表达分布选择背景和异常模型；低覆盖与缺少可比队列限制检出能力，不能用任意健康组织补齐参考数量。

| 决策与配置 | 处理要求 |
|---|---|
| 事实与缺口 | 先读现有文件和报告；不能据文件名猜实验类型、参考或样本关系；只补问无法核实且会改变分析的背景 |
| 参数来源 | 区分协议必需设置、数据估计、方法默认和研究选择；说明实际取值及理由，不要求用户填写专业参数 |
| 可执行配置 | 仅把已支持的选择映射为当前版本的原生字段；不支持的步骤另行交接，不虚构开关 |
| 阈值复核 | 默认值先评估适用性；依据质控、对照及敏感性检查调整，不能按显著结果数量调参 |

| 资料 | 使用时机 |
|---|---|
| [参数模式.json](references/参数模式.json) | 编写 params.json 时核对字段、类型、枚举及条件约束 |
| [输入模式-1.json](references/输入模式-1.json) | 准备 ae_genes_to_test、as_genes_to_test 对应的样本表或输入文件时读取 |

仅在已授权且配置齐备时运行。

```bash
nextflow run nf-core/drop -r 20388350d242746f8e799b28c3ae80421627b077 -params-file params.json
```

模式文件的许可见 [LICENSE](LICENSE)。

## 质控与解释

检查覆盖、队列大小、隐藏混杂、样本离群及多重检验，审查异常事件的读段或计数支持。

交付 RNA 异常候选及证据；异常不直接构成致病诊断，需结合 DNA、表型和专业复核。
