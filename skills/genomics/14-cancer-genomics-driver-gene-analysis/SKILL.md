# 体细胞变异临床解读与驱动基因分析

1. 核对肿瘤类型、分期、治疗线、样本时间、变异表示和肿瘤纯度。
2. 区分已知热点、功能域、抑癌基因失活和可能乘客变异，结合疾病特异背景。
3. 收集指南、监管批准、临床试验、队列和功能证据，按肿瘤类型与证据等级排序。
4. 明确生物标志物适用的药物、线别、联合方案、耐药方向和地区限制。
5. 输出驱动判断、证据分级、可行动性、冲突和更新时间。

本Skill不直接开具治疗方案；临床决策需由肿瘤多学科团队结合患者情况完成。
