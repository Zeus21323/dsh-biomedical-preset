# cfDNA 片段组学分析

1. 核对双端测序、建库方式、片段选择、批次、测序深度和比对过滤。
2. 统一去重复、插入片段计算和可比区域，排除低质量、异常长和黑名单片段。
3. 提取长度谱、短长比、末端基序、断裂位点或核小体特征，并控制GC和覆盖偏倚。
4. 预测建模按患者划分训练验证，所有标准化和特征选择仅在训练集完成。
5. 输出特征矩阵、批次诊断、模型性能与外部验证需求。

片段特征高度依赖前分析和建库流程；跨平台模型未经校准不可直接迁移。
