# 基因组两两比对与共线性检查（nf-core/pairgenomealign）

## 识别数据与研究目标

从交付文件与报告中识别一个目标组装和待比较组装清单，核对物种、组装版本及序列命名。

## 方法选择

使用该版本的 LAST 比对流程比较 query 与 target，明确重复序列处理和方向性；不同参考方向的结果不能无条件互换。

先核对 [版本约定](references/流程约定.json)。

| 核对项 | 固定范围 |
|---|---|
| 上游版本 | `3.0.4`；`8ee09a1cdc920fc90cd62358952045e5019e1fe0` |
| 上游维护 | 未归档；使用这里固定的源码，不自动跟随新版本 |
| 本地运行 | 未进行真实分析运行；不能据本 Skill 文件声称实跑通过 |
| 引擎声明 | `!>=26.04.0`；还需核验 Java、容器和 profile |

## 根据数据确定参数

按物种距离、重复比例和目标结构尺度选择比对敏感度与重复处理；抽查多重匹配和断裂区域，判断差异来自组装还是生物变化。

| 决策与配置 | 处理要求 |
|---|---|
| 事实与缺口 | 先读现有文件和报告；不能据文件名猜实验类型、参考或样本关系；只补问无法核实且会改变分析的背景 |
| 参数来源 | 区分协议必需设置、数据估计、方法默认和研究选择；说明实际取值及理由，不要求用户填写专业参数 |
| 可执行配置 | 仅把已支持的选择映射为当前版本的原生字段；不支持的步骤另行交接，不虚构开关 |
| 阈值复核 | 默认值先评估适用性；依据质控、对照及敏感性检查调整，不能按显著结果数量调参 |

| 资料 | 使用时机 |
|---|---|
| [参数模式.json](references/参数模式.json) | 编写 params.json 时核对字段、类型、枚举及条件约束 |
| [输入模式-1.json](references/输入模式-1.json) | 准备 input 对应的样本表或输入文件时读取 |

仅在已授权且配置齐备时运行。

```bash
nextflow run nf-core/pairgenomealign -r 8ee09a1cdc920fc90cd62358952045e5019e1fe0 -params-file params.json
```

模式文件的许可见 [LICENSE](LICENSE)。

## 质控与解释

检查覆盖、重复匹配、倒位和断点，区分真实重排与组装碎片或重复导致的歧义。

交付两两比对与图形结果；共线性异常需要其他证据支持，不能仅靠比对图宣布结构变异。
