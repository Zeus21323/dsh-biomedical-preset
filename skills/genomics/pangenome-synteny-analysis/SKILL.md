# 泛基因组与共线性分析

只有质量和注释流程可比的组装才能直接比较。先统一基因/转录本选择、重复处理和同源判定，记录哪些差异可能来自组装或注释批次。

根据问题选择序列图泛基因组、基因家族 presence/absence，或基于基因顺序的共线性分析。核心/可变基因的阈值、一个样本含多个旁系同源时的规则必须明确。

共线性区块结合方向、基因顺序和覆盖解释；断裂处用原始组装图、覆盖或长读证据区分真实重排和错组装。参考基因组只作为坐标框架，不能让“参考缺失”自动等同其他样本获得。

输出泛基因组图或矩阵、核心/可变集合、共线区块、结构差异和质量敏感性分析。
