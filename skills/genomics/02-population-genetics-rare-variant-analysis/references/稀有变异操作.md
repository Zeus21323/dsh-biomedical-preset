# 从有害突变到聚合检验

检查WES/WGS、共同可调用区域、注释版本、亲缘、病例定义和祖源。智能体预先确定LoF/错义掩码、频率上限、基因边界、单变异最低质量及权重，不让用户挑一串阈值，也不能按显著基因数回改。记录携带者而不只是累积AC。

## 原生操作

1. 用规范化变异和固定注释建立variant→gene→mask及每mask变异清单；处理多转录本和重复计数。
2. 生成样本顺序一致的基因型矩阵Z与表型/协变量，保留剂量/缺失处理理由。
3. 小规模适配队列按[SKAT官方包](https://cran.r-project.org/package=SKAT)：SKAT_Null_Model建立模型，SKAT(Z,obj,method="SKATO")运行SKAT-O；burden或SKAT按研究预设选择，安装版手册核对权重与二分类校准。普通null model不自动处理复杂亲缘和极端不平衡。
4. 大规模/亲缘/不平衡按[SAIGE-GENE+原生示例](https://saigegit.github.io/SAIGE-doc/docs/set_example.html)建立null model、groupFile、annotation、MAF与各检验；group格式必须按实际版本，不能捏造通用TSV。可用nf-core-rarevariantburden时先核查其固定版本能力。
5. 多重校正覆盖实际基因×掩码×检验×性状，报告单变异驱动和去除最高影响变异的敏感性。

输出原始P、校正值、统计量、实际MAC/携带者和掩码；SKAT的P不带统一效应方向，不能画假OR森林。实际结果直接画基因层曼哈顿/QQ、掩码一致性、携带者计数图，PDF/SVG+600dpi PNG并附图表数据和背景/检验族图注。极低计数遵守披露约束。方法来源：[SKAT 2011](https://doi.org/10.1016/j.ajhg.2011.05.029)、[SAIGE-GENE+ 2022](https://doi.org/10.1038/s41588-022-01178-w)。聚合关联不证明所有成员变异致病。
