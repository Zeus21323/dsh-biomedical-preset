# 稀有变异关联分析

在分析前冻结基因/区域、功能掩码、频率阈值和注释版本。掩码可按 LoF、预测有害错义等分层，但不能查看关联结果后不断换定义。

## 选择检验

- 预计大多数变异同方向影响：burden。
- 允许方向和大小不同：SKAT。
- 无法提前判断：SKAT-O 或预先限定的组合。
- 存在亲缘、病例对照不平衡或极低 MAC：选能处理相应结构的混合模型/校准方法。

检查每个基因的有效 MAC、携带者数、单变异驱动、祖源与批次，并在基因/掩码范围内做多重校正。交付效应或统计量、携带者计数、掩码定义、校准图和去除单个高影响变异后的敏感性结果。

## 识别、执行与自动交付

“测了外显子怎么找病因”“这个基因患者突变更多吗”先识别研究单位、家系、对照与注释。读[掩码到结果的操作](references/稀有变异操作.md)，由智能体选择固定掩码及方法。结果后直接生成基因层QQ/曼哈顿、掩码对照和携带者汇总图；不把聚合检验P值画成有方向的效应。仅有候选基因列表不能执行负担检验。
