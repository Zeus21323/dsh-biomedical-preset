# PacBio全长转录本辅助基因组注释（nf-core/isoseq）

## 根据数据确定参数

从交付数据处于 subreads、CCS 还是 FLNC 阶段决定处理起点；结合引物、完整性和重复支持选择转录本整理规则，避免重复执行已完成步骤。

| 决策与配置 | 处理要求 |
|---|---|
| 事实与缺口 | 先读现有文件和报告；不能据文件名猜实验类型、参考或样本关系；只补问无法核实且会改变分析的背景 |
| 参数来源 | 区分协议必需设置、数据估计、方法默认和研究选择；说明实际取值及理由，不要求用户填写专业参数 |
| 可执行配置 | 仅把已支持的选择映射为当前版本的原生字段；不支持的步骤另行交接，不虚构开关 |
| 阈值复核 | 默认值先评估适用性；依据质控、对照及敏感性检查调整，不能按显著结果数量调参 |

| 资料 | 使用时机 |
|---|---|
| [参数模式.json](references/参数模式.json) | 编写 params.json 时核对字段、类型、枚举及条件约束 |

仅在已授权且配置齐备时运行。

```bash
nextflow run nf-core/isoseq -r c7536ab0e18a27460476d4e8557845950292f070 -params-file params.json
```

模式文件的许可见 [LICENSE](LICENSE)。

## 质控与解释

核查全长比例、嵌合、比对覆盖及剪接连接支持，区分转录本冗余与真实异构体。

交付该模式的全长转录本及基因组坐标注释；未检出转录本可能源于组织和表达限制，不能推断基因不存在。
