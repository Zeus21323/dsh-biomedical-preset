# 癌症公共队列分析

1. 明确癌种、队列、分子平台、样本类型和主要临床终点，避免混合原发与转移样本。
2. 记录研究标识、数据版本、下载日期和患者—样本映射，处理同一患者多样本。
3. 按可检测分母计算变异频率，表达和CNV分析处理平台、纯度及批次。
4. 生存或临床关联预先定义协变量与时间起点，校正多重比较并检查比例风险。
5. 输出队列纳排、数据字典、分析脚本和可复查结果。

公共队列是观察性数据；关联不代表预后独立性或治疗预测价值。
