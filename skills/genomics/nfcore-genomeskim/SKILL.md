# 浅测序流程版本核验与读段质控（nf-core/genomeskim）

## 识别数据与研究目标

确认用户希望做浅测序 QC、细胞器组装还是核基因组分析；当前固定开发源码实际只连接输入检查、FastQC 与 MultiQC。

## 方法选择

需要读段质量报告时核对原生样本表并使用已存在的 QC 路径；需要细胞器组装时明确本 revision 不提供该能力，转交适用的组装任务而非猜参数。

先核对 [版本约定](references/流程约定.json)。

| 核对项 | 固定范围 |
|---|---|
| 上游版本 | `dev`；`bb613a28fafa8d7dc5cc86b5a55fb5bdd2531a16` |
| 上游维护 | 开发版本；按当前代码实际实现的范围使用 |
| 本地运行 | 未进行真实分析运行；不能据本 Skill 文件声称实跑通过 |
| 已核查的实现边界 | 已检查 workflow：只有输入检查、FastQC、MultiQC 和版本记录；当前 revision 不提供细胞器组装。 |
| 引擎声明 | `!>=21.10.3`；还需核验 Java、容器和 profile |

## 根据数据确定参数

按实际读长、质量和污染线索选择 QC 汇总；本固定源码没有细胞器组装，任何组装深度或过滤设置都不能弥补缺失实现。

| 决策与配置 | 处理要求 |
|---|---|
| 事实与缺口 | 先读现有文件和报告；不能据文件名猜实验类型、参考或样本关系；只补问无法核实且会改变分析的背景 |
| 参数来源 | 区分协议必需设置、数据估计、方法默认和研究选择；说明实际取值及理由，不要求用户填写专业参数 |
| 可执行配置 | 仅把已支持的选择映射为当前版本的原生字段；不支持的步骤另行交接，不虚构开关 |
| 阈值复核 | 默认值先评估适用性；依据质控、对照及敏感性检查调整，不能按显著结果数量调参 |

| 资料 | 使用时机 |
|---|---|
| [参数模式.json](references/参数模式.json) | 编写 params.json 时核对字段、类型、枚举及条件约束 |
| [输入模式-1.json](references/输入模式-1.json) | 准备 input 对应的样本表或输入文件时读取 |

仅在已授权且配置齐备时运行。

```bash
nextflow run nf-core/genomeskim -r bb613a28fafa8d7dc5cc86b5a55fb5bdd2531a16 -params-file params.json
```

## 质控与解释

检查 FASTQ 完整性、质量分布和接头等实际 QC；源码中的软件版本汇总不构成细胞器组装完成证据。

交付读段 QC 或流程适配审查结论。上游介绍中的细胞器目标不能作为当前代码已生成细胞器序列的承诺。
