# 三联体与家系变异排序

1. 先核对亲缘、样本身份、性别、覆盖与基因型质量，确认家系结构可靠。
2. 按可能遗传模式筛选新发、纯合、复合杂合、X连锁、线粒体和嵌合候选。
3. 新发候选检查父母位点深度与等位平衡；复合杂合需要相位或家系证据确认反式。
4. 结合群体频率、基因机制、变异后果和HPO匹配排序，并保留非典型模型。
5. 输出候选表、遗传模式、读段证据、相位状态和验证计划。

家系阴性不能排除低水平嵌合、结构变异、重复扩增或难测区域；候选必须人工复核。
