# GWAS精细定位

准备区域汇总统计和与研究祖源、样本相匹配的 LD。变异顺序、效应等位基因、频率和坐标必须逐项协调，回文或不一致位点先解决再运行。

根据区域是否可能含多个信号选择 SuSiE、FINEMAP 等模型；先做条件分析或使用多因果模型，不能把一个宽区域强行假设为单因果。记录最大因果数、先验和 credible set 覆盖概率。

检查 LD 矩阵正定性、样本重叠、区域边界和不同 LD/先验下 PIP 稳定性。交付可信集、PIP、LD 诊断、模型配置和功能注释。高 PIP 是在模型与候选集合下的概率，不是实验验证。

## 识别、执行与自动交付

“一大片位点到底验证谁”不要求用户先说精细定位。先检查区域结果和可用参考，不让用户选择最大因果数；依据问题提出配置与理由。需要计算时读[精细定位操作](references/精细定位操作.md)，调用 `scripts/run_finemapping.R`；结果后直接产出区域PIP、可信集图和图注。文档中的FINEMAP是官方命令分支，不是脚本里的虚构选项。源码、数据和结果分离；不匹配的LD先停，不为缩小可信集调整参数。

出图时核验svglite可用，以保留SVG文字；现有PDF/PNG同时交付。GWAS精细定位图的科学参考线保留，背景主次网格默认关闭；在仓库外检查最终图件并提供三格式链接，不能将导出失败描述为完成。
