# 基因组结构与功能注释

输入组装应先完成污染和冗余检查。根据物种准备重复库、同物种转录证据、近缘蛋白和必要的 RNA-seq 比对。

## 注释顺序

1. 建立并屏蔽重复序列，同时保留重复分类结果。
2. 整合从头预测、转录本和同源证据生成基因模型。
3. 识别 tRNA、rRNA 和其他非编码 RNA。
4. 用蛋白域、同源、GO 和通路数据库注释功能；原始证据与综合名称分开保存。
5. 稳定化 gene/transcript/protein ID，并验证 GFF3 父子关系和 CDS phase。

用 BUSCO、转录支持率、完整 ORF、AED、基因长度和异常高拷贝评估质量。交付 GFF3/GTF、转录本/CDS/蛋白 FASTA、功能表和未支持模型清单。
