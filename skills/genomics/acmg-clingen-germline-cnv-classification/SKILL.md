# ACMG 与 ClinGen 胚系 CNV 分类

1. 规范化基因组版本、区间、类型和拷贝数，核对平台分辨率与断点不确定性。
2. 评估剂量敏感基因、已知区域、基因内容、群体频率和与患者表型的重叠。
3. 收集病例、分离、遗传来源与功能证据，严格区分缺失和重复机制。
4. 依据评分框架逐项计分并记录证据，边界情况提供敏感性分析。
5. 输出评分表、五级分类、关键基因、验证与家系检测建议。

CNV大小本身不是致病性的充分依据；嵌合、复杂重排和断点基因需额外分析。
