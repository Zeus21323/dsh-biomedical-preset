# 病毒整合位点候选检测（nf-core/viralintegration）

## 识别数据与研究目标

从交付文件与报告中识别测序数据、宿主和病毒参考、建库类型及样本信息，明确 DNA 或 RNA 信号的区别。

## 方法选择

按嵌合读段路径识别宿主—病毒候选断点，记录 split/spanning 支持、方向及重复过滤。

先核对 [版本约定](references/流程约定.json)。

| 核对项 | 固定范围 |
|---|---|
| 上游版本 | `0.1.1`；`70e558aaff836d43f5d662bf9c28414f4e6db642` |
| 上游维护 | 未归档；使用这里固定的源码，不自动跟随新版本 |
| 本地运行 | 未进行真实分析运行；不能据本 Skill 文件声称实跑通过 |
| 引擎声明 | `!>=23.04.0`；还需核验 Java、容器和 profile |

## 根据数据确定参数

根据 DNA/RNA 类型、split/spanning 支持、重复区域和对照背景选择候选条件；RNA 嵌合信号本身不足以确定基因组整合。

| 决策与配置 | 处理要求 |
|---|---|
| 事实与缺口 | 先读现有文件和报告；不能据文件名猜实验类型、参考或样本关系；只补问无法核实且会改变分析的背景 |
| 参数来源 | 区分协议必需设置、数据估计、方法默认和研究选择；说明实际取值及理由，不要求用户填写专业参数 |
| 可执行配置 | 仅把已支持的选择映射为当前版本的原生字段；不支持的步骤另行交接，不虚构开关 |
| 阈值复核 | 默认值先评估适用性；依据质控、对照及敏感性检查调整，不能按显著结果数量调参 |

| 资料 | 使用时机 |
|---|---|
| [参数模式.json](references/参数模式.json) | 编写 params.json 时核对字段、类型、枚举及条件约束 |

仅在已授权且配置齐备时运行。

```bash
nextflow run nf-core/viralintegration -r 70e558aaff836d43f5d662bf9c28414f4e6db642 -params-file params.json
```

模式文件的许可见 [LICENSE](LICENSE)。

## 质控与解释

排查文库嵌合、序列同源、重复区域和交叉污染，检查断点附近的独立支持。

交付整合候选与断点证据；RNA 嵌合或少数读段不能单独证明稳定 DNA 整合，候选需实验验证。
