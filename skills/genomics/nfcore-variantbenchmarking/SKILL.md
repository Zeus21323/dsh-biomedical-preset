# 变异检测准确性基准评估（nf-core/variantbenchmarking）

## 识别数据与研究目标

从交付文件与报告中识别待评估 callset、真值集、高置信区域、参考与变异类别，明确单样本或多样本及基准指标。

## 方法选择

统一 contig、表示和样本对应，在兼容区域内比较调用结果；按变异类型和困难区域分层，而非仅算总体一致率。

先核对 [版本约定](references/流程约定.json)。

| 核对项 | 固定范围 |
|---|---|
| 上游版本 | `1.5.0`；`8b21c01749c4447b285d242a198127736f3ffe51` |
| 上游维护 | 未归档；使用这里固定的源码，不自动跟随新版本 |
| 本地运行 | 未进行真实分析运行；不能据本 Skill 文件声称实跑通过 |
| 引擎声明 | `!>=25.04.0`；还需核验 Java、容器和 profile |

## 根据数据确定参数

匹配真值适用区域、变异类别和样本后设置比较范围；分层报告精确率与召回率，调参用开发集合，最终评价保留独立区域或样本。

| 决策与配置 | 处理要求 |
|---|---|
| 事实与缺口 | 先读现有文件和报告；不能据文件名猜实验类型、参考或样本关系；只补问无法核实且会改变分析的背景 |
| 参数来源 | 区分协议必需设置、数据估计、方法默认和研究选择；说明实际取值及理由，不要求用户填写专业参数 |
| 可执行配置 | 仅把已支持的选择映射为当前版本的原生字段；不支持的步骤另行交接，不虚构开关 |
| 阈值复核 | 默认值先评估适用性；依据质控、对照及敏感性检查调整，不能按显著结果数量调参 |

| 资料 | 使用时机 |
|---|---|
| [参数模式.json](references/参数模式.json) | 编写 params.json 时核对字段、类型、枚举及条件约束 |
| [输入模式-1.json](references/输入模式-1.json) | 准备 input 对应的样本表或输入文件时读取 |

仅在已授权且配置齐备时运行。

```bash
nextflow run nf-core/variantbenchmarking -r 8b21c01749c4447b285d242a198127736f3ffe51 -params-file params.json
```

模式文件的许可见 [LICENSE](LICENSE)。

## 质控与解释

检查真值覆盖限制、规范化影响和匹配策略，报告 precision、recall 及无法评价的区域。

交付基准统计、分层结果及错误候选；真值集未覆盖区域不能当作假阳性，结果不能无条件推广到其他平台和群体。
