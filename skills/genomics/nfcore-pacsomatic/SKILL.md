# PacBio肿瘤正常配对体细胞分析（nf-core/pacsomatic）

## 识别数据与研究目标

从交付文件与报告中识别配对 PacBio HiFi 数据、患者关系、参考、肿瘤纯度和测序深度，确认该版本支持的变异类别。

## 方法选择

按专属体细胞路径协调肿瘤与正常比对、调用及过滤，不把胚系 PacBio 模型直接当作体细胞检测器。

先核对 [版本约定](references/流程约定.json)。

| 核对项 | 固定范围 |
|---|---|
| 上游版本 | `dev`；`24c84cb371b0339c1d65a4de9451671945e19772` |
| 上游维护 | 开发版本；按当前代码实际实现的范围使用 |
| 本地运行 | 未进行真实分析运行；不能据本 Skill 文件声称实跑通过 |
| 引擎声明 | `!>=24.04.2`；还需核验 Java、容器和 profile |

## 根据数据确定参数

结合肿瘤纯度、正常污染、长读错误与深度确定候选质量条件，检查配对一致性；胚系模型和体细胞低频目标不能共用未经核验的过滤设置。

| 决策与配置 | 处理要求 |
|---|---|
| 事实与缺口 | 先读现有文件和报告；不能据文件名猜实验类型、参考或样本关系；只补问无法核实且会改变分析的背景 |
| 参数来源 | 区分协议必需设置、数据估计、方法默认和研究选择；说明实际取值及理由，不要求用户填写专业参数 |
| 可执行配置 | 仅把已支持的选择映射为当前版本的原生字段；不支持的步骤另行交接，不虚构开关 |
| 阈值复核 | 默认值先评估适用性；依据质控、对照及敏感性检查调整，不能按显著结果数量调参 |

| 资料 | 使用时机 |
|---|---|
| [参数模式.json](references/参数模式.json) | 编写 params.json 时核对字段、类型、枚举及条件约束 |
| [输入模式-1.json](references/输入模式-1.json) | 准备 input 对应的样本表或输入文件时读取 |

仅在已授权且配置齐备时运行。

```bash
nextflow run nf-core/pacsomatic -r 24c84cb371b0339c1d65a4de9451671945e19772 -params-file params.json
```

模式文件的许可见 [LICENSE](LICENSE)。

## 质控与解释

检查配对身份、污染、等位支持、拷贝数与正常样本覆盖，评估低纯度下的检出能力。

交付体细胞候选和技术证据；低频阴性不能排除肿瘤事件，临床解释需结合独立验证。
