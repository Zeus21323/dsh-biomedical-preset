# 癌症基因依赖性分析

1. 锁定DepMap发布版本、细胞系身份、癌种映射和所用CRISPR或药物数据层。
2. 检查基因效应评分方向、共同必需基因和批次校正，过滤低质量或错配细胞系。
3. 比较目标癌种与其他谱系的选择性，并用表达、突变、CNV或甲基化解释依赖背景。
4. 关联分析控制谱系结构、拷贝数伪影和多重检验，使用独立筛选或药理数据验证。
5. 输出效应分布、选择性、分子关联、稳健性和实验优先级。

细胞系依赖不等同于患者疗效或安全靶点；体内环境与正常组织毒性需另行验证。
