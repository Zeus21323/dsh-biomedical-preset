# 古DNA处理与损伤评估（nf-core/eager）

## 识别数据与研究目标

核对交付包中的古 DNA 测序数据、文库类型、UDG 处理、单双端、参考与污染检测目标；区分现代对照和古样本。

## 方法选择

根据片段长度和处理方式选择比对、重复处理、损伤评估及基因分型路径；避免对短片段沿用现代高深度 WGS 的默认判断。

先核对 [版本约定](references/流程约定.json)。

| 核对项 | 固定范围 |
|---|---|
| 上游版本 | `2.5.3`；`3f9d64ced5e287391bcd5517a0c40153a01268e5` |
| 上游维护 | 未归档；使用这里固定的源码，不自动跟随新版本 |
| 本地运行 | 未进行真实分析运行；不能据本 Skill 文件声称实跑通过 |
| 引擎声明 | `>=20.07.1`；还需核验 Java、容器和 profile |
| 语法兼容 | 原生入口含历史 process/channel 写法；先核验匹配的 Nextflow 版本 |

## 根据数据确定参数

由片段长度、UDG 处理和损伤模式调整比对与末端处理；低覆盖的不确定性保留到分型，现代高深度数据的过滤条件不能直接照搬。

| 决策与配置 | 处理要求 |
|---|---|
| 事实与缺口 | 先读现有文件和报告；不能据文件名猜实验类型、参考或样本关系；只补问无法核实且会改变分析的背景 |
| 参数来源 | 区分协议必需设置、数据估计、方法默认和研究选择；说明实际取值及理由，不要求用户填写专业参数 |
| 可执行配置 | 仅把已支持的选择映射为当前版本的原生字段；不支持的步骤另行交接，不虚构开关 |
| 阈值复核 | 默认值先评估适用性；依据质控、对照及敏感性检查调整，不能按显著结果数量调参 |

| 资料 | 使用时机 |
|---|---|
| [参数模式.json](references/参数模式.json) | 编写 params.json 时核对字段、类型、枚举及条件约束 |

仅在已授权且配置齐备时运行。

```bash
nextflow run nf-core/eager -r 3f9d64ced5e287391bcd5517a0c40153a01268e5 -params-file params.json
```

模式文件的许可见 [LICENSE](LICENSE)。

## 质控与解释

关注末端损伤、内源比例、污染、重复率和覆盖，明确损伤修剪与重标定对后续结论的影响。

交付读段/比对、古 DNA 真实性相关指标和所选分析产物；群体历史结论仍依赖取样、覆盖与相应统计模型。
