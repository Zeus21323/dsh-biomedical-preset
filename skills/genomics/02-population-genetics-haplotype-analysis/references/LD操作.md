# 先明确LD产物的用途

工具去相关/区域着色常用r²；精细定位/相关工具MR需要带符号r且与效应编码一致；D′与相位单倍型是另一对象。LD参考明确build、祖源、样本数、平台和位点集合，不默认欧洲面板。

[PLINK2 LD官方](https://www.cog-genomics.org/plink/2.0/ld)核对安装版相位/非相位计算选项；旧版PLINK命令不能盲用到PLINK2。可用PLINK1.9 --r square gz生成其支持的矩阵，但必须同时导出计算时实际等位基因与SNP顺序，再按效应方向对行列同步翻转。clumping用P阈值、窗口、r²与匹配参考，保留未在面板中的工具，而不是静默丢失。代理检索额外记录相位与原/代理等位基因。

已整理矩阵TSV首列SNP、其余列名为SNP，行列完全相同；stats.tsv需同顺序SNP。运行：
`python scripts/check_ld.py --matrix ld.tsv --stats stats.tsv --out ld_review_new`
需要numpy，检查有限、对称、对角、范围、PSD与顺序，保存诊断；它不能检测所有链错误，仍需效应等位基因与参考审计，不自动修复矩阵。

真实矩阵直接用发散色带[-1,1]画带符号r热图，r²采用[0,1]并明确标签；大区域按信号分面，不让密集标签重叠。保存PDF/SVG、高清PNG、变异顺序与底层矩阵。需要单倍型频率时先核查相位，再使用相应软件；未相位数据不得编造确定单倍型。产物交给精细定位/共定位时附完整参考记录。
