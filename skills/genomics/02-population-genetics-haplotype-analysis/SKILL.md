# 连锁不平衡与单倍型分析

LD 依赖群体、样本量和变异频率，必须在祖源相对一致的样本中计算。说明使用 r² 还是 D′、距离窗口、MAF 和缺失过滤；不能直接把另一祖源 LD 用作本队列事实。

需要单倍型时确认基因型是否已经相位。SHAPEIT、Beagle 等相位可利用家系或参考面板，输出应保留相位置信和 switch error 可评估信息。区块划分的方法与阈值也要报告。

核对变异顺序、等位基因方向、重复样本和长程 LD 区。交付 LD 矩阵/区块、相位 VCF、单倍型频率和适用群体，明确这些结果是否足以支持填充、精细定位或标签 SNP 选择。

## 识别、执行与自动交付

“这些SNP是不是一回事”先解释LD与独立因果信号不同，再读[LD操作](references/LD操作.md)。使用 `scripts/check_ld.py`检查已经计算的带符号矩阵与SNP顺序；该脚本不生成LD也不自动修复错配。实际结果直接输出顺序一致的LD热图、区域图与clumping清单，不用r²替代精细定位所需r。
