# 亚克隆拷贝数与全基因组加倍分析

1. 输入应包含肿瘤—正常读深、杂合位点BAF和经审核分段；核对参考版本、肿瘤纯度与取样时间。
2. 用ASCAT、FACETS、Sequenza或同类方法比较多个纯度—倍性候选解，不能只接受默认最优解。
3. 依据主要染色体臂的主等位拷贝数、突变多重性和模型规则判定肿瘤WGD，并报告阈值与置信度。
4. 对每个分段估计癌细胞比例，区分克隆与亚克隆CNV；用重采样或多工具检查低纯度样本的稳定性。
5. 输出纯度、倍性、WGD状态、亚克隆分段、候选解比较及其对HRD、VAF和克隆分析的影响。

这里的WGD指肿瘤细胞染色体组加倍，不是物种进化中的古多倍化；二者方法和输入完全不同。
