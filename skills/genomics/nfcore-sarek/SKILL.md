# 胚系与体细胞变异流程（nf-core/sarek）

## 识别数据与研究目标

确认 FASTQ/BAM/CRAM 等实际输入阶段、WGS/靶向模式、样本及患者关系、肿瘤/正常身份和参考资源。

## 方法选择

先选择 germline、tumor-only 或配对分析目标，再核对调用器兼容性、BQSR 与参考辅助文件；有家系或队列需求时明确是否包含相应联合分析。

先核对 [版本约定](references/流程约定.json)。

| 核对项 | 固定范围 |

## 根据数据确定参数

由 WGS/捕获设计、肿瘤正常关系、深度和研究目标选择调用模式；低频过滤结合分子或错误证据与覆盖评估，不能把常规胚系条件直接用于低纯度肿瘤。

| 决策与配置 | 处理要求 |
|---|---|
| 事实与缺口 | 先读现有文件和报告；不能据文件名猜实验类型、参考或样本关系；只补问无法核实且会改变分析的背景 |
| 参数来源 | 区分协议必需设置、数据估计、方法默认和研究选择；说明实际取值及理由，不要求用户填写专业参数 |
| 可执行配置 | 仅把已支持的选择映射为当前版本的原生字段；不支持的步骤另行交接，不虚构开关 |
| 阈值复核 | 默认值先评估适用性；依据质控、对照及敏感性检查调整，不能按显著结果数量调参 |

| 资料 | 使用时机 |
|---|---|
| [参数模式.json](references/参数模式.json) | 编写 params.json 时核对字段、类型、枚举及条件约束 |
| [输入模式-1.json](references/输入模式-1.json) | 准备 input、input_restart 对应的样本表或输入文件时读取 |
| [输入模式-2.json](references/输入模式-2.json) | 准备 snpsift_databases 对应的样本表或输入文件时读取 |

仅在已授权且配置齐备时运行。

```bash
nextflow run nf-core/sarek -r 8ccac7ad37b05dd792447763bf9671b719824587 -params-file params.json
```

模式文件的许可见 [LICENSE](LICENSE)。

## 质控与解释

检查样本身份、污染、覆盖与可调用区域，按 caller 的过滤语义审查 SNV/Indel 和其他实际产物，肿瘤样本另考虑纯度和 FFPE。

交付比对/变异结果、过滤与 QC、模式及参考说明；检测结果不自动形成临床解释，阴性结果必须限定在可调用范围。
