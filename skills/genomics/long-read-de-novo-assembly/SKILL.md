# 长读长从头组装

根据平台、覆盖、倍性、杂合度和目标成品选择组装器。HiFi 的高准确读段和 ONT 的长度/误差特征需要不同参数，不能互换预设。

保留组装图，先判断是否需要单倍型分离、亲本信息或 Hi-C。ONT 组装安排与数据匹配的长读及必要短读抛光；HiFi 避免无依据的多轮抛光破坏真实变异。去冗余前区分 haplotig 与真实重复/拷贝。

评价 k-mer QV、完整度、错组装、重复单倍型、污染和读段回贴，而不只看 contig N50。染色体 scaffold 还要检查方向、连接和接触图。

交付 FASTA/GFA、单倍型状态、抛光记录、质量矩阵和未解决区域。
