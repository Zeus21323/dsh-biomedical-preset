# VCF质量统计与样本一致性

先按样本和位点分别统计调用率、深度、基因型质量、等位平衡、Ti/Tv、杂合度和单例数。阈值要结合 WGS、WES、面板或填充剂量，不能跨数据类型照搬。

## 身份检查

利用指纹位点、性染色体、亲缘和重复样本核对样本名、声明性别和家系关系。污染或样本混合通常同时影响杂合度、等位平衡和亲缘，不依据单个指标下结论。

按测序批次、中心、捕获 kit 和祖源查看分布，区分技术异常与真实群体差异。删除样本前保留证据和影响评估。

交付样本级、位点级 QC 表，标出可继续、需复核和应重做的对象，并说明每条判定使用的指标。
