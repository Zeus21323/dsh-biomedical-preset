# 液体活检检测性能验证

1. 明确预期用途、样本类型、目标变异或信号、报告范围和阳性阈值。
2. 设计跨VAF/浓度、DNA输入、变异类型和重复批次的稀释与重复实验。
3. 分别估计空白限、检出限、定量限、重复性、再现性和干扰因素。
4. 对分类模型报告受试者级灵敏度、特异度、校准、置信区间和预设亚组。
5. 输出验证设计、原始判定、失败模式、锁定阈值和变更控制要求。

不能用训练集或富集病例对照替代独立验证；分析有效性与临床有效性必须分开陈述。
