# 长读长基因组组装与scaffolding（nf-core/genomeassembler）

## 识别数据与研究目标

检查已有 ONT 或 PacBio HiFi reads、预期基因组大小、覆盖和倍性信息，辨明是否要求单倍型分相。

## 方法选择

选择适配测序类型的组装路径，按本版本支持的选项处理 scaffolding 与校正；流程定位于单倍体或未分相组装时不承诺双单倍型结果。

先核对 [版本约定](references/流程约定.json)。

| 核对项 | 固定范围 |
|---|---|
| 上游版本 | `1.1.0`；`ccf1b89898cb720f46a966029c3a60dbcc25b012` |
| 上游维护 | 未归档；使用这里固定的源码，不自动跟随新版本 |
| 本地运行 | 未进行真实分析运行；不能据本 Skill 文件声称实跑通过 |
| 引擎声明 | `!>=24.10.5`；还需核验 Java、容器和 profile |

## 根据数据确定参数

从读长、覆盖、基因组大小与倍性选择组装路线及修正强度；异常覆盖先排查污染和重复，要求分相时核验该路线能否交付。

| 决策与配置 | 处理要求 |
|---|---|
| 事实与缺口 | 先读现有文件和报告；不能据文件名猜实验类型、参考或样本关系；只补问无法核实且会改变分析的背景 |
| 参数来源 | 区分协议必需设置、数据估计、方法默认和研究选择；说明实际取值及理由，不要求用户填写专业参数 |
| 可执行配置 | 仅把已支持的选择映射为当前版本的原生字段；不支持的步骤另行交接，不虚构开关 |
| 阈值复核 | 默认值先评估适用性；依据质控、对照及敏感性检查调整，不能按显著结果数量调参 |

| 资料 | 使用时机 |
|---|---|
| [参数模式.json](references/参数模式.json) | 编写 params.json 时核对字段、类型、枚举及条件约束 |
| [输入模式-1.json](references/输入模式-1.json) | 准备 input 对应的样本表或输入文件时读取 |

仅在已授权且配置齐备时运行。

```bash
nextflow run nf-core/genomeassembler -r ccf1b89898cb720f46a966029c3a60dbcc25b012 -params-file params.json
```

模式文件的许可见 [LICENSE](LICENSE)。

## 质控与解释

同时报告连续性、完整性、污染与读段回贴覆盖，排查冗余 haplotig 和结构性错误。

交付组装序列、组装图或该模式实际产生的辅助文件及 QC；连续性提高不能替代染色体结构验证。
