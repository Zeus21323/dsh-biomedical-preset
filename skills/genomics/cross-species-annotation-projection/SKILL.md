# 跨物种基因注释投影

确认参考和目标确实足够近缘，并评估目标组装连续性。输入包括参考 FASTA/GFF3、目标 FASTA 和必要的蛋白/转录证据。

使用 Liftoff、miniprot 或同源比对时保留覆盖度、身份度、完整 CDS 和一对多状态。不能为追求“映射率”把拆分、融合或仅部分覆盖的模型直接当完整基因。

重点审查未投影基因、异常拷贝扩张、跨 contig 模型、内部终止和 CDS frame。共线性与转录证据可帮助区分真实缺失、组装断裂和投影失败。

交付目标 GFF3、映射统计、部分/重复/未映射清单及需从头注释的区域。远缘物种应转用证据整合的结构注释，而非继续放宽投影阈值。
