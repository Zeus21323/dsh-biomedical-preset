# 靶向测序分析

开始前取得面板版本、目标 BED/扩增子、引物或捕获方式、UMI 结构、样本类型和经验证的检测限。

UMI 必须在比对或共识流程要求的阶段提取，家族构建和错误校正规则需报告。扩增子数据要剪除/屏蔽引物，避免引物序列支持假变异。低频调用使用与样本类型匹配的背景错误模型和阳阴性对照。

逐目标检查原始深度、唯一分子深度、链与位置偏倚、UMI 家族大小和低覆盖。面板外、引物结合位点和低可比区域不能按常规灵敏度解释。

交付共识 BAM、变异结果、逐位点覆盖、对照表现、检测限口径和失败区域。
