# 基因组编码基因结构注释（nf-core/genomeannotator）

## 识别数据与研究目标

从交付文件与报告中识别待注释组装、物种信息及所需的转录/蛋白证据；核对 repeat masking、contig 命名与证据物种距离。

## 方法选择

依据上游支持的方法组织重复处理、基因结构预测和证据整合，区分从头模型与同源证据驱动模型。

先核对 [版本约定](references/流程约定.json)。

| 核对项 | 固定范围 |
|---|---|
| 上游版本 | `dev`；`d80105de179fec01765ad3c84ea26c9330e29fb0` |
| 上游维护 | 开发版本；按当前代码实际实现的范围使用 |
| 本地运行 | 未进行真实分析运行；不能据本 Skill 文件声称实跑通过 |
| 引擎声明 | `!>=21.10.3`；还需核验 Java、容器和 profile |

## 根据数据确定参数

根据物种、重复含量及转录和蛋白证据质量选择预测模型与证据权重；以完整性和异常基因结构复核，避免为增加基因数放宽所有证据门槛。

| 决策与配置 | 处理要求 |
|---|---|
| 事实与缺口 | 先读现有文件和报告；不能据文件名猜实验类型、参考或样本关系；只补问无法核实且会改变分析的背景 |
| 参数来源 | 区分协议必需设置、数据估计、方法默认和研究选择；说明实际取值及理由，不要求用户填写专业参数 |
| 可执行配置 | 仅把已支持的选择映射为当前版本的原生字段；不支持的步骤另行交接，不虚构开关 |
| 阈值复核 | 默认值先评估适用性；依据质控、对照及敏感性检查调整，不能按显著结果数量调参 |

| 资料 | 使用时机 |
|---|---|
| [参数模式.json](references/参数模式.json) | 编写 params.json 时核对字段、类型、枚举及条件约束 |
| [输入模式-1.json](references/输入模式-1.json) | 准备 assembly、references、rnaseq_samples 对应的样本表或输入文件时读取 |

仅在已授权且配置齐备时运行。

```bash
nextflow run nf-core/genomeannotator -r d80105de179fec01765ad3c84ea26c9330e29fb0 -params-file params.json
```

模式文件的许可见 [LICENSE](LICENSE)。

## 质控与解释

检查基因与转录本数、完整性、剪接结构和异常短蛋白，评估组装碎片化对注释的影响。

输出基因结构注释、蛋白/转录本序列与证据说明；结构预测不能自动视为实验确认的基因功能。
