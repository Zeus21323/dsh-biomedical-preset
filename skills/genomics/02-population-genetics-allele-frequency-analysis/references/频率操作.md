# 计数、分母与群体比较

统一build与REF/ALT，先区分等位基因频率、携带者比例和基因层负担。AN来自实际高质量可调用染色体，性染色体/PAR/缺失不简单样本数×2。病例与对照在相同可调用区域和QC条件比较；亲缘、批次、祖源与测序深度不一致需解释或调整。

在用户目录按[PLINK2频率](https://www.cog-genomics.org/plink/2.0/basic_stats)用--freq counts输出实际AC/AN；分层使用明确样本清单分别运行并保留重叠关系。外部gnomAD等先核验版本、群体、PASS及覆盖，数据库中未出现不能等于真零频率。置信区间按合适模型：独立染色体二项近似有条件限制，亲缘/复杂抽样不能照搬。

实际结果直接画分层AF及区间、计数标签或稀有范围对数图（零值单独标注），携带比例另画，不混分母。PDF/SVG、600dpi PNG和AC/AN/区间/群体定义表一起交付；图注说明置信水平、方法与可调用区域。极小亚组保护携带者隐私；“只在病例出现”先看对照规模和检出能力，不直接称为疾病特异变异。
