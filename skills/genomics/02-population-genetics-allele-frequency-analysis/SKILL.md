# 群体等位基因频率分析

先统一参考构建、REF/ALT 表示和群体纳入规则。频率分母是实际获得高质量基因型的染色体数，不是简单的样本数乘二；性染色体和缺失基因型需单独处理。

按群体报告 AC、AN、AF，必要时给二项分布置信区间。比较队列时检查近亲、祖源、测序平台、可调用区域和质量过滤是否一致。极小群体中的一个携带者应同时显示计数，避免只报看似精确的百分比。

外部数据库查询先规范化变异并记录版本、总体/亚群和过滤状态。交付分层频率表、携带者/染色体数、质量限制和数据库对照；数据库中未出现不等于变异在群体中不存在。

## 识别、执行与自动交付

“这个突变是不是我们患者特有”先核查可调用区域、样本量、祖源与数据库覆盖，不能以未检出证明特异。读[频率操作](references/频率操作.md)，直接生成带计数与区间的分层频率图，并区别等位基因频率和携带者比例。个体信息去标识，极小分层避免对外泄露携带者身份。
