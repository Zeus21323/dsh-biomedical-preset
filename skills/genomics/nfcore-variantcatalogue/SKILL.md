# 群体变异目录与频率汇总（nf-core/variantcatalogue）

## 识别数据与研究目标

从交付文件与报告中识别全基因组样本集合、变异或原生所需输入、参考与群体分组，明确样本纳入和频率计算口径。

## 方法选择

按统一表示与过滤规则组织变异目录，记录位点可调用样本数、等位基因数和多等位位点拆分策略。

先核对 [版本约定](references/流程约定.json)。

| 核对项 | 固定范围 |
|---|---|
| 上游版本 | `dev`；`0073caae753b27b1999aa56a029c0bfa722d21a7` |
| 上游维护 | 开发版本；按当前代码实际实现的范围使用 |
| 本地运行 | 未进行真实分析运行；不能据本 Skill 文件声称实跑通过 |
| 引擎声明 | `!>=22.10.1`；还需核验 Java、容器和 profile |

## 根据数据确定参数

依据样本可调用范围和倍性设置计数分母，按群体和位点质量分层汇总；缺失基因型不计为参考等位，低样本量频率保留不确定性。

| 决策与配置 | 处理要求 |
|---|---|
| 事实与缺口 | 先读现有文件和报告；不能据文件名猜实验类型、参考或样本关系；只补问无法核实且会改变分析的背景 |
| 参数来源 | 区分协议必需设置、数据估计、方法默认和研究选择；说明实际取值及理由，不要求用户填写专业参数 |
| 可执行配置 | 仅把已支持的选择映射为当前版本的原生字段；不支持的步骤另行交接，不虚构开关 |
| 阈值复核 | 默认值先评估适用性；依据质控、对照及敏感性检查调整，不能按显著结果数量调参 |

| 资料 | 使用时机 |
|---|---|
| [参数模式.json](references/参数模式.json) | 编写 params.json 时核对字段、类型、枚举及条件约束 |
| [输入模式-1.json](references/输入模式-1.json) | 准备 input 对应的样本表或输入文件时读取 |

仅在已授权且配置齐备时运行。

```bash
nextflow run nf-core/variantcatalogue -r 0073caae753b27b1999aa56a029c0bfa722d21a7 -params-file params.json
```

模式文件的许可见 [LICENSE](LICENSE)。

## 质控与解释

检查重复个体、亲缘、缺失、批次及群体构成，区分零计数与没有检测机会。

交付变异及频率目录、样本范围和质控；目录频率不能不加条件地作为其他人群或平台的参考。
