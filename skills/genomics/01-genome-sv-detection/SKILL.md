# 结构变异检测

先确定数据是短读长还是长读长、样本是胚系还是肿瘤、关注的最小事件和是否有匹配对照。

短读长调用应综合 discordant pair、split read、read depth 和局部组装；长读长使用跨断点读段和局部组装。多个调用器不能简单拼接，合并规则需考虑 SV 类型、断点距离、方向和重叠比例。

对关键候选查看支持读段、覆盖变化、断点微同源、重复/着丝粒区域和等位比例。队列分析应统一事件后重新基因分型，而不是只按坐标取交集。

交付标准化 SV VCF、证据字段、合并规则、浏览器视图和低可信区域。复杂重排应保留组成事件及其连接关系。
