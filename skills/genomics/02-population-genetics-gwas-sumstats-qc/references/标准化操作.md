# 标准化操作

## 检查、配置与执行

先看文件头/元数据，确定分隔符、列名、效应尺度、build、祖源和全量/区域/显著子集。智能体填写assets/sumstats.config.json中的input/output/columns/metadata；列映射是标准列名到原始列名。所有路径相对配置目录，null必须按真实资料填写。脚本标准库实现，支持CSV/TSV及gzip；不依赖网络，不修改原文件。

在本Skill目录：
`python scripts/prepare_sumstats.py --config sumstats.config.json --dry-run`
查看路径和元数据后：
`python scripts/prepare_sumstats.py --config sumstats.config.json`

必需映射CHR POS SNP EA NEA BETA SE P；可选EAF N INFO。metadata需build、ancestry、trait、effect_scale和coverage，effect_scale为beta/log_odds/odds_ratio，coverage为full/region/significant_only。odds_ratio必须确认se_scale为log_odds才取log，不能对SE一起取log。过滤只应用配置中的明确值，不自动用统一MAF/INFO。P=0拒绝并提示保留MLOG10P后使用合适工具，不能替换为1e-300声称原值。SNP重复及多等位重复是冲突，不自动挑最显著一行。

输出标准sumstats.tsv.gz、excluded.tsv、metadata.json和qc.json。需要参考序列验证、liftover、indel规范化和链协调时使用[GWASLab](https://cloufield.github.io/gwaslab/)或相应官方工具。此轻量脚本仅支持双等位单碱基SNP；合法indel、其他染色体表示和P下溢均阻断整个步骤，不能当低质量变异丢掉后继续。此时用支持原始表示/MLOG10P的工具输出下游所需产物，不能声称先规范indel便可输入本脚本。FAILED标记目录中的表是未完成结果。此脚本不把REF等同于EA，也不证明GWAS因果有效。

## 图与交接

从qc.json画处理流程及排除原因柱图；从全量标准表画N、EAF、INFO分布。用有实际数据的Matplotlib/ggplot2操作输出PDF/SVG和600dpi PNG，长标签使用横向或分面，保存计数/分布数据与图注。可用“科研可视化与报告”时复用其已安装入口；不可用时按本规范在用户工作区生成项目绘图脚本，不能引用不存在的共享工具。

交接说明保留变异数、单位、覆盖类型、缺失字段与变换。全量结果可用于QQ/LDSC等；significant_only不能称为full。字段不够时明确哪些分支不能做，不能用格式检查通过代替科学审查。
