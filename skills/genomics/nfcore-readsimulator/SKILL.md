# 测序读段模拟与基准数据构建（nf-core/readsimulator）

## 识别数据与研究目标

从任务与样本背景判断参考、测序类型、深度/读长分布、错误模型和随机种子，明确模拟 amplicon、捕获、宏基因组或 WGS 的哪类实验。

## 方法选择

按可用模拟器与场景生成数据，保留真值和生成参数；混合群落需明确每个成员的丰度和基因组来源。

## 根据数据确定参数

以目标实验的读长、错误与丰度分布设计模拟条件和重复种子；覆盖与变异频率覆盖预期应用范围，避免只在偏向某调用器的模型上比较性能。

| 决策与配置 | 处理要求 |
|---|---|
| 事实与缺口 | 先读现有文件和报告；不能据文件名猜实验类型、参考或样本关系；只补问无法核实且会改变分析的背景 |
| 参数来源 | 区分协议必需设置、数据估计、方法默认和研究选择；说明实际取值及理由，不要求用户填写专业参数 |
| 可执行配置 | 仅把已支持的选择映射为当前版本的原生字段；不支持的步骤另行交接，不虚构开关 |
| 阈值复核 | 默认值先评估适用性；依据质控、对照及敏感性检查调整，不能按显著结果数量调参 |

| 资料 | 使用时机 |

nextflow run nf-core/readsimulator -r 0e8805ddbcd0e0fdcdc62105d59c3f29dd985a64 -params-file params.json

## 质控与解释

核对读数、覆盖、错误谱、配对关系及真值可追踪性，避免将模拟器生成假设当作真实仪器分布。

交付合成 reads、真值和配置；模拟结果适用于明确的假设范围，不能替代真实样本的性能验证。
