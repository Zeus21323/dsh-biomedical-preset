# BAM与CRAM读段恢复及质控（nf-core/bamtofastq）

## 识别数据与研究目标

从交付文件与报告中识别 BAM/CRAM、配对模式、read group 与样本映射；CRAM 还需核验解码参考是否匹配。

## 方法选择

确认需要恢复哪些主比对、未比对或孤立读段，按版本选项保持 mate 配对与样本边界；预估解压后的磁盘空间。

先核对 [版本约定](references/流程约定.json)。

| 核对项 | 固定范围 |
|---|---|
| 上游版本 | `2.2.1`；`8a295860c0c9221337dec7f2620709a47cea254d` |
| 上游维护 | 未归档；使用这里固定的源码，不自动跟随新版本 |
| 本地运行 | 未进行真实分析运行；不能据本 Skill 文件声称实跑通过 |
| 引擎声明 | `!>=25.10.4`；还需核验 Java、容器和 profile |

## 根据数据确定参数

由 read group、配对标记和目标重分析范围决定保留的读段类别及孤立 mate 处理；CRAM 参考先匹配，输出大小由数据实际规模估算。

| 决策与配置 | 处理要求 |
|---|---|
| 事实与缺口 | 先读现有文件和报告；不能据文件名猜实验类型、参考或样本关系；只补问无法核实且会改变分析的背景 |
| 参数来源 | 区分协议必需设置、数据估计、方法默认和研究选择；说明实际取值及理由，不要求用户填写专业参数 |
| 可执行配置 | 仅把已支持的选择映射为当前版本的原生字段；不支持的步骤另行交接，不虚构开关 |
| 阈值复核 | 默认值先评估适用性；依据质控、对照及敏感性检查调整，不能按显著结果数量调参 |

| 资料 | 使用时机 |
|---|---|
| [参数模式.json](references/参数模式.json) | 编写 params.json 时核对字段、类型、枚举及条件约束 |
| [输入模式-1.json](references/输入模式-1.json) | 准备 input 对应的样本表或输入文件时读取 |

仅在已授权且配置齐备时运行。

```bash
nextflow run nf-core/bamtofastq -r 8a295860c0c9221337dec7f2620709a47cea254d -params-file params.json
```

模式文件的许可见 [LICENSE](LICENSE)。

## 质控与解释

比较输入与输出 read 数，核查 read name、配对顺序、重复读段和质量编码，解释过滤引起的数量变化。

交付 FASTQ 与转换质控；已在 BAM 中丢弃、硬剪切或修改的信息不能保证恢复为测序仪原始文件。
