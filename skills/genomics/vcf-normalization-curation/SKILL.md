# VCF规范化与整理

同一个生物变异可以有多种文本表示。开始前确认 VCF 与参考 FASTA 的构建、contig 名和 REF 碱基一致。

按用途决定是否拆分多等位位点；左对齐并最简化 Indel 时保留原记录标识，便于追查注释和样本基因型变化。排序、bgzip 压缩和索引后检查 header 中 INFO/FORMAT 定义及样本列。

合并前先说明操作语义：

- 同一批位点增加样本列：横向合并，要求位点表示一致。
- 多个调用集取并集：需要处理相同位点的 FILTER、INFO 和 genotype 冲突。
- 比较两个结果：先规范化，再按等位基因而非位置匹配。

输出规范化 VCF、被拆分/丢弃/REF 不匹配的记录、前后位点与基因型对账，以及合并规则。禁止用文本拼接合并 VCF。
