# Results, Tables, And Figures

## Results Paragraphs

Use this sequence when applicable:

```text
question -> minimal method context -> exact finding -> uncertainty or qualification
-> interpretation -> table/figure reference
```

Report direction, magnitude, unit, comparison, sample/corpus, statistic, and uncertainty when available. State missing uncertainty or sample information rather than inventing it. Separate null results from equivalence and interpretation from direct tests.

## Object Registry

Record for every table and figure:

- stable ID and caption;
- scientific question and mapped claim IDs;
- source files and producing script;
- transformations, filters, units, aggregation, sample size, and version;
- statistical test and correction method when applicable;
- output path and editable source path;
- limitations and missing cells.

## Table Rules

- Use one analytical question or tightly related specification family per table.
- Define units, metric direction, abbreviations, sample, uncertainty, tests, and notes.
- Keep symbols and construct names identical to their definitions.
- Do not hide missing baselines, null results, dropped samples, or failed models.
- Make each prose claim resolve to a table and column when columnar estimates support it.
- Match fixed-effect, control, clustering, and sample rows to the actual model.

## Figure Rules

- Generate quantitative figures from saved data or results with reproducible scripts.
- Use image generation only for non-empirical illustrative art explicitly requested by the user, never for quantitative axes or scientific evidence.
- Group multi-panel figures by the claim they establish, not by chart type.
- Preserve readable labels, units, legends, uncertainty, color accessibility, and venue dimensions.
- Create a preview before large publication outputs and verify embedded media in final DOCX.
- Give legends enough information to understand panels, samples, tests, corrections, and abbreviations.

## Interpretation Checks

- Recalculate percentages, percentage points, ratios, odds, speedups, and economic magnitude.
- Check denominators and comparison direction.
- Inspect abnormal zeros, signs, fit statistics, confidence intervals, or sample changes before writing explanations.
- Report alternative explanations and scope limitations.
- Do not infer causality, prevalence, generalization, biological mechanism, or practical superiority from evidence that establishes only association or a narrow benchmark result.
