# 生物网络可视化

1. 先确定图要回答的问题，只保留支持该问题的节点、边和属性。
2. 节点大小、颜色、形状与边宽分别绑定一种明确变量，提供图例和缺失值样式。
3. 大网络先按社区或层级汇总，再提供可追溯的局部子图，避免“毛线团”图。
4. 布局固定随机种子，标签只显示重点节点；统计显著性与效应方向不要共用一种视觉编码。
5. 输出节点表、边表、样式映射、布局参数和矢量图。

图形用于呈现而不是替代统计检验；删边和筛节点规则必须在图注中说明。
