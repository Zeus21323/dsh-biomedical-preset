# GSEA 与样本级基因集评分

1. 先分清问题：比较条件的通路富集用GSEA；需要每个样本的通路活动分数时用GSVA或ssGSEA。过度表示分析属于“通路与功能富集分析”，不在这里混用。
2. GSEA使用带方向、全量且可比较的排序统计量，去除重复标识并记录聚合规则；根据样本量与设计选择表型置换或基因集置换。
3. GSVA/ssGSEA使用经过适当归一化的表达矩阵，在同一基因宇宙和同一基因集版本内计算样本级相对分数，再按样本设计或受试者层级建模。
4. 固定MSigDB或自定义基因集的版本、物种、标识映射和大小范围；报告映射损失，并整理高度重叠的通路。
5. GSEA报告NES、FDR、leading-edge基因和方向；样本级评分报告算法、参数、分数矩阵、组间效应和多重校正。
6. 检查核心结果是否由极少数基因、批次、组成变化或单一染色体区域驱动，并用替代排序量或基因集版本做敏感性分析。

正负NES必须按排序统计量方向解释。GSVA/ssGSEA分数是队列内相对量，不经校准不能跨不相容平台或队列直接比较，也不能把每个分数当成新的生物学重复。
