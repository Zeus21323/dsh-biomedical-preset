# 宏基因组来源MHC表位预测（nf-core/metapep）

## 识别数据与研究目标

从交付文件与报告中识别蛋白、分类单元、组装或 bins 中一种支持输入及 HLA/MHC 等位基因，明确肽段生成规则。

## 方法选择

根据输入路径获取/预测蛋白并生成肽，使用本版本支持的 SYFPEITHI、MHCflurry 或 MHCnuggets 等方法评分。

先核对 [版本约定](references/流程约定.json)。

| 核对项 | 固定范围 |
|---|---|
| 上游版本 | `1.0.0`；`84feafc9476978c2a1b84849871a553cffd9762a` |
| 上游维护 | 未归档；使用这里固定的源码，不自动跟随新版本 |
| 本地运行 | 未进行真实分析运行；不能据本 Skill 文件声称实跑通过 |
| 引擎声明 | `!>=24.04.2`；还需核验 Java、容器和 profile |

## 根据数据确定参数

依据输入完整性、物种注释和 HLA 类别确定翻译及肽长范围，再按预测器语义筛选；分数尺度不同不能直接排序混合，候选不等于实验免疫原性。

| 决策与配置 | 处理要求 |
|---|---|
| 事实与缺口 | 先读现有文件和报告；不能据文件名猜实验类型、参考或样本关系；只补问无法核实且会改变分析的背景 |
| 参数来源 | 区分协议必需设置、数据估计、方法默认和研究选择；说明实际取值及理由，不要求用户填写专业参数 |
| 可执行配置 | 仅把已支持的选择映射为当前版本的原生字段；不支持的步骤另行交接，不虚构开关 |
| 阈值复核 | 默认值先评估适用性；依据质控、对照及敏感性检查调整，不能按显著结果数量调参 |

## 质控与解释

追踪微生物来源、蛋白预测质量、等位基因适用范围和重复肽，检查数据库缺失导致的偏倚。

交付宏基因组来源的表位候选与亲和预测；候选不证明体内表达、呈递或免疫反应。
