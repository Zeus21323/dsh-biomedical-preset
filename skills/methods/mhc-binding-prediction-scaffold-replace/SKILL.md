# 肽—MHC 结合与呈递预测

1. 核对HLA命名、MHC类别、肽长、物种和蛋白/突变序列，生成野生型与突变型配对肽。
2. 使用支持相应等位基因的方法，记录模型版本与训练覆盖，优先采用百分位而非跨等位基因原始分数比较。
3. 结合结合力、加工、表达、突变特异性和正常组织表达排序。
4. 对等位基因覆盖差或结果不一致的候选标记低置信，并保留多长度、多窗口结果。
5. 输出肽、HLA、分数、百分位、证据分解和实验验证集合。

预测结合不等于细胞表面呈递，更不等于能诱导有效T细胞反应。
