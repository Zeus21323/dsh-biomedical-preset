# 申报书逻辑诊断

## 输入

接受文件路径或粘贴文本。先读取完整输入；不足约 100 个汉字且缺少上下文时，说明无法可靠判断并索取相邻段落。

## 步骤

1. 判断文本属于立项依据、研究现状、研究内容、研究目标、关键科学问题、技术路线或其他部分。
2. 将作者实际表达的论证写成链条：`论点 A → 论点 B → 论点 C → 结论`，不要先替作者补齐。
3. 识别缺少因果连接、概念未定义、证据不足或结论不随前提成立的位置。
4. 对每个真实断点输出：

```text
[逻辑断点 N] “原文准确引句”
缺失环节：文本从 X 跳到 Y，但尚未说明 Z。
修复建议：增加一句用于说明……，或降低……的结论强度。
```

5. 给出总体判断：逻辑完整性为强/中等/弱；最优先修复项；预计需要增加或调整的句子数量。

## 边界

- 只在逻辑诊断中报告逻辑问题，不把遣词偏好伪装成逻辑缺陷。
- 必须引用准确原文。
- 如果逻辑成立，明确说明，不制造问题。
- 区分“缺少文献证据”和“推理本身不成立”。
