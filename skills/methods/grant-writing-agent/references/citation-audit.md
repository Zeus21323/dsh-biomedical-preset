# 论点与参考文献核对

## 模式选择

- 只有文献：判断每篇文献能够和不能够支持什么论点。
- 只有草稿：逐项标记哪些实质性论断需要文献。
- 草稿和文献都有：将未获支持的论点与候选文献匹配。

## 文献输入

对每篇文献输出：作者与年份、短标题、证据类型、可直接支持的表述、不能支持的常见过度解读，以及核实风险。没有标题、摘要或全文依据时，不推断其结论。

## 草稿输入

逐项输出：

| 原文论点 | 状态 | 后续动作 |
|---|---|---|
| “……” | 已有可靠引用 | 无 |
| “……” | 缺少引用 | 给出检索关键词和合适的研究类型 |
| “……” | 引用只能部分支持 | 指明支持边界 |
| “……” | 定义或明确的逻辑推论 | 通常不需要引用 |

结尾统计未获支持的论点，并指出最优先补证据的一项及原因。

## 联合输入

对每项匹配给出强/部分/弱，并解释候选文献实际支持到什么程度。主题相关不等于能够支持论断。

## 可靠性规则

- 不得编造论文、作者、期刊、年份、卷期、页码或 DOI。
- 无法从可靠来源核实存在性或内容时，用 `⚠️ 待核实` 标记。
- 区分原始研究、系统综述、指南和观点文章的证据作用。
- 申请指南明确要求的引用格式优先；格式正确不能替代内容匹配。
