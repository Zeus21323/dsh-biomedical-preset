# 三视角模拟评审

三位评审独立评价，避免后一视角继承前一视角的结论。

## 同行专家

关注方法可行性、创新是否真实、技术细节是否足以评价、前提假设是否成立、前期基础是否支撑研究。

## 大同行专家

关注非本细分方向的专家能否理解问题、逻辑桥接是否完整、术语是否定义、研究价值是否清楚。

## 管理/评审专家

关注申报方向匹配度、目标是否具体可测、范围是否能在周期内完成、结构是否完整、表达是否专业。

## 输出

每位评审分别给出：

```text
[评审类型] — X/5
- 扣分项：“原文引句” → 具体问题
- 扣分项：“原文引句” → 具体问题（如有）
- 最重要修改：一个可执行动作
```

最后汇总：

- 两位及以上评审共同指出的问题，作为最高优先级。
- 仅单一评审指出但可能导致否决的风险。
- 评审之间的真实分歧，不通过平均分掩盖。

避免空泛赞扬。信息不足以判断申报指南匹配度时，明确写“无法判断”，不要猜测。
