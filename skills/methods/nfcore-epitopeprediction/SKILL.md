# 抗原表位预测与注释（nf-core/epitopeprediction）

## 识别数据与研究目标

从交付文件与报告中识别抗原序列或流程要求的变异来源、物种、MHC/HLA 等位基因与目标类别，明确肽长和候选范围。

## 方法选择

选择该版本支持且适配等位基因的预测器，记录结合/呈递评分语义、版本与必要许可。

先核对 [版本约定](references/流程约定.json)。

| 核对项 | 固定范围 |
|---|---|
| 上游版本 | `3.1.1`；`48f2eaaeb9b2226489d60a69ce1796c2db4642f2` |
| 上游维护 | 未归档；使用这里固定的源码，不自动跟随新版本 |
| 本地运行 | 未进行真实分析运行；不能据本 Skill 文件声称实跑通过 |
| 引擎声明 | `!>=25.04.0`；还需核验 Java、容器和 profile |

## 根据数据确定参数

根据 MHC 类别、等位基因覆盖和肽长选择预测器，按模型校准解释分数或 rank；候选截断说明用途，结合表达与加工证据而非仅凭结合分数定论。

| 决策与配置 | 处理要求 |
|---|---|
| 事实与缺口 | 先读现有文件和报告；不能据文件名猜实验类型、参考或样本关系；只补问无法核实且会改变分析的背景 |
| 参数来源 | 区分协议必需设置、数据估计、方法默认和研究选择；说明实际取值及理由，不要求用户填写专业参数 |
| 可执行配置 | 仅把已支持的选择映射为当前版本的原生字段；不支持的步骤另行交接，不虚构开关 |
| 阈值复核 | 默认值先评估适用性；依据质控、对照及敏感性检查调整，不能按显著结果数量调参 |

| 资料 | 使用时机 |
|---|---|
| [参数模式.json](references/参数模式.json) | 编写 params.json 时核对字段、类型、枚举及条件约束 |
| [输入模式-1.json](references/输入模式-1.json) | 准备 input 对应的样本表或输入文件时读取 |

```bash
nextflow run nf-core/epitopeprediction -r 48f2eaaeb9b2226489d60a69ce1796c2db4642f2 -params-file params.json
```

模式文件的许可见 [LICENSE](LICENSE)。

## 质控与解释

检查序列来源、等位基因支持、肽段重复和阈值敏感性，区分不同模型不可直接比较的分数。

交付表位候选、排名及模型证据；预测结合或呈递不等于 T 细胞免疫原性，实验验证不可省略。
