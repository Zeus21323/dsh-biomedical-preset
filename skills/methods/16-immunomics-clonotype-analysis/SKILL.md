# 免疫受体库多样性与克隆追踪

1. 确认样本深度、组织、时间、链和克隆型定义一致，低深度样本单独处理。
2. 报告丰富度、Shannon、Simpson、克隆度与克隆大小分布，并用下采样或覆盖校正比较。
3. 追踪共享克隆时区分完全序列一致、相似CDR3和公共克隆，记录匹配规则。
4. 纵向分析使用个体内模型，评估扩增、消失与新出现克隆的技术检测概率。
5. 输出多样性、重叠、克隆轨迹、置信区间和敏感性分析。

读数增加不一定代表细胞数增加；PCR扩增、采样深度和组织迁移均可影响观察。
