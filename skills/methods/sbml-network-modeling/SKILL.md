# SBML 生物网络建模

1. 确认SBML级别、版本、单位、区室、物种、反应和参数是否完整。
2. 运行一致性检查，定位未平衡反应、未定义符号、重复标识和缺失初值。
3. 保留注释、数据库交叉引用与单位；格式转换前建立元素映射表。
4. 模拟时明确动力学方程、边界条件和求解器容差，并用已知稳态或轨迹验证。
5. 输出验证报告、修改清单、模型文件和复现实验配置。

不得在无证据时自动补写动力学参数；修复应区分语法错误与生物学假设。
