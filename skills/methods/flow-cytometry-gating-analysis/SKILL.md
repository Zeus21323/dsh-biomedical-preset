# 流式细胞术门控分析

1. 根据实验设计建立去碎片、单细胞、活细胞和目标谱系的门控顺序。
2. 使用未染、FMO、单染和生物阴性对照确定边界，不能只凭处理组分布设门。
3. 门控模板跨样本应用后逐样本检查漂移；必要时用锚点或批次模板调整并留痕。
4. 报告每一级父群体分母、事件数和比例，低事件群体给出不确定性。
5. 输出门控树、边界、群体统计、异常样本和代表图。

手动门控含主观性；盲法、预注册边界和重复审阅可降低组别偏倚。
