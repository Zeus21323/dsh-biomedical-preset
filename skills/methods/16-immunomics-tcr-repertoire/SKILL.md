# TCR 与 BCR 免疫受体库分析

1. 核对受体类型、链、物种、建库方式、UMI、单双端和样本配对信息。
2. 完成读段质控、V(D)J比对、CDR3提取与生产性判断，记录参考胚系库版本。
3. 明确定义克隆型所用链、V/J、CDR3核酸或氨基酸以及相似度阈值。
4. 统计有效重排率、克隆型数、链配对、读数/UMI支持和异常扩增。
5. 输出AIRR兼容表、克隆型丰度、序列质控与不可解释重排。

克隆型定义改变会显著影响结果；不同建库协议的丰度不能未经校正直接比较。
