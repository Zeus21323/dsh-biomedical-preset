# 免疫治疗疗效预测

1. 明确癌种、药物类别、治疗线、表达平台、真实结局和模型训练适用人群。
2. 按各模型要求处理表达并锁定版本，避免在测试队列上重新选择基因或阈值。
3. 同时报告AUC、灵敏度、特异度、校准和临床决策阈值，不只展示分组P值。
4. 与TMB、MSI、PD-L1及临床变量比较增益，采用外部队列和患者级划分验证。
5. 输出模型分数、预设阈值、性能区间、失败亚组和适用边界。

研究性评分不能直接决定用药；模型跨癌种或跨平台使用前必须重新验证。
