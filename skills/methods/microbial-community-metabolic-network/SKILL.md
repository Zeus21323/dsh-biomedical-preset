# 微生物群落代谢网络

1. 审核每个基因组的完整度、污染、代谢模型覆盖和培养基条件。
2. 分别校验单菌模型的质量守恒、堵塞反应与生长可行性，再组合群落模型。
3. 明确共享环境、摄取上限和丰度约束，比较多种环境条件而非只跑一个默认培养基。
4. 识别潜在交叉喂养代谢物和必需伙伴，并用反应敲除或约束敏感性验证。
5. 输出物种—代谢物网络、通量范围、关键假设和不可辨识部分。

模型通量是约束下的可行解，不是直接测得的分泌速率；需要代谢组或培养实验验证。
