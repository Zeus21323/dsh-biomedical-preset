# 肿瘤抗原与表位预测

1. 整合高可信体细胞事件、HLA分型、肿瘤表达、纯度和克隆性，排除正常来源与CHIP。
2. 正确重建突变蛋白或融合断点序列，生成覆盖事件的候选肽。
3. 综合MHC结合/呈递、等位基因表达、突变特异性、克隆性和正常组织安全性排序。
4. 对野生型肽进行对照，标记相似人类蛋白和潜在脱靶风险。
5. 输出候选肽、HLA限制、证据分项、优先级和验证设计。

计算排名不能证明免疫原性或治疗有效性；候选需经质谱、结合与T细胞功能实验验证。
