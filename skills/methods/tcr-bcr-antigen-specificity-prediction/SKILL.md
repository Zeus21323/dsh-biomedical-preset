# TCR 与 BCR 抗原特异性预测

1. 核对受体链配对、CDR3、V/J、物种、HLA背景和抗原表示，去除低质量或非生产性序列。
2. 区分数据库精确匹配、序列相似、结构模型和机器学习预测，保留训练域信息。
3. 对TCR同时考虑HLA限制；对BCR区分线性表位、构象表位和成熟状态。
4. 采用阴性对照、已知阳性和外部验证集评估精确率，避免只给无校准分数。
5. 输出候选配对、证据类型、置信等级和实验验证优先级。

预测特异性不能替代四聚体、结合或功能实验；公共克隆可能产生交叉反应。
