# 时序基因调控网络

1. 明确真实时间、采样间隔、重复个体和批次；伪时间应与真实纵向数据分开解释。
2. 对缺失时间点和不等间隔选择合适模型，保留个体内相关结构。
3. 比较动态贝叶斯网络、状态空间或滞后回归，限制候选边数以适配样本量。
4. 通过置换时间标签、留一时间点和重采样检查边方向与延迟的稳定性。
5. 输出分阶段网络、边出现时间、稳定性和关键转换节点。

时间先后提升方向判断但仍不自动证明因果；采样频率不足时必须降低时序结论强度。
