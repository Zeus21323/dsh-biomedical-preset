# 疫苗表位与人群HLA覆盖设计

先定义病原体或肿瘤抗原、目标地区和人群、疫苗平台、HLA 类别、目标免疫反应及安全限制。单个肽的高结合预测不等于能够加工、呈递并产生保护性免疫。

候选生成应联合抗原表达、保守性、变异逃逸、蛋白酶加工、MHC 结合、免疫原性和自身相似性。人群覆盖必须使用目标人群的 HLA 等位基因频率，并说明是否掌握单倍型或连锁信息；不能把不同数据库、不同分辨率的频率直接相加。

需要计算覆盖逻辑、冗余和风险时读取[表位与覆盖规范](references/表位与覆盖规范.md)。交付候选表位、支持证据、覆盖人群、HLA 等位基因、保守性、自身相似性、组合冗余和实验验证方案。

预测适合候选排序，不证明保护效果。传染病与肿瘤疫苗还必须分别考虑病原体变异、免疫逃逸、肿瘤异质性和正常组织安全性。
