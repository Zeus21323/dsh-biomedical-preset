# FCS 数据质量控制与转换

1. 读取FCS版本、事件数、参数、标记、量程、补偿矩阵和采集时间，统一通道命名。
2. 检查时间漂移、流速异常、饱和、零值、边界事件和批次差异，标记需排除区间。
3. 流式数据核对单染对照并应用补偿/解混；质谱流式数据检查信号漂移和珠子通道。
4. 根据数据类型选择logicle、arcsinh或不变换，记录每个通道参数。
5. 输出清洗后FCS或矩阵、通道字典、QC图和处理日志。

补偿、解混和数值变换是不同步骤；不能靠后续门控掩盖采集或补偿错误。
