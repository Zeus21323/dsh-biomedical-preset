# 生物学命名规范速查

只在需要判断“来源写法是否本来就正确”或“用户给的写法是否需要保留”时读取。原则不变：来源怎么写就怎么保留；本文只用于在用户明确要求规范化、或需要向用户解释为什么不能改写时提供依据。

## 基因、转录本与蛋白的书写

| 物种 | 基因符号 | 蛋白 | 例子 |
| --- | --- | --- | --- |
| 人 | 全大写，斜体 | 全大写，正体 | *TP53* / TP53 |
| 小鼠、大鼠 | 首字母大写，其余小写，斜体 | 全大写，正体 | *Trp53* / TRP53 |
| 斑马鱼 | 全小写，斜体 | 首字母大写 | *tp53* / Tp53 |
| 果蝇 | 依首次描述，可大小写混合，斜体 | 同基因名正体 | *w*、*Notch* |
| 线虫 | 三字母小写-数字，斜体 | 全大写 | *let-7* / LET-7 |
| 酵母 | 三字母大写+数字，斜体 | 首字母大写+p | *RAD51* / Rad51p |
| 拟南芥 | 全大写斜体 | 全大写正体 | *FLC* / FLC |
| 细菌 | 三字母小写+大写字母，斜体 | 首字母大写 | *recA* / RecA |

因此把小鼠的 Trp53 写成 TRP53 是改变了物种信息，不是格式修饰；把人蛋白 TP53 写成 p53 是换了另一个名字（历史蛋白名），不是同一写法。

## 容易被当作普通词或缩写的基因符号

CAT、MET、SHH、WAS、REST、SET、CAMP、IMPACT、MICE、COIL、LARGE、CLOCK、PIGS、SOX、ATM、PC、TH、KIT、FOS、JUN、MAX、AXIN、FAT、SHE、HR、ACE、ABC。它们在基因名上下文（表格的 gene 列、“基因 X 表达上调”）中是标识符；在其他上下文中可能是普通词。不能只凭是否全大写决定，要看所在位置。

## 家族名、别名与历史名

- 同一基因多个名字：ERBB2 = HER2 = neu；TP53 蛋白常写 p53；MAPK1 = ERK2。来源用哪个就保留哪个，不替换成“更标准”的那个，除非用户要求统一并说明映射依据。
- 家族与成员：IL6 是基因，IL-6 是文献中常见蛋白写法；HLA-A 是基因，HLA-A*02:01 是等位基因；两者不能互相改写。
- 希腊字母：TNF-α、IFN-γ、PPARγ、ERα 与拉丁转写 TNFA、IFNG、PPARG、ESR1 属于不同层面的名字（前者蛋白常用名，后者 HGNC 符号），保留来源写法。
- 融合基因：HGNC 现行写法为 BCR::ABL1（双冒号）；旧文献写 BCR-ABL1 或 BCR-ABL。不同写法指向同一融合但不能静默替换。

## 编号的版本号

- Ensembl 基因/转录本/蛋白编号带 `.版本号`（ENST00000269305.9）；版本不同意味着序列或注释不同，不可省略。
- RefSeq 同理（NM_000546.6）；无版本号的 NM_000546 表示“任意版本”，与带版本号的含义不同。
- UniProt 登录号（P04637）本身不带版本，但 P04637-2 表示异构体，连字符后缀不可去掉。
- 基因组坐标必须伴随基因组版本（GRCh37 与 GRCh38 的同一基因坐标不同）。

## 变异记法

- HGVS 有 c.（编码 DNA）、g.（基因组）、p.（蛋白）、m.（线粒体）、n.（非编码）、r.（RNA）层面；不能互相推导后替换。
- 蛋白层面三字母（p.Arg175His）与单字母（p.R175H）表示同一变异但是不同写法；来源用哪个就保留哪个。
- 变异需要伴随参考序列（NM_000546.6:c.524G>A），单独的 c.524G>A 在不同转录本上可能指向不同位置。

## 数值与单位

- p 值和 padj 保留来源写法：3.21e-05 不写成 3.2e-5 或 0.0000321；<2.2e-16 不写成 0 或 2.2e-16。
- log2FC 与 FC 不同量纲；不把 log2FC = 1 改述成“上调 1 倍”，而应是“上调 2 倍”，且这属于解释而非改写数值。
- µ（微）不能替换为 u；°C 不能替换为 C；kDa 不能写成 kD。
- 千分位、有效位数、正负号、百分号按来源保留；不做单位换算。

## 常见细胞系与模式生物

细胞系名称大小写与连字符固定（HEK293T、HeLa、MCF-7、SH-SY5Y、RAW 264.7、NIH/3T3）；模式生物拉丁名斜体且缩写规则固定（*E. coli*、*S. cerevisiae*、*C. elegans*、*D. melanogaster*、*M. musculus*）。
