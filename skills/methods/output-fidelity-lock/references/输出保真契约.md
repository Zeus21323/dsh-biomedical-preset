# 输出保真契约

本契约适用于代理产生的任何输出：回答、报告、翻译、转写、改写、表格、图注、JSON、给下游脚本的参数，以及对用户消息的复述。它不按任务类型触发，而是对“来自输入的内容再次出现在输出里”这个动作本身做约束；来源可以是用户消息，也可以是当前任务中由代理从附件读取并登记的文本投影。

## 一个根本判断

代理输出内容时是在重新生成，不是在复制。基因名被翻译、版本号被丢、FDR 从 6.84e-9 变成 6.84e-8、Lgals1 和 Lgals3 的 FC 互换、NA 被填成 0、译文里整段数据消失，本质是同一件事：凡经模型重写的内容都可能变形，而且上下文越长、输出越长，变形越多。因此契约分两档：

- 少量事实（几个基因名、几个数值、一句结论）允许代理直接写，但交付前必须通过绑定校验；
- 批量数据（表格、列表、超过 10 个数据点）禁止代理手写，必须由脚本从源文件原样填充，代理只写叙述。

## 四层结构

```
任务识别层    翻译/转写/改写/报告，且输入含数据  →  强制进入本契约
文件读取层    PDF/DOCX/XLSX 由代理生成带定位的文本投影，登记 SHA-256 与覆盖范围
生成保护层    protect / restore / render，减少第一次写错
数据校验层    verify 按“实体—字段—值”绑定关系对比，只报告数据错误
交付门禁      重新读取最终产物再校验；fail 阻止交付，unverifiable 明示范围
```

校验层只处理可解码文本。二进制文件必须先由代理或已有阅读工具生成文本投影，投影要保留页码、段落号、表格号和行列号；无法读取的页面、公式或图片表格必须用 `--unverifiable` 登记，不能声称全部通过。登记后的来源不得替换。

## 校验的对象是绑定关系，不是值的集合

清单记录的是事实关系：`Lgals1 → fc → 43.69`、`Lgals1 → fdr → 6.84e-9`、`ENSG00000141510.18 → padj → 0.00042`，以及每条事实的文件、行号或表格行列。因此：

- 两个基因的数值互换，即使全局数字集合不变，也会被报告为“数值绑定到错误实体”；
- 译文删掉全部数据，会被报告为“来源实体丢失”和“候选稿未包含任何来源数据”；
- 保护标记数量不变但位置互换，回填时会被报告为“绑定改变”。

表格中同一行的其他标识符列（gene_symbol 之于 gene_id）作为主键的别名登记；候选稿用 TP53 引用 ENSG00000141510.18 的数值时按同一实体处理。

## 数据错误与形式差异分开

正式问题列表只包含数据错误：值丢失、值改动、精度改动、绑定到错误实体、凭空新增、版本号丢失或改动（版本号是编号的一部分）。

大小写、连字符、`::` 与 `-`、希腊字母与拉丁转写、三字母与单字母氨基酸记法这类形式差异默认只作警告，用于生成辅助；需要时用 `--form-as-error` 升级。

## 数值等价规则

- 独立的纯整数允许阿拉伯数字、中文数字和英文数字词互换：“36 只小鼠”译成 “thirty-six mice” 不报错。
- 科学小数、精度、正负号、指数、比较符、百分号、单位和实体绑定不得放宽：`<0.05` 与 `0.05`、`5%` 与 `5`、`3.5e-3` 与 `3.5e-4` 都不等价；`43.69` 与 `43.7` 是精度改动。
- 千分位和写法差异（`1,532.7` 与 `1532.7`）数值相同，不报错。
- 图表、章节、方法、步骤编号（表 2、Fig. 3B、方法 4.8、Methods 4.8）只记录不比较，避免把交叉引用当作数据。
- `itself`、`Methods`、`Total` 一类普通语言成分不作为实体参与校验。

## 两种模式

- `translate`（翻译、转写、改写，默认）：来源数据必须全部保留且不得新增，`--allow-novel` 被禁止；来源数据丢失是错误。
- `analysis`（分析报告）：允许本次分析真实产生的新结果，但每个新值必须能指向产生它的文件，并用 `--allow-novel` 登记；来源数据未被引用只作警告，加 `--require-all` 后升级为错误。

## 硬规则

1. 不变量逐字符复制。不翻译、不缩写、不补全、不改大小写、不四舍五入、不换算单位、不重排、不去重、不填补缺失值。任何变换都必须是用户明确要求的，并在输出中标注。
2. 不确定就标记，不许编造。记不清某个值时重新读源文件；无法读取时写 `[UNVERIFIED]`。
3. 翻译或改写时不变量不进入被重写的文本：先保护，完成后回填并核对数量、顺序和绑定。
4. 批量数据用插槽由脚本填充，不手写。
5. 交付前重新读取最终产物形成候选文本再校验，不校验生成前的草稿。
6. 校验未通过必须修改后重新校验，不允许在交付说明里“解释”掉错误；不能为了让校验通过而登记自己说不清来源的值。
7. 存在不可校验范围时，交付说明必须明示范围，状态是 `unverifiable` 而不是 `pass`。

## 与外部查询的关系

不变量识别完全离线，靠格式模式和停用词，不靠在线词表。只有当代理需要判断“这个词是不是基因”而上下文无法回答时，才对单个符号查询基因数据库；不逐词查询，不把词表读进上下文。
