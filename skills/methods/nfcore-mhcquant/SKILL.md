# 免疫肽组质谱鉴定与定量（nf-core/mhcquant）

## 识别数据与研究目标

从交付文件与报告中识别 MHC 洗脱肽质谱、蛋白数据库、样本设计及 HLA 信息，区别免疫肽组与常规胰酶蛋白组。

## 方法选择

按本版本无酶切或适用免疫肽搜索设置组织鉴定与定量，保留肽长、修饰及错误控制。

先核对 [版本约定](references/流程约定.json)。

| 核对项 | 固定范围 |
|---|---|
| 上游版本 | `3.2.0`；`6ec12c97f7889a3e1f09ab89930723045c6bac68` |
| 上游维护 | 未归档；使用这里固定的源码，不自动跟随新版本 |
| 本地运行 | 未进行真实分析运行；不能据本 Skill 文件声称实跑通过 |
| 引擎声明 | `!>=25.04.0`；还需核验 Java、容器和 profile |

## 根据数据确定参数

从免疫肽实验、仪器误差和肽长分布限定无酶切搜索及修饰空间，分层检查 FDR；不可沿用普通胰酶蛋白质组的酶切和长度假设。

| 决策与配置 | 处理要求 |

| 事实与缺口 | 先读现有文件和报告；不能据文件名猜实验类型、参考或样本关系；只补问无法核实且会改变分析的背景 |
| 参数来源 | 区分协议必需设置、数据估计、方法默认和研究选择；说明实际取值及理由，不要求用户填写专业参数 |

| 阈值复核 | 默认值先评估适用性；依据质控、对照及敏感性检查调整，不能按显著结果数量调参 |

```bash
nextflow run nf-core/mhcquant -r 6ec12c97f7889a3e1f09ab89930723045c6bac68 -params-file params.json
```

模式文件的许可见 [LICENSE](LICENSE)。

## 质控与解释

检查肽段 FDR、长度分布、污染、共享序列和样本重复，结合 HLA motif 评估一致性。

交付免疫肽鉴定、定量和 QC；检出洗脱肽支持呈递相关证据，但不单独证明 T 细胞活化。
