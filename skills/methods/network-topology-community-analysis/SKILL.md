# 生物网络拓扑与社区分析

1. 明确网络是有向、加权、二部还是多层，并检查自环、重复边和断开分量。
2. 选择与网络含义匹配的度、介数、PageRank或特征向量中心性，不混合不可比指标。
3. 使用Louvain、Leiden等方法发现社区，并对分辨率和随机种子做稳定性分析。
4. 用保度随机网络或合适零模型判断拓扑特征是否超出规模效应。
5. 输出节点指标、社区成员、稳定性、零模型比较和异常结构说明。

“枢纽”只是网络定义下的统计角色，不能直接等同于生物必需基因或药物靶点。
