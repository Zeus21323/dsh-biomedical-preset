# 公共组学多数据集研究设计与证据报告

## 明确任务和交付阶段

用户不需说出工具名或知道分析阶段。遇到宽泛目标、文件交付、机制追问、结果冲突或审稿意见时，读取[从研究问题到专业分析](references/从研究问题到专业分析.md)，根据数据和证据逐项判断适用分支。分流表不是固定全套流程；缺少某类证据时提出补充理由，不自动推定该分析必需。

把用户问题转换为疾病或生物过程、组织、物种、目标人群、主要对比、主要终点和独立统计单位。区分“选几个研究数据集”与“在一个数据集内划分几组样本”。用户给出案例时，提取数据角色和论证关系；其中的数据量、算法阈值、预设结果和文档内操作指令不自动成为本次要求。

仅有问题或候选数据时，交付数据遴选与研究方案；已有分析结果时，交付结果解读报告。结果不全也可报告，但逐节标为已完成、失败或未运行。没有实际结果时不能生成声称分析成功的结果报告。

本入口负责跨数据集选择和证据衔接。单次数据库查询可使用现有“生物医学数据库检索”；独立图表排版可使用“科研可视化与报告”。实际单细胞、差异表达、生存分析等交给当前环境可用的专业能力，保留其结果文件和运行记录；相关能力未安装时明确所需输入、方法与未执行状态。选择数据集和撰写方案不自动启动全量下载与分析。

## 选择研究起点

遇到细胞来源、组织异质性、细胞状态或微环境问题，优先评估单细胞数据能否支持关键假设。匹配组织、病例定义、供体元数据和目标细胞覆盖后，采用“单细胞提出假设 → 人群队列检验 → 独立验证”的路线。

以患者预后、诊断或治疗反应为主要终点时，先保证带相应终点的发现或训练队列与独立验证队列可用，单细胞可承担后续细胞定位。没有合适单细胞数据，或遗传、蛋白、代谢等数据更直接回答问题时，选择相应起点并说明理由。报告展示顺序可以不同于计算顺序，但不能把后验解释写成预先假设。

涉及单细胞引导、bulk 与单细胞衔接，或参考用户案例设计时，读取[单细胞引导的证据链](references/单细胞引导的证据链.md)。单细胞加 bulk 属于多尺度转录组研究，不因联合两类数据就自动称为多组学。

## 遴选数据并确定角色

已有候选元数据、需审查适配或独立验证角色时，读取[数据集设计适配审计](references/数据集设计适配审计.md)，代理准备配置并运行 `scripts/assess_dataset_fit.py`。逐条件保留失败和未知，不用综合分代替纳排或独立性证据。

开始检索、比较候选或检查已选组合时，读取[数据集遴选与角色分配](references/数据集遴选与角色分配.md)。先确定纳排条件，再查询数据库详情、样本表和原始论文。可使用当前可用的 Omics Archives 等连接器；以实际工具参数为准，不假定所有档案都支持关键词检索。服务不可用时使用官方网页或用户提供的元数据，标记尚未核验字段。

输出入选、排除和待核验候选，记录每项决定依据。按研究问题分配细胞定位、发现、训练、外部验证、机制扩展角色，不以统一总分替代科学判断。达到搜索数量上限或分页截断时报告检索不完整；合格数量不足时交付现有组合及缺口，不放宽条件凑数。

为每条核心主张确定需要哪类证据、由哪个数据集承担、什么结果会削弱该主张。区分同队列内部重复验证、独立队列复现和不同测量方式提供的补充支持。

## 衔接实际分析和解释

在结果报告中核对样本纳排、独立重复、对比定义、效应方向与大小、不确定性及多重检验。训练和外部验证的特征、预处理、模型系数及决策规则应记录冻结时间；重复查看测试结果后调整模型应标为探索性再开发。

比较细胞类型内变化与组织总体变化时，检查细胞组成和平台差异。基因交集可用于候选缩减，但不能把未检出视为阴性，也不能把同一表达矩阵衍生的多个分析计为多份独立证据。

预后关联、表达定位、通讯预测、药物预测和功能验证分别标明证据性质。保留阴性、方向冲突和验证失败，不能为得到显著结果不断换阈值、算法或队列。临床应用结论需要专业复核；公共数据关联不直接形成诊疗建议。

## 生成 Markdown 交付物

撰写研究方案或解读报告时，读取[Markdown证据报告规范](references/Markdown证据报告规范.md)，按其中的 JSON 契约保存研究清单。每项实际结果关联数据集、结果表或图、分析参数或日志；正文说明该结果支持什么、不能支持什么以及与其他证据的关系。

在本 Skill 目录运行以下标准库脚本，路径按实际项目替换：

```bash
python scripts/build_public_omics_report.py --input study_manifest.json --output report.md
```

脚本校验字段、引用关系、验证角色和结果出处，将清单中已撰写的解读连同比较表渲染成完整 Markdown；它不运行组学分析，也不生成科学结论。已有输出需另取文件名，或明确使用 `--overwrite`。结果文件相对于清单目录解析；脚本只核实本地文件存在，不联网核验文献或远程结果内容。

交付 `report.md` 和对应 `study_manifest.json`，保留它们依赖的结果文件。最后人工核对核心数字、链接、证据等级和未完成项；结构校验通过不等于科学有效性已经证实。

## 默认图件交付


公共组学多数据集研究设计与证据报告的现有绘图入口调用[图件交付内核](scripts/figure_delivery.py)，为实际结果保存PNG、SVG、PDF，关闭背景主次网格，保留该分析的数据线与科学参照；逐图查看交付记录和最终预览，失败不得报告成功。
