# 数据集设计适配审计（OmicsDesignIndex方向）

## 触发

“帮我选几组数据”“这套数据适合课题吗”“能不能当验证集”“几篇文章样本是不是重复”时，先明确问题，再对有候选元数据的组合执行。只有疾病时先检索；不强制单细胞起步，不爬取全网数据库。

## 契约与计算

脚本assess_dataset_fit.py逐项比较要求和有来源的事实，区分pass/fail/unknown。硬条件失败即排除，未知即待核验；软条件展示但不凑总分。先冻结纳排规则。

配置增加requirements非空列表：每项field唯一，op为eq/in/ge，value为所需值或列表，hard为布尔值。datasets每项id唯一，role为discovery/training/validation/localization/extension；facts按field索引，已知事实包含value和非空source；缺事实或value=null表示未知。

每个dataset可有overlap_status：unknown/overlap/independent_verified；非unknown必须有overlap_source。验证集有重叠或独立性未知均为pending_independence，不计独立验证。

示例条件结构：{"field":"tissue","op":"eq","value":"研究组织","hard":true}。事实结构：{"value":"研究组织","source":"样本表路径与字段"}。供体数阈值由具体功效和设计决定，不能用细胞数代替。

执行：python scripts/assess_dataset_fit.py --config /外部目录/fit.json --out-dir /外部目录/fit-001

## 输出与边界

eligibility.tsv为角色和审查状态，criteria.tsv为逐字段出处，dataset_fit图为核验矩阵。eligible_for_review不表示最终纳入或可发表。人工核验患者重复、研究嵌套、病例和终点定义；不同accession不代表独立。来源真实性、伦理许可、科学质量仍需核实。

这是OmicsDesignIndex方向的本地规则审计，不是全网索引、训练好的质量评分器或已建成数据库。

## 代理负责准备、执行和复核

用户不需要写JSON或命令。先读取文件与元数据，确认问题、独立统计单位、对比和出处；只用普通话补问确实无法核实且改变设计的事实。只有疾病/基因/毕业愿望时先回公共研究设计；缺输入交付缺口清单，不用模拟数据冒充结果。

代理在用户指定的仓库外目录创建配置。所有配置必填question（实际问题）、parameter_reason（参数与设计依据）、evidence_notes（来源、已核验事实与不确定性）；可选font为覆盖图中文字的已安装字体。参数不得由显著性倒推。路径相对配置文件解析。CSV/TSV为UTF-8、唯一表头，TSV以.tsv结尾；保留原始数据，不自行覆盖。每次指定新输出目录。

Python 3.11+，依赖numpy、pandas、scipy、matplotlib。代理在隔离环境准备并记录版本，不要求新手安装。各适配器自包含，无跨Skill脚本依赖，不需要根目录packages。输入1GB保护上限不等于内存保证；失败非零退出，已有输出目录则留下失败记录，不把残留产物视作成功。

交付完整TSV、summary.json、run_record.json、report.md、可编辑PDF/SVG、400 dpi PNG和图注。作图数据来自对应完整结果表；图的截取规则必须说明。配置、输入/输出哈希、版本和状态均留痕。脚本摘要不等于科学论文：代理需据真实数字补写观察、样本量、效应/区间、阴性/冲突、替代解释、证据等级和下一步，关联具体表行和图件。描述性模式不能声称显著。

打开PNG或渲染PDF，按最终版面检查缺字、截断、图例、颜色、单位、比例、方向和区间；重要发现回查输入。分辨率不是论文质量保证。原始记录保持“需视觉与科学复核”状态；复核可另存review.md，不篡改运行记录。结果、缓存、测试数据和日志只放仓库外。本地适配器不代表后台数据库或未实现的论文方法已完成。
