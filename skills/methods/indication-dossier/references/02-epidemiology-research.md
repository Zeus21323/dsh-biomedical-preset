# 阶段 2——流行病学研究

**何时执行：** `waypoints/meta.json` 已存在，而 `waypoints/epidemiology.json` 不存在时。

## 目标

刻画这一患者人群：如何识别他们、有多少人，以及他们随时间会经历什么。

## 操作

### 步骤 1：诊断标准与人群定义

- 使用 `WebSearch` 检索共识诊断标准，例如肌少症的 EWGSOP2、COPD 的 GOLD；
- 确定临床上如何识别该人群，以及如何将其与相关人群区分；
- 记录标准是否仍在演变或存在争议；
- 对于非标准适应症，记录现有的替代定义，例如研究标准、临床试验入组标准和专家共识。

### 步骤 2：患病率和发病率

- 使用 `pubmed` MCP 检索近期关于患病率的系统综述和荟萃分析；
- 使用 `WebSearch` 检索 CDC、WHO 或国家登记数据；
- 收集全球患病率、美国患病率、发病率和随时间变化的趋势；
- 如相关，区分社区居住人群与临床人群；
- 记录数据质量：估计值来自大型流行病学研究，还是小型单中心研究？

### 步骤 3：人口统计学特征和风险因素

- 年龄分布、性别差异、种族／族裔差异；
- 关键风险因素和合并症；
- 如有显著差异，记录地域变化。

### 步骤 4：自然病程与疾病进展

- 典型病程，例如急性或慢性、进行性或复发性；
- 如适用，记录分期系统；
- 死亡率和疾病负担数据；
- 疾病轨迹中的关键转折点，即干预最重要的时间。

### 步骤 5：写入 `waypoints/epidemiology.json`

遵循 [references/waypoint-schemas.md](waypoint-schemas.md) 中的 schema。为每个子章节记录覆盖程度。

## 指南

- 优先使用系统综述和荟萃分析，而不是单项研究；
- 对于罕见病，可以接受规模较小的研究，但必须说明证据质量；
- 如果适应症较新或不属于标准诊断，应明确说明流行病学数据有限，并解释有哪些替代数据；
- 使用并行子代理同时检索 `pubmed` MCP 和 `WebSearch`。
