# 免疫浸润综合分析

1. 核对表达单位、物种、平台、肿瘤类型、批次和签名矩阵的适用范围；混合表达与签名矩阵的基因标识、归一化和平台必须相容。
2. 自建单细胞签名时保证各细胞类型有足够样本，按受试者划分训练与验证数据，避免同一人的细胞同时进入两侧。
3. 同一数据使用一致预处理，并按任务选择相对比例、绝对模式、富集分数或CIBERSORTx高分辨率细胞型表达；不同尺度不能直接混算。
4. 检查拟合P值、相关性、RMSE、零比例、细胞类型共线性和肿瘤纯度，尽可能用病理、流式或独立单细胞参考验证。
5. 组间或结局关联在样本或受试者层面建模，纳入批次、纯度和临床协变量，并统一多重检验。
6. 输出签名来源、方法参数、细胞比例或细胞型表达、拟合质量、稳健共识、方法分歧和适用边界。

去卷积是模型估计而非细胞计数；高分辨率细胞型表达同样是估计值。参考中缺失的细胞类型、小样本或严重平台差异会造成不可辨识结果。
