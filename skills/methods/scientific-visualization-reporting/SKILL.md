# 科研可视化与报告

## 对所有图形执行同一流程

1. **明确比较。** 用一句话确定读者要比较什么、独立观察单位及证据层级。检查现有数据、元数据与分析记录；只有截图不补造数值。仅补问文件无法核实且会改变设计的事实，配置与图形选择由智能体承担。
2. **保持事实。** 保留实体身份、单位、变换、参考/比较方向、筛选及统计来源。排序、聚合、归一化必须有依据且可追溯；缺失、零、未检验和无发现不混同。配对、时间、空间、层级和组成关系按实际设计保留，不为外观改变统计结论。
3. **选择表达。** 从比较任务和变量类型选择位置、长度、颜色、形状等编码，不按疾病名或范图机械套模板。每种编码须说明含义，标签能回到稳定身份；同语义跨图映射一致，尺度/截断/不确定性透明。已有R或Python流程沿用实际对象，不强制换语言。
4. **同源生成。** 图、源表、图例与图注中的数字从同一已核实结果生成；绘图与解释分开。每项结果性陈述对应具体数据或分析记录，无依据时缩为描述或明确未知；关联、预测、显著性与因果机制不得互换。读[通用验收](references/有效性与布局验收.md)核对，不能只润色句子。
5. **验证交付。** 核查源数据→展示数据→视觉编码→文字解释是否一致，再看最终尺寸下的实际图。失败先定位数据、分析、绘图或导出环节并修复，不靠删异常/阴性值或调阈值凑图。正式静态图默认同一最终图形成套导出PNG/PDF/SVG，附数据、配置、图注和来源记录，输出不覆盖。技术通过、视觉审阅和科学解释分别报告，不保证录用。

默认白底、无背景网格、无面板内标题；科学参考线保留。合理例外按读图用途说明。颜色、字体与布局细节仅在配置/检查时读[配色与多面板](references/配色无网格与多面板规范.md)，导出时读[统一交付](references/三格式导出与交付.md)。不把所有支持资料一次性加载。

## 按实际输入调用资源

下列是实现适配器，不是仅限这些图的能力清单。未列出的图形仍执行上述流程，核验专业方法与实际工具；无法满足时明确缺口，不硬转成热图。跨Plugin调用先确认能力已安装。

| 当前需要 | 按需读取/调用 |
|---|---|
| 已计算的长表，适配器支持的点估计/矩阵/散点/趋势 | [输入契约](references/证据图件输入契约.md)；`scripts/render_evidence_figure.py` |
| 表达矩阵涉及基因注释和展示变换 | [表达矩阵适配契约](references/论文级表达热图规范.md)；可选 `scripts/render_expression_heatmap.py` |
| 建立项目配色 | `assets/scientific_palettes.tsv`；`scripts/scientific_colors.py` 或 `scripts/scientific_colors.R`，用完整类别映射而非按每图顺序选色 |
| 同一个最终对象成套导出 | `scripts/figure_delivery.py` 或 `scripts/figure_bundle.R`；`scripts/verify_figure_bundle.py`做文件/尺寸检查，不能证明语义正确 |

## 防止规范继续膨胀

遇到新错误先归因到身份/尺度、视觉编码、证据解释或导出执行，再修复公共机制并加入最小回归案例。主入口不累加图名、案例和故障清单；特殊资料只保留确实改变科学判断的条件或适配器输入契约。维护时合并重复规则，保留必要来源与边界。现有脚本测试不能证明所有未来图形、旧出口或R环境均已验证；不把文字约束当运行时保证。
