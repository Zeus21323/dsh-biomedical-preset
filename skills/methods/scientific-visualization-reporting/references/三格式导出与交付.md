# 三格式导出与交付
每张正式单图、组合图、补充图默认PNG/SVG/PDF；PDF图集不能替代每图PDF。保存显式Figure；每个文件stem三格式同数据、同尺寸。PNG默认400DPI，矢量质量不按DPI定义。SVG保留文字，PDF嵌入字体；必要位图层记录，整PNG包装成SVG/PDF不是可编辑矢量。只有截图而无源数据时说明限制。
通用内核在暂存目录写出，文件可解析后成套确认，拒绝覆盖；失败回滚本次新增文件，保留失败记录。复杂批量任务保留成功项但整体明确partial。每图delivery记录文件哈希、物理尺寸与有限技术检查；图注/源表/配置/环境由调用流程交付。
脚本调用同目录figure_delivery.py；副本由仓库构建分发命令分发并校验，独立Plugin无需假定相邻Plugin安装。不要手工编辑副本。
回复展示PNG并链接PDF/SVG、作图数据、图注。导出、技术检查、目视审图分别记录；组图再次检查页框、字体、裁切和透明度。
来源：[Matplotlib savefig](https://matplotlib.org/stable/api/_as_gen/matplotlib.pyplot.savefig.html)，2026-09-08核查。

## 一份图形配置，不按格式分别设计

同一图件的数据、样本/基因顺序、颜色映射、字体、字号、坐标范围、图例、标签和物理尺寸只定义一次。PNG、PDF、SVG是同一最终图形的三个序列化结果，不设pdf_style/svg_style等独立外观配置。PNG的DPI、PDF的字体编码和SVG的文字表示是导出细节，不改变图形内容。不得分别计算PCA、聚类、标签位置或随机布局。

Python同一个最终Figure仅调用一次save_figure，由共享内核成套导出；有限布局检查后核对PNG像素与共同尺寸/DPI、SVG物理尺寸、PDF页尺寸/裁切框。任何格式缺失、文件不可解析或尺寸不一致即失败，临时文件不作为成功结果交付。记录bundle_consistency及实际文件摘要；重复调用时若文件被外部改变，不复用旧成功记录。该机制不能证明任意复杂图的三格式语义、字体和像素完全一致，仍需审图。

## R的统一出口

已有R代码保留R分析。在绘图参数、颜色映射、顺序和布局确定后，构建一次最终grid grob，再调用本Skill `scripts/figure_bundle.R` 中的figure_export_bundle。同一个grob、同一套尺寸和样式用于三个设备，不接受各格式的单独样式或每次重新执行的绘图函数。

```r
# 先用scientific_colors.R校验并应用项目颜色到原始R绘图代码。
# ggplot对象可以先用ggplot2::ggplotGrob(p)转换；热图须先固定布局与顺序。
source(file.path(skill_dir, "scripts", "figure_bundle.R"))
figure_export_bundle(final_grob, out_dir,
                    width_mm=160, height_mm=120,
                    python=python_with_figure_dependencies,
                    verifier=file.path(skill_dir, "scripts", "verify_figure_bundle.py"),
                    source_files=c(matrix_path, metadata_path, config_path))
```

参数路径由智能体定位，用户不需要填写。要求支持Cairo的R、svglite、Python及图件依赖（Pillow、pypdf），依赖缺失停止，不静默换语言。R输出到临时目录，调用同一Python文件校验器；通过后再确认整套目录。保存最终对象、共享配置、来源摘要和R会话，失败写诊断并退出，拒绝覆盖。SVG使用svglite保留文字，PDF/PNG使用Cairo；不同设备仅承担格式编码，共用grob与样式配置。字体在创建和查看环境都需可用，仍须检查设备字体度量差异。本适配器目前未在本机R环境运行验证。

独立R/其他工具已经导出的成套文件也可调用 `scripts/verify_figure_bundle.py`，指定stem、width-mm、height-mm、dpi及新record路径；非零返回表示不合格。但仅运行这个后置检查只能证明文件/尺寸符合，不能替代共用图形对象、颜色映射校验或图注审查。没有使用这些入口的旧代码不受运行时约束，必须按实际任务接入并验证，不能声称仓库全部R出口已经迁移。

R SVG设备参数依据：[svglite官方文档](https://svglite.r-lib.org/reference/svglite.html)。
