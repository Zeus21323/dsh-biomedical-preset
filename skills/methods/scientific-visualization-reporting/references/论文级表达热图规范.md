# 表达矩阵适配契约

仅在基因×样本输入需要注释映射或展示变换时读取；通用身份、编码、解释和交付规则以主Skill及通用验收为准。本文件不是所有热图的统一科学方法，也不要求已有R流程换成Python。

## 影响科学判断的条件

- 稳定gene_id用于匹配；symbol由已核实注释得到，重名时增加ID区分而非合并。样本元数据按ID匹配，不按当前行序猜测。
- 比较基因内相对模式可在适当变换后用行z-score；比较表达水平保留相应尺度。表达层、计算样本范围和标准差定义须明确，不重复标准化，不在绘图阶段擅自校正批次。
- 展示基因来自真实结果与有依据的选择规则，不固定数量或强制上下调平衡。基于同一比较筛选的展示不是独立验证；无发现保留阴性结果。
- 设计规定的样本顺序优先；聚类距离/链接与输入层须记录。提取最终绘制顺序后导出矩阵；做不到时预先固定顺序，关闭二次重排。
- 下面适配器的输入/规模限制是实现范围，不是适用于所有研究的硬性统计标准。更复杂数据可沿用已核验的原生实现，执行相同通用验收。

## 可选Python入口与依赖

没有需要沿用的原始实现、且Python适合当前环境时，可使用本Skill的 `scripts/render_expression_heatmap.py`（Python、numpy、scipy、matplotlib、Pillow及共享交付内核依赖；仓库验证用 `uv run --frozen --extra figures`）。此入口实际执行标签映射、样本排序、行标准化、层次聚类、分类注释与三格式矢量交付，不执行差异检验。

```bash
python scripts/render_expression_heatmap.py --config /analysis/heatmap.json --out-dir /analysis/heatmap-delivery
```

路径相对配置文件解析；输出目录不得存在，失败返回非零并在父目录写失败JSON，不留下部分成功目录。输出目录应在用户分析工作区，测试产物放仓库外。

输入表使用TSV或CSV，表头不得重复，记录列数一致：

| 配置路径 | 必需结构 |
|---|---|
| matrix | gene_id加每个sample_id一列；全部输入基因可保留，展示子集由selected_genes给出 |
| samples | sample_id、sample_label、group；可附pair、batch等。与矩阵列严格一一对应 |
| genes | gene_id、gene_symbol；覆盖输入矩阵所有基因，symbol缺失留空但身份不得缺失 |
| differential_results（可选） | gene_id、log2FC、pvalue、padj；保留其他分析字段和全部行。不同工具原列名须显式映射并记录原文件来源；NA代表未检验/不可估计，不填0 |

配置由智能体检查来源后生成，下列仅为结构示例，不能冒充真实数据或默认筛选规则：

```json
{
  "matrix": "expression.tsv",
  "samples": "samples.tsv",
  "genes": "genes.tsv",
  "expression_layer": "vst",
  "expression_provenance": "填写真实分析记录、变换参数和样本范围",
  "annotation_source": "填写实际参考注释及版本",
  "selection": "填写真实比较、筛选阈值、排序和展示数量依据",
  "selected_genes": ["gene_A", "gene_B"],
  "row_scale": "zscore",
  "gene_label": "symbol",
  "column_order": "group",
  "cluster_rows": true,
  "cluster_cols": "none",
  "distance": "euclidean",
  "linkage": "average",
  "annotations": ["group"],
  "show_title": false
}
```

- expression_layer接受vst、rlog、log2_normalized、log2_tpm、row_zscore；expression_provenance具体说明上游变换（含必要伪计数等）。这是来源声明，脚本无法从数值证明VST真实运行过，须读取分析记录。
- row_scale为zscore或none，默认zscore；输入row_zscore时必须none，且验证所列样本均值0、样本标准差1（容差1e-6）。范围/ddof不一致时返回上游核实，不重复z-score掩盖问题。
- gene_label为symbol（默认）或stable_id。脚本不会联网猜注释。
- column_order为group（默认，组内沿元数据顺序）或metadata。sample_order可给完整唯一ID列表，优先于默认排序，不能同时要求列聚类。
- cluster_rows为布尔值，默认false；为true时真实计算并显示行树。cluster_cols为none/within_group/all，默认none；真实重排列，不绘列树，图注明确这一点。within_group会按组分块，不适用于必须保持跨组配对顺序的图。
- distance为euclidean/correlation；linkage为average/complete/single/ward，ward仅配euclidean。缺失值或无效距离禁止聚类，不插补。
- annotations默认[group]，最多4条；缺失类别须明确Unknown。颜色使用[共享配色规范](配色无网格与多面板规范.md)：palette默认categorical_clear；color_registry提供项目TSV映射，按注释字段名匹配变量，子集保留颜色。annotation_colors可给完整类别映射并与项目映射一致，六位HEX，同变量不同类别不能同色；超过色板容量需有依据的扩展/分面。
- continuous_palette默认按绘图数值类型选择blue_white_pink（z-score）或blue_sequential（原展示尺度），不得把分类色板用于连续数值。图件保存resolved_colors.tsv和颜色来源指纹。
- allow_missing默认false；开启后NA保持NA。title仅在show_title=true时显示。
- color_limits可提供覆盖所有值的上下限；z-score须对称；不支持静默饱和截断。
- width_mm/height_mm、font、dpi可选，默认按行列估算尺寸、8pt字、400dpi；输出后仍须按目标版面检查。支持最多80行40列，超限先分面，不用硬限作为推荐基因数量。
- 提供differential_results时同时提供contrast与analysis_provenance，描述方向、统计独立单位、模型和真实检验/多重校正方法。脚本仅校验并交付已有结果，不计算P值，不补造区间。

已有R流程以及复杂多面板/注释可沿用经核验的R绘图实现（例如ComplexHeatmap或pheatmap），但必须兑现同样的数据和交付契约；不把当前Python入口宣称为ComplexHeatmap。

## 适配器输出

- figure.png、figure.svg、figure.pdf：相同内容和尺寸；热图格子保留矢量图元，文字可编辑，非整图嵌入位图。
- heatmap_matrix.tsv：gene_id、gene_symbol及按图顺序排列的样本列，保存实际绘图值与完整精度。
- heatmap_readable.tsv：同一结构、三位小数，仅供阅读；不是计算源文件。
- heatmap_long.tsv：完整精度gene×sample记录，明确row_zscore或expression_value，列名不使用含义模糊的z。
- sample_metadata.tsv、selected_genes.tsv：实际行列顺序、短标签和原始身份映射。input_*保留完整输入，不能只保留展示子集。
- differential_results.tsv：仅真实提供时输出完整统计结果，基因名与稳定ID分列，不从z-score推断。没有时在记录及图注说明未提供。
- config.json、figure_manifest.json、caption.md：输入指纹、脚本指纹、依赖版本、处理和选择依据、实际顺序、色阶/配色、行聚类树、缺失数量及有限检查状态。

输出后的检查按[通用验收](有效性与布局验收.md)执行；程序的导出成功状态不代表科学解释已验证。
