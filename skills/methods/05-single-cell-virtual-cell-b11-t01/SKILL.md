# CyTOF 归一化与双联体去除

1. 检查微球通道、条码方案、事件长度、DNA、活死和时间参数是否齐全。
2. 基于微球信号随时间漂移进行归一化，保存归一化因子和失败采集段。
3. 去条码时评估分离度与交叉样本，保留不确定事件而非强制分配。
4. 结合事件长度、DNA、中心度或高斯参数识别双联体，并用已知单细胞群复核阈值。
5. 输出标准化单细胞事件、排除原因、批次诊断和处理参数。

过强过滤会选择性删除大细胞或活化群体；阈值应在各批次做敏感性检查。
