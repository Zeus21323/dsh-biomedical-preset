# 方法选择与报告

## 不把诊断当成自动开关

正态性检验在大样本中会对微小偏离过度敏感，在小样本中又缺乏功效。结合 Q-Q 图、残差、估计目标和模型稳健性判断，不使用“Shapiro P 值大于 0.05 就选 t 检验”的机械规则。方差不齐时默认优先 Welch 方法；秩检验检验的是分布差异，只有在相应假设下才能解释为中位数差异。

## 效应量

- 连续独立组：均值差、标准化均值差或 Hodges–Lehmann 位置差。
- 配对数据：配对差的均值或中位位置差。
- 二分类结果：风险差、风险比、优势比及其置信区间。
- 相关：相关系数及区间，同时说明调整变量。

效应量方向必须绑定清晰的参考组。不得只给显著性星号。

## 多重检验

同一科学问题的一组并行检验默认采用 BH-FDR；强控制族错误率时使用 Holm 等方法。预设主要终点与探索性终点分开报告，不能把事后挑选的最小 P 值当作主要结论。

## 最小报告字段

保留样本数、排除数、缺失处理、组别顺序、统计量、自由度、效应量、95% CI、P 值、校正方法、软件及版本。模型结果同时保留公式、变量编码、参考水平和诊断。
