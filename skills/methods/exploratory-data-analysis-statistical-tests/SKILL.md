# 探索性数据分析与统计检验

## 先确认分析单位

识别每行代表患者、动物、样本、细胞还是技术重复，明确主要结局、分组、配对或重复测量关系、协变量、批次和缺失编码。先保存数据字典和分析所用行列，不按结果反复改变排除规则。

## 探索性分析

1. 报告样本数、变量类型、唯一值、缺失率、无穷值、重复主键和近零方差变量。
2. 数值变量检查分布、尺度、离群和变量间关联；分类变量检查稀疏水平和组间不平衡。
3. 图形按真实统计单位绘制，技术重复不得被当作独立样本扩大精度。
4. 相关分析先区分 Pearson、Spearman、偏相关及重复测量结构，不把相关写成因果。

需要批量检查数值变量的正态性、组间方差和缺失情况时，可运行 `scripts/assumption_checks.py`。脚本输出诊断表和运行元数据，但不自动替用户选择最终检验。

## 统计检验选择

- 两组独立连续结果：根据 estimand、分布和样本量选择 Welch t 检验、Mann–Whitney 或稳健模型。
- 配对连续结果：使用配对 t 检验、Wilcoxon 符号秩或配对模型。
- 多组结果：使用 ANOVA/ANCOVA、Welch ANOVA、Kruskal–Wallis 或回归模型，并预先定义事后比较。
- 分类结果：根据期望频数使用卡方、Fisher 或回归模型。
- 重复测量、分层或批次结构：使用混合模型、GEE 或分层置换，不压成独立观测。

每项检验同时报告效应量、置信区间、原始 P 值、多重检验方法和校正后 P 值。若假设诊断与样本量不足以支持正式推断，明确标记为探索性。

## 输出契约

交付数据概况、排除记录、描述统计、诊断结果、完整模型或检验定义、效应量与不确定性、校正方法、敏感性分析和限制。运行记录包含输入文件哈希、分析单位、变量角色、软件版本、参数和随机种子。

更多决策细节见[方法选择与报告](references/方法选择与报告.md)。
