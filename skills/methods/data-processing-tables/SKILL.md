# 科研表格数据处理

## 不先改原表

先识别文件编码、表头、主键、单位、缺失值表示和公式列，保留原始文件。颜色、合并单元格和列位置不是可靠的数据定义；含义不清的列先询问。

## 处理规则

- 类型转换前统计无法解析的值，日期必须说明时区和日/月顺序。
- 去重应给出业务键和保留规则，不能直接“删除重复行”。
- 表连接前检查主键唯一性，连接后报告一对多膨胀和两侧未匹配记录。
- 单位换算保留原值、原单位、目标值和公式。
- 派生列使用可重算的脚本或公式，手工修订单独记录。

交付清洁表、字段字典、异常表和处理说明。用处理前后行数、主键数、缺失率和关键数值范围对账；若对不上，先定位差异再交付。
