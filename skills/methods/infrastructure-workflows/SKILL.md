# 科研计算环境与工作流

## 最小可复现单元

把软件与数据库版本、参考资源、输入清单、参数和资源需求写入配置，而不是散落在命令历史或个人路径中。容器或锁文件固定运行环境，参考文件另记录版本与校验信息。

工作流中的每一步应声明输入、输出、失败条件和可重跑边界。中间结果只有在输入与参数未变时才能复用；随机过程固定种子，队列任务保留退出码和标准错误。

先用足以覆盖主要分支的小数据运行，确认断点续跑不会重复或跳过步骤，再扩大到完整数据。交付环境定义、入口命令、配置示例、运行日志位置和资源估计，使另一台机器不依赖作者的目录结构也能复现。
