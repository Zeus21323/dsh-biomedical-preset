# 差异调控网络

1. 各条件采用一致的预处理、候选节点和网络推断参数，确认样本量可比。
2. 区分节点表达变化、边权变化和社区结构变化，避免把差异表达误写成网络重连。
3. 对边权差异使用置换或自助法估计不确定性，并统一校正多重比较。
4. 对关键重连边检查是否由离群样本、方差差异或细胞组成改变驱动。
5. 输出增益边、丢失边、差异模块、效应量和稳健性分析。

只有在相同数据生成机制下网络差异才可直接比较；批次与平台差异需单独控制。
