# 高维流式细胞聚类与表型鉴定

1. 完成FCS质控、补偿/归一化、变换和基础活细胞/单细胞筛选。
2. 选择用于聚类的表型标记，排除仅用于功能读出的通道并说明下采样策略。
3. 用FlowSOM、Phenograph等聚类，系统比较随机种子、簇数和分辨率稳定性。
4. UMAP/t-SNE仅用于可视化；亚群注释依据标记表达、已知谱系和人工复核。
5. 输出细胞簇、元簇、标记热图、注释依据和稳定性。

二维图上的距离不是定量生物距离；稀有簇需排除批次、死细胞和技术伪影。
