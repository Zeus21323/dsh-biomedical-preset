# 基因调控网络推断

1. 明确数据类型、样本数量、时间结构和可用TF/基序/染色质先验。
2. 预先过滤低信息基因并校正批次，不能用差异基因筛选替代全局调控建模。
3. 依据设计选择GENIE3/GRNBoost、回归或先验约束方法，保留边权与方向。
4. 通过重采样、伪数据和外部ChIP或扰动数据评估边的稳定性与精确率。
5. 输出调控边表、模块、关键TF、稳定性和无法判断方向的关系。

共表达推断的边不是直接结合证据；没有时间或干预信息时不得宣称因果调控。
