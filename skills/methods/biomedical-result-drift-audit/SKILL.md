# 数据库版本与分析结论漂移审计

## 理解用户而非要求用户选工具

根据普通语言、文件、阶段和异常判断适用性。只有疾病、基因或课题目标时先进入公共研究设计，不将愿望当作执行、上传或大规模下载授权。先查文件，只有无法核实且改变设计的事实才用普通话补问。缺数据交付缺口，不生成模拟结果冒充真实分析。

## 执行

本Skill执行脚本为 `scripts/audit_result_drift.py`；代理准备外部配置后使用 `--config` 与 `--out-dir` 运行。

先完整读取[执行契约](references/版本漂移执行契约.md)，选择其中真实支持的模式。代理准备配置、检查依赖并运行本Skill脚本；用户不需要写JSON或选检验。参数、独立单位、来源与资源边界先明确。输入只读，结果保存在仓库外新目录，失败非零退出，不覆盖历史。

## 解读和交付

交付真实表、运行记录、Markdown、可编辑PDF/SVG、高清PNG、作图数据与图注；打开预览检查最终尺寸、字体、单位、颜色和布局。补写实际数字对应的观察、阴性/冲突、不确定性、替代解释、证据层级与后续验证。脚本运行成功不等于科学审核通过；描述性模式不宣称显著，不保证机制证实或论文录用。

## 边界

这是现有通用Plugin内的任务Skill，不新增MCP或独立Plugin。不内置大规模数据库、定时服务和未经验证的新算法；范围以执行契约为准。其他专业能力未安装时明确缺口，不能把分流链接当成可用工具。

## 默认图件交付


数据库版本与分析结论漂移审计的现有绘图入口调用[图件交付内核](scripts/figure_delivery.py)，为实际结果保存PNG、SVG、PDF，关闭背景主次网格，保留该分析的数据线与科学参照；逐图查看交付记录和最终预览，失败不得报告成功。
