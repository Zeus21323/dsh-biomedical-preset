# BCR 抗体谱系重建

1. 使用与个体匹配或经审查的胚系库进行V(D)J注释，处理等位基因缺失。
2. 依据V/J、CDR3长度和相似度划分克隆家族，系统评估阈值敏感性。
3. 重建未突变共同祖先，区分替换与沉默突变并检查测序/扩增错误。
4. 构建谱系树并标注时间点、同种型、组织和突变，比较多个近似树。
5. 输出家族成员、祖先序列、谱系树、突变路径和不确定节点。

树的内节点是推断序列；没有功能实验时不能把某条分支直接解释为亲和力提升。
