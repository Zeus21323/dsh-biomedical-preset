# 蛋白质互作网络构建

1. 统一物种、基因标识和参考版本，记录未映射与一对多映射。
2. 按问题选择证据源：STRING需区分实验、数据库、共表达和文本挖掘等通道；BioGRID需区分物理互作与遗传互作，也可加入其他有明确证据类型的数据库。
3. 按研究目的设置信度与证据类型，避免仅靠文本共现生成循环论证。
4. 构建网络后报告输入覆盖率、背景网络、孤立节点和多重边处理规则。
5. 输出边表、节点表、证据来源、网络摘要与可复现查询参数。

数据库互作不代表当前组织或条件下实际发生；关键边应由原始实验或正交证据确认。
