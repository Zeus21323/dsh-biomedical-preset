# 观察性组学因果驱动分析

该能力用于 CauFinder 一类“从观察性组学推断候选驱动因子”的任务，不代替孟德尔随机化，也不把机器学习重要性当作因果效应。先定义处理或状态、结局、时间顺序、混杂因素、批次和可用的先验网络。

建立与研究问题匹配的因果图，明确哪些变量可调整、哪些可能是中介或碰撞点。模型训练必须把样本、供者或队列正确分组切分；驱动分数需要与普通预测重要性、差异表达和网络中心性比较。使用重采样、负对照、替代调整集和外部队列检查稳定性。

设计变量角色、稳健性分析和输出时读取[因果识别与验证](references/因果识别与验证.md)。交付假设因果图、识别条件、候选驱动排序、效应方向、稳定性、替代解释和实验验证建议。

没有干预、时间、遗传工具或充分混杂控制时，只能称为“候选因果驱动”或“与假设一致的驱动信号”，不能声称已经证明因果关系。
