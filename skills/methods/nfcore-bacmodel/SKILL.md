# 细菌代谢网络功能建模（nf-core/bacmodel）

## 识别数据与研究目标

从交付文件与报告中识别细菌基因组/注释、培养条件、营养摄取与模型资源，明确构建、补全或模拟的目标。

## 方法选择

按该版本的系统建模路径生成网络，记录反应映射、gap filling、目标函数和边界条件。

先核对 [版本约定](references/流程约定.json)。

| 核对项 | 固定范围 |
|---|---|
| 上游版本 | `dev`；`48ee4d824f47d923da9d7b5495b0680dc451a153` |
| 上游维护 | 开发版本；按当前代码实际实现的范围使用 |
| 本地运行 | 未进行真实分析运行；不能据本 Skill 文件声称实跑通过 |
| 引擎声明 | `!>=25.04.0`；还需核验 Java、容器和 profile |

## 根据数据确定参数

以实际培养基、摄取限制和实验表型设定边界及目标函数，缺口填补结果单独标记；不能为保证生长任意开放营养交换。

| 决策与配置 | 处理要求 |
|---|---|
| 事实与缺口 | 先读现有文件和报告；不能据文件名猜实验类型、参考或样本关系；只补问无法核实且会改变分析的背景 |
| 参数来源 | 区分协议必需设置、数据估计、方法默认和研究选择；说明实际取值及理由，不要求用户填写专业参数 |
| 可执行配置 | 仅把已支持的选择映射为当前版本的原生字段；不支持的步骤另行交接，不虚构开关 |
| 阈值复核 | 默认值先评估适用性；依据质控、对照及敏感性检查调整，不能按显著结果数量调参 |

| 资料 | 使用时机 |
|---|---|
| [参数模式.json](references/参数模式.json) | 编写 params.json 时核对字段、类型、枚举及条件约束 |
| [输入模式-1.json](references/输入模式-1.json) | 准备 input 对应的样本表或输入文件时读取 |

仅在已授权且配置齐备时运行。

```bash
nextflow run nf-core/bacmodel -r 48ee4d824f47d923da9d7b5495b0680dc451a153 -params-file params.json
```

模式文件的许可见 [LICENSE](LICENSE)。

## 质控与解释

检查质量守恒、不可行反应、能量生成循环和培养条件下的预测，避免为匹配结果任意开放交换反应。

交付代谢模型、参数与预测；约束模型的可行通量不是实际测得通量，实验生长与分泌数据仍需验证。
