# 流式细胞差异丰度与状态分析

1. 保留样本为统计单位，不能把单细胞事件当作独立生物重复。
2. 丰度分析明确父群体分母，使用适合比例、计数或组成数据的模型。
3. 状态分析在预定义细胞群内比较标记表达，纳入批次、个体和时间结构。
4. 对细胞群和标记统一校正多重检验，并报告效应量与置信区间。
5. 输出样本级统计表、模型公式、敏感性分析和关键群体图。

差异簇必须回到原始标记与门控复核；极低事件数结果不得作强结论。
