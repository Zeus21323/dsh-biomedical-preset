# 实验仪器数据标准化

原始文件始终作为不可变来源保存。先确认仪器型号、采集软件和方法版本，再解释导出列；相同列名在不同固件中可能含义不同。

建立逐字段映射，至少包含原字段、标准字段、数据类型、原单位、目标单位、受控词和无法映射时的处理。样本 ID 必须来自样本表或条码关系，不从孔位或文件名猜测。

转换时保留采集时间、校准、方法、批次和仪器状态。单位换算使用明确公式；低于检出限、未采集、解析失败和真正的零使用不同编码。

抽取若干记录与仪器原始界面或导出逐值核对，并检查样本顺序、时间顺序和换算边界。交付标准化数据、字段映射、未识别字段和转换异常，不能为追求表面整洁丢掉元数据。
