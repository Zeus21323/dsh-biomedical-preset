# 因果识别与验证

## 开始前必须回答

- 暴露、状态或处理是什么？
- 结局是什么，是否晚于处理发生？
- 哪些变量是共同原因、哪些是中介、哪些可能是碰撞点？
- 样本是否存在供者、批次、组织或时间层级？
- 目标是总体效应、直接效应还是驱动因子排序？

## 最低稳健性检查

- 分组交叉验证，防止同一供者泄漏；
- 与差异表达和普通预测重要性进行对照；
- bootstrap 或重复采样稳定性；
- 替代混杂调整集；
- 负对照暴露或结局；
- 外部队列或扰动数据验证；
- 对未测混杂进行定性或定量敏感性分析。

## 禁止的解释

- SHAP、特征重要性或网络中心性本身不等于因果效应。
- 状态分类准确不代表找到产生状态的驱动因素。
- 事后从同一数据挑选候选再报告显著性，会低估不确定性。
