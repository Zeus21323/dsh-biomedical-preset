# 科研软件开发与测试

从输入输出契约和一个已知答案的小样例开始。解析、核心计算和文件写出应能分别测试，避免把所有逻辑塞进一条脚本路径。

测试至少覆盖：正常样例、空输入、边界值、格式错误、重复记录和一个会触发失败的样例。数值算法声明容差，随机算法固定种子并测试统计性质；生物信息文件同时检查坐标、参考版本和样本顺序。

重构前建立能复现当前正确行为的回归测试，重构后比较结果而不只比较是否退出成功。性能优化使用代表性规模测量时间和内存，不能牺牲正确性。

交付代码、可执行入口、测试、依赖版本和已知限制。测试数据使用合成或获授权数据，不得放入真人基因型、临床记录或密钥。
