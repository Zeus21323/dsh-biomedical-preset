# 网络药理学分析

1. 明确药物实体、疾病表型、物种与证据等级，规范化化合物和基因标识。
2. 靶点信息区分实验测定、临床已知和计算预测，不把预测值当作同等级证据。
3. 疾病基因设定客观纳排标准，构建药物—靶点—疾病网络并记录每条边来源。
4. 拓扑、富集和表达证据联合排序，检查数据库热门基因造成的偏倚。
5. 输出证据表、候选子网络、可验证假设和实验优先级。

网络重叠与中心性不能证明药效或安全性；结论应明确是机制生成而非临床推荐。
