# HLA 与 KIR 分型

1. 明确测序类型、读长、参考版本、祖源背景，以及HLA所需的一字段、二字段、三字段或四字段分辨率和KIR所需的基因/等位基因层级；报告使用当前HLA命名法，不再用易混淆的“二位、四位、六位”。
2. HLA按数据选择OptiType、arcasHLA、HLA-HD等方法；KIR需考虑拷贝数和高度同源结构。
3. 比较读段支持、等位平衡、候选分数与多个方法的一致性，标记可能的新等位基因。
4. 检查样本身份、污染、肿瘤LOH和RNA表达偏倚对分型的影响。
5. 输出标准命名等位基因、分辨率、支持证据、数据库版本和不确定结果。

不同工具支持的基因座和分辨率不同；临床用途需要经验证的正交分型确认。
