# API与外部系统集成

## 接入前先问清

- 接口是只读查询、批量导入，还是会改变外部系统状态？
- 认证令牌放在哪里，谁有权使用，是否涉及患者或未公开实验数据？
- 分页方式、速率限制、增量更新时间和稳定主键分别是什么？

## 实施

先发一个最小只读请求，保存状态码、响应头和一条脱敏响应。确认字段含义后再建立本地字段映射，显式处理时区、空值、枚举和废弃字段。

读取可对超时、429 和 5xx 做有上限的退避重试；写入只有在接口支持幂等键或已能查明写入结果时才能自动重试。游标分页和页码分页不要混用，增量同步应记录水位和重叠窗口。

## 验收

用一组已知记录核对数量、主键、更新时间和单位，单列无法映射与重复记录。交付调用示例、字段映射、限流策略、失败记录及恢复办法。密钥、令牌和可识别数据不得进入日志或示例。
