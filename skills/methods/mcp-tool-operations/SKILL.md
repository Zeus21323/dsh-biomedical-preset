# MCP工具发现与故障处理

先读取当前会话真实暴露的服务器、工具名和参数模式；配置文件里出现过的名字不代表当前可调用，不能凭记忆补全工具。

## 定位故障

- 看不到服务器：检查进程、地址和连接状态。
- 看得到服务器但没有工具：检查初始化与工具枚举响应。
- 参数错误：对照当前 schema，先做最小只读调用。
- 超时或服务端错误：记录请求范围和错误码，缩小请求后重试。
- 写入结果不确定：先查询外部状态，未确认幂等前不得重复写入。

输出应包括实际可见工具、最小复现、故障所在层和下一步。这个 Skill 只负责发现与排障，不修改 MCP 服务器、组件 ID、地址、权限或协议契约。
