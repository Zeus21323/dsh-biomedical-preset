# 经济学知网优先检索

使用本 skill 来规范经济学文献研究任务。本 skill 定义来源优先级、期刊筛选和输出要求；具体浏览器操作规则来自 `browser_use` 或 remote-browser skill。

## 必须配合使用的 Skill

使用浏览器工具前，先读取并遵循：

`browser_use`

然后再满足本 skill 的相关约束。

每个任务中本 skill 文件读一次后就要记住其中的路由和检索规则。不要反复重新打开或重读这个 SKILL.md，除非用户要求查看或修改该文件、上下文丢失后需要恢复，或有明确理由核验文件已经变化。

如果可用 `mcp_remote_browser_*` 工具，遵循其生命周期规则：先列出设备，创建任务专属 session，打开重复标签页前检查已有标签页，优先使用结构化元素 ref，对敏感操作请求用户批准，并在浏览器工作结束前 finalize tabs。

## 研究流程

1. 先判断用户请求是否属于经济学相关问题：
   - 经济学和金融学：宏观经济学、微观经济学、计量经济学、金融学、产业经济学、发展经济学、劳动经济学、财政学、国际贸易、区域经济学、环境经济学、农业经济学、政治经济学、经济史、中国经济政策或实证经济学研究。
   - 如果不是经济学相关问题，使用主 standardization skill 的通用研究流程。
2. 对经济学相关请求，必须优先检索知网：
   - 从知网开始，使用用户问题中的中文关键词、英文关键词、作者名、理论名、政策名、数据集名、地区名和时间范围构造检索式。
   - 当任务需要更快发现文献、引用脉络或同时覆盖中文和国际文献时，如果浏览器/工具能力允许，应并行检索知网和 Google Scholar。知网仍是中文经济学文献主来源；Google Scholar 是高优先级并行来源，用于查找引用链、国际版本、全文入口和高引用文献。
   - 如果知网搜索框不响应 Enter，不要反复按 Enter 或在同一个输入框里重复尝试。应直接用编码后的 query 导航到知网搜索结果页，或使用知网高级检索/页面导航控件。
   - 普通关键词检索结果噪声大或结果稀少时，使用知网高级检索。
   - 用户要求学术证据时，优先看期刊论文，不要优先依赖未审稿网页。
   - 不要过度关注导航栏、页脚、推荐文献、服务链接、作者链接、期刊链接、AI 阅读链接等页面无关内容；重点关注有用的结果元数据，并认真阅读相关摘要。
   - 记录标题、作者、期刊、年份、期号、可用 DOI、知网来源 URL、关键词、摘要、可见引用量和下载/访问状态。
   - 知网全文下载通常需要登录、机构订阅、校园网 IP 或 VPN。用户要求下载知网论文时，必须立刻弹出/提示用户先登录知网或开启机构/VPN 访问，再尝试知网全文下载。提示中必须告知用户：“建议优先登录机构账号或开启校园网/VPN 访问；个人账号可能仍无法下载付费/订阅文章。”除非页面明确标注免费/开放获取，不要无意义地尝试未登录下载知网全文。
   - 只下载免费/开放获取的知网条目，或用户当前登录、机构订阅、校园网 IP、VPN 已授权可访问的条目。如果知网条目需要付费、订阅或当前授权不可用，不要尝试绕过访问限制；说明具体访问原因，并保留题录元数据。
   - 如果用户迟迟不确认登录/访问权限或没有回应，不要一直卡在知网下载。继续转向 Google Scholar、`academic_search_cn`、出版社页面、作者主页、机构仓储或其他合法全文来源，并明确说明知网全文未下载的原因是登录/访问权限未确认。
3. 知网之后，把 Google Scholar 和 arXiv 作为高优先级补充检索来源：
   - 尽早使用 Google Scholar 查找高引用经济学论文、中文议题的英文文献、相关国际研究和引用网络。
   - Google Scholar 是全文入口发现来源，不是批量下载器，也不是稳定 PDF 托管源。用它发现题录、引用链、所有版本和候选全文链接后，必须进入真实来源页面，例如出版社、作者主页、机构仓储、SSRN、NBER、RePEc、CEPR、IZA 或期刊页面。
   - 不要通过 Google Scholar 结果链接批量下载 PDF。候选全文链接必须逐篇处理；每次下载后检查 HTTP 状态、Content-Type 和 `%PDF-` 文件头。如果 Google Scholar 或真实来源返回验证码、异常流量、Access Denied、HTML、登录页或付费墙，停止该下载路径，并说明具体原因。
   - 如果识别到用户问题明显属于西方经济学、国际经济学文献、经典经济理论、英文实证研究或非中国特定研究，不要在知网上反复尝试不同关键词组合。完成一次聚焦的知网检索后，应尽早转向 `academic_search_cn` 和 Google Scholar。
   - 经济学下载任务中，不要早于 Google Scholar/全文发现路线使用 arXiv。必须先用 Google Scholar 和 `academic_search_cn` 找真实来源页面，再尝试出版社、作者主页、机构仓储、NBER、SSRN、RePEc、CEPR、IZA 和期刊页面。
   - 只有当 Google Scholar/全文发现和真实来源页面都无法提供可下载 PDF 后，才把 arXiv 作为兜底下载来源，除非用户明确要求 arXiv/预印本。arXiv 兜底更适合 working paper、数量方法、计量经济学、金融学、机器学习与经济学、网络经济学或近期国际研究。
   - 使用 arXiv 兜底时，最多尝试一到两次聚焦检索；如果结果稀少或偏题，应停止重试 arXiv，并报告必需来源没有提供可下载 PDF。
   - 普通经济学文献下载、中文经济学主题、微观经济学理论/课程主题，或用户要求 CNKI/Google Scholar 下载时，不要把 arXiv 当主来源。arXiv 只能在 CNKI/Google Scholar 或其他经济学来源尝试后，用于方法类/working paper 补充发现。
   - 如果用户明确要求知网、Google Scholar 或经济学文献来源，不要因为 arXiv 返回大量 PDF 就切换到 arXiv。arXiv 结果数量多，不能替代用户要求的来源路线。
   - Google Scholar 和 arXiv 的补充检索优先级高于普通网页搜索、新闻页面、博客和无来源的二级总结。
   - 不要把 arXiv 预印本直接当成已同行评议的期刊证据，除非已核验其后续发表版本。
   - 重要的 Google Scholar/arXiv 发现，应尽量用期刊页面、出版社页面、NBER/SSRN/RePEc/CEPR/IZA 页面、作者主页或机构仓储交叉核验。
   - OpenAlex、Semantic Scholar、Crossref、Unpaywall 或类似 API 不是经济学文献发现的主检索路线。除非用户明确要求这些来源，或已完成知网 + Google Scholar/`academic_search_cn` 路线且仍需要补充 DOI、作者、发表信息、引用线索或开放获取链接，否则不要启动这些 API 检索。
   - 如果使用 OpenAlex、Semantic Scholar、Crossref、Unpaywall 或类似 API，必须在输出中说明它们只是元数据/开放获取核验工具，不得把 API 返回结果替代知网、Google Scholar、`academic_search_cn`、出版社、作者主页、机构仓储、NBER、SSRN、RePEc、CEPR、IZA 或期刊页面的来源优先级。
4. 优先看中国人民大学核心期刊目录中的经济学期刊：
   - 先筛选中国人民大学核心期刊目录中的期刊，尤其是经济学 A 类和经济学 B 类。
   - 在相关性和证据质量接近时，经济学 A 类优先于经济学 B 类。
   - 除非目录或可靠来源确认，不要声称某期刊属于人大经济学 A/B。
   - 如果目录不可访问，或期刊分类无法核验，要明确说明“未核验分类”。
5. 再考虑其他经济学相关顶刊和高引用文献：
   - 中文文献中，也可以考虑 CSSCI、北大核心和有影响力的经济学期刊；但当用户明确需要中文经济学顶刊时，仍以人大经济学 A/B 为优先。
   - 国际文献中，可考虑 AER、QJE、JPE、Econometrica、Review of Economic Studies、Journal of Finance、Review of Financial Studies、Journal of Financial Economics、Journal of Labor Economics、Journal of Development Economics、Journal of International Economics 等综合或领域顶刊。
   - 只在文献与用户问题高度相关时，才因高引用而优先；不要只按引用量排序。
   - 综合考虑引用量、时效性、识别策略、数据质量、期刊质量和与问题的直接相关性。
6. 下载高相关文献前先询问用户：
   - 为了提高响应速度，第一轮文献检索时不要直接下载论文，除非用户一开始就明确要求下载。
   - 先识别并总结最相关的文献，然后询问用户是否需要下载全文。
   - 只有在用户允许且访问权限允许时，才下载完整论文。默认要求交付 PDF。每个下载到的 PDF 都要保存到工作区，并通过平台的用户可见文件/产物机制把同一 PDF 提供到对话区。
   - 如果因为访问限制、登录、付费墙、缺少 PDF 链接或技术问题无法下载，说明具体原因，并保留文献元数据。
   - 当用户明确要求下载文献时，两个位置都必须完成：工作区文件和对话区文件/产物。不要把浏览器标签页、Chrome 下载记录、来源 URL 或只有元数据的引用当作已完成下载。
   - 当用户追问“为什么没下载”、要求下载全文/PDF，或任务产物明显需要论文文件时，视为下载请求。不要只写元数据或论文清单后结束。
   - 对知网论文，必须在知网全文下载前立刻提示用户登录知网或开启机构/VPN 访问。提示中必须写明：“建议优先登录机构账号或开启校园网/VPN 访问；个人账号可能仍无法下载付费文章。”除非条目明确免费/开放获取，不要尝试“未登录直接下载”知网全文。如果用户迟迟不确认访问权限，继续使用 Google Scholar、`academic_search_cn`、出版社页面、作者主页、机构仓储、NBER、SSRN、RePEc、CEPR 或 IZA，并说明知网全文未下载的原因是登录/访问权限未确认。
   - 知网下载范围只限免费/开放获取条目，以及用户当前登录、机构订阅、校园网 IP 或 VPN 授权可访问的条目。付费、订阅限定或当前授权不可用的知网文件，应报告为不可下载，不要反复尝试。
   - 知网批量提速规则：确认访问权限后，可以先从选中的知网结果页/文章页批量建立下载队列，只纳入明确提供 `PDF下载` 或等价 PDF 按钮的条目。优先从当前结果页、页面 DOM、链接元素或已打开文章页中提取文章 URL 和 PDF 下载 URL；如果能从列表页/当前页提取 PDF 链接或按钮目标，不要为了点击 `PDF下载` 而逐篇串行打开详情页。不要把 `CAJ下载` 链接放进队列。下载时最多保持 2 个浏览器下载并发；每一小批下载后先校验并移动到工作区，再开始下一批。
   - 详情页兜底：只有当结果页/列表页没有暴露可用 PDF 下载目标，或必须进入详情页确认 PDF 权限时，才逐篇打开知网详情页。复用已有标签页并关闭已完成详情页；当可以批量提取时，不要对每篇论文重复“回列表、开详情页、点 PDF、关标签页”的慢流程。
   - 知网批量下载必须维护清单，记录题名、来源 URL、点击的按钮/链接类型、下载文件名、最终工作区路径和 PDF 校验状态。如果任一下载返回登录页、验证码、HTML、CAJ/NH/KDH、零字节/过小文件或非 `%PDF-` 文件头，必须立刻暂停批量流程，先诊断该条目再继续。
   - 知网格式规则：下载到 CAJ、NH、KDH 或其他知网阅读器专用格式，不算完成 PDF 下载。不要把 CAJ 重命名成 PDF，也不要报告为下载成功。如果知网只提供 CAJ/阅读器格式，应说明该来源未提供 PDF，保留题录元数据，并继续走 Google Scholar/全文发现，或询问用户是否明确接受 CAJ。
   - 浏览器下载位置规则：如果浏览器把文件保存到默认下载目录，必须立刻定位该文件，检查 `%PDF-` 文件头确认是 PDF，然后移动或复制到任务工作区，并提供到对话区。只留在 Chrome 下载记录里不算交付。
   - 不要为了检查论文是否下载完成而把当前浏览器标签页跳转到 `chrome://downloads` 或下载记录页。应让用户停留在文章页/来源页，通过浏览器下载事件、下载按钮/浮层或文件系统在后台定位下载文件。
   - 每篇下载文件必须做 PDF 校验：检查扩展名、可用时检查 Content-Type，并检查文件头。如果文件头不是 `%PDF-`，停止把它当 PDF，报告实际格式或前几百字节诊断信息。
   - Google Scholar 下载范围：绝不能把 Google Scholar 当文件来源。Google Scholar 只能作为真实全文位置的索引；不要从 Google Scholar 批量点击或批量下载，必须逐篇进入真实宿主站点后再尝试下载。
   - 经济学下载请求必须按来源顺序执行，除非用户另有要求：中文经济学主题先查知网元数据/权限；再用 Google Scholar 和 `academic_search_cn` 发现全文；再查出版社、作者、机构仓储和 working paper 仓库。只有当 Google Scholar/全文发现和真实来源页面失败后，才允许 arXiv 兜底；或用户明确要求 arXiv/预印本时使用 arXiv。
   - 经济学下载请求中，OpenAlex、Semantic Scholar、Crossref、Unpaywall 或类似 API 只能用于补齐 DOI/题录、定位开放获取候选链接或核验元数据；不得作为批量下载分支，也不得早于知网访问检查、Google Scholar/`academic_search_cn` 全文发现和真实来源页面检索启动。
   - 经济学下载硬性停止条件：如果当前计划是“arXiv 找到很多结果，现在批量下载 PDF”，但还没有尝试必需的知网/Google Scholar/全文发现路线，这个计划无效。必须停止，放弃把 arXiv 当下载来源，回到必需来源路线。
   - 经济学下载硬性停止条件：如果当前计划是“用 OpenAlex/Semantic Scholar 批量找论文，再用 Unpaywall 批量取开放获取 PDF”，但还没有尝试必需的知网/Google Scholar/`academic_search_cn`/真实来源路线，这个计划无效。必须停止，回到必需来源路线。
   - 普通经济学、微观经济学、中文经济学、知网或 Google Scholar 下载请求中，不要把 arXiv PDF 计入任务完成，除非已先尝试 Google Scholar/全文发现和真实来源页面且失败，或用户明确同意 arXiv/预印本。
7. 进行多源核验：
   - 当期刊分类、发表年份、引用量、作者身份、政策或事件时间影响答案时，必须核验。
   - 重要信息可用知网、期刊官网、出版社页面、高校/图书馆页面、Google Scholar、arXiv、Web of Science、CSSCI/北大核心目录、NBER、SSRN、RePEc、CEPR、IZA 或其他可靠索引交叉检查。
   - 区分来源直接支持的事实和自己的推断。
8. 综合归纳，不要大段粘贴：
   - 不要直接倾倒完整摘要或搜索结果页。
   - 用用户请求的语言总结文献。
   - 尽可能附上来源链接和标识符。

## 知网检索建议

使用适合知网的检索策略：

- 主题检索：组合核心概念、同义词和政策/事件名，例如 `数字经济 AND 企业创新`、`共同富裕 AND 收入分配`、`产业政策 AND 全要素生产率`。
- 实证设计检索：加入 `双重差分`、`断点回归`、`工具变量`、`面板数据`、`准自然实验`、`机制检验`、`异质性分析` 等词。
- 数据检索：加入数据集或数据来源名，例如 `中国家庭追踪调查`、`工业企业数据库`、`上市公司`、`海关数据库`、`城市面板`、`县域数据`。
- 期刊筛选：先过滤或人工筛选人大经济学 A/B 期刊，再看其他顶刊或高影响期刊。
- 国际补充检索：知网之后，用英文关键词、作者名、数据集名和方法名检索 Google Scholar 和 arXiv；这两个来源优先于普通网页搜索。
- Google Scholar 处理：只把 Google Scholar 用作发现入口。不要把它当直接 PDF 下载 API；必须进入真实宿主站点，并逐篇核验下载结果。
- 并行检索：有必要时并行检索知网 + Google Scholar，尤其适合既需要中文经济学文献，又需要国际引用脉络的问题。
- 西方经济学：如果主题主要是西方/国际经济学，而不是中国特定中文文献，完成一次聚焦的知网检索后，应尽早转向 `academic_search_cn` 和 Google Scholar，不要在知网上反复改关键词消耗时间。
- arXiv 兜底限制：经济学下载任务中，只有 Google Scholar/全文发现和真实来源页面失败后，才使用 arXiv，除非用户明确要求 arXiv/预印本。一次或两次聚焦检索失败或偏题后就停止重试。
- arXiv 防偏航：不要因为 arXiv PDF 容易下载，就用 arXiv PDF 满足知网/Google Scholar/经济学文献下载请求。如果使用 arXiv，必须说明此前哪些 Google Scholar/全文发现和真实来源路线失败了。
- 无效计划模式：“arXiv 找到 N 篇相关论文，现在批量下载 PDF”不适用于普通经济学下载任务。必须改为知网访问检查、Google Scholar/全文发现，以及出版社/作者/仓储检索。
- API 防偏航：OpenAlex、Semantic Scholar、Crossref、Unpaywall 或类似 API 只可作为 DOI、题录、引用线索、开放获取链接的核验工具。不要把“并行查询 OpenAlex/Semantic Scholar，并用 Unpaywall 找 PDF”作为经济学文献主检索或下载计划，除非用户明确要求这些 API。
- 无效计划模式：“知网结果不理想，所以改用 OpenAlex/Semantic Scholar 批量检索，再用 Unpaywall 批量找 PDF”不适用于普通经济学任务。必须先完成一次聚焦知网检索，再按规则使用 Google Scholar、`academic_search_cn` 和真实来源页面。
- 引用排序：把引用量作为相关性信号之一，不要作为唯一排序标准。

## 并行检索建议

使用并行检索来减少等待时间并提高覆盖面，但要保持来源优先级清楚：

- 知网 + Google Scholar：经济学文献发现时，尽可能并行检索。知网用于中文期刊文献、人大经济学 A/B 筛选、CSSCI/北大核心语境和中国政策文献；Google Scholar 用于引用链、国际版本、英文论文、全文入口和高引用研究。
- Google Scholar 分支只应输出候选真实来源页面，不应批量下载 PDF。如果遇到反爬、验证码或异常流量页面，停止该分支并报告限制原因。
- 知网 + `academic_search_cn`：当主题是中国特定问题但需要更广学术索引，或知网页面导航较慢时，可以并行检索。
- Google Scholar + `academic_search_cn`：西方/国际经济学主题完成一次聚焦知网检索后，可以并行检索。
- arXiv 默认不是主要并行分支。经济学下载任务中，除非用户明确要求 arXiv/预印本，否则不要在 Google Scholar/全文发现和真实来源页面失败前启动 arXiv 下载分支。
- OpenAlex、Semantic Scholar、Crossref、Unpaywall 或类似 API 默认不是并行检索分支。不得与知网/Google Scholar 同时启动为经济学主检索；只有在主路线已产出候选文献后，才可用于补齐 DOI、开放获取链接、引用线索或元数据。
- 经济学下载任务不要只跑 arXiv，除非用户明确要求 arXiv/预印本。如果 arXiv 返回大量 PDF，但 CNKI/Google Scholar/全文发现路线还没有失败，应忽略 arXiv 作为下载来源，继续执行必需来源路线。
- 如果 arXiv 分支最先完成，不允许让它决定最终交付。必须等待或继续知网/Google Scholar/全文发现分支，再按来源优先级决定下载。
- 总结前按标题、DOI、working paper 编号、作者/年份和期刊去重。
- 如果并行来源结论冲突，要说明冲突，并按不同 claim 类型选择最权威的来源。

## 知网页面处理效率规则

知网结果页通常包含大量无关内容，例如导航栏、页脚、推荐文献、服务链接、作者链接、期刊链接、AI 阅读链接和重复工具链接。不要在这些内容上消耗过多注意力。

提取文章结果时按以下顺序处理：

1. 先调用 `interactive_elements`。
2. 如果 `interactive_elements` 中没有文章标题链接，不要立刻完整分析整个 snapshot。
3. 如果知网搜索框不响应 Enter，应直接用编码后的 query 导航到知网搜索结果页，不要反复按 Enter。
4. 调用 `snapshot` 或 `page_info`，但如果工具支持，要限制 `max_chars`。
5. 在返回内容里搜索用户关键词、`篇名`、`作者`、`来源`、`下载` 和 `HTML阅读`。
6. 认真阅读有用的摘要，用摘要判断文献相关性。
7. 忽略作者链接、期刊链接、AI 阅读链接、推荐链接、服务链接、导航链接和页脚链接，除非它们对当前任务确实必要。
8. 必要时只打开最相关的 1-5 篇文章。

## 输出标准

提供简洁的研究答案，包含：

- 先给直接答案或文献结论。
- 必要时给一个简短证据表：标题、作者、期刊、年份、已核验的期刊类别、可见引用量、方法/数据和相关性。
- 明确说明是否已优先检索知网。如果未使用知网，说明原因。
- 说明使用了哪些并行检索，例如知网 + Google Scholar 或 Google Scholar + `academic_search_cn`，以及为什么使用。
- 说明是否使用 `academic_search_cn`、Google Scholar 和 arXiv 作为补充检索。如果 arXiv 被跳过或提前停止，简要说明 arXiv 只是辅助来源或不适合该问题。
- 说明检查了哪些人大经济学 A/B 期刊或论文，以及分类是否已核验。
- 输出最贴近用户问题、最相关且质量最高的一组文献。
- 最后询问用户是否需要下载最相关文献全文，除非用户已经明确要求下载。
- 说明重要限制：访问限制、期刊分类无法核验、引用量可能滞后，或不同来源之间存在冲突。
