# WGCNA 共表达网络

多组学、共识网络或WGCNA+执行时读取[WGCNAplus方法分支](references/WGCNAplus.md)。单组学仍可用经典WGCNA，不为“AI”标签强制更换方法。代理准备配置、样本对应和参数依据；`scripts/run_wgcna_multiomics.R` 仅运行已安装且确认许可的适配版本，默认关闭外部AI与网络报告。

1. 检查样本聚类、离群值、批次与表达过滤；样本过少时先说明网络不稳定。
2. 选择有生物依据的signed或unsigned网络，通过尺度无关性与平均连接度共同确定软阈值。
3. 构建TOM、切分并合并模块，记录最小模块大小和合并阈值。
4. 模块特征向量与性状关联时纳入协变量并校正多重检验。
5. 用模块成员度、基因显著性和外部证据联合定义候选枢纽，并做保留性验证。

输出模块分配、关联矩阵、候选基因和参数；不能只按模块颜色或高连接度声称机制。

直接交付模块–性状效应/不确定性图、跨层模块关联热图及保留性比较；树状图作为建模诊断。保持各组学实体身份，不把蛋白、代谢物全称为基因。跨队列缺少一一配对时不计算虚假的样本级跨层相关。AI文字仅辅助解释，并逐条回指真实成员/富集证据；无外部验证就明确为探索性网络。
