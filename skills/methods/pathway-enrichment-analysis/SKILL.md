# 通路与功能富集分析

1. 统一标识和物种，建立真正被检测到的背景集，不默认使用全基因组。
2. 选择与数据类型相符的数据库版本，处理一对多映射并记录未注释比例。
3. 进行过度富集并校正多重检验，同时报告命中数、背景数、效应和FDR。
4. 合并高度重叠的术语，用核心命中基因解释而非逐条复述通路名称。
5. 输出完整结果、冗余整理、数据库版本和可复现输入集。

富集表示候选集合中的过度代表，不证明通路被激活，也不应从挑选后的几个术语反推假设。
