# CPIC 与 DPWG 用药指南解释

1. 确认患者基因型或星等位基因、代谢表型、药物、适应证、年龄和关键合并用药。
2. 锁定指南组织、版本、发布日期和适用人群，检查监管标签与本地规范。
3. 将基因型准确映射到指南表型和推荐分支，保留无法唯一映射的情况。
4. 逐条说明推荐强度、替代药、剂量调整、监测和非遗传影响因素。
5. 输出指南原意摘要、患者匹配、证据等级和临床复核问题。

本Skill解释指南，不替代医师处方；CPIC与DPWG不一致时必须并列呈现而非任选其一。
