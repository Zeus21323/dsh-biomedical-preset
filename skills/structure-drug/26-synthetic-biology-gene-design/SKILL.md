# DNA组装与分子克隆

## 方法选择

- 少量片段、一次性无缝构建通常先评估 Gibson。
- 模块化组合、方向性多片段或文库构建通常先评估 Golden Gate。
- 已有兼容限制位点的简单插入可考虑传统酶切连接。

开始前需要载体和全部插入片段的完整 5'→3' 序列、预期拓扑、片段方向、连接点、阅读框和可用载体/酶。

## 连接设计

1. 按最终产物顺序拼出理论序列，包括环状起点连接。
2. 检查重复、极端 GC、阅读框、启动子方向及 Golden Gate 内部 Type IIS 位点。
3. Gibson 重叠需唯一且退火性质相容；Golden Gate 四碱基粘性末端需定向、互不重复且避免自配对。
4. 将连接序列转成扩增引物或合成片段，并再次核对接头方向和总长度。
5. 设计菌落PCR、诊断酶切和跨全部连接点的测序；关键构建优先完整质粒测序。

## 交付

给出方法理由、片段顺序、每个连接点、扩增/合成序列、理论产物和验证读出。计算上可拼接不代表克隆一定正确，不能省略结构验证。
