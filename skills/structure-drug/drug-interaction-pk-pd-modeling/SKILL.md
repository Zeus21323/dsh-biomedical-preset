# 药物相互作用与PK-PD建模

先分别列出受害药、施害药、代谢酶、转运体、给药时间、剂量、肝肾功能和药物基因型。药物基因型影响基础代谢能力，但不能替代抑制、诱导、竞争底物和疾病状态的评估。

DDI 证据按体外机制、临床暴露变化、标签或指南和真实世界结果分层。PK-PD 建模先定义结构模型、观察模型、协变量和终点时间关系；若只有少量汇总数据，应限制为机制评估或情景模拟，不能伪装成群体模型。

需要组织 CYP/转运体证据、暴露变化和模型诊断时读取[相互作用与建模规范](references/相互作用与建模规范.md)。交付作用方向、证据等级、预期暴露变化、基因型修饰、模型参数、不确定性和需要监测的终点。

任何剂量建议都必须引用适用指南或经验证模型，并由临床专业人员复核；模型预测不能自动成为处方指令。
