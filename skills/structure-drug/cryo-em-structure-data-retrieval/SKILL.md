# 冷冻电镜结构数据检索

1. 按靶标、复合物组成、状态和物种检索，并关联EMDB图谱与PDB模型。
2. 核对全局与局部分辨率、粒子数、对称性、掩膜、地图锐化和验证报告。
3. 检查构象状态、配体、缺失亚基和模型到地图的拟合，不只比较名义分辨率。
4. 下载原始或处理后地图时保留标识、版本、像素大小和轮廓建议。
5. 输出结构—地图对应表、质量摘要和最适合目标任务的候选。

局部分辨率较差区域不应支持原子级结论；不同处理地图的轮廓值不能机械横向比较。
