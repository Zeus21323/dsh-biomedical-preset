# 药物响应预测模型规范评估（nf-core/drugresponseeval）

## 识别数据与研究目标

从交付文件与报告中识别药物响应、细胞模型/药物特征、候选模型和评价方案，明确按样本、药物或二者留出的泛化目标。

## 方法选择

依据 DrEval 的交叉验证和嵌套超参选择组织比较，启用需要的随机化/稳健性测试，保持各模型训练信息公平。

先核对 [版本约定](references/流程约定.json)。

| 核对项 | 固定范围 |
|---|---|
| 上游版本 | `1.2.2`；`84cb752a7ca4584fcb95fcb7492aceb4137a3df7` |
| 上游维护 | 未归档；使用这里固定的源码，不自动跟随新版本 |
| 本地运行 | 未进行真实分析运行；不能据本 Skill 文件声称实跑通过 |
| 引擎声明 | `!>=25.10.4`；还需核验 Java、容器和 profile |

## 根据数据确定参数

依泛化目标选择按细胞、药物或双重留出的划分，超参数只在训练内层选择；指标结合响应尺度与类分布，不用测试表现挑模型。

| 决策与配置 | 处理要求 |
|---|---|
| 事实与缺口 | 先读现有文件和报告；不能据文件名猜实验类型、参考或样本关系；只补问无法核实且会改变分析的背景 |
| 参数来源 | 区分协议必需设置、数据估计、方法默认和研究选择；说明实际取值及理由，不要求用户填写专业参数 |
| 可执行配置 | 仅把已支持的选择映射为当前版本的原生字段；不支持的步骤另行交接，不虚构开关 |
| 阈值复核 | 默认值先评估适用性；依据质控、对照及敏感性检查调整，不能按显著结果数量调参 |

| 资料 | 使用时机 |
|---|---|
| [参数模式.json](references/参数模式.json) | 编写 params.json 时核对字段、类型、枚举及条件约束 |

仅在已授权且配置齐备时运行。

```bash
nextflow run nf-core/drugresponseeval -r 84cb752a7ca4584fcb95fcb7492aceb4137a3df7 -params-file params.json
```

模式文件的许可见 [LICENSE](LICENSE)。

## 质控与解释

检查重复细胞系、药物重叠、预处理泄漏和响应尺度，分别报告划分间不确定性。

交付模型预测、指标、稳健性和可重复设置；体外模型表现不能直接转换为患者治疗反应结论。
