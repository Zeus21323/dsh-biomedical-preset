# 蛋白质结构质量评估

1. 区分X射线、冷冻电镜、NMR和预测模型，选择对应质量指标。
2. 检查Ramachandran、键长键角、侧链构象、碰撞和链断裂，并定位到具体残基。
3. 实验结构结合分辨率、R值或地图拟合；预测结构结合pLDDT、PAE和模型间一致性。
4. 对活性位点、界面和突变位点单独评估，不能只报告全局平均质量。
5. 输出问题清单、严重度、可修复建议和下游适用性结论。

质量分数不能证明生物构象正确；局部缺陷可能比全局评分更影响具体任务。
