# 蛋白质结合口袋识别

1. 准备结构并保留相关辅因子、金属和关键水，区分实验与预测模型。
2. 综合几何、保守性、已知配体和多工具预测得到候选口袋，不能只采用单一最高分。
3. 评估体积、深度、疏水性、极性、可接近性和构象稳定性。
4. 通过同源结构、分子动力学或突变证据验证口袋是否持续存在且具有功能相关性。
5. 输出口袋坐标、残基、评分分解、对接盒建议和不确定性。

“可成药性”是相对优先级而非成药保证；隐蔽口袋与诱导契合需动态证据支持。
