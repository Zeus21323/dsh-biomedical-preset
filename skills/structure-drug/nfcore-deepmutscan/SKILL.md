# 深度突变扫描与适应度估计（nf-core/deepmutscan）

## 识别数据与研究目标

从交付文件与报告中识别 DMS shotgun DNA 测序、参考 ORF、突变设计、选择前后/时间点及重复，明确需要估计的表型。

## 方法选择

按 alignment、QC、error-aware fitness 三阶段处理，选择与设计匹配的 DiMSum、Enrich2、rosace 或其他实际支持方法。

先核对 [版本约定](references/流程约定.json)。

| 核对项 | 固定范围 |
|---|---|
| 上游版本 | `dev`；`3a055755d43dbbd69af64e6f0130fd82cf6833b9` |
| 上游维护 | 开发版本；按当前代码实际实现的范围使用 |
| 本地运行 | 未进行真实分析运行；不能据本 Skill 文件声称实跑通过 |
| 引擎声明 | `!>=25.10.4`；还需核验 Java、容器和 profile |

## 根据数据确定参数

根据文库设计、输入计数、误差及重复选择计数过滤和适应度模型；低计数候选保留不确定性，选择过程不同不能只用终点比例统一解释。

| 决策与配置 | 处理要求 |
|---|---|
| 事实与缺口 | 先读现有文件和报告；不能据文件名猜实验类型、参考或样本关系；只补问无法核实且会改变分析的背景 |
| 参数来源 | 区分协议必需设置、数据估计、方法默认和研究选择；说明实际取值及理由，不要求用户填写专业参数 |
| 可执行配置 | 仅把已支持的选择映射为当前版本的原生字段；不支持的步骤另行交接，不虚构开关 |
| 阈值复核 | 默认值先评估适用性；依据质控、对照及敏感性检查调整，不能按显著结果数量调参 |

| 资料 | 使用时机 |
|---|---|
| [参数模式.json](references/参数模式.json) | 编写 params.json 时核对字段、类型、枚举及条件约束 |
| [输入模式-1.json](references/输入模式-1.json) | 准备 input 对应的样本表或输入文件时读取 |

仅在已授权且配置齐备时运行。

```bash
nextflow run nf-core/deepmutscan -r 3a055755d43dbbd69af64e6f0130fd82cf6833b9 -params-file params.json
```

模式文件的许可见 [LICENSE](LICENSE)。

## 质控与解释

检查突变覆盖、测序错误、瓶颈、重复一致性和计数噪声，保留多突变组合与单突变效应的区别。

交付突变计数、适应度与不确定性；实验条件中的 fitness 效应不自动等同人类致病性或所有环境下的功能。
