# CRISPR编辑与筛选测序分析（nf-core/crisprseq）

## 识别数据与研究目标

区分 targeted 编辑评估与 pooled screening，准备扩增子/文库、gRNA、参考、对照和实验设计。

## 方法选择

按本版本模式分别组织编辑位点分析或筛选命中流程，保持 guide 与目标基因映射，避免将两种输入样本表混用。

先核对 [版本约定](references/流程约定.json)。

| 核对项 | 固定范围 |
|---|---|
| 上游版本 | `2.3.0`；`0e9f915c4a3c89d02a66ec58e2decbc832323c8b` |
| 上游维护 | 未归档；使用这里固定的源码，不自动跟随新版本 |
| 本地运行 | 未进行真实分析运行；不能据本 Skill 文件声称实跑通过 |
| 引擎声明 | `!>=24.04.2`；还需核验 Java、容器和 profile |

## 根据数据确定参数

先按目标区与 guide 文库区分编辑检测和筛选，编辑窗口依据切点及供体设计，筛选过滤依据 guide 覆盖和对照；两种任务不共用默认样本表与阈值。

| 决策与配置 | 处理要求 |
|---|---|
| 事实与缺口 | 先读现有文件和报告；不能据文件名猜实验类型、参考或样本关系；只补问无法核实且会改变分析的背景 |
| 参数来源 | 区分协议必需设置、数据估计、方法默认和研究选择；说明实际取值及理由，不要求用户填写专业参数 |
| 可执行配置 | 仅把已支持的选择映射为当前版本的原生字段；不支持的步骤另行交接，不虚构开关 |
| 阈值复核 | 默认值先评估适用性；依据质控、对照及敏感性检查调整，不能按显著结果数量调参 |

| 资料 | 使用时机 |
|---|---|
| [参数模式.json](references/参数模式.json) | 编写 params.json 时核对字段、类型、枚举及条件约束 |
| [输入模式-1.json](references/输入模式-1.json) | 准备 input 对应的样本表或输入文件时读取 |

仅在已授权且配置齐备时运行。

```bash
nextflow run nf-core/crisprseq -r 0e9f915c4a3c89d02a66ec58e2decbc832323c8b -params-file params.json
```

模式文件的许可见 [LICENSE](LICENSE)。

## 质控与解释

定向编辑检查比对和 indel 背景，筛选检查文库覆盖、guide 一致性与对照，分开技术和生物学重复。

交付编辑结果或筛选统计及 QC；guide 富集不直接证明特异机制，需脱靶和独立验证支持。
