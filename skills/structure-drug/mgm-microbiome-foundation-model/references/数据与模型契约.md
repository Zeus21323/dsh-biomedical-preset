# MGM 数据与模型契约

## 表格方向

在运行前明确 MGM 版本期望“样本×特征”还是“特征×样本”，不要依赖第一列猜测。标签表必须通过样本 ID 显式连接，连接后报告丢失、重复和顺序变化。

## Checkpoint 兼容性

记录 MGM 版本、checkpoint SHA-256、特征词表、最大长度和预处理方式。缺少词表或与输入特征空间不兼容时停止；不得仅凭张量维度相同推定模型兼容。

## 训练与生成

训练输出记录数据切分、优化器、学习率、批量大小、epoch、早停标准和随机种子。生成数据必须标为 synthetic，并报告生成数、采样参数、与训练样本的近邻或重复检查及隐私风险。

## 预测

预测结果保留样本 ID、原始分数、概率或连续值、模型版本和阈值。分类阈值必须来自训练/验证数据或外部规范，不能在目标测试集上选择。
