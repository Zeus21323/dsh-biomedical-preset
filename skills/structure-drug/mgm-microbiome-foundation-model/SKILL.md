# MGM 微生物组基础模型

## 输入与边界

输入必须是带稳定样本 ID 和特征 ID 的丰度表；监督任务另需按样本 ID 对齐的标签或结局表。检查非数值值、负值、重复 ID、全零样本、缺失特征和训练/推理词表兼容性。不要把 FASTQ、contig 或尚未定量的物种列表直接送入 MGM。

## 模式选择

- `construct`：从丰度表构建 MGM 语料。
- `pretrain`：从头训练表征模型，需明确训练资源和停止规则。
- `finetune`：在已有兼容 checkpoint 上适配目标队列。
- `predict`：对标签或结局进行监督预测。
- `generate`：生成模型样本，不能作为真实受试者数据使用。
- `reconstruct`：将模型表示恢复为可解释的丰度形式。

可使用 `scripts/run_mgm.py` 调用外部 MGM CLI。详细约束见[数据与模型契约](references/数据与模型契约.md)。

## 防止泄漏

词表构建、归一化、特征选择、预训练适配和超参数选择必须遵守患者、中心和时间切分。若在目标测试队列上继续预训练或重建，应明确这是转导设置，不得作为完全外部验证。

## 输出

交付语料或模型产物、样本级预测/嵌入/生成/重建结果、未识别特征、输入与 checkpoint 哈希、完整命令、随机种子、软件版本和运行状态。模型权重不进入本仓库。
