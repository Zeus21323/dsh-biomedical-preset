# 计算与质控规范

## 最低输入字段

- 受试者或实验单位；
- 给药周期或 occasion；
- 实际相对时间；
- 浓度和浓度单位；
- 剂量和剂量单位；
- 给药途径；
- BLQ、缺失、重采样和输注结束信息。

## 参数定义

- `Cmax`、`Tmax`：观测值，不通过曲线平滑制造。
- `AUClast`：到最后可量化浓度的面积。
- `lambda_z`：终末对数线性回归斜率的相反数。
- `t1/2`：`ln(2) / lambda_z`。
- `AUCinf`：`AUClast + Clast/lambda_z`。
- 血管外 `CL/F = Dose/AUCinf`，`Vz/F = CL/F/lambda_z`。

## 质控

- 至少三个终末相点，且时间不同、浓度为正。
- 报告终末拟合调整后决定系数和采用点。
- 报告 AUC 外推比例；比例过高时标记不可靠。
- 单位必须在计算前统一，不允许脚本猜测换算。
- 重复给药、稳态、输注和尿排泄参数需要另行建模，不能套用简单单剂量公式。
