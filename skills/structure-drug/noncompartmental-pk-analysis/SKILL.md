# 非房室药代动力学分析

先确认给药途径、剂量、剂量单位、浓度单位、实际采样时间、BLQ 规则和受试者周期。时间必须使用实际采样值；不能用计划时间掩盖偏差。静脉和血管外给药的清除率与分布容积解释不同。

按预先规定的线性、对数线性或线性向上—对数向下规则计算 AUC。终末相点不能只按最后三个点机械选择，应检查浓度单调下降、拟合优度和终末相覆盖；AUC 外推比例过高时，AUCinf、半衰期和相关参数不可靠。

实际计算前读取[计算与质控规范](references/计算与质控规范.md)，再运行 `scripts/nca.py`。脚本使用标准 CSV、明确剂量和给药途径，输出逐受试者参数与质控标记；维护时运行 `scripts/test_nca.py`。

交付原始曲线、BLQ 处理、终末相点、参数和单位、AUC 外推比例及排除理由。该结果服务研究分析，不能在缺少方案与专业复核时直接用于个体给药决策。
