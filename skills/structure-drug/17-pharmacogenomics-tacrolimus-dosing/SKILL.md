# 他克莫司基因型指导剂量

1. 核对CYP3A5基因型、移植器官、年龄、祖源、给药途径、合并药和目标谷浓度。
2. 将基因型映射为表达者或非表达者表型，确认罕见等位基因与检测覆盖。
3. 按最新指南解释起始剂量调整倍数、上限和适用条件，不忽略药物相互作用。
4. 强调治疗药物监测，根据谷浓度、肾功能和临床状态快速个体化调整。
5. 输出指南匹配、起始讨论范围、监测计划和技术/临床限制。

基因型主要帮助起始剂量，不能替代血药浓度监测；最终处方由移植团队决定。
