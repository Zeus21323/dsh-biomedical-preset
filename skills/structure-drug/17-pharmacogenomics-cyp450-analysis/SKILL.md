# CYP450 星等位基因与代谢表型

处理 CYP2D6 复制、杂合基因、多解或从表型延伸到联合用药时，读取[复杂位点与药物相互作用边界](references/复杂位点与药物相互作用边界.md)。星等位基因转换与多药 PK/PD 分析是相邻但不同的任务。

1. 核对参考版本、检测平台、覆盖、目标基因和是否能检测CNV、杂合融合或相位。
2. 使用当前等位基因定义匹配变异组合，保留多个可能双倍型与未覆盖判定位点。
3. 对CYP2D6等复杂位点检查拷贝数、结构变异、杂合基因和相位，必要时建议专门检测。
4. 按权威指南把双倍型转换为活性分数和代谢表型，记录版本与例外规则。
5. 输出星等位基因、表型、置信度、技术盲区和需复核事项。

缺失变异不等于参考等位基因；低分辨率结果不得强行指定唯一星等位基因。
