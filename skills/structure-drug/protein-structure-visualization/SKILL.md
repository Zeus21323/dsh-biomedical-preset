# 蛋白质结构可视化

1. 明确图要表达的结构关系，并锁定链、残基编号和构象。
2. 主体、配体、关键残基和不确定区域使用一致且色盲友好的编码，避免颜色含义冲突。
3. 界面或口袋图同时给出整体定位和局部近景，必要时显示表面、距离或密度。
4. 保留脚本或会话、相机方向、选择语句和渲染参数，确保可重复生成。
5. 输出矢量或高分辨率图、图注和结构来源。

不得通过裁剪、视角或隐藏冲突原子夸大结构证据；预测低置信区域应清楚标示。
