# 药物基因组证据检索

1. 规范化基因、变异、星等位基因、药物和表型，确认人群与临床场景。
2. 从ClinPGx、PharmGKB及相关原始来源分开收集临床注释、变异注释、药品标签和指南，记录证据等级与更新时间。
3. 关键建议回到CPIC、DPWG、监管标签或原始研究，不依赖聚合摘要单独决策。
4. 处理方向冲突时比较终点、剂量、合并用药、祖源和研究设计。
5. 输出可审计证据表、结论范围、冲突和需要临床确认的事项。

数据库内容会更新；研究关联不自动等于可执行的处方建议。
