# 化学骨架与SAR分析

## 数据可比性

先统一化合物身份、活性单位、关系符号、靶点构建体和测定体系。不同实验平台、物种或终点分层分析；删失值和重复测量保留原始语义与误差。

## 从系列到设计假设

1. 提取Bemis–Murcko或项目定义骨架，说明环、连接子和取代基的切分规则，统计每个系列与单例的覆盖。
2. 在同一测定口径内做匹配分子对，记录具体结构变换、样本数、活性差方向及不确定性，避免把相关变换重复计数为独立证据。
3. 有共同核心和足够组合覆盖时做R基团分解；只有设计近似正交且样本充足时才使用Free–Wilson，检查共线性和未观测组合。
4. 标记活性悬崖并回查测定误差、化合物身份、溶解度和立体化学，再判断是否值得提出机制假设。
5. 将活性、选择性、理化性质和ADMET并排展示，形成可合成、可验证的下一轮结构改造，而不是单指标优化。

## 交付

给出系列与骨架图、MMP/R基团效应、活性悬崖、证据强弱和候选设计。局部SAR通常不能无验证外推到新骨架，小系列也不支持稳定的定量贡献结论。
