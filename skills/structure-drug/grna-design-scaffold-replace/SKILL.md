# CRISPR gRNA设计

## 先确定编辑机制

取得物种和参考基因组、目标基因或区域、主转录本、Cas/PAM、敲除或调控模式、细胞背景及载体限制。KO、CRISPRi 与 CRISPRa 的有效靶区不同，不能共用一套位置规则。

## 产生候选

1. 核对目标链、外显子/TSS 和功能区，避开仅存在于非目标转录本的位点。
2. 能找到同物种、同Cas且有实验验证的导向RNA时先列为参考，再从头枚举补充候选。
3. 排除明显多重比对、极端 GC、长同聚物、常见变异覆盖及不兼容克隆序列。
4. 用与Cas和实验模式匹配的活性模型排序，同时保留全基因组脱靶数量与高风险位点。
5. 选取多条靶位不重叠的导向RNA，并配置非靶向和已知阳性对照。

## 交付与复核

输出序列、坐标、方向、PAM、转录本、活性/脱靶指标、淘汰理由和克隆接头。参考组、转录本和评分模型版本必须明确；单个高分导向RNA不能替代多条候选及功能实验。
