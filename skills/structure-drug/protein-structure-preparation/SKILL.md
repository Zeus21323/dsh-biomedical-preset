# 蛋白质结构预处理

需要在 PDB 与 mmCIF 之间转换、提取序列、选择生物学组装体或编辑结构时，先读取[结构读写与编辑规则](references/结构读写与编辑规则.md)。

1. 选择正确生物组装体、链、配体和构象，建立原始到处理后残基编号映射。
2. 检查缺失原子、残基、替代构象、非标准残基、金属、共价连接和晶体水。
3. 依据实验pH确定质子化与互变异构体，重点复核活性位点和组氨酸。
4. 缺失环区仅在任务需要时建模，并用多构象或不确定性标记保留影响。
5. 输出处理结构、变更日志、质子化选择和待人工确认项。

不要无记录地删除辅因子、水或金属；这些成分可能决定对接和催化结果。
