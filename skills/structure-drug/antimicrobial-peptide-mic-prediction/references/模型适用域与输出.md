# APEX 模型适用域与输出

## 内置病原体

使用模型实际提供的病原体列及顺序，运行时从兼容配置或固定版本定义中读取并记录。不得自行增加物种、合并菌株或把一个菌株的预测改名为整个物种结论。

## 输入处理

保持 peptide ID 与序列一一对应。重复序列可以共享计算，但输出仍应恢复全部原始 ID。非标准残基只有在模型文档明确给出编码时才能转换；否则停止相应序列。不要静默截断超过 50 aa 的序列。

## 最小输出字段

每行至少包含 peptide ID、序列、序列长度及各病原体的预测 MIC。运行元数据记录 APEX 版本、checkpoint 文件清单和 SHA-256、ensemble 数量、输出变换、MIC 单位、设备、批量大小、开始结束时间和退出状态。

## 解释

仅在训练分布覆盖的序列长度、字符和病原体范围内比较模型结果。模型排序不能替代 MIC 实验、溶血、细胞毒性、蛋白酶稳定性和体内有效性评估。
