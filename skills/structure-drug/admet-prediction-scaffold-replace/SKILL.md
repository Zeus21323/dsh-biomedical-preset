# ADMET性质与毒性预测

## 端点与阶段

明确当前是早期大库筛选、系列优化还是候选确认，并逐项定义所需端点、单位与可接受区间。模型预测只用于提出风险和实验优先级；需要综合体外、动物和暴露证据作候选决策时转用“候选化合物毒理风险评估”。

## 预测与复核

1. 使用统一的父分子、质子化与互变异构规则，同时保留可能影响渗透、代谢或离子通道的主要化学状态。
2. 区分理化规则、结构警报和机器学习预测；为每个端点记录模型版本、训练端点、单位、适用域和不确定性。
3. 根据项目选择溶解度、渗透、血浆蛋白结合、代谢稳定性、CYP、转运体、BBB、hERG、AMES、肝毒等端点，不用无关指标堆成总分。
4. 对PAINS、反应性和毒性子结构回看具体SMARTS及化学环境；命中用于人工检查，不自动淘汰。
5. 比较同系列分子时检查预测是否在适用域、是否由单一模型驱动，并以低成本实验优先验证会改变设计方向的端点。

## 决策表

输出逐端点预测、单位、模型与置信度、适用域、结构警报、系列趋势和实验顺序。不同模型若端点定义或训练体系不同，不能简单平均成一个“ADMET分数”。
