# CRISPR脱靶预测与验证

## 搜索定义必须明确

需要导向RNA方向、Cas和PAM、物种、参考基因组、允许的错配与DNA/RNA bulge、非经典PAM范围，以及适用时的个体或人群变异。搜索范围不同的结果不能直接比较。

## 从候选到证据

1. 用支持所需错配和 bulge 的方法枚举候选，保留序列、坐标和搜索参数。
2. 注释外显子、剪接、调控区、染色质和人群变异，区分参考组中不存在与个体中新出现的位点。
3. 使用与该Cas/PAM经过验证的评分排序；“错配少”与“预测切割高”分别报告。
4. 按用途选择定向扩增测序、GUIDE-seq、CIRCLE-seq 等经验检测，并包含未编辑和阳性对照。
5. 将结果分为计算预测、实验检测和正交验证三个等级。

## 交付边界

输出候选表、风险分层、变异感知结果、验证路线和判定阈值。计算未发现不等于不存在脱靶；治疗性场景必须扩大到人群变异和无偏经验检测，不能只引用单一评分。
