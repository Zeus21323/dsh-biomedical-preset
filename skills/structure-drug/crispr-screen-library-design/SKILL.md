# CRISPR筛选文库设计

## 先算实验规模

明确 KO、CRISPRi、CRISPRa、Cas12a 或编辑器筛选，物种和细胞系、靶基因集、筛选终点、可用细胞数、MOI、期望覆盖和寡核苷酸长度。若实验规模无法维持文库覆盖，应先缩小靶集。

## 文库构建

1. 按编辑模式选择外显子、TSS 或特定编辑窗口，统一参考组和转录本。
2. 为每个基因保留多条位置分散的候选，综合活性、脱靶、常见变异和可合成性。
3. 加入足量非靶向、安全靶向、必需和非必需基因对照，使每个筛选批次均有质量基准。
4. 添加与载体匹配的接头或阵列构架，检查内部限制位点、重复序列、条形码冲突和方向。
5. 去重后重新计算实际复杂度，并由覆盖、感染效率和瓶颈反推每阶段最低细胞数。

## 发布前检查

交付文库表、目标坐标、评分、对照构成、克隆序列和规模计算。不同编辑化学的靶区规则不可混用；高平均分不能补偿缺基因、低覆盖或克隆瓶颈。
