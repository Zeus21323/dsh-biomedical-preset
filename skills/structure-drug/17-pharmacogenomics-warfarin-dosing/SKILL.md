# 华法林基因型指导剂量

1. 核对基因型、祖源、年龄、体重、目标INR、适应证、合并用药和肝肾功能。
2. 确认检测覆盖祖源相关CYP2C9等位基因，未知或低置信基因型不得按参考型处理。
3. 选择经过相应人群验证的指南或剂量模型，保留模型版本和输入项。
4. 将模型结果作为起始讨论范围，并结合INR动态、相互作用和临床监测调整。
5. 输出剂量模型输入、估计范围、证据依据、缺失因素和监测重点。

不得把计算剂量当作处方；实际给药和后续调整必须由临床医生依据INR完成。
