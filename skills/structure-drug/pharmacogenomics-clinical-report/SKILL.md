# 药物基因组临床报告

1. 列明患者与样本标识、检测方法、覆盖基因/等位基因、参考版本和技术限制。
2. 对每个基因报告基因型或双倍型、功能、表型、置信度和无法判定项。
3. 仅纳入有明确适用药物和证据等级的关联，注明指南、版本、适应证与人群。
4. 将建议写成供临床讨论的剂量、替代药或监测提示，并列出关键非遗传因素。
5. 输出可审计证据表、简明结论、复核建议、更新日期和免责声明。

报告不得包含未经授权的个人基因原始数据或可识别信息；也不得替代处方和遗传咨询。
