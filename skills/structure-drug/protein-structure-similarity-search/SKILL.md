# 蛋白质结构相似性搜索

1. 检查查询结构链、残基范围和低置信区，必要时按结构域拆分。
2. 选择与问题匹配的PDB、AlphaFold或自建数据库，并记录版本。
3. 综合E值、覆盖度、TM-score、序列一致性和对齐区域，而非只取最高分命中。
4. 对重复链、同源家族和低复杂区域去冗余，使用结构叠合复核关键候选。
5. 输出排序命中、对齐坐标、候选功能与可信边界。

结构相似可提示共同折叠，不自动代表相同功能或相同底物特异性。
