# 蛋白质三维结构预测（nf-core/proteinfold）

## 识别数据与研究目标

从交付文件与报告中识别蛋白序列、链组成、单体/复合物目标和可用模板，核对当前模式的模型、数据库及算力需求。

## 方法选择

选择本版本支持的预测后端并固定参数，明确 MSA、模板日期和输入 stoichiometry，避免用单体模式承诺复合物界面。

先核对 [版本约定](references/流程约定.json)。

| 核对项 | 固定范围 |
|---|---|
| 上游版本 | `2.0.0`；`5338c24b2af62cc4c02dcd34bcc49912eebffb3a` |
| 上游维护 | 未归档；使用这里固定的源码，不自动跟随新版本 |
| 本地运行 | 未进行真实分析运行；不能据本 Skill 文件声称实跑通过 |
| 引擎声明 | `!>=25.10.2`；还需核验 Java、容器和 profile |

## 根据数据确定参数

根据链数、序列长度与模板可用性选择后端、MSA 和模板策略；比较模型置信与跨链关系，不能将单一高分区当作全结构或界面均可信。

| 决策与配置 | 处理要求 |
|---|---|
| 事实与缺口 | 先读现有文件和报告；不能据文件名猜实验类型、参考或样本关系；只补问无法核实且会改变分析的背景 |
| 参数来源 | 区分协议必需设置、数据估计、方法默认和研究选择；说明实际取值及理由，不要求用户填写专业参数 |
| 可执行配置 | 仅把已支持的选择映射为当前版本的原生字段；不支持的步骤另行交接，不虚构开关 |
| 阈值复核 | 默认值先评估适用性；依据质控、对照及敏感性检查调整，不能按显著结果数量调参 |

## 质控与解释

检查每残基及域间/链间置信度、无序区、链冲突和多模型一致性，区分局部高置信与整体构象确定性。

交付预测结构、置信指标和输入说明；预测结构不等同实验结构，低置信区域不宜直接用于精细机制判断。
