# 药物靶点证据整合与验证

## 定义决策

确认靶点基因或蛋白、亚型、物种、疾病亚群、期望干预方向、治疗窗口和当前项目阶段。把“靶点与疾病相关”与“调节靶点能改善疾病”分成两个待验证命题。

## 证据链

1. 核对靶点身份和疾病定义，明确基因—疾病效应方向、组织与细胞类型，处理同源蛋白和命名歧义。
2. 分开整理人类遗传、患者组学、扰动实验、动物模型和临床证据；为每项记录因果接近度、方向、模型适用性和重复性。
3. 评估口袋、已知配体、抗体或其他模态的可成药性，同时检查同源选择性、正常组织表达、遗传耐受性和机制性安全风险。
4. 检查已有药物或临床项目的成功与失败原因，区分靶点失败、分子失败、剂量/暴露不足和试验设计问题。
5. 按预先声明的权重生成证据矩阵；冲突证据不以总分掩盖，单列会改变决策的关键假设与补充实验。

## 决策输出

交付靶点证据矩阵、干预方向、可成药路径、安全风险、GO/NO-GO理由、数据缺口和验证里程碑。计算预测或已有化合物都不能单独证明靶点有效。
