# 药物基因组反应与不良反应解读

1. 明确药物、剂量、适应证、治疗阶段、临床终点、祖源和合并用药；涉及HLA时同时核对等位基因分辨率与分型可信度。
2. 将患者变异、单倍型或HLA等位基因转换为功能和表型，确认检测平台覆盖关键位点且没有低质量或相位盲区。
3. 分开评价疗效、药代、毒性和HLA超敏证据；优先使用适用地区的监管标签和专业指南，再纳入临床队列与功能研究，并记录版本和日期。
4. 区分强制检测、建议检测、风险提示和研究性关联；解释HLA关联时同时给出适用祖源、阳性/阴性预测值、等位基因频率和可选治疗背景。
5. 纳入肝肾功能、年龄、药物相互作用和表型转换等非遗传因素，避免将遗传关联孤立成用药结论。
6. 输出可行动级别、风险方向、适用条件、证据来源、复核要求、替代或监测讨论点和不确定性。

遗传结果只占用药决策的一部分；阴性HLA结果不能排除全部不良反应，也不得依据未经验证的关联直接停药或换药。
