# 分子相似性与子结构检索

## 明确检索语义

区分精确结构、子结构、相似性和活性悬崖四类任务。确定盐型与立体化学是否参与匹配，并让查询结构与目标库使用同一标准化、芳香性和互变异构规则。

## 执行检索

1. 相似性检索按任务选择指纹及度量：Tanimoto适合对称近邻，Tversky适合有方向的“查询包含于候选”，Dice等仅在有明确理由时使用。
2. 记录指纹算法、半径、位长、手性、计数/位语义和阈值；同时报告连续相似度，不只给“命中/未命中”。
3. 子结构检索用可读、可测试的SMARTS，显式处理芳香性、价态、电荷、环、递归模式和原子映射；用阳性与反例验证查询。
4. 大库采用近似近邻时，以精确搜索子集估计召回率；对排名边界附近分子做精确复算。
5. 活性悬崖要求可比较实验端点，并同时考虑结构差异、活性误差和系列背景。

## 返回结果

输出命中结构、相似度或匹配原子、查询与参数、骨架关系、阈值敏感性和人工复核项。结构相似或警报命中只提供检索证据，不自动证明活性、毒性或药理等效。
