# 结合蛋白生成设计

1. 准备靶标构象并定义热点、禁区、允许接触面和期望骨架长度。
2. 用RFdiffusion或BindCraft生成多样骨架，记录随机种子、contig与对称约束。
3. 对骨架进行序列设计和复合物回折叠，检查界面PAE、形状互补、埋藏面积和碰撞。
4. 去除高度相似候选，加入单体稳定性、非特异疏水面、聚集和表达风险筛选。
5. 输出多指标候选集、结构、序列、设计轨迹和实验验证优先级。

计算设计只产生候选，不得把预测界面分数直接表述为亲和力或实验成功率。
