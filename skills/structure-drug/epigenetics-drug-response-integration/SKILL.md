# 表观遗传与药物响应整合

先确定药物响应终点是 IC50、AUC、存活率、临床疗效还是耐药状态，并记录剂量、时间、批次和实验系统。表观层可能来自 DNA 甲基化、ATAC-seq、组蛋白修饰或调控元件，必须统一样本、基因组版本和特征层级。

在整合前分别完成药物响应曲线和表观数据质控。将 peak 或 CpG 映射到基因时保留距离、染色质互作或 eQTL 等证据类型，不能只用最近基因。模型需要控制组织来源、谱系、拷贝数、表达和批次；外推到患者前必须说明细胞系、类器官与临床样本的差异。

需要确定模型、混杂控制和验证顺序时读取[整合与验证规范](references/整合与验证规范.md)。交付效应量、响应终点、表观特征、调控证据、模型性能、独立验证和候选机制。

相关性不能证明表观改变导致药物响应。优先提出可通过去甲基化、染色质扰动、CRISPR 或前后治疗样本验证的方向性假设。
