# 整合与验证规范

## 数据准备

- 使用统一的样本或模型标识，检查同名异样和重复测量。
- 药物响应保留原始剂量—反应曲线、拟合模型和质量标记。
- CpG、peak、增强子和基因必须记录参考版本与映射方法。
- 缺失值处理应在训练折内完成，避免信息泄漏。

## 建模选择

- 单特征关联报告效应量和多重检验结果。
- 多特征预测使用嵌套交叉验证，组织或谱系应分层或分组。
- 若目标是机制，优先使用中介、调控网络或扰动数据，而非只追求预测性能。
- 与表达、突变、CNV 和组织来源基线模型比较，证明表观层提供增量信息。

## 验证层次

1. 重复实验或留出批次；
2. 独立细胞系或类器官；
3. 治疗前后临床样本；
4. 表观编辑或药理扰动；
5. 机制性功能实验。
