# CRISPR筛选命中分析

## 先按实验设计选模型

需要 gRNA 计数、样本和条件、时间点、细胞系、批次、重复、文库映射及阳阴性对照。两条件终点可考虑 MAGeCK RRA；多条件或时间序列用 MLE；药物筛选可比较 drugZ；多细胞系依赖性需考虑 Chronos 等模型。模型名称不能替代设计矩阵。

## 命中判定

1. 继承上游样本质量结论，并记录排除或降权的样本。
2. 用正确对照构建设计，检查批次、配对和交互项能否估计。
3. 需要时处理拷贝数切割毒性和导向RNA效能，但保留未校正结果作比较。
4. 联合基因效应、FDR、同一基因多条导向RNA方向及对照恢复能力排序。
5. 对关键候选用第二种合理模型或留出重复复核，区分稳定、方法依赖和矛盾结果。

## 结果交付

提供设计矩阵、模型选择、基因效应/FDR、导向RNA支持度、多方法一致性和验证优先级。显著但效应微弱、只由单条导向RNA支持或质量门未通过的结果不得列为高置信命中。
