# 蛋白质结构数据库检索

1. 统一物种、UniProt编号、同工型和目标残基范围，避免选错蛋白版本。
2. PDB候选比较实验方法、分辨率、链覆盖、突变、配体和生物组装体。
3. AlphaFold结构检查pLDDT与PAE，低置信或柔性区域不得当作确定构象。
4. 按任务选择全长、结构域或复合物，并记录缺失残基、工程改造和坐标编号映射。
5. 输出候选结构对照表、首选理由、下载标识和已知限制。

预测结构不能替代配体诱导构象或复合物实验结构；关键结论应比较多个候选。
