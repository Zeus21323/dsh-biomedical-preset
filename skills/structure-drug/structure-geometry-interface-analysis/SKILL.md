# 蛋白质结构几何与界面分析

1. 确认链、残基编号、构象状态和生物组装体，避免在晶体接触上做功能解释。
2. 明确定义原子选择、距离与角度阈值，并报告周期边界或多模型处理方式。
3. 计算界面面积、接触残基、氢键、盐桥和疏水核心，识别水或金属介导关系。
4. 对预测模型结合界面置信度，对动态体系结合轨迹占有率而非单帧结论。
5. 输出测量表、选择语句、结构快照和不确定区域。

几何接近不等同于相互作用能或功能重要性；关键判断应结合能量与实验数据。
