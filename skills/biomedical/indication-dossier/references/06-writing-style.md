# 写作风格

使用经过行业训练的分析师风格，清晰、完整地呈现事实。

## 行内引用格式

每项事实性主张都使用行内 Markdown 链接引用：`[描述性主张文字](source_url)`。每个链接都写成 `[标题](url)`；如果没有自然的主张文字可作为链接文字，则使用来源名称和文档类型作为标题。

只有当同一来源被引用五次以上，或者一项主张需要同时引用多个来源时，才使用编号引用 `[1]`。

## 哪些内容需要引用

始终引用：定量数据（患病率、疗效指标、市场规模）· 临床终点和结果 · 竞争情报（阶段、时间）· 日期（批准、专利权到期、预计完成时间）· 安全性数据 · 专利号。

不引用：一般医学知识、你自己的分析性解释，以及根据已引用输入所做的计算；计算只需引用其输入。

## 链接特异性

链接到具体页面，绝不链接到主页。

- ClinicalTrials.gov：`https://clinicaltrials.gov/study/NCT########`
- PubMed：`https://pubmed.ncbi.nlm.nih.gov/<PMID>/`，优先使用 PMID，而不是 DOI 重定向；
- 公司：具体新闻稿或演示文稿 URL；
- 专利：`https://patents.google.com/patent/US########X#`

## 来源冲突

当来源不一致时，同时引用二者，并说明采用哪一个以及理由：

> 新闻稿报告了 [200 名患者](url1)，而 ClinicalTrials.gov 显示 [实际入组 180 人](url2)。我们采用 180 人，因为这是官方登记数据。

## 完成前检查

确认每项定量主张、竞争对手阶段、日期和疗效数字都带有指向具体页面而非主页的行内链接，并确认所有来源冲突都得到说明。不得写“研究显示”而不说明具体研究；不得在写完正文后再回填引用。
