# 阶段 3——生物学与标准治疗研究

**何时执行：** `waypoints/epidemiology.json` 已存在，而 `waypoints/biology_soc.json` 不存在时。

## 目标

理解该患者人群背后的生物学机制，以及目前如何治疗他们。本阶段覆盖第 2 节“疾病生物学”和第 3 节“标准治疗”。

## 操作

### 步骤 1：病理生理学

- 使用 `pubmed` MCP 检索近期疾病机制综述；
- 识别涉及的关键生物学通路；
- 区分已经验证的药物靶点与新兴假说；
- 对于涉及多条通路的复杂疾病，重点关注与治疗干预最相关的通路。

### 步骤 2：生物标志物

- 诊断性生物标志物：如何确认该疾病？
- 预后性生物标志物：哪些指标预测疾病进展？
- 药效学标志物：哪些指标可衡量药物效应？
- 记录哪些标志物已获 FDA 资格认定，哪些仍属于探索性指标；
- 这些信息直接影响第 4 节中的临床终点。

### 步骤 3：获批疗法

- 使用 `WebSearch site:fda.gov` 检索获批用于该适应症的药物；
- 对每种获批疗法记录作用机制、批准年份和主要局限；
- 说明疗法是获批用于该特定适应症，还是超说明书使用；
- 识别主要药物类别及其定位，例如一线、二线等；
- 如果该适应症没有获批疗法，必须明确说明。

### 步骤 4：治疗指南

- 使用 `WebSearch` 检索专科协会指南，例如 NCCN、AASLD、ATS／ERS、AGS 等；
- 当前标准治疗算法；
- 如相关，比较不同地区的指南，例如美国与欧盟；
- 近期指南变化及其影响。

### 步骤 5：未满足需求

- 当前治疗无法解决什么问题？
- 哪些患者人群没有被现有治疗充分覆盖？
- 疾病修饰与症状管理之间有哪些缺口？
- 当前治疗未解决哪些生活质量影响？

### 步骤 6：写入 `waypoints/biology_soc.json`

遵循 [references/waypoint-schemas.md](waypoint-schemas.md) 中的 schema。

## 指南

- 对病理生理学应达到“分析师级”理解：解释关键通路，以及它们为什么与治疗有关，而不是追求教科书式深度；
- 对生物标志物，应明确联系其在临床试验中的用途；
- 对获批疗法，重点关注局限性，因为这些局限构成治疗机会；
- 使用并行子代理：`pubmed` MCP 负责生物学，`WebSearch` 负责指南，`WebSearch site:fda.gov` 负责批准信息。
