# bulk RNA-seq处理与表达质控（nf-core/rnaseq）

## 识别数据与研究目标

确认 FASTQ 或该版本支持的 BAM 重处理输入、链特异性、UMI、参考 FASTA/GTF 和样本重复关系。

## 方法选择

根据目标选择 STAR/Salmon、RSEM 或其他可用路线；HISAT2 路径不承诺表达定量，BAM 重处理需核对来源与原生接口。

先核对 [版本约定](references/流程约定.json)。

| 核对项 | 固定范围 |
|---|---|
| 上游版本 | `3.26.0`；`e7ca46272c8f9d5ceee3f71759f4ba551d3217a4` |
| 上游维护 | 未归档；使用这里固定的源码，不自动跟随新版本 |
| 本地运行 | 未进行真实分析运行；不能据本 Skill 文件声称实跑通过 |
| 引擎声明 | `!>=25.04.3`；还需核验 Java、容器和 profile |

## 根据数据确定参数

先用报告与抽样比对确认链方向、接头和 UMI，再按表达定量或比对需求选择路线；修剪依据读段质量与有效长度，基因过滤依据计数分布与实验设计，不能对未知 FASTQ 直接假定是 RNA-seq。

| 决策与配置 | 处理要求 |
|---|---|
| 事实与缺口 | 先读现有文件和报告；不能据文件名猜实验类型、参考或样本关系；只补问无法核实且会改变分析的背景 |
| 参数来源 | 区分协议必需设置、数据估计、方法默认和研究选择；说明实际取值及理由，不要求用户填写专业参数 |
| 可执行配置 | 仅把已支持的选择映射为当前版本的原生字段；不支持的步骤另行交接，不虚构开关 |
| 阈值复核 | 默认值先评估适用性；依据质控、对照及敏感性检查调整，不能按显著结果数量调参 |

| 资料 | 使用时机 |
|---|---|
| [参数模式.json](references/参数模式.json) | 编写 params.json 时核对字段、类型、枚举及条件约束 |
| [输入模式-1.json](references/输入模式-1.json) | 准备 input 对应的样本表或输入文件时读取 |

仅在已授权且配置齐备时运行。

```bash
nextflow run nf-core/rnaseq -r e7ca46272c8f9d5ceee3f71759f4ba551d3217a4 -params-file params.json
```

模式文件的许可见 [LICENSE](LICENSE)。

## 质控与解释

检查链特异性、rRNA、覆盖、比对和样本相似性，区分原始计数、估计计数与 TPM，不把技术重复当独立重复。

交付模式对应的表达/比对产物与 QC、参考说明；差异表达需要独立的设计和统计流程，不能仅凭定量矩阵得出组间结论。
