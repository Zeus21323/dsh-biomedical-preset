# 空间建模与质控

## 分析顺序

1. 核实组织图像与坐标方向，检查缩放、镜像和旋转。
2. 以样本或切片为单位计算 FRiP、TSS enrichment、片段数和重复率。
3. 统一 peak 集合后生成稀疏矩阵，记录 peak 生成方式。
4. 在 LSI 或其他适合计数稀疏性的表示中建立非空间基线。
5. 以组织可达关系构建空间图，比较加入空间约束前后的区域稳定性。
6. 差异分析使用真实生物重复，并控制批次、深度与组织区域。
7. 用 motif 偏离、peak-to-gene、共可及性或配对组学支持调控解释。

## 必查问题

- 同一切片上的相邻 spot 不等于独立生物重复。
- 平滑参数必须做敏感性分析，并保留未平滑结果。
- 坐标单位、图像像素和物理距离不能混用。
- 跨平台整合前分别检查各平台的捕获范围和分辨率。
- 区域边界应报告不确定性，不能只展示最漂亮的一张图。
