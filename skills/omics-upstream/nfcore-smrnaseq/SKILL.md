# 小RNA测序处理与定量（nf-core/smrnaseq）

## 识别数据与研究目标

明确小 RNA 建库接头、UMI、物种、miRNA/其他小 RNA 注释和样本设计，关注读段长度范围。

## 方法选择

按本版本进行接头处理、短序列比对与小 RNA 分类/定量，保留多重比对及同源家族处理策略。

先核对 [版本约定](references/流程约定.json)。

| 核对项 | 固定范围 |
|---|---|
| 上游版本 | `2.4.1`；`cb0af579b24cb8d5a3accd87b2f14ea93fe04832` |
| 上游维护 | 未归档；使用这里固定的源码，不自动跟随新版本 |
| 本地运行 | 未进行真实分析运行；不能据本 Skill 文件声称实跑通过 |
| 引擎声明 | `!>=25.04.2`；还需核验 Java、容器和 profile |

## 根据数据确定参数

先从建库说明和长度峰确认接头及 UMI，按目标 RNA 类别选择保留范围；多重匹配按同源家族解释，不能用普通长 RNA 裁剪长度清除目标短序列。

| 决策与配置 | 处理要求 |
|---|---|
| 事实与缺口 | 先读现有文件和报告；不能据文件名猜实验类型、参考或样本关系；只补问无法核实且会改变分析的背景 |
| 参数来源 | 区分协议必需设置、数据估计、方法默认和研究选择；说明实际取值及理由，不要求用户填写专业参数 |
| 可执行配置 | 仅把已支持的选择映射为当前版本的原生字段；不支持的步骤另行交接，不虚构开关 |
| 阈值复核 | 默认值先评估适用性；依据质控、对照及敏感性检查调整，不能按显著结果数量调参 |

| 资料 | 使用时机 |
|---|---|
| [参数模式.json](references/参数模式.json) | 编写 params.json 时核对字段、类型、枚举及条件约束 |
| [输入模式-1.json](references/输入模式-1.json) | 准备 input 对应的样本表或输入文件时读取 |

仅在已授权且配置齐备时运行。

```bash
nextflow run nf-core/smrnaseq -r cb0af579b24cb8d5a3accd87b2f14ea93fe04832 -params-file params.json
```

模式文件的许可见 [LICENSE](LICENSE)。

## 质控与解释

检查接头二聚体、长度峰、rRNA/tRNA 污染、miRNA 比例和文库复杂度，解释建库偏倚。

交付小 RNA 计数与 QC；短序列无法唯一定位时不能强行进行位点级解释，靶基因关系需要独立证据。
