# 原位阵列空间测序处理（nf-core/panoramaseq）

## 识别数据与研究目标

从交付文件与报告中识别原位阵列空间转录读段、barcode 设计、坐标映射、参考和样本信息，核对该平台的原始输入要求。

## 方法选择

按实际实现完成空间 barcode 处理、比对、定量与坐标关联，不把其他空间平台的样本表直接复用。

先核对 [版本约定](references/流程约定.json)。

| 核对项 | 固定范围 |
|---|---|
| 上游版本 | `dev`；`4908592cbc5ccd79a7f99edc56825c5a98079aae` |
| 上游维护 | 开发版本；按当前代码实际实现的范围使用 |
| 本地运行 | 未进行真实分析运行；不能据本 Skill 文件声称实跑通过 |
| 引擎声明 | `!>=24.04.2`；还需核验 Java、容器和 profile |

## 根据数据确定参数

从平台的 barcode 设计和坐标表确定纠错及映射规则，以有效空间条码和分子支持复核；不能借用 Visium 或液滴式白名单代替原实验映射。

| 决策与配置 | 处理要求 |
|---|---|
| 事实与缺口 | 先读现有文件和报告；不能据文件名猜实验类型、参考或样本关系；只补问无法核实且会改变分析的背景 |
| 参数来源 | 区分协议必需设置、数据估计、方法默认和研究选择；说明实际取值及理由，不要求用户填写专业参数 |
| 可执行配置 | 仅把已支持的选择映射为当前版本的原生字段；不支持的步骤另行交接，不虚构开关 |
| 阈值复核 | 默认值先评估适用性；依据质控、对照及敏感性检查调整，不能按显著结果数量调参 |

| 资料 | 使用时机 |

## 质控与解释

检查 barcode 识别、位置对应、背景、组织覆盖和空间表达分布，追踪丢失位置。

交付与阵列位置对应的表达与 QC；空间采样单元可能包含多细胞，不能未经解卷积解释为单细胞表达。
