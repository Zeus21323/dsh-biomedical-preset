# 二维谱与对齐参数

## 二维谱处理

- 分别记录直接维和间接维的点数、谱宽、零填充和加窗函数；
- 相位敏感与绝对值谱使用不同处理，不能混用峰强度；
- COSY、TOCSY、HSQC、HMBC 等回答的键连或相关关系不同；
- 化学位移容差应同时定义氢维和异核维；
- 峰匹配需要保留多重候选和人工复核标记。

## 对齐

- 先排除 pH、温度、离子强度和锁场异常，再考虑算法对齐；
- 使用 QC 和内标选择锚点，禁止按病例/对照标签进行有监督对齐；
- 对齐前后检查峰宽、峰面积和局部形状是否被扭曲；
- 对重叠严重区域，优先峰拟合或二维证据，不用大范围强制 warping。

## 注释等级

标准品在相同条件下的多维谱匹配强于单一化学位移数据库命中。每个代谢物应报告证据类型、匹配容差和冲突候选。
