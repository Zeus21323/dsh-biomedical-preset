# 宏基因组功能组成分析

1. 选用HUMAnN或等价的分层功能流程，确认核酸数据库、蛋白数据库和物种分类数据库版本相容，输入已完成宿主去除和基本质控。
2. 运行分层搜索并记录未映射、未整合和未分类比例，比例异常时先排查物种覆盖与数据质量。
3. 分别整理基因家族、通路丰度、通路覆盖度及物种分层贡献。
4. 根据比较目标转换单位或归一化，分层表与总表不要重复计数。
5. 输出功能矩阵、物种贡献表、质量摘要和数据库版本，再进行多重检验校正。

功能丰度代表群落潜在能力，不等同于转录活性或代谢通量；因果结论需要额外实验支持。

## 通路差异与富集

HUMAnN pathabundance 表按统一数据库和单位合并后，先区分总通路与物种分层行。两组无复杂协变量时可采用 CLR 后的秩和检验并校正 FDR；多组使用 Kruskal–Wallis 及预先指定的事后比较；存在连续协变量、批次或重复测量时使用 MaAsLin2 或匹配设计模型。排名富集应保存排名统计量、通路集合版本和驱动成员，不能把同一通路的分层与总量重复计票。
