# 单细胞数据格式与读写

## 转换前做字段清单

记录源/目标格式和软件版本，明确必须保留的 X、原始计数、layers/assays、obs/meta.data、var/features、降维、图、条形码及基因 ID。无法表示的字段先列为预期损失。

## 安全读写

1. 使用格式对应的原生或受维护读写器，显式指定哪个层写入主矩阵。
2. 在拼接样本前为条形码增加稳定样本前缀，并保证基因 ID 唯一。
3. 保持稀疏矩阵；除非数据量已确认安全，不要为转换方便整体稠密化。
4. 处理类别、布尔值、缺失值和字符串长度，避免 HDF5/跨语言类型被静默转换。
5. 保存到新文件，保留源文件和转换日志，不覆盖唯一副本。

## 往返验证

比较转换前后形状、非零项、总计数、细胞/基因顺序、层、元数据类别和嵌入坐标；抽取若干细胞逐值核对。文件能打开不代表转换正确。

## 交付

提供目标对象、字段映射、校验统计、预期/意外损失和软件版本；若原始计数已缺失，必须明确说明，不能从归一化值伪造。
