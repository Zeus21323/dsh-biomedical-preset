# RNA-seq可变剪接分析（nf-core/rnasplice）

## 识别数据与研究目标

从交付文件与报告中识别 RNA-seq、参考注释、实验分组和重复，明确事件、转录本或使用率层面的剪接问题。

## 方法选择

按版本支持的工具处理比对和剪接量化，保持事件定义与比较设计一致，明确差异剪接与差异表达的区别。

先核对 [版本约定](references/流程约定.json)。

| 核对项 | 固定范围 |
|---|---|
| 上游版本 | `1.0.4`；`1d0494ae3402d1a46e0adadad24f81a0ff855c77` |
| 上游维护 | 未归档；使用这里固定的源码，不自动跟随新版本 |
| 本地运行 | 未进行真实分析运行；不能据本 Skill 文件声称实跑通过 |
| 引擎声明 | `!>=23.04.0`；还需核验 Java、容器和 profile |

## 根据数据确定参数

根据目标是事件、转录本还是使用率选择模型，按 junction 覆盖与重复评估可检验事件；效应量与多重检验分别报告，不为显著性事后更换事件集合。

| 决策与配置 | 处理要求 |
|---|---|
| 事实与缺口 | 先读现有文件和报告；不能据文件名猜实验类型、参考或样本关系；只补问无法核实且会改变分析的背景 |
| 参数来源 | 区分协议必需设置、数据估计、方法默认和研究选择；说明实际取值及理由，不要求用户填写专业参数 |
| 可执行配置 | 仅把已支持的选择映射为当前版本的原生字段；不支持的步骤另行交接，不虚构开关 |
| 阈值复核 | 默认值先评估适用性；依据质控、对照及敏感性检查调整，不能按显著结果数量调参 |

| 资料 | 使用时机 |
|---|---|
| [参数模式.json](references/参数模式.json) | 编写 params.json 时核对字段、类型、枚举及条件约束 |

仅在已授权且配置齐备时运行。

```bash
nextflow run nf-core/rnasplice -r 1d0494ae3402d1a46e0adadad24f81a0ff855c77 -params-file params.json
```

模式文件的许可见 [LICENSE](LICENSE)。

## 质控与解释

评估 junction 覆盖、低表达、批次和注释依赖，检查重复支持与多重检验。

输出剪接事件/使用率及统计结果；显著剪接变化不自动说明蛋白功能改变，候选需连接具体转录本证据。
