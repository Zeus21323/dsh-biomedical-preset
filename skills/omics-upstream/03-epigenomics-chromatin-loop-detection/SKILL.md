# 染色质环与增强子-启动子互作

## 开始前

确认实验类型、矩阵或pairs格式、分辨率、有效接触数、重复和锚点注释。全基因组Hi-C、Micro-C与启动子捕获实验的可检出范围不同，不能共用同一背景假设。

## 执行流程

1. 按实验类型和深度选择loop caller；全基因组方法使用局部背景与距离校正，捕获实验同时校正bait设计和可捕获空间。
2. 过滤黑名单、低可比对区域和近对角伪影，保存每个环的锚点、距离、观测与期望强度及统计证据。
3. 在重复间匹配允许的坐标容差，评估环重现性；深度不同的样本用降采样或适当计数模型验证稳定性。
4. 比较条件时在统一候选环集合上重新量化，把批次与重复写入模型，不能只比较两个独立调用列表的有无。
5. 将锚点与增强子、启动子和CTCF方向注释整合，标记一对多关系，并用浏览器查看重点互作的局部背景。

## 交付与解释

交付环列表、锚点注释、互作强度、重复证据、差异结果和可视化。空间接触不等于调控因果；增强子—启动子关系仍需活性、表达或扰动证据。
