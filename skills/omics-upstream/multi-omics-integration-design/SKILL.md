# 多组学整合方案设计

1. 列出每种组学的样本、特征、批次、缺失模式、时间点和主要终点。
2. 判断样本是否严格配对：配对完整可考虑潜变量或监督整合，样本不重合更适合结果级或网络级整合。
3. 明确目标是分型、预测、机制发现还是数据压缩，再选择MOFA、DIABLO、SNF或分层模型。
4. 预先规定训练验证划分、协变量、性能指标和独立验证，避免方法跑完后再挑终点。
5. 输出整合决策表、数据前提、首选与备选路线以及失败回退方案。

不为了“整合”而强行拼接数据；若单组学已能回答问题，应说明增加组学的预期增益。
