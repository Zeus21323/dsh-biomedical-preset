# 病原体群体基因组监测（nf-core/pathogensurveillance）

## 识别数据与研究目标

从交付文件与报告中识别监测样本、测序数据、时间地区和参考资源，明确样本纳入规则与监测目的。

## 方法选择

根据版本支持的处理与群体比较链路生成可比结果，保持每次运行使用的数据库与命名方案。

先核对 [版本约定](references/流程约定.json)。

| 核对项 | 固定范围 |
|---|---|
| 上游版本 | `1.1.0`；`13547eaa7345dab4ac97db49775ae8284af4113d` |
| 上游维护 | 未归档；使用这里固定的源码，不自动跟随新版本 |
| 本地运行 | 未进行真实分析运行；不能据本 Skill 文件声称实跑通过 |
| 引擎声明 | `!>=25.04.6`；还需核验 Java、容器和 profile |

## 根据数据确定参数

按物种、测序批次和监测目的确定统一 QC 与数据库版本；阈值调整需评估历史样本可比性，新的聚类不能仅凭距离自动等同传播事件。

| 决策与配置 | 处理要求 |
|---|---|
| 事实与缺口 | 先读现有文件和报告；不能据文件名猜实验类型、参考或样本关系；只补问无法核实且会改变分析的背景 |
| 参数来源 | 区分协议必需设置、数据估计、方法默认和研究选择；说明实际取值及理由，不要求用户填写专业参数 |
| 可执行配置 | 仅把已支持的选择映射为当前版本的原生字段；不支持的步骤另行交接，不虚构开关 |
| 阈值复核 | 默认值先评估适用性；依据质控、对照及敏感性检查调整，不能按显著结果数量调参 |

| 资料 | 使用时机 |
|---|---|
| [参数模式.json](references/参数模式.json) | 编写 params.json 时核对字段、类型、枚举及条件约束 |
| [输入模式-1.json](references/输入模式-1.json) | 准备 input、reference_data 对应的样本表或输入文件时读取 |

仅在已授权且配置齐备时运行。

```bash
nextflow run nf-core/pathogensurveillance -r 13547eaa7345dab4ac97db49775ae8284af4113d -params-file params.json
```

模式文件的许可见 [LICENSE](LICENSE)。

## 质控与解释

检查采样偏倚、覆盖、混样和批次，区分技术变化与真正的谱系频率变化。

交付基因组监测结果和来源说明；监测样本频率不一定代表总体患病率或传播强度。
