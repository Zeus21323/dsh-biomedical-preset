# 单细胞降维与聚类

## 从实际阶段继续

检查质控矩阵、模态、表达/可及性层、供体、批次、协变量与已有降维结果，明确任务是解释/重画已有图，还是执行降维聚类。只有图形问题时复用有效结果，不因排版重新聚类。主要类型、细分亚型与连续状态需要不同粒度，只补问文件无法核实的研究事实。

## 分析与维数判断

1. RNA使用适合的标准化层与高变特征进行PCA；ATAC通常使用TF-IDF/LSI，核验分量与深度的关系，不把LSI直接套作PCA总方差比例。
2. 根据解释度或适用指标、技术相关、marker和稳定性选择维数，再构建kNN/SNN。拐点是辅助证据，不能据曲线变平断言所有后续分量均为噪声。
3. 在任务范围内扫描有依据的分辨率与邻居数，记录选择依据、参数和随机种子。
4. 检查供体、下采样与初始化下的复现，以及低质量、双细胞和批次驱动；无法执行的验证明确列出。
5. UMAP/t-SNE用于展示，聚类与统计基于明确定义的特征空间或图；不能根据可视化间隔创建新类型，也不能反复调参迎合预期marker。

## PCA绘图与口径

生成或修复PCA图时读取[PCA指标口径与绘图](references/PCA指标口径与绘图.md)。从实际降维对象和运行记录提取数据，使用 `scripts/render_pca.py`；需要提取时按reference调用 `scripts/extract_pca.py` 或 `scripts/extract_pca.R`。

区分标准差、相对总方差的解释比例与已保留分量内部比例，记录分母与输入特征空间。只有前K个PC的标准差时，不将其平方归一化结果冒充全输入方差解释率；无法确认分母时使用真实标准差或明确内部比例。

用点线和稀疏数字刻度展示PC，保留计划展示的数据，不在所有点上重复PC标签。累计曲线仅在口径有效且需要时增加独立面板；维数参考线必须来自实际分析决定。默认关闭背景主次网格，不静默改为对数轴。

## 交付与限制

按本次实际执行范围交付降维、邻居图、聚类、参数比较、稳定性及每簇样本组成；只重画时交付重绘及沿用结果来源。连续状态可保留连续表示，不强迫离散分类。

每张正式图、独立面板和组合图默认同时生成PNG、SVG、PDF，附源表、图注、配置及运行记录。检查范围、标签、单位、三格式一致性和矢量编辑性，展示预览并直接提供链接；空输入或绘制失败不能作为成功空图交付。

单细胞降维与聚类的现有绘图入口调用[图件交付内核](scripts/figure_delivery.py)，为实际结果保存PNG、SVG、PDF，关闭背景主次网格，保留该分析的数据线与科学参照；逐图查看交付记录和最终预览，失败不得报告成功。
