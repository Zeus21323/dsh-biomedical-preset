# RNA速度与细胞命运推断

## 使用前提

需要可靠的 spliced/unspliced 计数、兼容的比对/定量流程、相关谱系子集、邻居图、样本和批次。3'、5'、单核或特殊化学体系要先确认速度模型是否适用。

## 建模路线

- 检查每个细胞和基因的剪接层覆盖，剔除几乎没有动力学信息的基因。
- 根据数据决定稳态、stochastic 或 dynamical 模型；不要默认复杂模型一定更可信。
- 仅在生物学连通的谱系内拟合，并独立于 UMAP 选择根和候选终点。
- 使用 CellRank 等转移核时，比较仅速度、表达连接和先验组合后的终末状态稳定性。
- 在不同供体、邻居参数和随机种子下复现方向，并与采样时间或谱系标记核对。

## 何时不下结论

相图不符合模型、方向主要由批次驱动、根/终点极不稳定，或供体之间相反时，只报告模型诊断，不宣称发育方向。

## 交付

提供速度、latent time、终末状态、命运概率、相图诊断和敏感性结果。速度箭头是模型推断，不是实时细胞追踪。
