# 多组学数据对齐与标准化

1. 建立唯一受试者—样本—时间点映射表，先解决重复ID、错配和不完整配对。
2. 对每种组学分别完成技术质控和合理标准化，不用同一种变换处理所有数据层。
3. 统一特征标识与参考版本，记录一对多映射、无法映射项和聚合规则。
4. 批次校正时保护生物分组，训练集拟合的参数不得借用测试集信息。
5. 显式描述结构性缺失与随机缺失，除非方法要求且可验证，不默认均值填补。

输出样本对齐表、处理后矩阵、转换参数、缺失图和批次前后诊断图。
