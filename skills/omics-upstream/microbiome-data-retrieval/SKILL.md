# 微生物组公共数据检索

1. 把生物问题转换为生境、宿主、测序策略、时间和数据类型等条件，在MGnify及适合的原始数据归档中检索。
2. 收集研究、样本、运行和分析的稳定标识，保留分页与筛选条件。
3. 审核样本元数据完整性、同一研究内处理流程和许可条件，识别重复提交。
4. 下载前列出原始数据与派生结果的对应关系，不把不同流程产物直接合并。
5. 输出可复查的数据清单、纳排理由、访问日期和建议的统一再分析方案。

公共数据库注释可能滞后或不完整；关键分组应回到原始论文和样本记录核实。
