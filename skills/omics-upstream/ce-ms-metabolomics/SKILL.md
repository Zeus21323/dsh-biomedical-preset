# CE-MS代谢组分析

## 分析准备

取得原始文件或 mzML、阳/阴离子模式、迁移时间内标、毛细管和缓冲体系、样本顺序、空白与 QC。阳离子和阴离子方法分别建模，不能直接合并峰表。

## CE 特有处理

1. 检查电流、电渗流、喷雾稳定性和内标是否覆盖整个迁移区间。
2. 完成峰检测后，用内标或认可模型计算校正迁移时间；保留原始与校正值。
3. 跨样本匹配同时限制 m/z 和校正迁移时间，并检查同一物质的电荷与加合形式。
4. 依据样本量、内标或稳健总信号选择归一化；毛细管更换和缓冲液批次作为显式批次。
5. 候选注释结合精确质量、迁移时间、MS/MS 和标准品，按证据等级输出。

## 放行检查

评估迁移时间残差、质量误差、峰形、QC CV、空白比、carryover 和批次。漂移超过校准覆盖或电流异常的运行应单独重做，不能依靠事后强校正。

## 交付

提供峰矩阵、迁移时间校正模型、QC、批次处理、候选注释和失败运行；注明模式、毛细管条件和注释等级。
