# 表达及特征矩阵差异统计（nf-core/differentialabundance）

## 识别数据与研究目标

从交付文件与报告中识别特征矩阵、样本注释、比较定义和适用的特征注释，明确 counts、连续丰度或芯片原始数据及其支持模式。

## 方法选择

依据数据尺度选择该版本支持的统计方法，设计配对、批次与协变量；其他模态需验证参数适配，不能默认所有矩阵都符合 RNA-seq 模型。

先核对 [版本约定](references/流程约定.json)。

| 核对项 | 固定范围 |
|---|---|
| 上游版本 | `2.0.0`；`30ed7741fc392127156c2fb10cfa3d69d216b54b` |

| 本地运行 | 未进行真实分析运行；不能据本 Skill 文件声称实跑通过 |
| 引擎声明 | `!>=25.10.4`；还需核验 Java、容器和 profile |

## 根据数据确定参数

从原始计数、连续丰度或芯片表示选择模型，依据重复、配对、批次和检测率确定过滤与设计；预先说明效应量和 FDR 口径，不能围绕显著基因数量反复改阈值。

| 决策与配置 | 处理要求 |
|---|---|
| 事实与缺口 | 先读现有文件和报告；不能据文件名猜实验类型、参考或样本关系；只补问无法核实且会改变分析的背景 |
| 参数来源 | 区分协议必需设置、数据估计、方法默认和研究选择；说明实际取值及理由，不要求用户填写专业参数 |
| 可执行配置 | 仅把已支持的选择映射为当前版本的原生字段；不支持的步骤另行交接，不虚构开关 |
| 阈值复核 | 默认值先评估适用性；依据质控、对照及敏感性检查调整，不能按显著结果数量调参 |

## 质控与解释

核对样本顺序、设计矩阵秩、低计数过滤、离群和多重检验，避免把 TPM 直接作为标准负二项原始计数。

交付效应量、统计显著性和支持的富集/可视化；差异关联不证明因果，细胞组成与批次需在解释中体现。
