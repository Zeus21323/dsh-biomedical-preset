# 单细胞轨迹与伪时间分析

## 是否适合做轨迹

需要相关细胞子集、供体、邻居图或表达、候选起点、真实时间或谱系先验。互不相干的成熟细胞类型、只有终点横断面且无中间状态的数据，不应强行连成发育路线。

## 重建步骤

1. 去除明显由批次、细胞周期或低质量连接起来的细胞，保留每个供体的覆盖情况。
2. 根据先验显式选择根；比较 Monocle、Slingshot、Palantir 等适合的图或主曲线假设。
3. 计算伪时间与分支概率，在供体内检查顺序，再汇总跨供体一致性。
4. 沿轨迹拟合基因变化时控制细胞类型、供体和分支，避免简单相关排序。
5. 改变根、邻居、细胞子集和随机种子，记录分支与动态基因是否稳定。

## 交付边界

交付伪时间、分支、动态基因、根选择、供体覆盖和敏感性。伪时间只有相对顺序，不是实际小时/天数，也不能单独证明细胞谱系关系。
