# 差异甲基化区域识别

## 开始前

准备每个样本的甲基化与未甲基化计数、统一参考坐标、分组、批次、配对或重复测量信息。预先定义最小甲基化差异，而不是只凭P值筛选。

## 执行流程

1. 检查转换率、覆盖分布、样本相关性和主成分；去除极低覆盖及异常高覆盖位点，并记录每个样本的缺失模式。
2. 优先使用能处理二项计数和生物学变异的模型；DSS、methylKit或bsseq按样本量、平滑需要和协变量支持情况选择。
3. 先估计DML，再按基因组邻近、方向一致和统计证据合并DMR；或使用直接区域模型，但必须记录窗口、平滑和合并规则。
4. 同时要求效应大小、置信区间和多重校正；配对、批次、年龄或细胞组成等已知混杂写入设计。
5. 检查区域内方向一致性、覆盖差异、单样本驱动和参数敏感性，并在浏览器中回看重点DMR的逐样本轨迹。

## 交付与解释

交付DML/DMR表、甲基化差异与区间、覆盖质控、轨道和敏感性分析。混合组织中的DMR可能来自细胞比例变化，不能自动解释为同一细胞内的表观调控改变。
