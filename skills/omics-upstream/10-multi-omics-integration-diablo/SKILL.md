# DIABLO 监督式多组学建模

1. 确认各组学样本严格配对，标签定义无泄漏，并预先划分训练与外部测试集。
2. 只在训练数据内选择成分数、每层特征数和设计矩阵，采用重复嵌套交叉验证。
3. 评估平衡错误率、AUC、校准和类别不平衡，不以训练集图形分离作为性能。
4. 检查被选特征在重复抽样中的稳定性及跨组学相关方向。
5. 锁定模型后一次性评估测试集，输出特征模块、性能区间和完整预处理参数。

如果任务还涉及无监督 PLS、rCCA 或跨研究 MINT，不要把它们冒充 DIABLO 分类；读取[相关方法与MINT边界](references/相关方法与MINT边界.md)，在同一个多组学任务中选择正确支线。只有存在明确类别标签且样本配对时才进入 DIABLO。

DIABLO用于关联与预测，不证明跨组学因果关系；小样本高维结果需特别标注过拟合风险。
