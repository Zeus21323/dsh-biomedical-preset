# 环境RNA污染校正

## 必需数据

需要每个样本的 raw 与 filtered 矩阵、空液滴、细胞条形码、初步细胞群和可能的污染 marker。没有 raw 背景时可以评估污染迹象，但不能可靠重建环境表达谱。

## 校正步骤

1. 分样本比较空液滴与细胞表达，识别高丰度释放基因及污染最明显的低 RNA 细胞。
2. 用 SoupX、CellBender 等估计背景和污染比例；选择模型时说明是否依赖聚类或预设 marker。
3. 同时保存原始与校正计数，记录每个细胞和基因被调整的量。
4. 检查细胞类型特异 marker 是否被恢复，以及真实表达的高丰度基因是否被过度扣除。
5. 比较校正前后细胞质量、聚类、组成和关键差异，不因图更整齐就认定校正成功。

## 停止条件与交付

出现大量负面效应、低 RNA 群被清空或已知阳性 marker 消失时，降低校正强度并保留原始结果。交付背景谱、污染估计、校正矩阵、前后对比和不确定细胞。
