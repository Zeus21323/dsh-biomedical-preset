# 互作证据与建模

## 数据对齐

- 以宿主个体、时间点和采样部位建立唯一配对键。
- 明确抗生素、益生菌、饮食、药物、住院和感染状态。
- 微生物丰度使用适合组成型数据的方法，避免对相对丰度直接做普通相关。
- 宿主高维特征先预注册筛选或使用层级模型，控制多重检验。

## 证据层级

1. 同一队列的统计关联；
2. 独立队列重复；
3. 代谢或通路互补证据；
4. 时间先后或剂量反应；
5. 宿主遗传工具或其他准实验设计；
6. 细胞、动物或临床干预验证。

## 结果最低字段

- 宿主特征、微生物分类或功能、效应量和不确定性；
- 调整的混杂因素和多重检验方法；
- 数据层级、样本量、重复测量结构；
- 外部数据库和文献支持；
- 不能排除的反向因果与残余混杂。
