# 宿主与微生物互作分析

先明确宿主表型、微生物数据、采样部位、时间关系、干预、药物、饮食和批次。宿主与微生物关联极易受到共同环境和反向因果影响，不能把跨组学相关网络直接解释成互作机制。

微生物侧完成污染控制、组成型数据处理和物种或功能注释；宿主侧根据任务处理表达、遗传、免疫、代谢或临床指标。整合模型至少控制供者、采样时间、批次、年龄、性别、治疗和其他预先指定混杂因素；纵向数据使用个体内变化，不把重复采样当作独立个体。

需要选择关联层级、数据库证据和验证路线时读取[互作证据与建模](references/互作证据与建模.md)。交付经过混杂控制的关联、方向性假设、功能通路、证据来源、敏感性分析和可实验验证的候选。

数据库共现、文献共现、代谢物互补和统计关联属于不同证据层级。只有存在时间顺序、扰动、遗传工具或实验验证时，才可谨慎讨论因果方向。
