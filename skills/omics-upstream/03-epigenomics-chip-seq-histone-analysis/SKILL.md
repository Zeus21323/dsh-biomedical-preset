# 组蛋白ChIP-seq分析

需要决定宽域、spike-in校准、跨批次共识区间或差异分析时，先读取[修饰类型与跨数据集边界](references/修饰类型与跨数据集边界.md)。

## 开始前

记录抗体、修饰类型、IP与匹配input、是否有spike-in、参考基因组、黑名单、分组和生物学重复。依据标记的已知形态预先选择窄峰或宽域策略。

## 执行流程

1. 检查读段质量并比对，按文库复杂度和建库方式决定去重；分别统计IP与input的唯一比对、重复和黑名单比例。
2. 尖锐标记用窄峰模型，H3K27me3等宽广标记用宽域模型；每个样本使用匹配input，峰调用参数随片段长度和背景确定。
3. 检查FRiP、NSC/RSC、文库复杂度、input背景、已知基因组分布、抗体批次和重复相关性。
4. 尖锐标记且有足够重复时用IDR评估峰重现性；宽域不机械套用窄峰IDR，改用重叠比例、信号相关和预先定义的重复支持规则建立共识域。
5. 生成明确归一化方式的信号轨道；有spike-in时先验证校准假设，并同时保留未校准诊断。
6. 在固定共识区间重新计数并按实验设计检验差异富集，避免直接比较不同样本独立峰列表或归一化bigWig值。

## 交付与解释

交付样本峰/域、共识集合、信号轨道、差异结果、IDR或重复一致性和抗体/参数信息。组蛋白标记与活性状态相关，但单一标记不能独立证明增强或抑制机制。
