# 表达与开放染色质驱动的TF活性分析（nf-core/tfactivity）

## 识别数据与研究目标

检查已有表达与开放染色质数据、样本对应、参考和条件对比，确认 motif/调控网络资源的物种适配。

## 方法选择

按本版本支持的整合路径推断差异 TF 活性，区分 TF 自身表达、motif 可及性和靶基因集合信号。

先核对 [版本约定](references/流程约定.json)。

| 核对项 | 固定范围 |
|---|---|
| 上游版本 | `dev`；`e2af5dcda0056119b0cd02d6c0f6f52a6e294728` |
| 上游维护 | 开发版本；按当前代码实际实现的范围使用 |
| 本地运行 | 未进行真实分析运行；不能据本 Skill 文件声称实跑通过 |
| 引擎声明 | `!>=25.10.4`；还需核验 Java、容器和 profile |

## 根据数据确定参数

根据样本配对、物种 motif 与调控资源选择可用证据层，结合背景峰或基因集合设定比较；效应和稳定性共同评估，不把 TF 自身表达阈值当作活性判据。

| 决策与配置 | 处理要求 |
|---|---|
| 事实与缺口 | 先读现有文件和报告；不能据文件名猜实验类型、参考或样本关系；只补问无法核实且会改变分析的背景 |
| 参数来源 | 区分协议必需设置、数据估计、方法默认和研究选择；说明实际取值及理由，不要求用户填写专业参数 |
| 可执行配置 | 仅把已支持的选择映射为当前版本的原生字段；不支持的步骤另行交接，不虚构开关 |
| 阈值复核 | 默认值先评估适用性；依据质控、对照及敏感性检查调整，不能按显著结果数量调参 |

| 资料 | 使用时机 |
|---|---|
| [参数模式.json](references/参数模式.json) | 编写 params.json 时核对字段、类型、枚举及条件约束 |
| [输入模式-1.json](references/输入模式-1.json) | 准备 counts_design 对应的样本表或输入文件时读取 |
| [输入模式-2.json](references/输入模式-2.json) | 准备 input 对应的样本表或输入文件时读取 |

```bash
nextflow run nf-core/tfactivity -r e2af5dcda0056119b0cd02d6c0f6f52a6e294728 -params-file params.json
```

模式文件的许可见 [LICENSE](LICENSE)。

## 质控与解释

检查模态匹配、细胞组成、批次、低表达 TF 和相似 motif 家族歧义，评估结果稳健性。

交付活性候选与各证据层；推断活性不等同直接测量结合或因果调控，优先输出可验证假设。
