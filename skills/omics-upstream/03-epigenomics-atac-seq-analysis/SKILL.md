# ATAC-seq染色质可及性分析

遇到线粒体读段异常、Tn5切点处理、共识峰构建或差异模型选择问题时，读取[方法细节](references/方法细节.md)。

## 开始前

确认参考基因组与黑名单版本、单双端布局、细胞或组织来源、样本分组、批次和独立生物学重复。明确输入是原始FASTQ、过滤后BAM还是已有峰集。

## 执行流程

1. 检查接头、碱基质量、读长和过度代表序列，再用适合短片段的参数比对；分别统计唯一比对、线粒体、重复和黑名单读段。
2. 根据是否保留线粒体信息和文库复杂度决定过滤与去重策略；Tn5切点偏移只应用一次，并在输出元数据中记录。
3. 对每个合格样本独立调用峰。MACS3与Genrich按片段或切点模型选择，不用一套参数同时处理所有文库。
4. 至少检查TSS enrichment、FRiP、插入片段周期性、文库复杂度和重复相关性；失败样本不得直接并入共识集。
5. 有足够重复时用IDR评估窄峰重现性；否则用“至少若干重复支持”的明确规则构建共识峰，同时保留各样本峰，不能只取简单并集。
6. 在固定共识区间内重新计数，用DESeq2、edgeR或limma建模差异可及性，并把批次、配对或供体写入设计矩阵。

## 交付与解释

交付样本峰、共识峰、计数矩阵、差异区域、信号轨道、逐样本质控和完整参数。开放或差异可及性表示调控候选，不等同于转录因子直接结合或因果调控。
