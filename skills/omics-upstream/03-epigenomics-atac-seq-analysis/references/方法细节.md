# ATAC-seq 方法细节

仅在需要排查 Tn5 偏移、峰调用或重复一致性时读取本文件。

1. ATAC-seq 通常没有 input；不要虚构 ChIP 风格对照。
2. 先去除 chrM、低质量、非主要 contig 和黑名单，再生成可比较信号。
3. Tn5 +4/-5 偏移只应用一次。使用真实成对片段的 BAMPE 峰模型时，不再叠加 cut-site 式 shift/extension。
4. 文库复杂度指标在去重前计算；FRiP、TSS enrichment 和片段周期性在统一定义下比较。
5. 多样本差异分析先构建固定宽度或明确规则的共识峰，再从每个样本原始片段计数。

先看片段长度与 TSS 聚合，再看浏览器中开放启动子和阴性区域，最后解释峰数与 FRiP。
