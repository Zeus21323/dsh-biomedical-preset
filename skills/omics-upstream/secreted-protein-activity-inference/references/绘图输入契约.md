# 分泌配体结果绘图

运行 `uv run --script scripts/render_results.py --config RUN.json --out NEW_DIR`。输出在Git仓库外的新目录；相对输入路径以配置文件目录为准。配置需dataset、method、method_version、score_definition，并记录接收细胞响应程序、背景及先验网络版本。一个配置对应一个响应程序，不能把不同程序的活性混在一张排名里。

- activities：TSV列ligand、aupr_corrected；对应原生NicheNet的test_ligand、aupr_corrected，导出时只改列名，不重新计算。负的校正AUPR保留。默认top_ligands=12为展示上限。
- target_links（可选）：ligand、target、weight，对应原生导出的配体-靶基因调控潜力。热图灰色为未导出的联系，不补零；分页共用色标。
- expression_support（可选）：cell_type、role（sender/receiver）、gene、fraction（0–1）、mean_expression，需来自同一表达层与明确的细胞群汇总。不能从配体活性反推出表达支持。

自动输出PNG/PDF/SVG、源表副本/摘要、selection.json、figure_manifest.json和图注。缺输入记not_applicable，重复或无效输入失败退出；输出后逐图打开检查。该程序是原生结果适配器，不代替NicheNet推断、受体复合体核验或MultiNicheNet的多供体模型。

方法依据：[NicheNet官方配体活性教程](https://github.com/saeyslab/nichenetr/blob/master/vignettes/ligand_activity_geneset.Rmd)。本仓库不包含真实表达数据或先验模型文件；真实运行验收过程在仓库外。

## 生物学复核

绘图前确认响应基因来自当前接收细胞的研究问题，背景基因代表该接收群可检测的表达范围。不能为了让某个配体排名靠前而更换背景或删除竞争配体。发送端表达、接收端受体表达和靶基因程序属于不同证据，图注分别说明；只有先验调控潜力时，不将靶基因联系解释为本样本已经发生的调控。

跨供体出现不同排名时，先检查细胞数、响应程序和背景是否可比较；单个响应程序的活性条形图不提供供体层面的差异检验。缺少接收端程序或先验网络时，当前只能完成输入检查和就绪说明，不能用配体表达量代替活性结果。论文叙述应保留阴性候选、竞争解释和后续验证方向。
