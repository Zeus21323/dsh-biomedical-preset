# 脂质组学分析

## 输入与命名规则

需要正/负离子原始数据、色谱和采集方式、类别内标、样本/QC/空白、谱库及采用的脂质命名规范。先确定结果要报告到 lipid species、molecular species、sn 位点还是双键位置。

## 分析路线

- 分离处理不同极性和 adduct，使用类别特异碎片与保留行为筛选候选。
- 结合 LipidSearch、MS-DIAL、LipidBlast 等结果时，统一命名并保留原始证据。
- 同位素、源内碎片、氧化伪影和不同加合物要去冗余，避免重复计数。
- 定量优先使用匹配类别及链长的内标；没有同位素内标时报告相对或半定量。
- 对同分异构体只报告由诊断碎片、专门分离或标准品支持的结构层级。

## 质控

检查空白污染、carryover、类别内标回收、RT、MS/MS 诊断离子、QC CV、峰形和命名一致性。

## 交付

输出标准化脂质表、结构层级和证据、类别定量、内标与 QC、未知/歧义异构体；常见脂质名称不能替代实际结构证据。
