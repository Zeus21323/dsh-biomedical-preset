# RNA测序小变异检测（nf-core/rnavar）

## 识别数据与研究目标

从交付文件与报告中识别 RNA-seq、参考注释、样本和目标区域，确认链特异性及是否有匹配 DNA 数据。

## 方法选择

依据该版本 GATK RNA 变异路径处理剪接比对和调用，保留表达依赖的可调用范围。

先核对 [版本约定](references/流程约定.json)。

| 核对项 | 固定范围 |
|---|---|
| 上游版本 | `1.3.0`；`a0e4641409eb7aed4b325e543d20577f9c08e437` |
| 上游维护 | 未归档；使用这里固定的源码，不自动跟随新版本 |
| 本地运行 | 未进行真实分析运行；不能据本 Skill 文件声称实跑通过 |
| 引擎声明 | `!>=25.10.4`；还需核验 Java、容器和 profile |

## 根据数据确定参数

由剪接比对质量、位点覆盖和编辑背景决定过滤及可调用区域；没有 DNA 支持时区分转录层候选与胚系结论，低表达未检出不等于无变异。

| 决策与配置 | 处理要求 |
|---|---|
| 事实与缺口 | 先读现有文件和报告；不能据文件名猜实验类型、参考或样本关系；只补问无法核实且会改变分析的背景 |
| 参数来源 | 区分协议必需设置、数据估计、方法默认和研究选择；说明实际取值及理由，不要求用户填写专业参数 |
| 可执行配置 | 仅把已支持的选择映射为当前版本的原生字段；不支持的步骤另行交接，不虚构开关 |
| 阈值复核 | 默认值先评估适用性；依据质控、对照及敏感性检查调整，不能按显著结果数量调参 |

| 资料 | 使用时机 |
|---|---|
| [参数模式.json](references/参数模式.json) | 编写 params.json 时核对字段、类型、枚举及条件约束 |
| [输入模式-1.json](references/输入模式-1.json) | 准备 input 对应的样本表或输入文件时读取 |

仅在已授权且配置齐备时运行。

```bash
nextflow run nf-core/rnavar -r a0e4641409eb7aed4b325e543d20577f9c08e437 -params-file params.json
```

模式文件的许可见 [LICENSE](LICENSE)。

## 质控与解释

检查剪接边界、RNA editing、等位表达偏倚、覆盖和重复，区分未表达位点与参考等位证据。

交付 RNA 支持的变异与过滤信息；RNA 变异不能全部视为 DNA 胚系变异，更不能把无覆盖解释为阴性。
