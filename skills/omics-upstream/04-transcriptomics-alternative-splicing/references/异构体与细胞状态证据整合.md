# 异构体与细胞状态证据整合（IsoformStateDB方向）

## 从口语识别证据层级

“表达没变会不会剪接变了”“同一基因在不同细胞功能不同”“转录本版本有什么区别”“长短读长结果矛盾”时核查真实定量。普通3′表达矩阵或spliced/unspliced不能证明完整结构；先完成适用事件检测，再整合。

## 真实计算契约

python scripts/integrate_isoform_evidence.py --config /外部目录/isoform.json --out-dir /外部目录/isoform-001

配置：table，groups（对照、病例），entity_kind（junction_event/full_length_isoform），bootstraps（100–10000），seed。

表列study,donor,cell_type,group,gene,entity,support,total,annotation,source。研究×供体×细胞类型×实体唯一，一个供体在同研究中只归一组；配对任务另用配对模型。细胞聚合需在固定类型内至供体，记录方法，不能给细胞改名冒充供体。注释必须同版，实体到基因单值；跨版先做明确结构/坐标映射，不自动删ID后缀。

junction_event：support为预定义包含证据整数计数，total为同事件包含+排除可比计数，先核对有效长度等事件定量定义，不能拼不等价工具字段。full_length_isoform：support为目标转录本定量丰度，total为同基因同样本可比异构体总丰度；全长结构读段证据另查，此比例不证明全长结构。

0≤support≤total；total=0不可测而非比例0。逐研究/细胞类型/实体计算独立供体组差；每组至少3位可测供体才重采样给描述性百分位区间，否则保留不足状态。不输出p/q，不能按未经多重校正的区间逐项声称差异。

## 解释与边界

donor_support.tsv保留计数和比例，isoform_evidence.tsv保留全部比较与缺失。森林图默认按ID显示前30项，完整表不删。正式差异检验用与设计和计数匹配的主流程方法。

分清局部连接、全长RNA结构、跨队列支持、ORF/NMD预测、蛋白证据与实验功能。保留低覆盖、冲突和细胞组成/表达量/平台替代解释。本脚本不组装reads，不验证蛋白，不建立公共IsoformStateDB。

依据：[SciPy bootstrap说明](https://docs.scipy.org/doc/scipy/reference/generated/scipy.stats.bootstrap.html)；本实现为独立供体百分位bootstrap，不是默认BCa。

## 代理负责准备、执行和复核

用户不需要写JSON或命令。先读取文件与元数据，确认问题、独立统计单位、对比和出处；只用普通话补问确实无法核实且改变设计的事实。只有疾病/基因/毕业愿望时先回公共研究设计；缺输入交付缺口清单，不用模拟数据冒充结果。

代理在用户指定的仓库外目录创建配置。所有配置必填question（实际问题）、parameter_reason（参数与设计依据）、evidence_notes（来源、已核验事实与不确定性）；可选font为覆盖图中文字的已安装字体。参数不得由显著性倒推。路径相对配置文件解析。CSV/TSV为UTF-8、唯一表头，TSV以.tsv结尾；保留原始数据，不自行覆盖。每次指定新输出目录。

Python 3.11+，依赖numpy、pandas、scipy、matplotlib。代理在隔离环境准备并记录版本，不要求新手安装。各适配器自包含，无跨Skill脚本依赖，不需要根目录packages。输入1GB保护上限不等于内存保证；失败非零退出，已有输出目录则留下失败记录，不把残留产物视作成功。

交付完整TSV、summary.json、run_record.json、report.md、可编辑PDF/SVG、400 dpi PNG和图注。作图数据来自对应完整结果表；图的截取规则必须说明。配置、输入/输出哈希、版本和状态均留痕。脚本摘要不等于科学论文：代理需据真实数字补写观察、样本量、效应/区间、阴性/冲突、替代解释、证据等级和下一步，关联具体表行和图件。描述性模式不能声称显著。

打开PNG或渲染PDF，按最终版面检查缺字、截断、图例、颜色、单位、比例、方向和区间；重要发现回查输入。分辨率不是论文质量保证。原始记录保持“需视觉与科学复核”状态；复核可另存review.md，不篡改运行记录。结果、缓存、测试数据和日志只放仓库外。本地适配器不代表后台数据库或未实现的论文方法已完成。
