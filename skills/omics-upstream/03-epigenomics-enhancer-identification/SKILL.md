# 增强子与超级增强子识别

## 开始前

准备同一参考版本的开放染色质、H3K27ac/H3K4me1、Mediator/BRD4或eRNA证据、启动子注释、匹配对照、样本分组和重复。先明确要识别一般候选增强子、活性增强子还是超级增强子；若只有ATAC-seq，只能提名可及的远端调控区或候选增强子簇。

## 执行流程

1. 过滤黑名单和低质量峰，按预先定义的TSS距离排除或单列启动子；ATAC用于界定可及候选区，活性增强子再结合H3K27ac、H3K4me1或eRNA支持。
2. 在单样本或可复现共识峰上计算归一化信号，避免把测序深度差直接当增强子活性差。
3. 只有具备H3K27ac、Mediator、BRD4等能表示连续调控占据的信号时，才使用ROSE或透明的等价实现识别超级增强子，并记录stitching距离、是否越过启动子、排序信号与拐点算法；ATAC-only结果不得直接标为超级增强子。
4. 检查阈值和stitching距离敏感性、重复一致性、基因密集区偏倚以及宽域信号造成的合并。
5. 条件比较使用共同候选区间和适当的计数模型；不能只比较两个样本各自的排名标签。

## 交付与解释

交付候选增强子、活性证据、满足证据要求时的超级增强子区间、排名曲线、信号矩阵、阈值敏感性和轨道。超级增强子是操作性定义，不等于已证明的关键驱动元件；ATAC-only候选必须降级标注。
