# Bulk RNA-seq 差异表达方法细节

仅在需要选择定量路线、设计矩阵或避免数据尺度错误时读取本文件。

- Salmon 索引、参考转录组、GTF 与 tx2gene 必须同一发布版。
- 比较、协变量、配对/重复测量和交互项在查看显著基因前写进设计矩阵。
- 原始计数或 tximport 的 count-scale 输出进入 DESeq2/edgeR/limma-voom；TPM、VST、rlog 不能再作为计数模型输入。

| 场景 | 合适方法 |
| --- | --- |
| 常规计数、样本量中小 | DESeq2 或 edgeR |
| 复杂设计或重复测量 | limma-voom/duplicateCorrelation |
| 转录本定量后基因层比较 | tximport 后进入计数模型 |

先过滤低表达，再拟合模型；效应量、置信区间和 FDR 一起报告。
