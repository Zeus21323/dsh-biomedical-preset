# 序列驱动的调控效应预测

## 开始前

确认变异坐标、参考版本、等位基因方向、目标细胞类型、预测任务、模型版本和输入窗口。多等位或结构变异需先定义每个替代序列如何构建。

## 执行流程

1. 左对齐并核对参考等位基因，围绕同一锚点生成参考与替代序列；处理正负链、窗口边界和插入缺失后的长度对齐。
2. 只读取模型声明支持的物种、窗口、检查点和输出轨道；Borzoi等模型的RNA-seq、CAGE、DNase或ChIP轨道必须匹配目标组织或细胞，表达、可及性、组蛋白与接触图预测分别保存，不把不同尺度分数直接相加。
3. 计算参考—替代预测差异，保留完整位置分辨轨迹，并在预先指定的启动子、增强子或基因体区间分别报告峰值、汇总值与方向；必要时对正反向或窗口平移做集成，检查边缘效应和单一窗口位置敏感性。
4. 使用匹配的常见变异、随机序列或实验测量校准分数；若模型训练域不覆盖目标细胞或物种，明确标为外推。
5. 对重点变异结合motif、QTL、等位特异信号和功能实验排序，说明不同模型一致与冲突之处；跨组织扫描需区分事先指定与事后挑选的轨道。

## 交付与解释

交付逐变异的模型与检查点、窗口、坐标映射、原始预测、输出轨道差异、区间汇总、校准结果、稳定性和候选机制。模型分数是优先级证据，不是致病性、真实表达方向或因果机制的单独证明。
