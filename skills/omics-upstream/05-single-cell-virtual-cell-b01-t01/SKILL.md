# scRNA-seq预处理

## 识别当前数据阶段

先检查已有矩阵、h5ad/RDS、样本表、基因注释和运行记录，识别物种、协议、样本、供体、条件和已有过滤阶段；只有研究目标没有数据时先给数据准备与设计说明。

核验矩阵方向、基因ID、条形码唯一性及元数据按ID对应，确认哪个层保存适用的原始计数。已有有效QC对象或表时直接复用，不因重画图再次执行全部预处理。缺失且改变设计的采样、配对或实验事实用普通语言补问。

## 建立和核验质量指标

设置空液滴、分样本阈值或计数层时读取[预处理方法细节](references/方法细节.md)。

- 有适用raw液滴矩阵时使用knee、emptyDrops或背景模型识别真实细胞；只有filtered矩阵时说明空液滴判断受限，不将其当作已经完成全部质控。
- 每个样本核对总计数、检测基因、复杂度、线粒体以及适用的核糖体/红细胞指标；只有协议支持时将总计数称为UMI。
- 标记环境RNA、双细胞和应激，保留依据及原因，再决定下游过滤；不得单凭固定阈值删除所有组织的细胞。
- 原始计数与归一化、特征选择、缩放层分开保存；不从缩放矩阵伪造原始QC指标。
- 比较过滤前后的每样本细胞数和群体倾向，避免系统删除低RNA真实群体；缺少过滤前对象时如实标记。

## QC图与异常处理

生成QC图或遇到空图、全零、缺指标时读取[QC数据与空图处理](references/QC数据与空图处理.md)。由代理准备配置，调用 `scripts/render_qc.py`；需要从对象提取指标时先按reference使用 `scripts/extract_qc.py` 或 `scripts/extract_qc.R`，保留来源与字段映射。

检查每个面板的观察数、有效数值、单位、组别和实际数据图层。缺列、ID错配、空对象或必需值全缺失不能交付成功空图；合法常数使用点/线等适用表示，不强制密度估计。过滤后零细胞报告过滤计数和规则，不自行放宽阈值制造可画数据。

按样本和真实阶段展示检测基因数、总计数、线粒体比例，必要时分页；不同指标分别设轴，同一指标过滤前后保持可比较尺度。阈值线仅来自已确定规则；背景主次网格默认关闭，标签明确单位和样本量。

## 交付

提供QC对象、细胞/基因过滤表、阈值依据、计数层记录及适用QC图。每张正式单图和组合图默认输出PNG、SVG、PDF，附作图数据、图注与运行记录；检查最终尺寸、文字、范围和三格式内容，直接展示预览及文件链接。

细胞级QC用于描述细胞质量；条件差异以供体等实际实验单位为重复。保留未解决异常与被过滤群体，不为增加显著性调过滤条件。

scRNA-seq预处理的现有绘图入口调用[图件交付内核](scripts/figure_delivery.py)，为实际结果保存PNG、SVG、PDF，关闭背景主次网格，保留该分析的数据线与科学参照；逐图查看交付记录和最终预览，失败不得报告成功。
