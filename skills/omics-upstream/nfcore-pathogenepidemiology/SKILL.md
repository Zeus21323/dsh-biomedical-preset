# 指定病原体基因组流行病学（nf-core/pathogenepidemiology）

## 识别数据与研究目标

从任务与样本背景判断病原体、测序数据、采样时间地点及可用参考，核对该版本支持的物种 profile。

## 方法选择

按物种配置组织预处理、变异/分型与实际下游模块，明确每种病原体的可比区域和过滤标准。

先核对 [版本约定](references/流程约定.json)。

| 核对项 | 固定范围 |
|---|---|
| 上游版本 | `dev`；`13621e99c2baa915276f94820023ff697a304dae` |
| 上游维护 | 开发版本；按当前代码实际实现的范围使用 |
| 本地运行 | 未进行真实分析运行；不能据本 Skill 文件声称实跑通过 |
| 引擎声明 | `!>=25.10.4`；还需核验 Java、容器和 profile |

## 根据数据确定参数

从病原体种类、参考距离和可调用区域选择受支持配置；遗传距离判据结合采样背景与不确定性，不能用跨物种统一 SNP 数宣称传播。

| 决策与配置 | 处理要求 |
|---|---|
| 事实与缺口 | 先读现有文件和报告；不能据文件名猜实验类型、参考或样本关系；只补问无法核实且会改变分析的背景 |
| 参数来源 | 区分协议必需设置、数据估计、方法默认和研究选择；说明实际取值及理由，不要求用户填写专业参数 |
| 可执行配置 | 仅把已支持的选择映射为当前版本的原生字段；不支持的步骤另行交接，不虚构开关 |
| 阈值复核 | 默认值先评估适用性；依据质控、对照及敏感性检查调整，不能按显著结果数量调参 |

| 资料 | 使用时机 |
|---|---|
| [参数模式.json](references/参数模式.json) | 编写 params.json 时核对字段、类型、枚举及条件约束 |
| [输入模式-1.json](references/输入模式-1.json) | 准备 input 对应的样本表或输入文件时读取 |

仅在已授权且配置齐备时运行。

```bash
nextflow run nf-core/pathogenepidemiology -r 13621e99c2baa915276f94820023ff697a304dae -params-file params.json
```

模式文件的许可见 [LICENSE](LICENSE)。

## 质控与解释

检查污染、混合感染、覆盖和分型置信，处理参考差异及低质量样本对关联的影响。

交付病原基因组比较与 QC；相似性或聚类只能作为流行病学线索，不能单独确定传播链。
