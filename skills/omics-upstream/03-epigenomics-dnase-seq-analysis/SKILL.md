# DNase-seq染色质可及性分析

## 开始前

确认单双端测序、DNase消化条件、参考基因组、黑名单、对照、样本分组和重复。输入已有BAM时先核对是否做过切点转换与重复过滤，避免重复处理。

## 执行流程

1. 完成读段质控、比对、重复评估和不可比区域过滤，保留每步读段数量。
2. 生成5'切割位点信号，并用Hotspot、F-Seq2或其他适配DNase数据的方法调用DHS；峰参数需随测序深度和背景调整。
3. 检查SPOT或FRiP、文库复杂度、热点富集、切割偏好、黑名单富集和重复相关性。
4. 只用质量合格样本构建可复现DHS集合，在固定区间重新计数并按实验设计检验差异。
5. 若继续做足迹分析，先校正DNase序列切割偏好，并把足迹结果与DHS峰调用结果分开保存。

## 交付与解释

交付样本DHS、共识DHS、切割轨道、差异区域、质控和方法参数。DHS代表开放染色质，足迹也只是结合候选，均需表达、ChIP或扰动证据支持具体调控结论。
