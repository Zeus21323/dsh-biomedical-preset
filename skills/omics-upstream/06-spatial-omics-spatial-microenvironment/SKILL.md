# 空间细胞通讯与微环境分析

默认用户不了解空间算法或skill。智能体检查文件、坐标单位、组织图像及样本关系，选择适用方法并准备参数；只用普通语言补问无法核实且影响设计的事实。缺少空间数据时说明当前可做的非空间分析，不仿造位置；宽泛研究愿望不自动授权上传或大规模下载。

## 开始前必须有

真实空间坐标、样本/供体关系、测量矩阵及其尺度。细胞组成/配体–受体分支还需细胞或spot标签、适用组织边界和带版本LR库；多细胞spot的细胞类型通讯需解卷积及不确定性。MISTy等整体标记邻域预测按自身输入执行，不要求虚构LR或细胞类型分解。

## 关键判断

先定义“邻近”的实际距离和组织可达性。相邻像素、同一视野和跨组织腔室不是同一种接触；没有空间分辨率支持时只能报告共现，不能声称直接通讯。

## 分析步骤

1. 在每个样本内建立物理邻接图，校正边缘、细胞密度和视野面积。
2. 计算细胞邻域或生态位富集，并以随机置换的空间空模型评估其超出随机共现的程度。
3. 仅在发送群表达配体、接收群表达完整受体复合体且位置相容时计算通讯候选。
4. 跨条件比较使用供体级汇总或分层模型，同时报告细胞组成变化。
5. 对优先候选核对下游靶基因、空间位置和独立实验可验证性。

## 质控与交付

已有空间方法导出的坐标和支持边时，按[绘图输入契约](references/绘图输入契约.md)运行 [render_results.py](scripts/render_results.py)，自动生成组织定位、位置约束通讯图与LR汇总图。此脚本不执行空间空模型或解卷积；原生推断未执行时不能将已有坐标可视化描述为通讯验证成功。

检查分割/解卷积误差、低细胞数、数据库冗余、复合体亚基缺失和多重检验。交付邻域、通讯边、供体效应、空模型结果和证据分级；配体-受体共表达不等于已发生信号传递。

完整分析默认连续生成组织细胞/生态位定位图、邻域富集热图、位置约束的重点通讯网络和 LR 气泡图，不停在表达矩阵或等待追加绘图指令。有足够样本及距离覆盖时增加供体级条件比较或距离关系图。优先复用核验后的结果；每个样本的重点发送/接收群和分子按当前邻近、表达、空模型及供体支持筛选，不固定套用示例通路，也不把缺失细胞群当成特异性缺失。

空间图保留真实坐标、比例尺和组织边界，不用 UMAP 距离替代物理距离；跨切片比较统一颜色和数值尺度，连接仅展示方法实际支持的空间范围。每图保留源表、筛选规则、代码、图注、PNG 和 PDF/SVG，实际打开检查，并记录生成、不适用或失败及原因。没有空间输入时明确当前只能完成非空间通讯部分，不能仿造组织定位图。

## 原生空间通讯与连续出图

有真实空间表达及坐标时，发现已安装主通讯组件 `05-single-cell-virtual-cell-b08-t04` 并读取其方法注册与多方法执行契约。其 run_spatialdm.py 执行 SpatialDM 0.3.1 全局/局部空间关联，run_commot.py 执行 COMMOT 0.0.3 竞争运输和原生方向向量；由 run_communication.py 的 methods 配置统一启动并自动生成热点、坐标数值图、空间连接及向量图。每个坐标必须有真实来源和 μm 换算依据，带组织底图时记录图像变换。不存在的 donor、细胞标签、三维位置不得补造。

SpatialDM 的 FDR 不能解释成运输强度，COMMOT 的运输方向不能解释成因果证据；混合细胞 spot 明确标为 spot。注册表中的其他空间/微环境模型依照各自可取得的原生实现执行，缺实现或输入时具体记录，不替换成上述两种模型。

真实单细胞空间数据可运行 [run_spatalk.R](scripts/run_spatalk.R)：固定 SpaTalk 1.0 源码提交 c86829c42008fb059eba75bec1eec523378e8da6，Rscript 接收配置 JSON 和新输出目录两个参数。输入 RDS 包含基因×细胞 expression（整数 counts）及按细胞 ID 对齐的 metadata（sample/donor/condition/cell_type/x/y）；配置明确 species、resolution=single_cell、coordinate_unit 与 coordinate_provenance。它执行原生近邻 LR 置换和胞内路径，输出 LR 气泡、焦点网络、receptor–TF 评分、真实 ligand→receptor→TF→target 分层图及所选分子的空间检测/近邻共表达边。结果只覆盖原生保留候选，不能从筛后 P 重算全候选 FDR；此入口尚不执行 spot 解卷积。

SpaTalk 的 k 近邻分支可以保留有来源但未标定物理比例的 native 坐标，须设置 physical_scale_unavailable=true，图轴显示原生单位且不得声称微米传播范围。COMMOT 的物理距离参数仍需真实 μm 标定。由主通讯 methods 中 method=SpaTalk 自动调度；跨组件安装位置用 skill_roots 按稳定 ID 解析。推断后立即接续主组件 render_result_bundle.py，不等待追加绘图指令。既有结果包可经 bundle 入口核验后直接重绘。

## 默认图件交付


空间细胞通讯与微环境分析的现有绘图入口调用[图件交付内核](scripts/figure_delivery.py)，为实际结果保存PNG、SVG、PDF，关闭背景主次网格，保留该分析的数据线与科学参照；逐图查看交付记录和最终预览，失败不得报告成功。


空间邻域能否解释某些分子的变化时，运行 [run_misty.R](scripts/run_misty.R) 的MISTy原生随机森林分支。RDS包含特征×单元expression、按单元ID对齐的metadata和二维coordinates；metadata保留sample/donor/condition/cell_type，允许明确记录未知标签。按样本独立建模，不用UMAP代替空间。根据输入特征和实际空间尺度确定features/targets、juxtaview邻域阈值或paraview核尺度，提供feature_provenance/spatial_scale_provenance；不能把示例距离照搬到不同测量平台。输入尺度和预处理方法必须说明。可使用有来源并精确对齐的custom_views，混合spot明确标为spot，整体标记预测不要求虚构解卷积或LR数据库。

MISTy输出原生CV性能、空间模型增益、带符号视图系数、特征重要性和真实标记空间定位图，并保存原生OOB预测、元模型与未截断CV数据。原生汇总将负R²截零；正式交付同时展示未截断结果。重要性符号不等于生物激活或抑制，随机细胞CV不是独立供体/空间分块验证，元模型P值不作为通讯显著性。原生视图前缀保留邻域同一标记，避免被目标列覆盖；所有选择写入记录。来源版本、完整输入与复用约定见[空间多视图执行契约](references/空间多视图执行契约.md)。
