# 空间通讯结果绘图

运行 `uv run --script scripts/render_results.py --config RUN.json --out NEW_DIR`，输出在Git仓库外的新目录。配置需dataset、method、method_version、score_definition、coordinate_unit=um、spatial_method_definition。后者记录空间方法、距离、组织可达性和支持边判据，不能只写“邻近”。本接口针对已定位的细胞/spot节点，不能将解卷积的多个细胞类型当成已经定位的单细胞。

- coordinates：TSV列sample、cell、cell_type、x、y；每样本cell唯一，坐标为真实微米。负坐标可以是合法原点变换。保留等比例微米轴，不接受UMAP或未知单位。
- spatial_edges：sample、source_cell、target_cell、ligand、receptor、score、supported（TRUE/FALSE）。端点须属于同一样本并存在于坐标中；支持判据来自原生空间方法，不能由本绘图程序臆造。score须是非负可加的原生强度，不接受P值/rank。
- colors可指定共享细胞颜色，须完整覆盖；top_edges默认40仅控制每切片展示密度。所有边保留于源表，selection.json记录所画边。

自动输出组织定位、支持边箭头图和样本内LR总分图的PNG/PDF/SVG，以及源表副本/摘要、manifest与图注。总分受细胞密度/边数影响，不能直接解释为供体间效应。组织边界、解卷积不确定性和邻域空模型结果仍需根据实际方法另行展示，不由节点坐标推断。真实数据及验收脚本/日志/图片全部在仓库外。
