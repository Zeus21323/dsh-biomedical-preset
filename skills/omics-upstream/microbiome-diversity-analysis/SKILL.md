# 微生物群落多样性分析

1. 检查特征表方向、测序深度、零值、批次、重复测量和分组样本量。
2. α多样性按问题选择丰富度、Shannon或Faith PD，并用与设计匹配的检验或混合模型比较。
3. β多样性至少选择一种组成型距离和一种生态距离；排序图必须同时给出解释度与样本量。
4. PERMANOVA加入协变量和分层置换，并用离散度检验排除“组内波动不同”造成的假差异。
5. 输出效应量、置信区间、校正后P值、距离矩阵和可复现的预处理说明。

不要只凭PCoA图形分离宣称组间显著差异，也不要把稀释曲线当成所有下游分析的唯一标准化方法。

## 计算契约

输出应同时保留每个样本的 α 多样性表、距离矩阵、排序坐标、解释度、PERMANOVA 设计式和离散度检验。简单独立组设计可使用 `scripts/run_diversity.R` 计算 Shannon、Simpson、Bray–Curtis、PCoA、PERMANOVA 和离散度；复杂设计应定制公式及置换层。使用 Faith PD、UniFrac 等系统发育指标前必须验证代表序列与树叶名称一一对应；分层置换应使用受试者、中心或批次等真实交换单元，并记录置换次数和随机种子。
