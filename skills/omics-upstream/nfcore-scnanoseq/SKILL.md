# Nanopore单细胞长读长转录组（nf-core/scnanoseq）

## 识别数据与研究目标

从交付文件与报告中识别 ONT 与相关 10x 数据、barcode/UMI 设计、参考及文库对应，核查是否需要匹配短读信息。

## 方法选择

按流程支持的方法进行条形码/分子标签处理、长读比对和转录本分析，明确新异构体与已有注释的判断规则。

| 核对项 | 固定范围 |

## 根据数据确定参数

根据长读错误、条形码白名单与短读支持选择纠错和分子聚合；新转录本要求结构与多分子证据，不能把每条长读均视为新异构体。

| 决策与配置 | 处理要求 |
|---|---|
| 事实与缺口 | 先读现有文件和报告；不能据文件名猜实验类型、参考或样本关系；只补问无法核实且会改变分析的背景 |
| 参数来源 | 区分协议必需设置、数据估计、方法默认和研究选择；说明实际取值及理由，不要求用户填写专业参数 |
| 可执行配置 | 仅把已支持的选择映射为当前版本的原生字段；不支持的步骤另行交接，不虚构开关 |
| 阈值复核 | 默认值先评估适用性；依据质控、对照及敏感性检查调整，不能按显著结果数量调参 |

| 资料 | 使用时机 |

```bash
nextflow run nf-core/scnanoseq -r 83d55ea87eb625a3564d40124fb1fa54c4c63f9e -params-file params.json
```

## 质控与解释

评估有效 barcode、UMI、全长程度、剪接一致性和每细胞覆盖，防止错配标签放大低支持异构体。

交付单细胞长读表达/转录本产物及 QC；稀疏长读支持不能自动证明每细胞特异异构体或功能差异。
