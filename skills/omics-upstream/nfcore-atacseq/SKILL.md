# ATAC-seq开放染色质分析（nf-core/atacseq）

## 识别数据与研究目标

从交付文件与报告中识别 ATAC-seq reads、单双端、参考与注释、样本重复及批次；辨明 bulk 与单细胞数据，不能直接混用输入。

## 方法选择

按该版本的比对、片段过滤、peak calling 和可用下游步骤处理，核对 Tn5 位移、线粒体与 blacklist 规则。

先核对 [版本约定](references/流程约定.json)。

| 核对项 | 固定范围 |
|---|---|
| 上游版本 | `2.1.2`；`1a1dbe52ffbd82256c941a032b0e22abbd925b8a` |
| 上游维护 | 未归档；使用这里固定的源码，不自动跟随新版本 |
| 本地运行 | 未进行真实分析运行；不能据本 Skill 文件声称实跑通过 |
| 引擎声明 | `!>=23.04.0`；还需核验 Java、容器和 profile |

## 根据数据确定参数

依据片段周期、TSS 富集、有效片段和重复表现确定过滤与峰集；线粒体比例与测序质量结合解释，不将单细胞计数表送入 bulk 原始读段路线。

| 决策与配置 | 处理要求 |
|---|---|
| 事实与缺口 | 先读现有文件和报告；不能据文件名猜实验类型、参考或样本关系；只补问无法核实且会改变分析的背景 |
| 参数来源 | 区分协议必需设置、数据估计、方法默认和研究选择；说明实际取值及理由，不要求用户填写专业参数 |
| 可执行配置 | 仅把已支持的选择映射为当前版本的原生字段；不支持的步骤另行交接，不虚构开关 |
| 阈值复核 | 默认值先评估适用性；依据质控、对照及敏感性检查调整，不能按显著结果数量调参 |

| 资料 | 使用时机 |
|---|---|
| [参数模式.json](references/参数模式.json) | 编写 params.json 时核对字段、类型、枚举及条件约束 |

仅在已授权且配置齐备时运行。

```bash
nextflow run nf-core/atacseq -r 1a1dbe52ffbd82256c941a032b0e22abbd925b8a -params-file params.json
```

模式文件的许可见 [LICENSE](LICENSE)。

## 质控与解释

评估 TSS enrichment、片段周期、FRiP、重复率和生物学重复一致性；低复杂度样本不靠增加测序量自动补救。

交付开放区域、信号轨道与 QC；染色质可及性不能直接等同基因表达或转录因子结合。
