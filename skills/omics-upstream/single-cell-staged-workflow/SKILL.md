# 单细胞分阶段分析工作流

## 判断从哪里开始

只给疾病、基因或毕业目标而无数据时先做研究设计和数据可得性评估，不因“全流程”生成假结果。读交付目录、样本表和报告判断FASTQ、计数、质控对象、整合对象或最终结果；仅询问无法读取的分组、供体与实验事实。该入口负责跨阶段执行计划和恢复，不替代具体注释、差异分析或通讯任务的科学判断。

已有明确的nf-core/scrnaseq或scdownstream适配路径时保留它，不因为新增工具重复分析。需要一个贯通多个阶段的EISCA运行或用户指定EISCA时，读取[EISCA版本与执行契约](references/EISCA.md)。从已有对象继续，保留raw counts和原始细胞/样本ID；不得把无供体信息的细胞检验解释为患者差异。

## 准备并执行

代理编写原生参数、阶段、参考资源、容器profile、供体对比和期望产物；向用户解释目的和缺口，不让新手填写技术字段。参数依据协议、数据质量和主要终点，记录理由；不按显著基因数量选择阈值。上游预设的默认全阶段不等于用户同意全跑。

使用 `scripts/run_eisca.py` 默认检查固定源码、参数模式和输入路径并输出计划；只有任务包含运行且计划已核实时添加 `--execute`。需要恢复时按reference提供原计划指纹和工作目录，不能把不同参数的旧缓存当本次结果。不支持或未实现的阶段交给已验证方法，明确方法变更；EISCA当前轨迹模块不能声明已实现。

## 图件、解释与交付

每阶段核实真实对象、样本/细胞数量和运行日志再继续。Nextflow退出零只表示引擎完成，还需检查目标模块和产物；记录失败、跳过及未运行内容。

交付参数、输入指纹、版本、阶段日志、分析对象和结果证据表。直接生成样本级QC图、细胞组成及目标基因在细胞类型内的表达图；只有做过相应统计才画组间效应/区间。UMAP是描述性定位，不是疾病分离显著性的证明；通讯分数不是配体作用的实验确认。

图件输出可编辑PDF/SVG与高清PNG、数据及图注，并打开预览检查。可用“科研可视化与报告”的证据图脚本；否则在分析工作区按相同输出和科学标准编写作图代码。最终解读回答研究问题、效应、不确定性、供体复现、替代解释及缺失验证，不承诺发文或毕业。
