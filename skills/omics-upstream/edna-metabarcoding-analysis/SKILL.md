# eDNA 宏条形码分析

1. 核对目标类群、条形码区段、现场空白、提取空白、PCR空白和重复样本。
2. 按引物与质量去噪，使用阴性对照和出现频率识别污染；低丰度阈值应结合对照而非机械设定。
3. 依据目标类群选择参考库，保留无法可靠到种的分类层级，并标明数据库覆盖缺口。
4. 分开报告检出概率与读数丰度；需要占域推断时纳入技术重复和检测不完全性。
5. 产出物种检出矩阵、对照审计表、分类可信度和样本间群落比较。

不得将一次低读数检出直接写成物种稳定存在，也不得用eDNA读数直接代表个体数量。
