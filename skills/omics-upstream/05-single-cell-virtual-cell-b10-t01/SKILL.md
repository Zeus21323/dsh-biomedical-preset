# CITE-seq分析

## 输入与对照

需要 RNA、ADT 和可选 HTO 原始计数，共享条形码，抗体 panel、同型对照或空滴、批次、供体和样本标签。先检查各模态条形码是否一一对应。

## 分开质控，再联合建模

- RNA 按转录组质量处理；ADT 单独检查背景、饱和、零膨胀和异常抗体。
- 根据是否有同型对照和空滴选择 CLR、DSB 或其他背景模型，保留校正前计数。
- HTO demultiplexing 与双细胞判定先完成，无法可靠分配的细胞单独标记。
- 用 WNN 或 totalVI 等整合时，查看不同细胞群的 RNA/ADT 权重，避免低质量模态支配邻域。
- 细胞标签同时参考 RNA marker、表面蛋白和抗体特异性，冲突时保留证据而非强行统一。

## 质控与输出

检查背景抗体、isotype、批次、板效应、RNA—蛋白一致性及双细胞。交付 RNA/ADT 层、校正参数、联合表示、标签和冲突清单；ADT 信号不等于绝对蛋白丰度。
