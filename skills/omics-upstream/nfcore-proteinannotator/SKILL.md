# 蛋白序列结构域与功能特征注释（nf-core/proteinannotator）

## 识别数据与研究目标

从交付文件与报告中识别蛋白 FASTA、物种背景及所需数据库版本，检查非法字符、片段和重复序列。

## 方法选择

按上游方法清理序列并选择 HMMER、InterProScan 或二级结构特征预测，保留数据库和模型来源。

先核对 [版本约定](references/流程约定.json)。

| 核对项 | 固定范围 |
|---|---|
| 上游版本 | `1.1.0`；`cbf78d471f62d91af666e8c77bcd580b4743c6be` |
| 上游维护 | 未归档；使用这里固定的源码，不自动跟随新版本 |
| 本地运行 | 未进行真实分析运行；不能据本 Skill 文件声称实跑通过 |
| 引擎声明 | `!>=25.10.4`；还需核验 Java、容器和 profile |

## 根据数据确定参数

依据蛋白长度、片段化与物种距离选择模型和覆盖条件；同源匹配同时看范围和可信度，短局部命中不能自动赋予整个蛋白完整功能。

| 决策与配置 | 处理要求 |
|---|---|
| 事实与缺口 | 先读现有文件和报告；不能据文件名猜实验类型、参考或样本关系；只补问无法核实且会改变分析的背景 |
| 参数来源 | 区分协议必需设置、数据估计、方法默认和研究选择；说明实际取值及理由，不要求用户填写专业参数 |
| 可执行配置 | 仅把已支持的选择映射为当前版本的原生字段；不支持的步骤另行交接，不虚构开关 |
| 阈值复核 | 默认值先评估适用性；依据质控、对照及敏感性检查调整，不能按显著结果数量调参 |

| 资料 | 使用时机 |
|---|---|
| [参数模式.json](references/参数模式.json) | 编写 params.json 时核对字段、类型、枚举及条件约束 |
| [输入模式-1.json](references/输入模式-1.json) | 准备 input 对应的样本表或输入文件时读取 |

仅在已授权且配置齐备时运行。

```bash
nextflow run nf-core/proteinannotator -r cbf78d471f62d91af666e8c77bcd580b4743c6be -params-file params.json
```

模式文件的许可见 [LICENSE](LICENSE)。

## 质控与解释

检查命中覆盖、得分、多结构域边界和冲突注释，区分完整蛋白与短片段的可信程度。

输出蛋白序列统计、结构域与功能特征；序列预测不是功能实验，也不等同三维结构验证。
