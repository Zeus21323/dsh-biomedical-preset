# 暴露组学分析

## 明确时间与来源

记录基质、采样时点、暴露窗口、环境或问卷测量、药物和饮食、结局时间、批次及协变量。先区分外源化学物、内源反应产物、实验室污染和无法判定的候选。

## 分析策略

1. 用空白、标准品、MS/MS 和稳定 ID 建立暴露物证据等级。
2. 对时变暴露评估重复测量可靠性；单个时点不能代表长期暴露时要明确。
3. exposome-wide scan 在受试者层建模并控制混杂、多重检验和检测频率。
4. WQS、BKMR 等混合模型需预设研究问题、方向假设与验证方案；不要从同一数据反复选择模型。
5. 使用负对照、分层和滞后分析评估药物、饮食、疾病状态及反向因果。

## 质控

检查批次、空白污染、相关暴露、低检出、采样时间和结局先后关系。外源候选若没有结构证据，不得仅凭数据库名称作暴露归因。

## 交付

输出暴露特征、注释证据、效应或混合模型、敏感性、时间窗口限制和验证优先级。
