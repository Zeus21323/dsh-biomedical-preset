# 多组学联合解释与验证

1. 把每个发现追溯到原始数据层、方向、效应和样本，而不是只保留综合得分。
2. 在统一基因或通路空间做映射，处理多对多关系并区分同一证据的重复计数。
3. 用扰动、留一组学、重采样和替代标准化检验结论是否依赖单一数据层。
4. 优先验证跨方法稳定且有明确生物链条的结果；外部队列中冻结特征与阈值。
5. 输出证据矩阵、敏感性分析、可证伪假设和分阶段实验验证建议。

联合出现不等于因果链；结论要分别标明统计关联、功能推测和实验确认的等级。
