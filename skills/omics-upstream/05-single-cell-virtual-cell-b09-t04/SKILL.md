# 虚拟敲除与扰动预测

## 输入和适用域

需要基线单细胞数据、模型及训练版本、目标基因/扰动方式、细胞类型、剂量或时间、对照和可用验证集。先确认模型见过相近物种、组织、细胞状态和扰动类型。

## 预测与验证

1. 建立匹配对照，检查目标基因在起始细胞中是否表达以及扰动在生物学上是否可执行。
2. 记录输入归一化、模型参数和扰动编码；输出后验或多个采样结果，不只给一个平均向量。
3. 量化目标样本到训练域的距离，未见细胞、未见基因组合或远剂量单独标记。
4. 用 held-out Perturb-seq、已知靶基因和通路方向评估校准；防止验证细胞或同一扰动泄漏进训练。
5. 比较不同种子、模型和简单基线，按一致性与实验可行性排序候选。

## 交付和限制

交付预测效应、细胞群差异、不确定性、适用域、失败外推、通路和实验优先级。虚拟敲除生成的是模型假设，不能作为真实基因扰动或因果结论。
