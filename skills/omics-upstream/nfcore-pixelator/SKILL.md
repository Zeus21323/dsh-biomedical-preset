# 单细胞蛋白丰度与互作数据处理（nf-core/pixelator）

## 识别数据与研究目标

核对 PNA 或历史 MPX 技术、试剂版本、panel、hashing 和读段结构；不同数据类型必须匹配支持它的 pipeline 版本。

## 方法选择

按当前 PNA 路径执行分子整理、图构建、细胞识别和去噪；历史 MPX 不能直接用仅支持 PNA 的新接口处理。

先核对 [版本约定](references/流程约定.json)。

| 核对项 | 固定范围 |
|---|---|
| 上游版本 | `5.0.1`；`eb3757a96a5c53b3eaaeb3a3e0692d82944dadc2` |
| 上游维护 | 未归档；使用这里固定的源码，不自动跟随新版本 |
| 本地运行 | 未进行真实分析运行；不能据本 Skill 文件声称实跑通过 |
| 引擎声明 | `!>=25.10.4`；还需核验 Java、容器和 profile |

## 根据数据确定参数

先根据试剂与交付说明匹配版本支持的技术，再按图大小、背景边和 panel 表现选择去噪；新 PNA 接口不适配历史 MPX 时先调整路线。

| 决策与配置 | 处理要求 |
|---|---|
| 事实与缺口 | 先读现有文件和报告；不能据文件名猜实验类型、参考或样本关系；只补问无法核实且会改变分析的背景 |
| 参数来源 | 区分协议必需设置、数据估计、方法默认和研究选择；说明实际取值及理由，不要求用户填写专业参数 |
| 可执行配置 | 仅把已支持的选择映射为当前版本的原生字段；不支持的步骤另行交接，不虚构开关 |
| 阈值复核 | 默认值先评估适用性；依据质控、对照及敏感性检查调整，不能按显著结果数量调参 |

| 资料 | 使用时机 |
|---|---|
| [参数模式.json](references/参数模式.json) | 编写 params.json 时核对字段、类型、枚举及条件约束 |
| [输入模式-1.json](references/输入模式-1.json) | 准备 input 对应的样本表或输入文件时读取 |

仅在已授权且配置齐备时运行。

```bash
nextflow run nf-core/pixelator -r eb3757a96a5c53b3eaaeb3a3e0692d82944dadc2 -params-file params.json
```

模式文件的许可见 [LICENSE](LICENSE)。

## 质控与解释

检查标记分配、分子/细胞图质量、hashing 冲突和 panel 覆盖，保留低质量细胞的过滤依据。

交付 PXL 等该版本的单细胞蛋白与互作产物、图分析和 QC；空间/互作信号受 assay 与图推断约束，不等同直接物理结合测量。
