# Hi-C数据处理与质量控制

## 开始前

确认酶切型或无酶建库方案、连接位点、参考基因组、样本重复和后续需要的最高分辨率。不要先承诺固定分辨率，实际分辨率由有效接触数和覆盖决定。

## 执行流程

1. 检查成对读段质量和连接位点，使用Juicer、HiC-Pro或pairtools等与建库方案匹配的流程完成嵌合读段处理和比对。
2. 分类dangling end、self-circle、religation、未配对和有效互作；去除PCR重复与低质量、多重或异常距离配对，并保留分类统计。
3. 构建pairs与cool/mcool或hic矩阵，明确bin大小；原始计数、平衡矩阵和观察/期望矩阵分别保存，不混用数值含义。
4. 评估有效配对率、cis/trans、短程与长程比例、距离衰减、重复率、覆盖均匀度和重复相关性。
5. 根据每个分辨率的接触密度与矩阵稀疏度给出可支持分辨率；失败文库先定位连接、消化、测序深度或污染问题。

## 交付与解释

交付过滤后的pairs、分层矩阵、逐步质控、重复一致性、推荐分辨率和完整参数。矩阵平衡不能恢复不存在的接触，也不能让低深度数据达到名义分辨率。
