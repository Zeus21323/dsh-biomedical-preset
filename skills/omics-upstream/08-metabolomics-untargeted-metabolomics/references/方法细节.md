# 非靶向代谢组预处理细节

仅在需要配置 XCMS/MS-DIAL、峰回填或 QC 过滤时读取本文件。

XCMS 的基本顺序是：findChromPeaks → 初步分组 → adjustRtime → 重新分组 → fillChromPeaks。高分辨质心 LC-MS 常用 centWave；参数、软件版本和处理顺序必须随特征表交付。

1. 特征表是峰检测与分组参数产生的模型结果，不是原始事实。
2. fillChromPeaks 在预期窗口积分，不代表样本中确有可信峰；重要特征要回看 EIC 和峰形。
3. 一个化合物常产生多个加合物、同位素、源内碎片或多聚体；注释时按证据合并。

正负离子、LC-MS 与 GC-MS 分开处理。QC CV、空白比、稀释线性、RT 漂移和批次共同约束参数。
