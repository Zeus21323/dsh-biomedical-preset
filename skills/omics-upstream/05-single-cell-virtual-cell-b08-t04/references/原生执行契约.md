# 原生执行与条件图

## 入口和环境

完整任务运行 `uv run --script scripts/run_communication.py --config RUN.json --out NEW_DIR --rscript /path/to/Rscript`。输出须是新目录且位于 Skill Git 仓库外。输入相对路径相对于配置文件目录。只补一个对象也使用相同入口。

原生适配器默认 CellChat 2.2.0.9001，接口依据官方提交 `75253cd0c9e68410e6e721a6d3a0419a1d7e358f`；不能自动跟随 main。R需 CellChat及其依赖、jsonlite、digest、svglite、ragg、ComplexHeatmap、circlize、ggplot2。另一个版本须先核验接口才能设置 expected_cellchat_version，不能为绕过检查改字段。Python固定 numpy 2.2.6、matplotlib 3.10.6、scipy 1.16.1。每次保存sessionInfo。上游依据：[固定源码版本](https://github.com/jinworks/CellChat/tree/75253cd0c9e68410e6e721a6d3a0419a1d7e358f)；仓库仅保存原创适配代码，不复制上游源码或数据库。

矢量色条要求ggplot2至少3.5.0，脚本在运行前检查。默认只加载现有环境，不偷偷切换系统R或更新其他项目的包。新增依赖应放入对应分析环境，固定版本信息随用户结果保存。

## 配置与对象

顶层必需 dataset、research_question、defaults、samples，可选 comparison、context、condition_order。defaults为共用设置，samples条目覆盖对应字段。

每样本必需 sample、donor、condition、species（human/mouse）、mode（infer/reuse）。独立供体设 analysis_unit=donor，池化对象设pooled；不能借用患者名将池化对象冒充独立重复。

- infer：input指向RDS，含expression（基因×细胞、唯一行列名、有限非负log-normalized稀疏/普通矩阵）和metadata（行名对应细胞；列cell_type/sample/donor/condition）。明确expression_layer=log_normalized。每次一个生物样本，不猜测表达层、不重做合格归一化。
- reuse：object指向含prob/pval张量的单CellChat对象；source_provenance说明来源与历史参数已知程度。拒绝merged对象；只在副本上派生过滤网络和centrality，不重算表达和通讯概率。
- min_cells默认10、alpha默认0.05、seed默认1、nboot默认100、average_method默认triMean、trim默认0.1、population_size默认false，是方法起点，需依据设计核验，不因图少降低阈值。
- database_categories默认Secreted Signaling、ECM-Receptor、Cell-Cell Contact；代谢信号不混入此蛋白通讯入口。
- expression_fraction、overexpression_logfc、overexpression_p对应过表达筛选，默认0、0、0.05；受体复合体按原生数据库处理，不自行拼装亚基。
- focus_sources/focus_targets/pathways指定研究焦点。未指定发送者时采用最高总发送强度，仅为探索起点。LR按焦点细胞对占该LR总分的比例、原生分数排序；通路按焦点内总分排序，都不是疾病特异性统计。top_lr默认20、top_pathways默认3为展示上限。
- 指定焦点在某样本不存在或低于细胞数要求时，保留其余完整推断并明确记录不适用，不用其他细胞替代，也不静默从供体比较中删除整个样本。指定通路在焦点内无支持时保留阴性记录。
- colors若提供必须覆盖对象全部细胞标签；跨条件共用映射，不复制参考图标签。

输出candidates.tsv保留原生候选张量中LR、原始score、细胞群置换p_value、tested和supported。未进入某样本张量的LR是未检验，不补零。edges.tsv仅支持边；同时保存细胞QC、可检验范围、网络源表、排名、选择记录、派生对象、版本和数据库摘要。

批量入口先读取各输入对象的细胞标签并建立共享颜色。旧对象缺少当前槽位时在副本上调用原生updateCellChat，记录转换步骤；输入对象不修改。过表达检验使用原生标准实现，避免隐式依赖可选加速包。主图另绘89×78毫米紧凑面板，聚焦至多两个发送群、三个高分接收群和既定优先通路；选择记录与完整图集同时保留，再无缩放组合为183×170毫米可编辑SVG与PNG预览。各面板另有PDF。不能将这种展示选择称为差异显著性。

## 条件比较

核实相同物种、表达层、数据库和推断设置后填写共同comparison_signature。程序还比较实际comparison_parameters、数据库摘要和版本；签名不能代替核验。infer自动记录实际参数；reuse须提供从历史记录核实的historical_comparison_parameters。参数未知时保留各对象独立图，不做定量比较。

comparison指定conditions: [参考条件, 比较条件]、paired、min_donors（至少3，默认3）、permutations（默认9999）、seed、fdr（默认0.05），可选focus_sources/top_lr。最低运行人数不代表功效充分；小样本精确置换可能无法达到常用显著性水平。

比较每供体未按P值置零的原生分数，效应=比较组减参考组。配对仅使用两条件均可检验的同一供体；非配对拒绝重复供体。先对全体满足人数的source-target-LR进行双侧均值差置换并BH，再按焦点选图。不能把一组不显著解释为组间显著差异。本实现无协变量/批次调整，多时间点、混杂及层级设计需适用模型或MultiNicheNet，不强塞此接口。分数受样本表达分布影响，需结合组成敏感性、表达支持和下游证据解释。

描述性条件热图共用细胞顺序、色标，按可检验样本等权汇总；灰色表示无可检验样本。候选检测范围会影响计数，因此计数差不是差异显著性。效应图配套完整FDR表、筛选记录及供体点图。

默认增加细胞数量过滤敏感性图：对同一结果采用原始及两倍最小细胞数阈值，比较支持联系数、通路数及总分。它不重算概率，也不等于完整的细胞组成、表达模型或数据库敏感性分析。条件网络图共用边宽上限；主图与完整图中的候选范围不同，须结合各自源表解释。

## 条件图输入

context下每项含path指向TSV。缺输入为not_applicable，已提供但无效为failed，不等待另一次画图指令。

| 项 | 必需列 | 配置说明 |
|---|---|---|
| embedding | cell、x、y、label | method说明降维方法，可选colors；复用现有坐标 |
| functional_scores | sample、donor、condition、cell_type、score_name、score | score_definition说明基因集来源、算法和聚合；每供体-条件-细胞群-评分唯一 |
| clinical_association | donor、feature、feature_value、outcome、outcome_value | outcome_definition说明实测/预测来源；每关联每供体唯一；可选seed/permutations |

功能评分为供体点与均值，不自动加星号，不从通讯强度伪造评分。临床关联用Spearman、供体随机置换与全体可检验关联BH；至少4位独立供体且变量非恒定才检验，无协变量调整。药敏响应分类热图需要实际分类结局和适用模型，不能从连续相关臆造。

## 状态与保存

返回0代表适用流程执行完成，仍为generated_pending_visual_review；实际图片需要Agent审查。技术问题/分支失败返回2，入口错误返回1。每图保存generated/not_applicable/failed、源表、图注、文件和technical_quality；程序不自动写visual_review=passed。布局调整复用已有对象和新目录，不覆盖结果或重算表达。

验收真实数据、专用下载/运行脚本、配置、环境、图片、日志和验收报告全部保存在Git仓库外。仓库只保留通用生产代码和虚构数据的单元测试，不加入真实样本、公开数据子集或本机路径。

## scTensor与scTenifoldXct

两者由多方法入口连续执行及出图，不需要用户认识参数。配置由智能体根据已读数据填写。

- scTensor固定2.18.2、nnTensor 1.4.0、rTensor 1.5.0，LRBaseDbi与SQLite资源另记版本及摘要。input为RDS，counts尺度使用counts字段，其他明确的normalized/log_normalized尺度使用expression字段，均为基因×细胞；metadata行名为细胞，含sample/donor/condition/cell_type。只接入已核验的人类NCBI Gene ID分支，必需database、database_provenance、gene_id_provenance、normalization_definition。基因映射歧义保留在仓库外，不用大小写转换代替身份转换。lr_evidence默认known，min_cells默认10。
- scTensor的ranks可预先指定两个正整数，缺省使用原生自动选择；rank_runs默认5且至少2。当前源码以NMF展开张量的RSS降低比例选秩，文档中的PCA描述与其不同。seeds默认42/43/44且至少两个不同种子；全种子保存，图中首种子预先固定。原生30次迭代完整保存。资源无多亚基语义，不把单基因LR外积补写成复合体算法。reuse_directory按输入/资源/参数/对象摘要验证后重导出。
- scTenifoldXct固定0.2.2，源码提交01f6666238e135e473039707025583447039444c；实际numpy/scipy/torch/scanpy等版本和源码文件摘要进入缓存签名。input为h5ad，expression_scale=log_normalized，指定layer及sample_key/donor_key/condition_key/cell_type_key；species=human，另需source_celltype、target_celltype、normalization_definition、input_provenance。两个细胞群不同，基因转换为原生大写后必须仍唯一且不含下划线，不以拆字符串恢复复合物。
- scTenifoldXct默认training_steps=1000（不低于1000）、learning_rate=0.01、min_cells=10（原生至少6）、threads=2、seed=0；原生网络构造重置种子，不能宣称任意seed生效。query_DB=None、alpha=0.5、mu=1、n_dim=3、GRN nComp=5固定。max_gene_pairs默认一千万，因为原生构造全部跨图距离及稠密拉普拉斯矩阵。test默认empirical_null，支持按原生P<alpha(默认0.05)；chi2分支按原生全基因对BH q<alpha。两个分支不可混成同一种显著性。
- scTenifoldXct保存原生返回的最后一次更新之前的投影；仅重载模型权重会生成不同投影，故复用有摘要的完整本地原生对象。基因调控网络显式导出原数组，避开上游保存函数仍写旧路径的行为。经验P无细胞/供体置换，距离越小是流形靠近而非作用增强的因果证据；没有供体差异、敲除或实验机制验证。

全部正式图由结果包绘图器生成PDF/SVG/600DPI PNG、作图数据、图注与审阅状态。迭代曲线保留所有实际步骤；潜在空间2D仅显示原生前三维中的前两维，3D显示全部三维，不标为UMAP或空间距离。真实验收文件不进入本仓库。


### exFINDER

`run_exfinder.R` 调用exFINDER 1.0.0（GPL-3.0，固定commit `516bcb946272ab313e3e3d802fef44d1fa51f80e`），按真实物种选择包内人/鼠/斑马鱼三层数据库，记录资源摘要。表达RDS含 `expression`（基因×细胞）和 `metadata`（行名为细胞，sample/donor/condition/cell_type）。尺度为已确认的normalized/log_normalized；不重复归一化已有结果。`targets`、`target_provenance`、`receiving_groups`、两个 `receptor_tf_cutoffs` 和 `cutoff_provenance` 必填，来自研究问题和输入尺度。`ligands` 与 `ligand_cutoff` 二选一；负阈值是原生低表达外源候选规则，不证明外源来源。可指定 `ligand_groups`，缺省为接收群。

原生流程依次为get_ltGRN、可选get_potentialex、get_exSigNet、fix_OverLap、get_NodeValue、get_EdgeWeight、get_LRMaxFlow、get_AcI。Kh默认2、AcI四参数默认2，显式记录。节点取指定群的最大平均表达；边为两端值乘积/(Kh+乘积)。原生TF角色包含部分非TF信号中介，展示为signaling并保留原角色字段。容量最大流和AcI为模型量，无P值，不代表真实物质转移或因果。缺先验/合格配体/完整网络分别记录真实零结果。

可选 `external_input` 使用同结构RDS，并提供 `external_provenance`、`external_pooling_definition`、与内部一致的 `external_expression_scale`；可指定 `external_groups`。没有参考或配体未测量时，原生固定配体值1，须保留假设。原生均值函数要求稠密矩阵，默认上限2 GiB，超限失败，不私自抽样。`reuse_directory`校验输入、数据库、参数和原生对象摘要后复用；原生图与角色裁剪前图均留在用户输出目录。统一流程自动出图，图注区分节点表达与配体常数。


### SpaCeNet

原生SpaCeNet 0.0.1（MIT），https://github.com/sschrod/SpaCeNet ，固定commit `22923caeecc4f24b1696715146ae815b0e064aa0`。Python入口run_spacenet.py使用主通讯h5ad契约：表达层layer/尺度expression_scale/物种species，obs含sample/donor/condition/cell_type，obsm.spatial为同单元二维真实坐标。resolution、coordinate_unit/coordinate_provenance、normalization_definition、features/feature_provenance、spatial_scale_provenance、penalty_provenance必填。此入口支持人/鼠的已变换连续表达，不把原始counts默认视为高斯测量；空间模型本身不需要LR库。

Theta参数默认smoothed_potential、L=3、scale_correction=min、standardize=false、Euclidean距离，支持原生Coulomb、其他原生距离/尺度定义；kNN尺度需k/quantile，未知物理标定用native单位且physical_scale_unavailable=true。最小非零距离尺度不等于物理扩散长度。重复位置、零方差特征、非有限值失败。逐样本至少30个单元，默认上限5000，Theta最多2 GiB，不自行抽样。

penalty提供alpha/beta，或grid完整提供min_alpha/max_alpha/n_alpha/min_beta/max_beta/n_beta/n_refinements/refinement_criterion（AIC或BIC）。原生网格关闭warm_start，按原生准则最优项从头复拟合，不挑通讯边较多的参数。最优项不收敛则明确失败而非换成有利参数。默认优化步长1e-6、momentum=.9、eps=1e-5、max_iter=10000，默认最多3次降低步长；调整数值参数须记录，不能放宽科学支持规则。

原生内部对输入按样本均值/样本标准差标准化，保存所有原生参数、源文件/输入/运行版本摘要。Omega是同单元对称条件参数，Drho是各阶空间距离势系数；均非LR分数或方向性生物效应。保留对角线与真实零值。仅检查Omega对角与数值有限性，并报告最小特征值；不宣称完整空间联合精度矩阵已验证正定。原生变量条件预测使用同一数据其他表达与邻域，不称外部预测准确率。

原生BIC的参数数目×log(N)存在Torch浮点提升产生的单精度中间项；保留原生BIC用于原生搜索，与双精度重算有微小数值差别，不静默改算法。优化曲线是投影点负伪似然、不含正则项，也不是最终参数点值；原生相对变化达阈值才报收敛，非独立性能保证。AIC/BIC来自训练伪似然，没有供体差异或P/FDR。

统一入口自动交付完整收敛曲线、Omega/各阶Drho热图、原生网格准则、每个选定特征的实测与条件拟合空间图及可编辑PDF/SVG、PNG、源表、图注。reuse_directory需精确匹配输入/原生源码/版本/科学参数及对象摘要。所有对象、环境、数据、缓存、网格与验收记录均在Git外。


## NicheDE：空间邻域响应与 Niche-LR

调用 `scripts/run_nichede.R config.json new_output`；统一入口在生成原生结果后自动绘图。固定上游 `kaishumason/NicheDE@87e0e89bb066702a54fa47638965b61dc6f24d05`，包版本 `0.0.0.9000`。实际 LICENSE 为 MIT，DESCRIPTION 仍留有模板占位符，版本和文件来源均应记录。

输入 RDS：`counts` 为基因×空间单元整数计数；连续值分支使用 `expression`，必须明确归一化含义；`metadata` 行与单元对齐，包含 sample/donor/condition/cell_type；`coordinates` 两列依次为真实 x/y，图像坐标应 x=imagecol、y=imagerow，并设置 y_down；`library_expression` 为细胞类型×基因的参考均值，`cell_fractions` 为同单元×同细胞类型的非负组成，行和为 1。参考表达尺度应与观测数据和原生细胞数估计相容，不能把推断比例或细胞数称为实测。单细胞组成必须由实际注释 one-hot 得到。

配置除通用输入项外，必须有 resolution、coordinate_unit/coordinate_provenance、reference_provenance、composition_provenance、gene_universe_provenance、sigma/spatial_scale_provenance。未知物理单位使用 native 且 physical_scale_unavailable=true；不能把像素或内部归一化单位写成微米。使用完整、有来源且尺度相容的基因背景，原生算法自行交集并计算文库总量；不能为快速运行只截取感兴趣靶基因而冒称完整结果。每个样本独立处理，30–5000 个单元为默认契约，并检查距离矩阵/稠密矩阵内存上限。未接入原生 >=10000 单元随机尺度估计和联合批次回归路径。

科学默认值：minimum_gene_counts=150、minimum_colocalized_units=10、reference_quantile=0.8、kernel_cutoff=0.05、alpha=0.05、self_niche=false。sigma 必须依据分辨率和空间问题事先确定，不按显著基因数量选择。记录下列原生语义：

- <10000 单元的代码用“100 / 平均第二近邻距离”缩放坐标，排序包含自点 0；教程所写的最近邻中位数不等于当前实现。Gaussian 权重为 exp(-d²/sigma²)，包含自身位置，截断低权重后乘估计细胞数，再按类型做 z 标准化。
- counts 分支先拟合 Poisson 均值，再在该均值下优化负二项离散度并形成协方差；不冒称联合 NB-GLM。原生空间单元并非独立供体。连续分支采用实际原生线性模型，不套用计数检验。
- 正/负各自组合；gene 层跨基因 BH，cell_type 层在每个基因内 BH，interaction 层在每个基因/index 类型内对 niche 类型 BH。不能写成全部交互的统一 FDR。核间按似然权重/Cauchy，基因及类型层使用相关性修正的 Fisher。出现 nearPD 修正须保留警告与限制。
- 原生 valid=0 混合了输入筛除及内部捕获的拟合异常；不能全叫阴性。某一核的缺失似然可能让多核交互值整体缺失，即使其他核有估计；保留缺失，不自行填零或改成另一种组合算法。

`niche_lr_queries` 中每项为 ligand_cell/receptor_cell，K 默认 25（至少 5）、M 默认 50、truncation_value 默认 3，必须来自研究焦点或实际数据设计。调用原生 niche_LR_spot/cell，保留原表及对象。默认包内 NicheNet/Ramilowski 资源只适用于人类；自有 `lr_resources` RDS 需要 ligand_target（靶×配体）及 lr 两列、lr_resource_species 与 lr_resource_provenance。未返回候选配体与未返回 LR 分别记录为明确阴性阶段；其他原生错误仍失败退出。

调用 `scripts/run_spaotsc.py --config config.json --out new_output`。固定 `zcang/SpaOTsc@def276221e3b636916a812b39f2658737584c212`、包版本 `0.2` 和 MIT 许可；适配器校验已核验的 `SpaOTsc.py` 摘要并调用原生 `spatial_signaling_ot`，不复制或改写上游传输算法。Python 运行环境须记录 spaotsc、NumPy、pandas、SciPy、POT、dit 和 anndata 版本。旧版 dit 在 Python 3.10 缺失的集合抽象基类只做名称兼容，不改变传输计算。

## TraSig：轨迹滑窗通讯评分与审计后置换

调用 `scripts/run_trasig.py --config config.json --out new_output`。固定 `doraadong/TraSig@465cffc10a77502aaee0b60f4d73940ca2e32379`、包版本 1.0.0 和 MIT 许可；适配器核对 `trasig/trasig.py` 摘要，并直接调用原生 `process_per_path`、paired dot/cov 评分。当前验收范围为 `align_type=unaligned`。DTW 的 aligned-fixed/aligned-specific、parent 起始窗口和上游后分析脚本尚未形成可接受的原生契约，入口明确拒绝，不能静默回退到 unaligned 后仍写成对齐结果。

输入为 h5ad：表达层必须有限非负，metadata 含 sample/donor/condition/cell_type，另有 `path_key` 和 `pseudotime_key`。伪时间必须来自已完成且记录方法/参数的真实轨迹，缩放到 [0,1]；不能用 UMAP 轴、采样日或任意细胞顺序代替。每样本至少两条轨迹，每条默认至少 max(20,n_lap) 个细胞。配置须提供 normalization_definition、input_provenance、trajectory_provenance、sampling_time_provenance、resource_provenance、版本化 LR TSV 及固定 native_root。`path_sampling_time` 精确覆盖全部轨迹，用于决定可以配对的同期分支；未知真实采样时间时可将全部分支置于同组，但必须 `sampling_time_unavailable=true`，结果只能解释为伪时间重叠假设。

原生过程把伪时间四舍五入到 0.01 的 101 个位置，按轨迹求每个位置的表达和细胞数，再用 bottleneck 移动和形成滑窗均值。n_lap 默认 20；smallerWindow 默认以前半窗口处理起始位置，另支持 discard 和 None。空 bin 是否转 0 由 nan2zero 明确控制。dot 是同期发送配体与接收受体滑窗曲线乘积的时间均值，cov 是同一曲线去均值后的总体协方差估计；二者不是表达差异、因果效应或物理通讯通量。所有有相同 `path_sampling_time` 的发送/接收分支有向配对，自身对保留。

**上游置换缺陷及处理必须随结果交付**：固定源码的 `generate_permutation` 执行 `permutated_times = self.cell_times_o`，随后按置换路径就地赋值；它会改写真实伪时间，并让后续轨迹从已污染数组读取条件时间。真实作者示例已核验：首条轨迹保持多重集，其他三条不保持，输入数组被改写。因此入口拒绝 `source_exact` P 值。唯一可执行模式 `documented_intent_copy` 使用同一确定性随机种子和路径标签置换，但先复制时间数组，再从未改写的原始轨迹提取时间并置换，符合上游 docstring 所述的轨迹比例和条件时间分布保持。它是明确标记的审计修复，不是逐字节原生置换结果。

P 值按 `(不少于观测分数的校正置换次数+1)/(B+1)`；B 默认 1000且至少100。BH 只在每个样本、发送–接收轨迹对和指标内执行，与作者后分析脚本范围一致。支持标记为 q<alpha。统计单位仍是固定、已由同一表达数据推断的轨迹下的细胞标签/伪时间置换；没有独立供体、轨迹不确定性或两条件模型，不能称患者层显著、条件特异或验证了轨迹方向。真实论文比较需要独立样本分别运行，并在另一步以供体为统计单位建模。

输出保留全部样本×轨迹对×LR 的原生 score、修正 P/q、校正范围和置换模式，另存全部路径×基因滑窗轨迹及原生评分数组。自动图件包括 LR 点图、支持数量网络/弦图、论文布局概览和按完整 q/score 选定的发送/接收轨迹曲线，交付 PDF/SVG/高清 PNG、源表和图注。展示曲线只帮助核查共同动态，不构成第二份检验；未显示候选仍在完整表和 NPZ 中。作者示例的原生观测评分可与仓库提供对象逐项核验，但作者置换结果因上述缺陷只作为失效证据保留。

调用 `scripts/run_scmlnet.R config.json new_output`。固定 `SunXQlab/scMLnet@ef2c245e2ce4c08839dd471fc67b37b65a8de3d1`、版本 0.1.0 和 GPL-2，校验 `R/Run_scMLnet.R` 及作者 `LigRec.txt`、`RecTF.txt`、`TFTargetGene.txt` 的 SHA256 后调用原生 `RunMLnet`。已验收环境为 Matrix 1.7.6、Seurat 4.4.0 与 SeuratObject 4.1.4；上游直接调用 Seurat 内部 `_Seurat_LogNorm`，因此其他版本明确失败。输入 RDS 必须包含基因×细胞的原始非负整数 `counts` 和身份对齐的 `metadata`，其中 `sample/donor/condition/cell_type` 完整；未知供体须明确写 unknown 或 published pool，不能由条码推测。

配置必须给出 `sender`、`receiver`、`native_root`、`input_provenance`、`resource_provenance` 和 `resource_version`。每次执行一个样本中的一个发送群→接收群；原生流程不含多样本模型，入口拒绝把多个样本合并为一个网络。各样本应分别运行，再用统一比较层以供体或真实实验样本为统计单位汇总。适配器只先排除无关细胞群，因为上游列归一化及其后所有检验只使用发送/接收细胞，这不改变两群的原生数值，也避免对整张无关图谱重复稠密化。不会为加快运行抽样细胞或基因。

必须随结果解释四项原生语义：

- `getHighExpGene` 在 raw counts 上先执行 `expm1` 后求均值对数形成 logFC，再用 Seurat 列归一化值做细胞层 t 检验；P 值未校正。这不是标准 count logFC，极端计数还可能溢出。输入出现非有限结果时失败，不能自动截断。
- TF 与受体阶段没有调用 Fisher 右尾检验，而是以组合数计算观察到该重叠数的单个超几何点概率。更严重的是，上游把名称和概率 `c()` 后形成字符矩阵，再执行 `<0.05`；科学计数法表示的极小数会按字符串比较而被漏掉。适配器逐项复算数值概率，验证作者字符规则的入选集合，并输出完整 `point_probability_audit_*`，但原生网络仍保持作者选择。
- Receptor–TF 与 TF–Target 候选在接收细胞 raw counts 上做 Kendall 相关，将 tau 保留两位有效数字、P 保留三位有效数字后，以 tau>0 且 raw P<0.05 入选，没有多重校正。适配器对全部候选独立复算，要求原生选择完全一致，并另列未舍入值和 BH 作为诊断；BH 不替换原生网络。
- 原生返回值只有三层边身份，没有边强度或可比较概率。统一 `value/score=1` 只表示成员；网络线宽、弦宽和计数不得解释为表达通量、信号剂量、条件差异或因果效应。

输出保留最终 LR、全部多层边、原生各阶段计数、分层 Kendall 热图、全部相关候选及 P/q、数值与字符点概率诊断、高表达基因、原生筛选表、原生 RDS、配置和运行摘要。自动图件包括 LR 证据点图、发送–接收网络/弦图/论文概览、多页 Ligand→Receptor→TF→Target 层级网络、分层弦图、阶段计数及独立色标的 Receptor–TF 和 TF–Target Kendall 热图，均交付 PDF/SVG/高清 PNG、作图数据和图注。单一 LR 的稀疏图应如实保留，不能靠放宽阈值或重复边制造视觉密度。作者 COVID-19 BALF 示例仅能验收算法复现和图形链路；其已发布池化对象不提供本次对比所需的独立供体结构，不能据此声称患者层显著或疾病特异机制。

## SoptSC/RSoptSC：单细胞概率分配与路径靶基因

调用 `scripts/run_soptsc.R config.json new_output`。固定 `mkarikom/RSoptSC@052195bb98157e6a35957b71141ef1bf5bb9f024`、版本 0.0.0.9000 和 MIT 许可，校验 DESCRIPTION、LICENSE 与 `R/Signaling.R` 的 SHA256 后调用原生 `ImportPathway`、`GetSignalingPartners`、`ClusterSig_single` 和 `ClusterSig`。配置必须提供非负 expression、严格对齐且包含 sample/donor/condition/cell_type 的 metadata、species、表达尺度与归一化定义，以及具备版本、来源和摘要的 Ligand-Receptor 与 Receptor-Target 资源。输入和资源在忽略大小写后不得出现身份冲突。每个样本独立执行；未知供体须明确记录，不能从细胞条码推测。

对每条 LR 和每个发送–接收细胞对，原生模型先计算 `alpha=exp(-1/(ligand×receptor))`；任一端表达为零时 alpha 为零。受体上调靶基因用 `beta=exp(-靶基因数/靶基因表达和)`，下调靶基因用反向表达形式形成 gamma，再由 kappa/delta 修正 LR 信号。每条 LR 都将每个有正总信号的发送细胞对全部接收细胞的分布归一化。`ClusterSig_single(normalize_rows=TRUE)` 会先丢弃零细胞对，因此群级 LR 值只除以该发送群内有正信号的发送细胞数；无信号细胞不进分母。每个有信号的发送群×LR 对全部接收群的值之和为 1。

`ClusterSig` 不是直接对细胞级 `P_tot` 求群均值。它先对每条 LR 分别执行上述活跃发送细胞群汇总，再等权相加所有 LR 的群分布，最后在每个发送群内归一化。接收群是互斥类别，因此最终表的同一发送群概率份额可以相加；不同资源集合、预处理或数据集之间的值不能当绝对信号强度直接比较。固定源码中的 `ids` 参数未参与计算，`normalize_aggregate` 也没有控制分支，原生实现始终归一化；受体靶基因按 receptor 与 direction 选择，不再按 ligand 区分。这些行为均写入运行记录和图注。

固定 RSoptSC 信号模块没有统计检验、置换、多重校正、供体模型或条件比较。统一结果中的 `tested=true` 只表示候选进入模型，`supported=true` 只表示模型份额为正；两者都不是统计显著性。数值是相对接收分配，不是结合概率、分子数、分子通量或因果效应。真实条件比较必须让独立样本分别执行，再以供体或真实实验样本为单位汇总，不能把池化细胞当重复。

输出包括全部正值 LR 群分配、发送群归一化总网络、路径基因的群平均输入表达、Ligand→Receptor→up/down Target 资源成员、原生 P 矩阵和群汇总、行和误差、源码/资源摘要及运行记录。自动图集包含分页 LR 点图、LR 支持计数网络/弦图、群级概率份额网络/弦图、路径表达热图、路径成员层级/弦图/分层图和论文布局概览，均交付可编辑 PDF/SVG、高清 PNG、作图数据和图注。原生实现会显式形成 LR×发送细胞×接收细胞长表；超过 `max_cell_pair_rows` 时入口失败，不静默抽样细胞或 LR。仓库外真实验收使用作者 RSoptSC GSE67602 Joost 完整示例：24,378 个非 ERCC 基因、720 个细胞、5 个作者注释群、4 条 TGFB LR 与 28 条合并路径记录，共核验 2,073,600 个细胞对行。独立脚本不调用 RSoptSC 函数，重算全部公式与导出，最大误差为 1.50e-15；作者数据没有可核实供体字段，这项验收只证明软件与图形链路可复现。


## scriabin：单细胞对 CCIM、prior graph 与 LR 共变程序

调用 `scripts/run_scriabin.R config.json new_output`，配置的 `mode` 必须为 `ccim_graph` 或 `programs`。固定 `BlishLab/scriabin@bce695bd598e2e2d37e51d983dca2a29d5ef61c7`、版本 0.0.0.9000、MIT 许可和内置 `lr_resources.rds` 摘要；入口同时校验 DESCRIPTION、LICENSE、关键源码及 `LoadLR`、`GenerateCCIM`、`BuildPriorInteraction`、`InteractionPrograms`、`InteractionProgramSignificance`、`ScoreInteractionPrograms`、`IPCellTypeSummary` 的已安装函数体摘要。当前上游提交在 CCIM/prior graph 中调用已被 Seurat 5 移除的 `slot` 接口，在 InteractionPrograms 中调用 Seurat 5 的 `layer` 接口，因此两个 mode 必须使用隔离环境：前者固定 Seurat 4.4.0/SeuratObject 4.1.4，后者固定 Seurat 5.5.1。入口拒绝用兼容包装把两种行为混在一个环境。上游 InteractionPrograms 还漏掉 `nest/map2/unnest` 的限定导入；入口只显式附加其 DESCRIPTION 已声明的 tidyr/purrr，不改算法。

输入 RDS 包含有限非负 `expression`、构建 Seurat RNA assay 所需的 `counts` 字段及严格对齐的 `metadata`，其中 sample、donor、condition、cell_type 完整。expression_scale、normalization_definition、input_provenance、resource_version、resource_provenance、parameter_provenance、native_root 和 scriabin_library 必须明确。RNA 测量层为连续值时只有显式设置 `allow_continuous_depth_layer=true` 并给出 `depth_layer_definition` 才能复现作者对象；此时列和只称 RNA measurement total，禁止写成 UMI depth。每个样本分别执行，未知供体明确记录。基因或细胞身份含等号会破坏上游 LR/细胞对拼接，入口失败，不猜测拆分。

`ccim_graph` 原生 `GenerateCCIM` 对每条 LR 和每个发送–接收细胞对计算 `sqrt(sender ligand expression × receiver receptor expression)`，没有 P 值。入口保留全部实测细胞对，超过 `max_ccim_cell_pairs` 时失败，不抽样后冒充全量；群级 LR 表是在实测细胞对内取均值。`BuildPriorInteraction` 对每个细胞对把资源中全部保留 LR 的几何表达等权求和。入口将群内细胞对总和输出为可加网络，并另列受群大小影响较小的群内均值。作者深度校正以两个细胞 RNA 测量列和之和作一元线性回归，交付残差群均值；残差可为负，不是概率或抑制证据。

`programs` 原生流程按细胞类型比例迭代抽取细胞，形成 LR×细胞对 CCIM，以 `0.5 + 0.5 × corSparse` 得到 LR 相似度，再经 soft power、TOM、完全聚类和动态树切割产生交互程序。任一细胞类型少于 `min_cells_per_type_iteration` 时上游 `sample_n` 会越界；入口明确失败，不改成有放回抽样。输出保留程序成员及 kWithin。`InteractionProgramSignificance` 对同大小随机 LR 集合重复单侧 Wilcoxon；其名为 pval 的值实际是这些 raw P 大于 0.05 的比例。该比例越低只表示作者随机集合规则下较稳定，不能称一次假设检验 P 值，也没有多重校正、供体模型或条件比较。`ScoreInteractionPrograms` 分别调用 Seurat AddModuleScore；`IPCellTypeSummary` 把发送群配体程序均值与接收群受体程序均值相加并只保留正值。该值不是 LR 通量、结合概率或因果效应。

自动输出覆盖 CCIM 分页 LR 点图、支持计数网络/弦图/论文概览、prior graph 总和网络/弦图、群均值和深度残差热图，以及程序成员分层图/层级图/弦图、配体和受体程序群得分、正程序群对矩阵与随机检验比例；每张图均交付 PDF/SVG、600 dpi PNG、作图数据和图注。仓库外真实验收使用作者 `panc8.SeuratData 3.0.2` 的全部 638 个 fluidigmc1 细胞。CCIM 验收覆盖 404 条非零 LR 和 98,040 个 beta→非 beta 细胞对；独立公式重算全部 638×638 prior graph、深度残差、全部群汇总及 128 个确定性抽取细胞对，最大相对或常规绝对误差低于 1.6e-12。程序验收独立重放两轮比例抽样及完整 442×442 LR 相似度矩阵，误差为 0，并核验 211 条成员、18 个程序比例、468 个群得分和 1,893 个正群对分数。作者数据没有可核实的独立供体字段，且其 RNA counts 槽为连续值；这项验收只证明原生算法、适配器和 33 张图的复现链路，不能作为疾病特异或供体层统计证据。


## Giotto：表达置换、空间邻域抽样与配对秩

调用 `scripts/run_giotto.R config.json new_output`。固定论文时期的 `RubD/Giotto` tag v1.1.0、提交 `eaccf736f431bdf80633bd05feb975c5b276b7df`、Giotto 1.1.0 和 MIT 许可；入口校验 DESCRIPTION、LICENSE、通讯与绘图源码、作者 `mouse_ligand_receptors.txt` 以及对象构建、归一化、Delaunay 网络、表达通讯、空间通讯和秩合并函数体摘要。当前适配器支持人或鼠单基因 LR；资源必须给出物种列、固定版本、来源和摘要，不把缺失亚基当作完整复合体。

输入 RDS 含有限非负整数 `counts`、严格对齐的 `metadata` 和 `coordinates`。metadata 必含 sample、donor、condition、cell_type；coordinates 为二维或三维实测位置，并声明 `um`、`pixel` 或 `native` 单位及来源。原生单位没有物理比例时必须设置 `physical_scale_unavailable=true`，不得把坐标差解释为微米。每个样本独立运行：只保留达到 `min_cells` 的实测群，调用 `normalizeGiotto` 后建立 Delaunay 网络，再执行两个原生分支。Giotto 1.1.0 在平均表达列名上全局删除字符串 `cluster_`，所以入口拒绝含该字面量的细胞类型，防止身份静默损坏。

`exprCellCellcom` 把发送群配体平均归一化表达与接收群受体平均归一化表达相加，再置换全部细胞的群标签。`spatCellCellcom` 对每个无序细胞类型组合取 Delaunay 相邻细胞，保留实际相邻子集的群组成，再从全样本相同细胞类型中抽取同等数量细胞。两者都输出 `LR_expr`、随机均值、平均差、差值标准差、z 值、带 0.1 加数的 log2fc、原生 P、调整 P 和 `PI=log2fc×−log10(adjusted P)`。`adjust_target=genes` 在每个有向细胞对内校正 LR，`adjust_target=cells` 在每次无序细胞对调用内按 LR 校正方向；原生空间 PI 的零 P 显示下限也在每次细胞对调用内确定。入口不把这些范围改成全局检验。

原生 P 不是标准双尾置换 P。算法把每次“观测减随机”的差值取正负号、求净比例，再按方向转换；零差不计数。固定源码直接比较浮点数且没有并列容差，因此数学上相等的表达和也可能产生约 `1e-16` 的正残差并计为正向置换。仓库外真实 seqFISH 验收中，使用 `1e-12` 仅作诊断的并列容差会改变 1,075 个空间候选中的 93 个原生 P，最大变化 0.44；原生输出仍逐值保留，但这项敏感性必须进入图注和解释，不能只凭原生 P/q 宣称空间特异通讯。细胞、邻域边和置换都不是独立供体；该方法没有供体条件模型。

`combCCcom` 在每条 LR 内分别对 expression PI 和 spatial PI 的细胞对降序排名。配套绘图除两套 LR 气泡/网络/弦图和论文概览外，自动生成真实细胞类型空间图、无向 Delaunay 邻域图、配对秩计数图和以 spatial rank 1 为目标的表达秩恢复曲线。每张图均交付 PDF、SVG、600 dpi PNG、作图数据、选择记录和图注；稀疏页保留真实空白，不补零或放宽阈值。

真实验收使用 Giotto v1.1.0 自带的 seqFISH field：1,774 个实测基因、118 个细胞、25 对测得的作者 LR。七个标签由作者文档明确支持的 K-means 分支在前五个 Giotto PC 上得到，只能称 author-workflow groups，不能称已人工注释细胞类型。100 次集成置换得到 1,225 行表达结果和 1,075 行空间结果。独立矩阵回放对表达全部统计量及空间连续量的最大误差为 `1.41e-14`；因上述机器精度并列问题，空间 P/q/PI 另以固定低层 Giotto 均值和子集函数重放，P/q 误差为 0、PI 最大误差 `8.89e-16`。全部导出最大误差 `8.89e-16`，36 张图均完成技术检查和逐图视觉审阅。该验收证明算法、适配器和绘图链路可复现，不提供疾病、条件或供体层结论；正式分析建议提高置换次数并报告并列敏感性。


## stLearn：空间转录组 LR 热点与细胞类型行列关联

调用 `scripts/run_stlearn.py config.json new_output`。入口固定 `BiomedicalMachineLearning/stLearn` tag `V1.4.1`、提交 `03e38844a599ef4f3df8235e3f57bd74a9e96fcf` 和 BSD-3-Clause 许可，逐文件校验 CCI 的 `analysis.py`、`base.py`、`permutation.py`、`perm_utils.py`、`het.py`、`het_helpers.py`、`go.py` 及两个内置 ConnectomeDB2020 资源摘要；只加载该固定 CCI 子包，避免把图像、深度学习或 SpatialData 的无关依赖当作算法要求。输入 h5ad 必须含严格对齐的 sample、donor、condition、cell_type 与有限二维真实空间坐标，并声明坐标单位、坐标来源、邻域距离和距离依据。表达只接受明确的 `normalized` 或 `log_normalized` 非负值及归一化定义；当前 V1.4.1 教程推荐总量归一化后不做 log1p，旧作者发布对象的兼容复核则必须单独记录其 log1p 来源。LR 可来自固定的 `connectomeDB2020_lit`、`connectomeDB2020_put` 或显式列表；细胞身份可用离散标签，也可用与位置逐行严格对齐的非负混合比例。

每个样本独立调用原生 `analysis.run`。对 LR=(L,R)，每个位置的分数将本位置 L 乘以邻域 R 均值与本位置 R 乘以邻域 L 均值后取平均，再乘以原生异质性权重；低于表达阈值的端点不贡献。背景由表达分布匹配的随机基因对形成，经验 P 为背景分数大于等于观测分数的比例，没有加一伪计数；随后在每个位置内，仅对该位置存在正分数的受检 LR 做 BH。这个校正范围不是全切片或全数据集。入口保留完整 LR 汇总、每位置分数/P/q、显著分数与可选背景，不根据目标图反向放宽阈值。

随后对通过 spot 支持阈值的 LR 调用原生 `analysis.run_cci`。原生行列矩阵统计细胞信息置换后的空间边数，经验 `P=count(permuted count≥observed count)/n_perms`，没有伪计数，也没有任何多重检验校正。对离散细胞标签，原生算法整体置换位置标签；对混合比例则逐细胞类型列分别置换。一个空间边只要存在 L→R 或 R→L 任一表达方向就可进入矩阵，因此矩阵行列代表热点焦点位置与邻域位置的角色，不解析分子发送者和接收者；网络、弦图和热图均按“行｜列”呈现。原生显著矩阵用 `P≤cutoff` 保留计数，但汇总计数使用 `P<cutoff`，两者的边界差异必须照实记录。

V1.4.1 的 CCI 置换在 Numba `prange` 内调用随机抽样。真实验收证明即使固定 seed 且单线程，重复调用仍会得到不同 CCI P；12 个 LR、100 次 CCI 置换的快速验收中，单个矩阵单元的 P 跨重复最大范围为 0.21，14 个有原始边的单元在支持与不支持之间变化。生产入口因此默认运行至少三轮原生 CCI 置换，保留首轮 P/显著计数、跨轮 P 最小值/最大值和 `P≤cci_alpha` 的重复支持率；最终 `supported` 同时要求首轮原生显著计数大于零且重复支持率达到声明阈值。稳定率是上游随机实现的敏感性诊断，不是校正后概率，也不能恢复单次置换的严格可复现性。正式分析建议至少 10,000 对 LR 背景和 1,000 次 CCI 置换，并报告重复次数、支持率阈值和不稳定单元。

自动图件包括 LR 支持汇总、spot LR 分数与 q 值地图、由固定原生 `het.get_edges` 得到的分子 L→R 空间箭头、细胞类型位置图、逐 LR 行列气泡图、原始/稳定支持 CCI 热图、无分子方向箭头的行列网络和弦图、置换稳定性矩阵及论文概览；每张图交付 PDF、SVG、600 dpi PNG、源表、选择记录和图注。分子箭头只用于具体 spot 的 L→R 表达边，不能传播到细胞类型 CCI 矩阵。

仓库外真实验收使用 10x Genomics `V1_Breast_Cancer_Block_A_Section_1` 的 3,798 个位置、22,240 个过滤后基因和作者教程提供的 9 类细胞比例。当前教程模式的邻域集合与原生逐项一致；独立重算 LR 分数最大绝对误差 `1.2438e-05`，spot 经验 P、逐位置 BH q、CCI 原始计数和跨 LR 汇总误差均为 0。12 个 LR 的快速运行生成并目视复核 31 张图，全内置数据库运行检验 1,548 个有效 LR 并生成 41 张图。作者另行发布的 LR 对象可核实使用 hires pixel 距离 100 和总量归一化后 log1p，而当前 V1.4.1 教程给出的默认距离约 29.29 且明确不做 log1p；按旧对象状态回放时，1,753 个 LR 名称、邻域和 LR 分数可复现至最大误差 `1.4634e-06`，但 spot P/q 最大差分别为 0.51/0.7464，进入 CCI 的 LR 数为 1 对 766。旧对象不能作为当前显著性调用的金标准。该验收只证明原生算法、适配器、稳定性诊断和绘图链路，不提供乳腺癌特异性、条件差异或供体层推断。


## SCOTIA：空间簇约束的非平衡最优传输与双随机置换

调用 `scripts/run_scotia.py config.json new_output`。入口固定 `Caochris/SCOTIA` 无 tag 的提交 `5c5feef08c1bb0d68e654b2f436be17cef2b36e7`、包版本 1.0.0 和仓库声明的 MIT 许可，逐文件核验 `dbscan.py`、`ot.py`、`permutation.py`、`run_scotia.py`、`visualization.py`、包入口、setup 与许可摘要。数值环境固定 Python 3.11、NumPy 1.26.4、POT 0.9.6.post1、scikit-learn 1.5.2 和 forest-fire-clustering 0.0.25；上游使用已从 NumPy 2 移除的 `np.Inf`，不能在不记录改写的情况下换到 NumPy 2。输入必须是单细胞分辨率 h5ad 整数 counts、严格对齐的 sample/donor/condition/cell_type/FOV 与真实二维微米坐标，并提供固定版本、来源和物种一致的两列 LR。SCOTIA 原生实现会稠密化矩阵，入口按声明的最大元素数提前失败，避免内存耗尽。

表达预处理逐项复现作者一键流程：在完整输入上对每个基因只取正值的 99% 分位数，每个细胞表达除以该分位数，再把大于 1 的值截断为 1。端点基因缺失或没有正表达的 LR 单独输出，不以 0 表达补成已检验。每个 sample/FOV 独立处理；每个细胞类型调用原生 `dbscan_ff_cell`，在候选 eps 上比较 DBSCAN 与 forest-fire 聚类一致性，只保留达到最小细胞数的合格簇。默认 eps 区间按作者 `lr_score` 的 FOV 尺寸公式产生；过小 FOV 没有搜索区间时明确失败，不能静默跳过。`sel_pot_inter_cluster_pairs` 只保留至少存在一对细胞在距离阈值内的不同空间簇组合，同簇自配对和未入簇细胞不进入 OT。

对每条 LR，原生 `source_target_ot` 先移除零距离、非有限或超过距离阈值的细胞对，把距离除以阈值，再除以源细胞 ligand 与靶细胞 receptor 表达外积形成代价。算法增加质量为 1 的 dummy 源/靶、使用 `ot.sinkhorn_unbalanced` 求非平衡传输，以 dummy–dummy 传输量归一化，并只保留 likelihood 大于阈值的有向细胞边。`post_ot` 对每个 LR/有向细胞类型对要求至少 8 条保留细胞边，先对每个源细胞取最大 likelihood，再对源细胞求均值；作者多 FOV 教程把同一候选的 FOV 均值相加。该 score 是模型 likelihood，不是分子通量、概率或跨方法可比强度。

当前上游 `lr_score` 一键函数只运行聚类和 OT，不运行 README 另列的置换步骤。适配器按作者 notebook 衔接原生 `permutation_test`：每轮同时无放回打乱表达行并在 x/y 上加入指定整数范围的随机位移，空间簇组合资格保持观测数据不变，再重新计算距离、OT 和 post_ot。教程经验 `P=count(null score>observed score)/n_permutations` 使用严格大于、没有加一伪计数；某轮候选因少于 8 条边而缺失时相当于 null score 0。入口保留原始 P，并追加同一样本、同一有向细胞类型对内跨原生合格 LR 的 BH q；由 raw P 或该 q 决定 `supported` 必须写入配置和图注。细胞和 FOV 置换不是独立供体统计，不能用于条件效应、协变量或配对设计。

自动图件包括输入细胞类型空间图、原生聚类与未入簇细胞图、各细胞类型所选 eps、输入/入簇细胞数、完整 LR 气泡图、支持计数与 likelihood 网络/弦图、论文概览、观测值与 null 中位数/95% 分位数、逐轮 null 热图，以及按支持/q/P/score 选择的前三个 LR–细胞类型组合的细胞级有向 OT 空间边。每图交付 PDF、SVG、600 dpi PNG、源表、选择记录和图注；稀疏或局部集中的箭头保留真实分布，不通过抽取别处细胞制造全图覆盖。

仓库外真实验收使用作者提交中 `merfish_liver_example.h5ad`：301 个真实细胞、140 个基因、1 个 FOV、8 类细胞和 22 对作者 LR。原生聚类保留 3 个簇、235 个细胞，得到 1,483 条细胞级 OT 边和 47 个 post_ot 候选；20 轮作者示例置换后，样本/有向细胞类型对内 BH 支持 9 个候选。与作者一键函数的 1,483 条边身份完全一致，likelihood 最大绝对差 `3.08e-08`；独立按“每源细胞最大值再求均值”重算全部候选的最大误差 `9.03e-17`，随机坐标和表达索引逐项一致，全部逐轮 null 最大误差 `9.72e-17`，P 误差 0、BH q 最大误差 `4.17e-17`。20 张图通过技术检查并逐图审阅。作者示例只有一个 sample，没有可核实独立 donor；20 次置换只能达到 0.05 的 P 分辨率，正式分析应增加置换次数并报告分辨率。该验收证明原生算法、适配器和绘图链路，不提供疾病特异或供体层结论。


## SpaCCI：混合 spot 的全局、区域与局部通讯

调用 `scripts/run_spacci.R config.json new_output`。入口固定 `LitingKu/SpaCCI@87ce16eb75a901440f4744594b7eae247cd6fead`、包版本 1.0.3、无上游 tag 和 DESCRIPTION 声明的 GPL (>=2)；逐文件核验包描述、NAMESPACE、数据库、global/regional/local 建模源码、可视化源码与 C++ 置换实现，同时核验已安装关键 R 函数体。上游 C++ 通过 `package:nnls` 查找 `nnls`，但包加载不保证该搜索路径存在；适配器显式附加已核验的 nnls 1.6，不改写算法。

输入 RDS 含有限非负的归一化 `expression`、严格对齐的 spot 级 `metadata`、二维 `coordinates` 和 `cell_proportions`。metadata 必含 sample、donor、condition、cell_type；后者用于统一来源和设计记录，SpaCCI 实际细胞类型以 `cell_proportions` 的列为准。比例必须有限、非负、每个 spot 总和在声明容差内接近 1；入口不自动重标准化。坐标声明 um、pixel 或 native 单位与来源；无物理比例时不得解释为微米。原生流程把表达转为稠密矩阵，入口在超过 `maximum_dense_elements` 时先失败。

LR 可选固定提交内置的 CellChat、CellPhoneDB、Cellinker、ICELLNET 或 ConnectomeDB，每个资源均校验 SHA256。CellPhoneDB、ICELLNET 和 ConnectomeDB 的固定分支只接受人类，不自动作同源转换。原生 `LR_database` 要求复合物全部组件基因存在，并根据在 spot 中正表达的比例过滤。可用 `lr_interactions` 锁定有先验的候选；局部分析的 `local_lr_pairs` 必须来自课题、实验或事先声明的范围，不得看完热点图后换分子。

每个样本独立执行。对每个配体或受体组件，SpaCCI 以 spot 细胞比例为设计矩阵作 NNLS，复合物组件系数取几何均值，再计算发送与接收细胞类型的外积 `t`。报告强度是 `t/(0.5+t)` 乘两端平均细胞比例的外积。global 和 regional 另建立 15 近邻比例交叉矩阵，但该矩阵只判断细胞对是否保留，不乘入 strength；因此 strength 不是空间边通量、配体结合概率或分子数。

global 固定做 500 次细胞比例行与细胞类型列置换。regional 固定做 1,000 次，每次从所选区域外无放回抽取同样多的 spot，所以区域至少需 16 个 spot 且不能超过样本一半。local 先为每个中心估计随机 5 个 spot 的平均最近邻距离，再以 `radius×单位距离+0.1` 定义邻域；默认 radius=2.5 只有在具体 Visium 标定有依据时才能说约 200–250 μm。local 置换次数为 `floor(n_spots/500)×100`，限制在 1–1,000；少于 500 个 spot 只有 1 次，论文级入口拒绝执行。

三个分支的原生 `P=count(null strength>observed strength)/nboot`，使用严格大于、无伪计数。SpaCCI 1.0.3 每次先计算 `p.adjust(..., "BH")`，下一行却把 `adjusted.PValue` 重新赋成原始 P，因此作者自带热图和弦图的 `alpha=0.05` 实际是名义 P 筛选。适配器保留 `native_adjusted_p_value`，另列每 LR 内 BH 和每样本/尺度全候选 BH，默认以后者判定支持。这是对已知上游缺陷的透明后处理，不修改原生对象或原始 P。

自动结果包交付 global/regional/local 完整候选、原生对象、中心级局部表、邻域大小、运行记录和源码/资源摘要。一次运行后立即生成分页 LR 气泡图、支持计数热图、有向网络、弦图、四面板论文概览、区域成员图、局部原生强度图和 BH 证据图。局部网络的 score 是支持中心数；中心级 P/q 另表完整保留。未进入合格邻域或原生未保留的空间位置显示为灰色，不补成零通讯；P/q=0 的 `-log10` 只在作图时按置换分辨率截断，源表不改写。

仓库外真实验收使用固定包内 `Tutorial_example_data.rda`：作者文档把它声明为 10x Visium 胰腺教程数据，并在数据页链接 GSE233254/GSE233293；对象本身未编码患者身份，验收不猜测。对象含 782 个 spot、16 个教程基因、6 类细胞比例和 133 个作者 interest-region spot。固定 3 对 LR 的 global/regional 与 EDN2–EDNRA local 验收得到 70、6 和 660 条原生中心级候选；默认全候选 BH 支持分别为 5、4 和 275 条，而 global 原始 P 支持为 9 条。独立 NNLS/几何均值强度公式误差为 0，独立重放全部 500 次 global 置换的 P 误差为 0，global/regional/local 导出最大误差均低于 `2.8e-17`；与作者内置 global 结果重叠的 70 条观测强度完全一致。25 张图通过技术检查和逐图视觉审阅。该验收对象只有一个未分层样本且基因被教程缩减，只能证明算法、缺陷防护、结果包和绘图链路，不能验收数据集特异性或供体条件推断。


## SVCA：空间方差分解与细胞邻域状态效应

调用 `scripts/run_svca.py --config config.json --out new_output`。入口固定 `damienArnol/svca@1454c908b360a6118c2384c675aecdb9de7fca2e`、SVCA 0.0.1、仓库内 limix 0.8.5 和 Apache-2.0 许可，逐文件校验模型、输入输出、长度网格、单特征/交叉验证入口和作者绘图源码摘要，并核对已安装核心函数源码。隔离环境固定 Python 3.10、NumPy 1.23.5、SciPy 1.10.1、pandas 1.5.3、scikit-learn 1.3.2、h5py 3.8.0 和 anndata 0.10.9；较新的 NumPy/解释器不能视为等价环境。

`Cell-cell interactions` 在这里表示“目标特征的变异有多少符合附近细胞分子状态相似性”的模型分量。它不识别配体、受体、复合物、发送/接收细胞类型，不估计局部细胞贡献，也不提供 P/FDR。适配器因此不会用表达阈值补造 LR 边、用细胞标签拼出方向、或把高 interactions 份额写成特定分子机制。跨样本图保留每个图像估计；供体展示先在供体内对多图像取算术均值，但不自动计算条件 P 值。数据集特异性需要设计匹配的独立供体、同一检测面板/预处理和预先声明的条件模型，不能直接比较不同平台的归一化份额。

配置 `cross_validation_folds=3..10` 时，入口按作者固定种子 0 的细胞随机折叠，依次拟合 intrinsic、增加 environmental、再增加 interactions 的三个嵌套模型，并汇总全部折外 truth/prediction 的原始 R²。作者 R 脚本会把负 R² 截成 0；适配器源表和图均保留负值，并叠加样本–特征点和标准差。上游 Python 3 交叉验证入口还会对 `range` 调用 `remove`；适配器只将其实现为作者明确意图的“除目标外特征列表”，其余 Model1、固定折叠和预测公式不改写。

仓库外真实验收使用作者随仓提供的 `SVCA/examples/IMC_example_local/Cy1x7`：296 个真实分割细胞、26 个 IMC 蛋白和作者保存的 26 个方差结果。固定环境直接重跑 CD20 后，四个未归一化分量与作者文件按分量名对齐，最大绝对误差为 `7.95e-9`；行归一化方差份额最大误差为 `6.66e-9`，保存的原生状态与导出分量误差低于 `9.5e-17`。完整 296 细胞适配器生成 9 张正式图，技术质检和逐图视觉审查均通过。另用确定性前 60 个真实细胞验收三折嵌套交叉验证：180 行折外预测覆盖每个细胞和三个模型一次，独立回算 R² 与导出值完全一致，交互模型的负 R² `-0.1368808625` 在源表与图中均保留。该对象只有一个图像且未提供供体/条件设计，所以这些验收只支持原生数值、适配器、阴性结果保留和绘图链正确，不支持跨数据集生物特异性结论。数据、环境、日志、结果和审计记录全部保存在 Git 仓库外。


## NCEM：固定半径细胞邻域对接收细胞分子状态的影响

调用 `scripts/run_ncem.py --config config.json --out new_output`。入口固定 `theislab/ncem@216fd576d1d1842234ceec300435a1dafcdf8b0c`、tag/package 0.1.5 与 BSD-3-Clause 许可，并逐文件校验 linear model、design matrix、OLS、Wald test、工具常量和作者类型耦合绘图源码摘要。隔离环境固定 Python 3.10.20、NumPy 1.24.4、SciPy 1.9.1、pandas 1.5.3、anndata 0.8.0、patsy 0.5.6、diffxpy 0.7.4 和 h5py 3.8.0。NCEM 顶层导入会为线性 GLM 强制加载 TensorFlow；入口以受控包命名空间载入并原样执行已核验的 `ncem.tl.fit.backend.linear_model`，没有复制或改写拟合函数，也不声称运行 neural NCEM。

输入为逐细胞空间 h5ad。每个细胞必须有唯一身份、sample、donor、condition、显示细胞类型、模型安全且一一对应的细胞类型标签和真实二维坐标；一个 sample 只能对应一个 donor 和 condition。分子矩阵可来自有来源的 normalized、log-normalized 或 transformed continuous 层，所有值必须有限，尺度与预处理完整记录。坐标单位只能为 um、pixel 或 native，并记录来源；半径必须按实验平台或作者教程事先给定。入口用 `cKDTree` 在每个 sample 内分别建立无向半径图，去除对角线，禁止跨图像边；边数、稠密表达和设计矩阵超限时失败，不抽边、不删细胞类型。

标准模式调用原生 `linear_ncem`。对每个接收细胞，邻域设计为半径内各发送类型是否至少出现一次的二元变量；模型把接收细胞类型主项、接收类型×邻域发送类型项和配置中的批次项共同纳入 OLS。每个有向系数因此表示：控制已声明公式后，在某类接收细胞邻域中出现某发送类型时，该接收细胞基因或蛋白的条件均值变化。方向来自模型身份，不是物理扩散方向；系数可以为正、负或零，也不是 LR 分数、结合概率、分子通量或因果效应。

入口保留每个基因/蛋白×接收类型×发送类型的完整原生系数和 Fisher-information 近似 Wald P。NCEM 0.1.5 的 `test_standard` 先把所有 P 展平做全局校正，再以与带标签 P 矩阵不一致的顺序 reshape；真实验收中绝大多数 `native_q_value` 因此与标签错位。适配器不覆盖原生字段：完整导出 `native_q_value`，同时在已标记的完整原生 P 矩阵上按稳定顺序重算一次全局 BH，写为 `q_value` 并仅用它定义 `supported`。任何展示上限或 q 下限只用于颜色和坐标显示，源表 P/q 不改变。

`mode=differential` 调用原生 `differential_ncem`，以 Patsy 参考条件为基线增加 condition×接收类型×邻域发送类型系数，同时仍输出基线邻域系数。每条件少于两个真实供体时拒绝运行；还必须显式设置 `acknowledge_cell_level_differential=true`。这一门槛只防止无复制设计误用，不能修复原生 OLS/Wald 把同一供体大量细胞当作观察值的问题。正式疾病或治疗结论仍需要供体层模型、空间分块或独立队列复现；不能用很小的细胞层 P 值宣称数据集特异机制。

一次运行自动生成：完整系数/P/q 效应与火山图；按支持数选择的接收群有符号系数热图、全局 BH 证据热图和发送类型完整系数向量 Pearson 相关图；全局 BH 支持基因/蛋白数量的有向网络与弦图；供体内平均半径图度数；每个供体选一个细胞最多图像的输入细胞类型空间图。差异模式为基线和条件交互分别生成效应与接收群图。弦宽只表示支持分子特征数，空间图只是输入背景，发送相似性只表示系数向量相关。每图交付 PDF、SVG、600 dpi PNG、作图源表和图注；完整 native h5ad、图度数表、配置、摘要与运行状态同时保存。

仓库外真实验收使用作者 NCEM MIBI 教程对应的 Zenodo 3951613 `scMEP_MIBI_singlecell.csv`：63,747 个未经抽样的分割细胞、58 个图像、4 个供体、2 个条件、8 类细胞和36个蛋白，坐标为原表像素中心，半径使用教程的35 pixel。标准模式半径图有332,512个有向存储项；独立 `cKDTree` 重建边数完全一致，全部边在同一图像且距离不超过35。独立矩阵 OLS 对全部参数最大误差 `2.25e-15`，独立 Wald P 对原生值最大误差 `1.55e-15`，完整2,304行系数/P/对齐BH与结果包误差均不超过 `1.12e-16`；上游 q 标签错位2,281项。标准模式生成33张图并通过技术检查和逐图视觉审查。

同一真实对象另验收 `healthy` 相对 `carcinoma` 的原生差异代码路径：基线与条件交互各2,304个系数；独立 OLS 全参数最大误差 `1.56e-14`，基线和差异 Wald P 最大误差分别为 `4.05e-14` 与 `1.28e-14`，结果包系数/P/q 误差均不超过 `1.12e-16`，33张图技术检查和目视审查通过。该数据每条件仅2个供体，故差异验收只证明原生代码、标签、数值和绘图链正确，不把其 P/q 或图解释成论文可用的疾病特异证据。当前验收与入口范围仅含细胞分辨率 linear/differential NCEM；deconvoluted spot、spline 和 neural 分支仍未接入。全部数据、固定环境、源码快照、失败记录、运行结果和审计文件保存在 Git 仓库外。


## NicheCompass：基因程序约束的空间 niche 与相对通讯潜力

调用 `scripts/run_nichecompass.py --config config.json --out new_output`。入口固定 `Lotfollahi-lab/nichecompass@5bf7d2a09e70bd490c59e978e37f4df30f812994`、release/package 0.3.3 与 BSD-3-Clause 许可，并逐文件校验模型、VGPGAE、trainer、GP mask、分析函数和数据处理源码。隔离环境固定 Python 3.10.20、NicheCompass 0.3.3、PyTorch 2.8.0、PyTorch Geometric 2.8.0.post1、torch-scatter 2.1.2、torch-sparse 0.6.18、NumPy 2.2.6、SciPy 1.15.3、pandas 2.3.3、anndata 0.11.4、Scanpy 1.11.5、scikit-learn 1.7.2、igraph 0.11.9 和 leidenalg 0.10.2。上游顶层导入会加载 OmniPath 并可能触发网络访问；入口要求显式、带 SHA-256 和来源说明的 GP JSON，用空模块阻止这次未声明下载，只执行未改写的原生 GP mask、模型、trainer、summary 和 communication network 函数。

输入 h5ad 必须有唯一细胞/基因名、非负整数 raw counts 层、有限非负通讯表达层、sample/donor/condition/cell_type、与细胞逐行对齐的二维坐标、坐标单位和来源；每个 sample 唯一对应一个 donor/condition。GP JSON 的每个程序必须同时有非空 source/target 基因及逐项类别，基因全部存在于输入且 source/target 在通讯表达层中不能全零。训练 KNN 在每个 sample 内分别建立后对称化，重复坐标、样本细胞不足、跨样本边、矩阵或图超限均失败；不抽细胞、不补基因、不把重叠切片坐标连在一起。当前固定范围为 RNA-only、`gcnconv`、无 addon GP、无 ATAC；所有选择和超参数进入配置及运行签名。

`analysis_tier=publication` 至少要求3个唯一种子和每种子100个请求 epoch，默认关闭 early stopping 以保存完整100点轨迹。每个种子分别训练、保存 model/adata/latent/完整 GP summary/原生 stdout，并导出全部有限 train/validation loss。训练后的原生 `eval_end` 边重建 AUROC、AUPRC、最佳 accuracy/F1 与 source/target RNA MSE 从该种子原生日志严格提取；边指标与 RNA MSE 分图，避免量纲共享掩盖差异。primary seed 在 active-GP latent 上按固定参数运行 Scanpy neighbors、UMAP 和 Leiden；UMAP 只表示模型 latent，空间 niche 另投回真实组织坐标。

完整 GP 输出包括 source/target decoder signed weight、绝对归一化 importance、active 状态和细胞类型平均 latent。通讯展示 GP 必须在配置预声明，或按 primary-seed latent 方差的固定规则选择，同时保留所有程序结果与选择记录。作者 `compute_communication_gp_network` 对每个 GP：用逐基因最大值归一化表达乘 decoder 权重和该 GP latent，分别平均成 source/target score，将负值截为0，在空间 KNN 边上取 source×target，按细胞类型聚合，然后在该 GP 内 min-max 并四舍五入为2位，删除归一化后0边。入口对每个 sample 单独调用该原生函数，分别保存未缩放聚合值和缩放值；不同 GP、sample 或数据集的0–1值没有共同尺度，禁止比较、求和或称为分子流。无正边的 GP 保留逐细胞 score 与排除记录，不补画网络。

跨种子 GP 稳定性先按同名 active GP 对齐，再用两个 seed 的 decoder weight 向量点积符号消除 latent 与 decoder 同时翻转的等价方向，计算全部细胞 Spearman；未经方向对齐的相关同时保存在源表。任一 seed inactive 保持缺失，负相关不取绝对值。每个 seed 还在同一参数下独立做 Leiden，报告两两 adjusted Rand index。两类稳定性都只是优化/表示重复性，不是生物学复现或显著性。NicheCompass 本分支不产生 LR 假设 P/FDR、供体层条件效应、配体响应检验或因果链。

一次运行自动交付：训练曲线、边验证指标、RNA 重建指标、latent UMAP、物理空间 niche、细胞类型×GP latent 热图、GP source/target decoder weight 热图、GP 和 niche 种子稳定性热图、每个选定 GP 的 source/target potential 空间图，以及每个有正边 GP/样本的层级网络与弦图。每张正式图均有独立 PDF、SVG、600 dpi PNG、源表、图注和交付摘要；网络极稀疏时原样显示，不用表达量或其他方法补边。

仓库外真实验收使用 SCOTIA 作者仓库的 `example/merfish_liver_example.h5ad` 与 `lr_gene.list`：301个真实胎肝 MERFISH 细胞、140个基因、8个细胞类型和1个标为 `mut` 的样本；LR 表去除一条完全重复的 Dll1–Notch2 后得到21个 assay-matched GP，不增加外部分子。3个固定种子各完成100 epoch，21个 GP 全部保留且 active；边重建 AUROC 为0.8609–0.8764，AUPRC 为0.7977–0.8526。独立重建4近邻训练图得到1,556个有向存储项，与保存对象逐项一致且跨样本边为0；重载 seed 0 模型后 posterior mean latent 与导出301×21矩阵最大误差 `4.45e-16`。对6个展示 GP，独立重算逐细胞 source/target score 最大误差为0，完整未缩放细胞类型矩阵及4个实际产生正边 GP 的缩放网络最大误差均为 `1.17e-10`；另外2个展示 GP 没有上游阈值后的正边，保留完整零矩阵而未补造网络。全部40张图通过三格式、源数据、图注、技术检查和逐图视觉审查。

该真实对象只有一个样本且没有可核实的独立供体，21个程序也只是作者示例面板，而非全量 OmniPath/NicheNet/MEBOCOST。验收因此只证明固定原生代码、资源身份、训练、可重载性、公式、负结果保留和自动绘图链。方向对齐后63个 GP 种子相关中仍有19个为负，Leiden niche ARI 只有0.431–0.613；这些结果原样交付，说明该小数据的部分表示不稳定，不能包装为论文级生物发现。正式数据集特异结论需要多供体设计、预声明 GP 资源、相同平台/预处理、独立队列和供体层比较。数据、资源、源码、环境、失败记录、结果及数值/视觉审计均保存在 Git 仓库外。

每个 LR 的通信事件（CE）为配体表达、Gaussian 距离因子和受体表达的乘积，并按该视图均值归一化，再由原生表达匹配背景基因过滤边。张量方向是 receiver×sender；导出时明确转换为 source→target。每个保留 LR 自动计算发送、接收、总度数和特征向量中心性；细胞类型 CE 矩阵用作者函数聚合、去除对角线并在该矩阵内独立 min-max。HoloNet 的接触信号默认用全局最短非零距离的1.05倍定义局部邻接；对不规则坐标，入口先报告覆盖比例，低于预声明阈值时失败，除非配置明确关闭配体距离类别。关闭后所有 LR 使用同一个 Gaussian 距离核，结论必须随结果保留。

一次运行自动生成：距离核；LR 检测率、过滤边数和 CE 总量质控；重点 LR 的四种中心性空间图、全部非零细胞边、细胞类型 CE 网络；LR 中心性 UMAP、原生层次树和各簇空间热点；逐目标的训练轨迹、全切片与留出细胞基线对照、attention 热图与稳定性、实测/预测空间图、delta-E 和重点 FCE 网络；主目标全部单 LR 视图表现，以及预声明 pathway 的目标、LR×目标和来源细胞类型面板。每张正式图必须有 PDF、SVG、600 dpi PNG、作图源表、完整图注和技术检查；完整稠密张量、模型、拆分及重复日志留在原生结果目录。

原生 CE 边过滤不返回逐边或逐 LR P/q，模型的随机细胞留出也不消除空间自相关。独立数据集的 CE/FCE 与 attention 含各自归一化，不能直接比较数值或仅凭排序宣称数据集特异分子。疾病、治疗或供体特异性需要预声明相同 LR 资源、同一测量平台和表达处理、多个独立供体/切片、空间分块或供体层比较及独立队列复现。单切片运行只支持探索通信网络与目标表达的模型关联。

仓库外真实验收使用 SCOTIA 作者示例的胎肝 MERFISH h5ad：301个真实细胞、140个靶向基因、8种细胞类型、一个标为 `mut` 的样本和原生二维坐标。LR 资源由 HoloNet 作者随仓 CellChat mouse 三张数据库表按固定脚本抽取1,071个唯一单基因 pairwise 项；其中18对通过本面板5%严格表达比例过滤，背景过滤保留58,780条非零细胞边。Mki67、Vcam1、Col4a1 各完成50次 HoloNet 和50次 cell-type-only 初始化，每次300 epoch，保存300个最优模型和90,000行逐 epoch 记录。HoloNet 相对基线的全切片 Pearson 增量依次为0.1111、0.1486、0.2569，固定测试细胞增量只有0.0325、0.0332、0.0562；后者仍受同切片空间依赖影响，不能称为外部验证。

调用 `scripts/run_spacia.py --config config.json --out new_output`。入口固定 `yunguan-wang/Spacia@11809bbe38e9107ab2b4444466958fdf7ab1e369` 与 BSD-3-Clause 许可，并在运行前逐文件核验主入口、R 任务、C++ 模型、MIL wrapper、MCMC 与作者诊断脚本的 SHA-256。隔离环境固定 Python 3.10.21、NumPy 1.26.4、pandas 2.0.3、SciPy 1.10.1、scikit-learn 1.3.0、Matplotlib 3.7.2、anndata 0.10.8、h5py 3.11.0，以及 R 4.5.3、Rcpp 1.1.2、RcppArmadillo 15.6.0.1、RcppProgress 0.4.2、rjson 0.2.23、coda 0.19.4.1 和 ggmcmc 1.5.1.2。入口不更新包、不下载资源，也不把修改过的第三方源码写入仓库。

输入为一个细胞分辨率空间 h5ad，每次只允许一个切片/样本。细胞、基因、细胞类型和二维坐标必须完整、唯一、有限且逐行对齐；坐标重复时先核查分割身份。表达接受原始整数 counts 或已经声明来源的 `log1p_cpm`；counts 固定按细胞 library size 归一化至配置总量后 `log1p`。发送和接收细胞类型、signal 和 response 特征、距离阈值、坐标单位及来源必须明确。特征可以全部是单基因，也可以全部是每组至少两个基因的显式基因集，不能混用。相关基因聚合默认关闭；启用时只能用于单基因模式，并明确 `simple` 或 `weighted`，因为数据驱动扩展会改变特征身份和跨数据集可比性。同一发送和接收群会把自身细胞作为距离0候选，只有显式 `allow_self_pairs=true` 的自分泌问题才允许。

每个满足最低邻居数的接收细胞构成一个 bag，距离阈值内的声明发送细胞构成 instances。入口在拟合前检查接收/发送细胞数、合格 bag 数、候选边总数和 `number_bags`；如果上游将因 `number_bags` 较小而随机抽样，默认失败，只有显式 `allow_bag_subsampling=true` 才继续，并在原生记录中写明抽样前后的规模。输入细胞 ID 会映射为稳定的不透明字符串，避免上游对纯数字 ID 执行字符串拼接时报错，同时保存双向身份表。响应表达阈值只接受严格位于0和1之间的 quantile 或 `auto`。`analysis_tier=publication` 至少要求作者默认的50,000次总迭代、25,000次 warmup、10倍 thinning 和3条链；每条链第一个存储初值独立删除，完整原始链保留。

一次运行自动交付：全体细胞类型空间底图；每个实际建模 receiver bag 的发送细胞覆盖；逐 response 全部候选 sender→receiver primary-instance 源表、确定性的前100边展示和 receiver hotspot；全部 response×signal 有符号 beta、2.5%–97.5% posterior quantiles 和 posterior sign probability；逐 response 距离系数 `b.2` 的 posterior forest、`P(b.2<0)`、三链 trace；0.1–0.9 primary-instance Bayesian FDR；全部 beta 的 PSRF。每张图均由语义结果表自动生成 PDF、SVG、600 dpi PNG、作图 TSV 和图注。primary-instance probability 对 response 特异，却在同一 response 模型的 signal 特征之间共享，不能标成某个 ligand 或 signal 的细胞边概率；`b.2` 使用候选 bag 内归一化距离，是依赖阈值的无量纲量。

固定上游审计发现四项需要显式处理的问题。其一，作者代码调用 NumPy 2 已删除的 `np.asfarray`，故环境固定 NumPy 1.26.4。其二，作者测试脚本没有传播子进程失败，不能仅凭测试入口退出码判断成功；本入口同时检查结果文件、日志完成标记、维度和取值域。其三，纯数字细胞 ID 会触发 pandas 字符串拼接错误，故采用可逆不透明 ID。其四，原生每条链存储2,501行，其中首行为 initializer，但作者 Python 汇总按2,500行边界删除 `[0,2500,5000]`，正确边界应为 `[0,2501,5002]`。因此本入口从每条原始链独立删除 initializer 后重算 posterior 汇总；作者 P/q 还把 posterior draws 当作观察值，现只保留在原生文件中，不进入语义表、图或支持判断。作者 FDR 在零个 instance 超过阈值时把未定义值写成1；入口只在原始 pip 确认选择数为0时恢复为缺失，图线在该阈值停止，不画成 FDR=1。

仓库外真实验收使用 SCOTIA 作者示例胎肝 MERFISH h5ad：301个细胞、140个靶向基因、8种细胞类型、一个 `mut` 切片和原生二维坐标。固定问题为30个 SEC 发送细胞至66个 Erythroidpro 接收细胞，signal 为 Jag1、Wnt4、Bmp5，response 为 Notch2、Fzd5、Vcam1，距离阈值60 native units，最低 bag size 为2，不启用相关聚合。正式 MCMC 为3条链×50,000/25,000/10，实际建模66个 bag，每个 response 有731个候选细胞对。15张正式图全部通过技术检查与逐图视觉审阅；没有裁切、重叠、虚构空图或 SVG 内嵌位图，全部保留可编辑矢量、600 dpi PNG、源表和图注。

独立数值审计通过159项检查。正确分链后 beta 均值和 quantile 最大绝对误差分别为 `7.63e-17` 和 `9.37e-17`，距离汇总最大误差 `5.55e-17`，FDR、PSRF、pip、hotspot 和 trace 均逐项一致。九个 beta 中只有 Fzd5←Wnt4 的95% posterior interval不跨0，均值0.3118、区间 `[0.0435,0.5897]`；另外八项全部保留为跨0结果。Notch2、Fzd5、Vcam1 的距离均值分别为0.1203、0.1735、0.4368，三个区间均跨0。全部 beta PSRF 位于约0.9998–1.0050；FDR 中无选择对象的高阈值保持缺失。该验收只有一个切片、没有供体复制与物理尺度，证明的是固定原生执行、独立数值重算、自动图形交付和阴性结果保留，不能证明条件/疾病/数据集特异性、配体结合或因果机制。跨数据集问题必须预声明相同细胞身份映射、相同 signal/response 特征、表达处理和物理距离规则，按独立供体/切片分别拟合，再在供体层比较效应和复现方向，不能把各自筛出的不同分子直接并表排名。


## CellNEST：空间图注意力、rank-product 与两跳 relay

调用 `scripts/run_cellnest.py --config config.json --out new_output`。入口固定 `schwartzlab-methods/CellNEST@2fd4f875ec2916ce51f674342aec1f59596c79ed`、GPL-3.0 许可和论文 `10.1038/s41592-025-02721-3`，运行前逐文件核验预处理、GAT、训练、postprocess、relay 及 PPI/GRN 先验脚本的 SHA-256。隔离环境固定 Python 3.10、NumPy 1.26.4、pandas 2.2.1、SciPy 1.12.0、scikit-learn 1.4.1.post1、anndata 0.10.6、h5py 3.10.0、Scanpy 1.9.8、qnorm 0.8.1、PyTorch 1.13.1、PyTorch Geometric 2.5.2、Matplotlib 3.8.3、Altair 5.2.0 与 NetworkX 3.2.1。macOS ARM 无法为 PyTorch 1.13.1 构建上游要求的旧 `torch-sparse` 0.6.18；入口只在内存中为未使用的 `SparseTensor` 导入提供失败封闭占位，实际 dense Tensor `edge_index` 分支、固定源码、权重、模型和输出算法不变，且把这一兼容边界写入运行记录。

跨数据集或条件问题必须预先固定细胞类型映射、LR 数据库、表达层、百分位、物理距离或同等邻域规则和所有训练参数，在每个独立供体/切片分别拟合，再以供体为统计单位比较预先定义的 LR、细胞类型边或 relay 的复现方向与秩。不同数据集各自 top 20% 中出现不同分子是候选空间、表达深度和图内缩放共同作用的结果，不能把两个图内 attention 值直接相减后称为特异性。一个切片只验收执行、数值、稳定性和图件，不建立疾病、条件或供体层特异性。

## DeepCOLOR：跨模态空间映射、共定位与调控配体活动

调用 `scripts/run_deepcolor.py --config config.json --out new_output`。入口固定 `kojikoji/deepcolor@7400a2aefb55045f596446f24d5b1df550474c5d` 与0.0.6源码，核验 workflow、commons、exp、modules、dataset 和 funcs 的 SHA-256。作者精确环境是 Linux Python 3.8.12、PyTorch 1.8.1 CUDA 11.1、NumPy 1.20.3、pandas 1.2.4、SciPy 1.7.3、Scanpy 1.7.2 和 AnnData 0.7.8；arm64 本机无法声称复原该 CUDA 环境。已核验兼容入口固定 Python 3.10.20、PyTorch 1.13.1、NumPy 1.26.4、pandas 2.2.1、SciPy 1.12.0、scikit-learn 1.4.1.post1、Scanpy 1.9.8、AnnData 0.10.6 和 Plotly 5.20.0，并把平台差异保留为解释限制。

输入必须是两个 h5ad：单细胞×基因和空间 spot×同一批完全同序基因，指定层必须为有限非负整数原始计数。单细胞要有唯一细胞身份和完整细胞类型；空间对象要有唯一 spot、同 spot 的二维真实坐标、坐标单位、来源、分辨率及 y 轴方向。入口拒绝静默取基因交集、四舍五入标准化值、使用 UMAP 冒充组织坐标或在内存不足时静默抽样。单细胞和空间数据若不是同一生物样本或有可信批次设计，映射结果只能作为跨样本参考投影，不能解释成原位共定位。

原生第一阶段训练单细胞负二项 VAE，第二阶段固定单细胞编码器并拟合每个 spot 上归一化的细胞权重。入口保存原生参数、完整 `map2sp`、逐单细胞行归一化 `p_mat`、潜在表示、完整细胞×细胞共定位矩阵及 mapped h5ad。`map2sc` 在每个 spot 跨单细胞和为1，用于计算细胞类型 spot 权重；`p_mat` 在每个单细胞跨 spot 和为1，用于计算 `log2(p_i·p_j)+log2(n_spots)`。两种归一化都独立复算并设误差门槛，不能互换。上游 `make_inputs` 捕获自己抛出的非整数错误后只打印，适配器改为训练前硬失败；`calculate_clusterwise_distribution` 无条件打印重名警告，适配器直接用原生映射矩阵作严格带身份汇总。

可选双细胞分支对预声明的两组细胞类型使用上游固定共定位大于1阈值。原生 `make_dual_zl` 虽计算潜在向量和与乘积，却实际只返回两细胞潜在向量之和；入口保留该行为并在来源中明示。候选少于3时保留真实数量并不运行 UMAP；足够时固定随机种子，运行作者 `analyze_pair_cluster`、Scanpy 邻居图、UMAP 与 Leiden，输出全部双细胞身份、原生簇及簇组成。UMAP 距离不是组织距离，Leiden 簇也不是新的细胞类型真值。

可选“通讯”分支要求目标基因×配体的有限非负 NicheNet 调控潜力矩阵、来源和摘要。仅这个后处理把单细胞表达做 CP10K+log1p；作者函数按每个细胞类型有放回抽样，以固定共定位阈值选细胞对，把每个细胞的前1%表达与配体经 NicheNet 加权后的前列表达二值化，再将两者乘积按细胞类型对求和。结果称 ligand-target coactivity。它没有 receptor 字段、复合受体检查、置换 P、FDR 或供体模型，不能包装成配体—受体结合、分泌或因果信号。配体机制图明确标为 ligand→target-activity→cell type；全零结果保留为阴性热图，不通过降低阈值生成网络。

## CellAgentChat：基础 agent-based LR 通讯与空间接收分数

调用 `scripts/run_cellagentchat.py --config config.json --out new_output`。入口固定 `mcgilldinglab/CellAgentChat@310cfc03df91c5ec917f110801e0c2ae4ab57800`、0.2.0与MIT许可，逐文件核验基础ABM、置换、背景分布、数据准备和模型接口摘要。兼容环境固定 Python 3.10.20、AnnData 0.10.6、NumPy 1.26.4、pandas 2.2.1、SciPy 1.12.0、scikit-learn 1.4.1.post1、statsmodels 0.15.0、PyTorch 1.13.1、Mesa 1.0.0、POT 0.9.6.post1 和 sparselinear 0.0.5。

输入为非负细胞×基因 h5ad、完整细胞类型和样本字段，以及有来源的三列以上 LR 表。距离模式还必须给出真实逐细胞二维或三维坐标、单位、来源和物理尺度是否可用。上游即使存在 `x_raw/y_raw`，只要缺少 Mesa 显示用 `x/y` 就会静默把 `dist_param` 置0；入口因此从真实坐标另作每轴0–100显示网格，同时保留未缩放坐标计算距离，并在距离仍被关闭时失败。上游用下划线拼接细胞类型对，入口拒绝带下划线的标签以免身份被静默拆错。

基础一步ABM对每个接收细胞计算受体表达相对权重，将发送群配体表达与可选的 `1/d^(tau×delta)` 相乘，再乘逐受体 conversion rate；随后对接收群细胞求平均得到群对LR分数，并保留逐细胞累计接收分数。正式运行应提供 receptor/rate 表和来源。`unit_base_abm` 把所有实测受体 rate 设为1，只用于验证基础空间ABM、置换、导出和绘图，必须显式确认；它没有运行神经网络 conversion-rate 训练，不能解释成完整机制模型。固定源码在导入时强制载入 sparselinear/torch-sparse，即使基础ABM不使用该层；入口只为未使用的神经层提供一旦实例化即报错的占位类，不复制或改写上游ABM代码，也不开放神经分支。

原生置换按固定种子打乱细胞类型，直到“每个LR累计的群对分数样本平均数”超过配置阈值；该阈值不是置换次数。上游对每个LR的置换分数拟合Gamma，并固定把shape乘0.98、scale乘1.2，随后对全部可拟合群对LR尾概率做Bonferroni。入口保存所有原生分数，`tested`只表示该LR得到可用Gamma，`supported`只表示原生校正通过；零支持必须保留。细胞标签置换不表示独立供体检验，Gamma拟合与固定参数调整也不是经验P值。

仓库外真实验收使用SCOTIA作者公开胎肝MERFISH示例：301个真实细胞、140个靶向基因、8类作者标签、一个 `mut` 切片、真实二维坐标和CellAgentChat随包mouse LR库。47个实测LR产生1,369条非零群对LR分数；在预声明的背景平均样本阈值512、tau=2、delta=1和全1转化率下，Bonferroni支持为0，阴性结果原样保留。独立审计不导入CellAgentChat或Plugin代码，重建float32距离归一化、全部基础ABM边、逐细胞接收分数及Gamma/Bonferroni调用，9/9项通过；边分数和接收分数最大绝对误差分别为 `2.90e-8` 和 `9.01e-8`，支持身份与q值误差为0。第二次运行的8张科学表逐字节一致。

## REMI：匹配独立供体的 LR 社区约束图形 Lasso

调用 `scripts/run_remi.R config.json new_output`。入口固定 `plevritis-lab/REMI@704b11b4f66e59c7683ad544cf9c0aa41751d83a`、源码版本0.0.0.9000，核验 DESCRIPTION、核心/辅助函数以及作者 LR、PPI 和通路基因集摘要。兼容环境固定 R 4.4.3、qgraph 1.10.1 和 igraph 2.0.3；igraph 2.1以后移除作者调用的 `inc()`，入口遇到其他版本即失败。DESCRIPTION 的 License 仍是 `use_mit_license(), use_gpl3_license() or friends` 模板文字，不构成有效许可证；Plugin 不分发上游源码、资源或作者数据。
