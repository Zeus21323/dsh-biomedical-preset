# 通用核心图集输入契约

## 使用边界与运行

程序读取已经完成真实推断的通讯边，不接收表达矩阵。每次处理一个数据集的一个条件，样本应为独立供体；重复切片先按设计形成供体结果。池化对象仅允许 `analysis_unit: pooled`、一个 sample，所有输出明确描述性，不计算供体 P 值。

在所选 Python 环境安装脚本声明的 NumPy/Matplotlib 依赖，或使用 uv 的独立脚本环境运行；下列路径均需替换为实际绝对路径，脚本路径相对本 skill 目录解析。

```bash
uv run --script scripts/render_communication.py --config run.json --out-dir communication_figures
```

输出目录需不存在或为空，防止旧图冒充本次结果。脚本绘图失败返回非零并在 manifest 中记录，不能当成完成；修复后用新输出目录重跑。绘图引擎的静态 PNG/PDF/SVG 不依赖 SpeedClaw 的 HTML 脚本执行能力。

## run.json

```json
{
  "dataset": "当前数据集标识",
  "condition": "当前条件",
  "method": "CellChat",
  "method_version": "填写实际版本",
  "database": "填写数据库版本或校验和",
  "score_name": "CellChat probability",
  "score_semantics": "nonnegative_additive_strength",
  "selection_rule": "填写真实检验、阈值、表达和细胞数过滤规则",
  "analysis_unit": "donor",
  "edges": "edges.tsv",
  "tested_pairs": "tested_pairs.tsv",
  "focus_sources": ["本次关注的发送亚群"],
  "focus_targets": [],
  "top_pathways": 3,
  "top_lr": 20,
  "max_chord_links": 24
}
```

`edges` 和 `tested_pairs` 相对 config 所在目录解析。其余文字必须填入真实来源；不能使用示例作为生物结果。`focus_sources` 省略或空列表时，按平均支持 LR 数量选择当前结果的首位发送群；同分按名称排序。`focus_targets` 空列表表示所有接收群。焦点必须为真实标签，程序拒绝拼写错误。未指定分子时根据当前焦点的候选支持率和平均过滤后强度选择通路/LR，并导出完整排序。

可选 `cell_order` 为全部细胞标签的排列；`colors` 是细胞标签到合法 Matplotlib 颜色的映射。可选 `scales` 的 `count`、`weight`、`lr`、`pathway` 为正数上限，低于实际最大值时拒绝而非裁断。第一次运行把实际 `scales` 写入 manifest；跨条件比较需先取所有条件最大值和候选并集，再用共同配置重画。单次程序不自动协调多个数据集，不将每个数据集自己的 top 列表视为可定量比较的集合。对条件并集图用任务代码或原生工具绘制。

可选 `font_family` 指定已安装的字体名称；默认尝试系统中文字体后回退 DejaVu Sans，最终字体写入 manifest。中文标签必须检查缺字警告和导出结果；必要时安装合适字体并指定重跑，不能把方框字当作合格图。网络超过18个节点时只绘制按连接值排名的18个，完整源表仍保留；需要观察低排名指定群时使用焦点范围或原生分面图。未映射到通路的 `Unassigned` 保留在 LR 图和结果表，但不进入重点通路图。

## tested_pairs.tsv：可检验范围

必需列：`sample, donor, source, target`（制表符分隔）。每行明确表示一个样本的发送→接收细胞对已完成推断、通过细胞数等质量要求，其结果可用于计数。不是仅列出显著细胞对，也不能凭边表中出现的标签笛卡尔积补造；从方法对象的已运行范围和 QC 元数据导出。每样本每细胞对唯一，一个 sample 只对应一个 donor，同一 donor 不能作为多个独立 sample 进入本次图集。

`analysis_unit: pooled` 时使用一个明确命名的池化 sample/donor，并在方法记录里列出原始组成。没有可检验范围时，先从原对象/日志恢复；恢复不了只能针对现有正边进行有限展示，不能运行该程序生成带零值的完整网络。

## edges.tsv：通过选择的通讯边

必需列：`sample, source, target, interaction, ligand, receptor, pathway, score`。只放按 config 中真实规则通过筛选的边，所有边须落在 `tested_pairs` 内。`interaction` 为数据库稳定 LR/复合体 ID，配体/受体保留完整亚基；同一 ID 的 ligand/receptor/pathway 映射须一致。一条边只有一个规范通路归属，不能因数据库别名重复计数；需保留多归属时用原生工具处理，不能在此程序重复行。缺通路映射统一填写 `Unassigned`，不推测补齐。

每样本每 source→target→interaction 唯一，score 为有限非负数。程序只接受可以相加且越大越强的原始强度；LIANA 的聚合 rank、P 值、logFC、NicheNet 配体活性不能直接填入。LIANA 可选明确的 magnitude 方法或走其原生 rank 图，不可把 1-rank 伪装成 CellChat probability。CellPhoneDB 需明确所选择分数及其是否适合聚合；不合适时使用原生 dot plot。

零候选时保留带表头的空 edges 文件与真实 tested_pairs。不要伪造一行零边；程序产生零候选状态，不画假阳性网络。

## 聚合和图形含义

- 数量：每样本每细胞对通过筛选的唯一 LR 数，按该细胞对可检验的独立供体等权平均，不随池化细胞数加权。
- 强度：每样本每细胞对已支持边分数求和，再在可检验供体间等权平均。不存在的已支持边贡献零，但这仅表示“过滤后网络中无边”，不能解释为原始表达/原始分数等于零。
- 缺失：没有任何可检验样本的细胞对为 NA，不纳入均值；热图用缺失色。源表写明 `n_tested`，不同细胞对的覆盖可能不同。
- LR 气泡：颜色是该 LR 在可检验供体上的平均过滤后分数；面积是支持供体比例（非 P 值）。每条 LR 的细胞对保留方向。
- 通路排名：针对每个细胞对、通路汇总已支持边；先按支持比例、再按平均过滤后强度排序。通路列表取排名中首次出现的通路；只用于选图，不是通路显著性分析。
- 角色散点：细胞对平均过滤后强度的出向/入向求和，是描述性角色，不命名为 CellChat centrality；覆盖不等时谨慎解释。
- 弦图：source|pathway → target 的有向联系，带宽是焦点范围的平均过滤后分数；限定 link 数并导出实际所画联系。不同弦图独立按总量布局，比较绝对量应看共用尺度的热图/网络及源表。

## 输出与任务衔接

默认生成总体数量网络、总体强度网络、焦点发送者网络、数量/强度热图、LR 气泡、角色散点、带供体点的焦点 LR 计数柱图、重点通路网络、重点通路弦图。每类图生成 PNG（600 dpi）、PDF、SVG，以及对应 TSV 源数据。默认读取仓库自带 Nature 风格配置，固定89/183 mm物理宽度，按内容调整高度；PDF/SVG保留矢量文字，热图单元格也使用矢量网格。

manifest 记录输入和样式哈希、方法、软件环境、筛选、焦点、尺度、输出状态与文件；源输入复制到输出以便复查。零候选状态为 `no_supported_edges`，绘图失败为 `partial`。字号、缺字或裁切技术检查失败时状态为 `needs_visual_revision` 且返回非零；成功出文件不能覆盖此状态。`visual_review` 默认为 `pending`，只能在实际看图后记录审查结论。

当选中面板均可在单栏宽度下保持字号时，另外输出183×170 mm四面板的 `communication_summary.svg` 和 PNG预览，不缩放文字。面板来源记录在 `summary_figure.panels`；其中PNG仅为预览，SVG保留各面板的原始矢量。内容超出固定版式时记录不适用，由Agent按实际数据另行排版，不强行缩小凑版。详细要求见[期刊图形验收](期刊图形验收.md)。

这不是整个科研任务的自动完成判定。Agent 需继续按[分析与图集规范](分析与图集规范.md)处理条件差异、UMAP、功能评分、临床关联和多面板排版，实际打开图片检查，补齐每个条件图的状态及源文件；解释本数据的分子候选和限制。程序生成的是描述性图集，不是差异检验或因果结果。

默认背景主次网格关闭。单图、组合图与补充图均须PNG/SVG/PDF；新增delivery记录包含文件摘要/尺寸，目视审图保持独立。组合PDF用PyMuPDF直接拼接原始矢量PDF面板并渲染核查，依赖不足则报告失败，不省略格式。
