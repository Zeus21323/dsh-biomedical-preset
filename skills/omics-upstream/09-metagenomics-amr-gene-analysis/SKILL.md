# 抗微生物耐药基因检测

1. 明确输入类型、目标药物类别、样本背景以及采用CARD、AMRFinderPlus等数据库的版本。
2. 同时评估读段级灵敏检测和组装级上下文；记录覆盖度、相似度和比对长度阈值。
3. 对点突变型耐药确认物种、基因坐标和参考等位基因，避免跨物种误判。
4. 分析耐药基因与质粒、整合子或宿主contig的共定位，但对短contig保持谨慎。
5. 输出标准化耐药谱、证据强度、潜在宿主和质量限制。

基因检出不等同于表型耐药；临床解释应结合药敏试验、表达和适用指南。

## ONN4ARG 路线

需要本体约束的蛋白质 ARG 分类时可选择 ONN4ARG。输入必须是预测蛋白 FASTA，并在运行前验证 Diamond、HHblits、模型目录和对应数据库版本。保存序列级命中、耐药本体层级、比对证据、阈值、未分类序列和模型版本；不得把核酸序列直接送入蛋白模型，也不得用模型类别替代 CARD/AMRFinderPlus 的标准证据。
