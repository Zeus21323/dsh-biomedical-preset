# 多通道组织影像到单细胞数据（nf-core/mcmicro）

## 识别数据与研究目标

核对交付包中的多轮/多通道全切片图像、marker 与轮次映射、像素尺寸和样本身份，确认是否已有拼接/配准结果。

## 方法选择

选择此版本支持的拼接、配准、背景处理、分割和定量模块，维护组织坐标与细胞 ID 的可追踪性。

先核对 [版本约定](references/流程约定.json)。

| 核对项 | 固定范围 |
|---|---|
| 上游版本 | `2.0.0`；`f4400001578642e370a72668966c6602fe172ef6` |
| 上游维护 | 未归档；使用这里固定的源码，不自动跟随新版本 |
| 本地运行 | 未进行真实分析运行；不能据本 Skill 文件声称实跑通过 |
| 引擎声明 | `!>=25.04.0`；还需核验 Java、容器和 profile |

## 根据数据确定参数

根据图像尺度、轮间漂移和标记背景选择配准及分割设置；从代表性组织区检查误配准和细胞边界，再扩展处理整片。

| 决策与配置 | 处理要求 |
|---|---|
| 事实与缺口 | 先读现有文件和报告；不能据文件名猜实验类型、参考或样本关系；只补问无法核实且会改变分析的背景 |
| 参数来源 | 区分协议必需设置、数据估计、方法默认和研究选择；说明实际取值及理由，不要求用户填写专业参数 |
| 可执行配置 | 仅把已支持的选择映射为当前版本的原生字段；不支持的步骤另行交接，不虚构开关 |
| 阈值复核 | 默认值先评估适用性；依据质控、对照及敏感性检查调整，不能按显著结果数量调参 |

## 质控与解释

检查轮次错位、拼接边界、染色背景和过分割/欠分割，使用代表性组织区人工核验。

交付图像处理结果、单细胞特征与空间元数据；算法分割对象不天然等同真实完整细胞，组织比较需控制批次。
