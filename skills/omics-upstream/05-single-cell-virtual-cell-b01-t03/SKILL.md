# 单细胞多组学预处理与整合

## 先确认是否真是同细胞

取得各模态原始数据、共享条形码、参考版本、供体、批次和缺失模态信息。配对实验与来自不同细胞的多组学不能采用同一整合假设。

## 处理原则

1. RNA、ATAC、ADT 或甲基化分别完成适合本模态的空背景、深度和质量检查。
2. 核对条形码交集与样本前缀；保留“某模态失败但另一模态合格”的状态，不默默删除。
3. 只有真实配对细胞才能直接建立 WNN 等联合邻域；非配对数据使用 MOFA 或锚定映射时要报告匹配不确定性。
4. 查看每个细胞和细胞群的模态权重，防止高深度模态压制另一个模态。
5. 联合聚类和标签必须回到各模态的原始信号验证。

## 验收

检查模态间细胞数、缺失模式、邻域稳定性、批次、供体和已知跨模态关系。整合前后都保留原始层和单模态结果。

## 交付

交付配对清单、各模态 QC、联合表示、模态权重、丢失细胞和适用下游；联合嵌入不是多组学机制证据。
