# 亚硫酸氢盐测序与DNA甲基化分析

## 开始前

确认WGBS或RRBS建库、单双端与方向性、参考基因组、未甲基化或外源转换率对照、样本分组和重复。RRBS还需记录限制性酶与预期片段范围。

## 执行流程

1. 去除接头和低质量碱基；RRBS按建库方案处理填平或酶切端，不能使用普通DNA比对流程。
2. 用Bismark、BS-Seeker或等价方法进行亚硫酸氢盐感知比对；依建库策略去重并提取甲基化与未甲基化计数。
3. 分别汇总CpG、CHG和CHH，检查比对率、重复率、转换率、M-bias、覆盖分布和链一致性。
4. 合并互补链前固定坐标规则；设定最小与最大覆盖阈值，避免低覆盖波动和PCR高覆盖位点支配结果。
5. 生成位点、固定窗口或注释区域的甲基化率，同时保留分子计数，供后续差异模型直接使用。

## 交付与解释

交付位点计数与甲基化率、覆盖文件、M-bias和转换率报告、基因组轨道及参数。低覆盖位点缺失不能简单填零；转换不完全会把未转化胞嘧啶误判为甲基化。
