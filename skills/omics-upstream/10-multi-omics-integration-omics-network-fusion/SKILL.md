# SNF 多组学相似性网络融合

1. 每层数据独立标准化并控制技术特征，确保样本顺序一致。
2. 构建各组学样本相似性网络，系统探索邻居数、核宽度和迭代次数。
3. 融合后用谱聚类或预设算法分群，并检查聚类数与参数敏感性。
4. 通过共识、轮廓系数和重采样评估稳定性，再关联临床结局并校正混杂因素。
5. 输出单层与融合网络、分群、稳定性和参数敏感性结果。

不能用同一临床结局既挑参数又宣称关联显著；分群标签必须在独立队列验证。
