# 环状RNA检测与表达分析（nf-core/circrna）

## 识别数据与研究目标

从交付文件与报告中识别 RNA-seq、建库与富集方式、参考注释和分组，明确 back-splice junction 检测及比较目标。

## 方法选择

按本版本支持的 circRNA 识别、定量、差异与 miRNA 候选分析组织流程，保留各调用方法和过滤证据。

## 根据数据确定参数

根据建库富集、读长、断点支持和重复一致性选择调用器与过滤；低支持候选单独保留证据级别，比较条件时控制线性表达和测序深度影响。

| 决策与配置 | 处理要求 |
|---|---|
| 事实与缺口 | 先读现有文件和报告；不能据文件名猜实验类型、参考或样本关系；只补问无法核实且会改变分析的背景 |
| 参数来源 | 区分协议必需设置、数据估计、方法默认和研究选择；说明实际取值及理由，不要求用户填写专业参数 |
| 可执行配置 | 仅把已支持的选择映射为当前版本的原生字段；不支持的步骤另行交接，不虚构开关 |
| 阈值复核 | 默认值先评估适用性；依据质控、对照及敏感性检查调整，不能按显著结果数量调参 |

## 质控与解释

检查 junction 支持、线性转录本干扰、重复序列和低计数，控制样本间建库差异。

交付环状 RNA 候选、计数与适用下游结果；计算预测及 miRNA 靶向关系均需独立验证，不能直接认定 sponge 机制。
