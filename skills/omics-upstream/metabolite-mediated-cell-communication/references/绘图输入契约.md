# 代谢通讯结果绘图

运行 `uv run --script scripts/render_results.py --config RUN.json --out NEW_DIR`。输出须是Git仓库外的新目录。配置需dataset、method、method_version、score_definition；分数必须为非负且越大支持越强的原生指标，不接受P值、rank或有符号差异分数冒充强度。

- communications：TSV列sample、source、metabolite、target、score、evidence_level；一条样本-发送者-代谢物-接收者唯一。evidence_level保留表达潜力、实测代谢物、空间或扰动证据的真实来源，不自动提升证据等级。
- molecular_evidence（可选）：cell_type、metabolite、gene、role、expression；role说明合成酶、释放/摄取转运体或受体等角色。expression须是明确表达层的同尺度汇总。
- top_links默认12为每样本展示上限。三层图按6条联系分页，各样本使用共同的分数线宽/坐标尺度，不将联系数量当供体重复。完整源表保留所有候选。

自动交付PNG/PDF/SVG、源表副本/摘要、筛选记录、manifest和图注；缺分子证据记录不适用，不编造基因。逐图检查长标签、线宽和证据解释。脚本仅复用原生推断结果；真实数据与运行验收过程放在仓库外。
