# 代谢物介导的细胞通讯分析

默认用户不了解工具和参数。智能体检查现有表达、代谢数据及样本信息后选择有依据的方法；只用普通语言补问无法核实且改变设计的事实。没有数据不生成分析结果，宽泛研究愿望不自动授权上传或大规模下载。

该任务补充配体—受体通讯，但不能仅凭酶或转运体 mRNA 推断细胞实际分泌或摄取某种代谢物。开始时确认组织、物种、细胞注释、表达矩阵、可用代谢组数据和候选代谢物数据库。

发送细胞需要合成、释放或转运证据，接收细胞需要受体、转运体或代谢反应证据。按供者或样本计算通讯强度，使用标签置换或样本级重采样建立背景；将组织丰度、细胞比例、检测限和通路共享酶作为混杂因素。

需要定义证据链和优先级时读取[代谢通讯证据规范](references/代谢通讯证据规范.md)。交付发送细胞、代谢物、接收细胞、支持基因、方向、样本重复性、代谢组支持和实验验证建议。

已有方法导出结果时，按[绘图输入契约](references/绘图输入契约.md)运行 [render_results.py](scripts/render_results.py)，连续生成三层候选网络、分数点图和可用分子证据图。该脚本不从mRNA推断代谢流，也不替代所选原生方法；缺少推断实现或数据库时明确就绪条件，不能用自定义乘积分数冒充论文方法。

只有表达证据时，应称为“代谢通讯潜力”。具有空间邻近、代谢物实测、同位素示踪或受体扰动时，才能提升机制可信度。

完整分析默认包含出图：推断后连续生成发送细胞→代谢物→接收细胞三层网络、候选气泡图、支持酶/转运体/受体证据热图及可用的样本级结果图，不以表达矩阵作为任务终点。已有结果先核验复用；重点代谢物由本次组织、样本支持和实测证据选择，不能套用固定清单或人为制造数据集特异性。网络权重、表达支持和代谢物实测量需分别编码，禁止互相替代。

交付每图源表、代码、图注、PNG 与 PDF/SVG，并打开检查；记录已生成、不适用和失败的图类及原因。缺少实测代谢物时继续完成适用的潜力图，同时明确证据层级，不虚构浓度或流量。

## 多方法图集衔接

与常规蛋白 LR 结果联用时，发现已安装主通讯组件 `05-single-cell-virtual-cell-b08-t04` 并读取其方法注册和语义结果包契约。MEBOCOST 必须保留代谢物–sensor 身份和酶/运输推断来源，不能把代谢物重命名成蛋白配体；资源 MetalinksDB 与推断方法分别登记。已有经过语义导出的结果自动接续对应结果包绘图，原生执行缺口必须说明，不能以描述性 renderer 冒充完成推断。

有表达数据与版本化 MEBOCOST 资源时，主通讯组件的 run_mebocost.py 原生执行 MEBOCOST 1.2.2 并自动绘图。database_config 中 HMDB 注释、物种酶表和 sensor 表必须为存在的绝对路径；每样本独立推断，保留 original_result、过滤结果及对象。默认酶表达代理不等于实测代谢物，不把未接入的外部通量分析标成完成。
