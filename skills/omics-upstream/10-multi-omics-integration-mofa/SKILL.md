# MOFA 多组学因子分析

1. 对齐样本并对各数据层做适当尺度处理，过滤无信息特征但保留规则。
2. 设定因子数、稀疏性和随机种子，多次初始化比较收敛与解的稳定性。
3. 检查每个因子在各组学的解释方差，识别被单一批次或技术指标主导的因子。
4. 依据高权重特征和样本因子分数解释生物含义，并用外部变量关联但控制多重检验。
5. 输出因子分数、特征权重、方差解释、稳定性和批次诊断。

潜因子是统计结构而非自动成立的生物机制；需用独立数据或实验验证。
