# 宏基因组物种分类与丰度估计

1. 确认宿主序列已经清除，记录读长、目标分类范围、样本类型、阴性对照和数据库版本；病原筛查还要纳入常见污染物与近缘物种。
2. 根据问题选路线：需要快速物种鉴定、病原筛查或自建数据库时用Kraken2/Bracken；需要基于标记基因获得组成谱、强调跨队列一致性时用MetaPhlAn。不要把两种方法的数值直接混成一列。
3. 走Kraken2/Bracken路线时，记录数据库构建日期与哈希、置信阈值和分类层级；Bracken的k-mer和读长模型必须匹配实际数据。
4. 走MetaPhlAn路线时，锁定数据库版本和分类层级，保留未分类比例；合并队列前确认所有样本使用同一数据库与参数。
5. 用阴性对照、标记或基因组覆盖、物种特异读段和必要的参考回贴复核重点检出，并说明近缘物种混淆与低生物量污染风险。
6. 输出统一的物种丰度矩阵、方法与数据库元数据、未分类比例、重点物种证据和后续组成数据统计要求。

这些结果主要反映相对组成，不等于绝对菌量、培养阳性或致病证据；需要绝对定量时必须有内标、总菌量或其他独立测量。

## MetaPhlAn 队列合并

合并多个 MetaPhlAn profile 前，应读取文件头中的数据库版本和分析层级，拒绝混合不兼容版本。按标准分类单元 ID 做外连接，缺失组合填 0，并保留每个输入文件到样本 ID 的映射；不得按行号拼接。可使用 `scripts/merge_metaphlan_profiles.py` 完成严格版本检查和外连接。输出同时给宽表、输入清单、重复样本处理结果和各样本总和检查。
