# CUT&RUN与CUT&Tag分析

## 开始前

记录实验类型、抗体靶标、IgG或无抗体对照、是否加入spike-in、单双端布局、参考基因组和生物学重复。先判断目标预期为尖锐结合位点还是宽广修饰域。

## 执行流程

1. 检查接头和片段长度，使用允许短片段且不产生错误截断的比对参数；分别统计宿主、外源、重复和低质量比对。
2. 去重不能照搬常规ChIP-seq：根据起始材料、UMI和文库复杂度判断真实重复与PCR重复，保留判定依据。
3. 低背景数据可用SEACR，或按目标形态配置MACS3；始终用匹配对照评估背景，不能仅按固定峰数截断。
4. spike-in只有在加入量、回收和实验设计满足可比假设时才用于校准；同时报告外源比例及未校准结果，避免校准因子放大低质量样本。
5. 检查片段结构、FRiP、靶位点富集、IgG背景、峰形、外源比例和重复一致性，再建立共识区间并做差异富集。

## 交付与解释

交付峰或修饰域、归一化轨道、差异结果、对照与spike-in诊断、逐步读段统计和参数。若抗体特异性或对照失败，应明确标记为实验质量问题，不能靠更宽松阈值补救。
