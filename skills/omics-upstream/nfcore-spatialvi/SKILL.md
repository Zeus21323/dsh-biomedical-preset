# Visium空间表达与图像联合处理（nf-core/spatialvi）

## 识别数据与研究目标

检查已有空间基因计数、坐标、组织图像及 scale factors，核对 Visium 数据版本和样本对应。

## 方法选择

按流程提供的空间建模与图像整合方法处理，明确计数过滤、归一化及模型输入，不丢失原始坐标体系。

先核对 [版本约定](references/流程约定.json)。

| 核对项 | 固定范围 |
|---|---|
| 上游版本 | `dev`；`630fb85d30a088363c60b4676e0fd60ae3283a82` |
| 上游维护 | 开发版本；按当前代码实际实现的范围使用 |
| 本地运行 | 未进行真实分析运行；不能据本 Skill 文件声称实跑通过 |
| 引擎声明 | `!>=25.10.4`；还需核验 Java、容器和 profile |

## 根据数据确定参数

从 spot 覆盖、组织占比、库大小与切片批次选择过滤和模型设置；比较图像权重或邻域尺度的稳定性，低质量图像不应主导表达分群。

| 决策与配置 | 处理要求 |
|---|---|
| 事实与缺口 | 先读现有文件和报告；不能据文件名猜实验类型、参考或样本关系；只补问无法核实且会改变分析的背景 |
| 参数来源 | 区分协议必需设置、数据估计、方法默认和研究选择；说明实际取值及理由，不要求用户填写专业参数 |
| 可执行配置 | 仅把已支持的选择映射为当前版本的原生字段；不支持的步骤另行交接，不虚构开关 |
| 阈值复核 | 默认值先评估适用性；依据质控、对照及敏感性检查调整，不能按显著结果数量调参 |

| 资料 | 使用时机 |
|---|---|
| [参数模式.json](references/参数模式.json) | 编写 params.json 时核对字段、类型、枚举及条件约束 |
| [输入模式-1.json](references/输入模式-1.json) | 准备 input 对应的样本表或输入文件时读取 |

仅在已授权且配置齐备时运行。

```bash
nextflow run nf-core/spatialvi -r 630fb85d30a088363c60b4676e0fd60ae3283a82 -params-file params.json
```

模式文件的许可见 [LICENSE](LICENSE)。

## 质控与解释

检查组织内外 spot、文库质量、图像对齐和空间模式稳定性，考虑 spot 混合细胞的影响。

交付空间处理结果及模型/QC 信息；空间表达结构不自动等同组织学诊断或特定细胞类型比例。
