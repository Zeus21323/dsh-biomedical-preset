# 非靶向质谱代谢组预处理（nf-core/metaboigniter）

## 识别数据与研究目标

从交付文件与报告中识别 MS1/MS2 数据、极性、采集方法、样本/空白/QC 和可用的鉴定资源，确认原始数据格式。

## 方法选择

按此版本处理峰提取、保留时间对齐、特征定量和 MS2 注释，保留不同离子形式与代谢物候选关系。

先核对 [版本约定](references/流程约定.json)。

| 核对项 | 固定范围 |
|---|---|
| 上游版本 | `2.0.1`；`55d82547604fcae3b6557fe7a3c442b623184f34` |
| 上游维护 | 未归档；使用这里固定的源码，不自动跟随新版本 |
| 本地运行 | 未进行真实分析运行；不能据本 Skill 文件声称实跑通过 |
| 引擎声明 | `!>=23.04.0`；还需核验 Java、容器和 profile |

## 根据数据确定参数

根据仪器质量精度、色谱峰宽和 QC 漂移确定提峰与对齐范围；空白及重复 QC 支持背景过滤，注释置信与峰强度阈值分开处理。

| 决策与配置 | 处理要求 |
|---|---|
| 事实与缺口 | 先读现有文件和报告；不能据文件名猜实验类型、参考或样本关系；只补问无法核实且会改变分析的背景 |
| 参数来源 | 区分协议必需设置、数据估计、方法默认和研究选择；说明实际取值及理由，不要求用户填写专业参数 |
| 可执行配置 | 仅把已支持的选择映射为当前版本的原生字段；不支持的步骤另行交接，不虚构开关 |
| 阈值复核 | 默认值先评估适用性；依据质控、对照及敏感性检查调整，不能按显著结果数量调参 |

| 资料 | 使用时机 |
|---|---|
| [参数模式.json](references/参数模式.json) | 编写 params.json 时核对字段、类型、枚举及条件约束 |
| [输入模式-1.json](references/输入模式-1.json) | 准备 input 对应的样本表或输入文件时读取 |

仅在已授权且配置齐备时运行。

```bash
nextflow run nf-core/metaboigniter -r 55d82547604fcae3b6557fe7a3c442b623184f34 -params-file params.json
```

模式文件的许可见 [LICENSE](LICENSE)。

## 质控与解释

检查空白污染、QC 变异、漂移、缺失和批次，避免将同位素/加合物重复计为不同代谢物。

交付特征矩阵、注释证据与 QC；MS2 候选匹配不是全部达到标准品确认的化合物身份。
