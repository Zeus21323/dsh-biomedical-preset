# RNA化学结构探测数据分析（nf-core/rnastructurome）

## 识别数据与研究目标

确认 DMS/SHAPE 等具体化学探测协议、处理与未处理对照、测序策略、参考和目标 RNA。

## 方法选择

按本版本的协议适配处理比对、突变或截断信号和反应性归一化，不混用不同化学方法的位点解释。

先核对 [版本约定](references/流程约定.json)。

| 核对项 | 固定范围 |
|---|---|
| 上游版本 | `dev`；`19c952892031ce026ccad54617dcca47bfea2c97` |
| 上游维护 | 开发版本；按当前代码实际实现的范围使用 |
| 本地运行 | 未进行真实分析运行；不能据本 Skill 文件声称实跑通过 |
| 引擎声明 | `!>=25.10.4`；还需核验 Java、容器和 profile |

## 根据数据确定参数

从处理对照、覆盖与背景突变评估可用位点和归一化区间；协议不同分别校准，不对反应性缺失位点填造可靠结构证据。

| 决策与配置 | 处理要求 |
|---|---|
| 事实与缺口 | 先读现有文件和报告；不能据文件名猜实验类型、参考或样本关系；只补问无法核实且会改变分析的背景 |
| 参数来源 | 区分协议必需设置、数据估计、方法默认和研究选择；说明实际取值及理由，不要求用户填写专业参数 |
| 可执行配置 | 仅把已支持的选择映射为当前版本的原生字段；不支持的步骤另行交接，不虚构开关 |
| 阈值复核 | 默认值先评估适用性；依据质控、对照及敏感性检查调整，不能按显著结果数量调参 |

| 资料 | 使用时机 |
|---|---|
| [参数模式.json](references/参数模式.json) | 编写 params.json 时核对字段、类型、枚举及条件约束 |
| [输入模式-1.json](references/输入模式-1.json) | 准备 input 对应的样本表或输入文件时读取 |

仅在已授权且配置齐备时运行。

```bash
nextflow run nf-core/rnastructurome -r 19c952892031ce026ccad54617dcca47bfea2c97 -params-file params.json
```

模式文件的许可见 [LICENSE](LICENSE)。

## 质控与解释

检查覆盖、背景、重复及高噪声位点，明确反应性阈值和可解释的碱基范围。

交付反应性和支持的结构相关结果；化学可及性受到细胞环境和蛋白结合影响，不能单独确定唯一三维构象。
