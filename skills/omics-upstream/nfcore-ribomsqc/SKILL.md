# 核糖核苷质谱仪性能质控（nf-core/ribomsqc）

## 识别数据与研究目标

从交付文件与报告中识别核糖核苷分析的原始质谱、QC 样本、目标离子/保留时间及批次顺序，核对支持的仪器格式。

## 方法选择

按固定版本完成 RAW 转换、XIC 提取和 QC 汇总，追踪同一标准物在不同批次中的表现。

先核对 [版本约定](references/流程约定.json)。

| 核对项 | 固定范围 |
|---|---|
| 上游版本 | `1.0.0`；`79916e8dea42d7d60b139607ca8eacfaf68e0e19` |
| 上游维护 | 未归档；使用这里固定的源码，不自动跟随新版本 |
| 本地运行 | 未进行真实分析运行；不能据本 Skill 文件声称实跑通过 |
| 引擎声明 | `!>=25.04.0`；还需核验 Java、容器和 profile |

## 根据数据确定参数

从标准物的质量误差、保留时间和批次内变异建立预警范围；结合空白与进样顺序定位漂移，不把一次告警直接解释为样本核苷变化。

| 决策与配置 | 处理要求 |
|---|---|
| 事实与缺口 | 先读现有文件和报告；不能据文件名猜实验类型、参考或样本关系；只补问无法核实且会改变分析的背景 |
| 参数来源 | 区分协议必需设置、数据估计、方法默认和研究选择；说明实际取值及理由，不要求用户填写专业参数 |
| 可执行配置 | 仅把已支持的选择映射为当前版本的原生字段；不支持的步骤另行交接，不虚构开关 |
| 阈值复核 | 默认值先评估适用性；依据质控、对照及敏感性检查调整，不能按显著结果数量调参 |

| 资料 | 使用时机 |
|---|---|
| [参数模式.json](references/参数模式.json) | 编写 params.json 时核对字段、类型、枚举及条件约束 |
| [输入模式-1.json](references/输入模式-1.json) | 准备 input 对应的样本表或输入文件时读取 |

仅在已授权且配置齐备时运行。

```bash
nextflow run nf-core/ribomsqc -r 79916e8dea42d7d60b139607ca8eacfaf68e0e19 -params-file params.json
```

模式文件的许可见 [LICENSE](LICENSE)。

## 质控与解释

关注质量准确性、保留时间、峰形、信号稳定性和空白残留，区分样品问题与仪器漂移。

交付核糖核苷质谱 QC 与异常建议；这是仪器/测量质量评估，不是核糖体足迹或 RNA 修饰功能推断。
