# 转录组状态转换的逆向扰动推断

## 明确任务与方向

适合“已知表达状态变化，寻找候选干预”的逆向任务。例如筛选与耐药形成同向或反向的基因敲除响应、为某细胞状态转换选择实验候选。单纯差异表达、实际 Perturb-seq 实验分析、给定基因预测扰动后状态、常规公共数据报告不默认触发本入口。

记录状态 A、状态 B、对比定义、物种、组织或细胞类型、处理与时间。统一将输入 `query.tsv` 定义为 `B − A`，并确认用户意图是解释观察变化、寻找反向候选还是两者兼顾。若输入为 `A − B`，在准备阶段显式取负并记录转换；不能根据文件名猜测方向。

以 A 为敏感、B 为耐药为例，正向臂检索表达响应类似“耐药减敏感”的敲除；反向臂检索相反响应。正向排序不是激活基因清单，反向排序也不等于已证明能恢复药敏。敲除向量取负不能直接充当真实过表达或基因激活实验。

## 准备表达签名与参考库

输入可由 bulk 对比或单细胞内特定细胞类型的供体层比较得到。先确保对照、归一化尺度和参考库兼容；单细胞病例对照以独立供体建模，不能直接汇总所有细胞把组成变化当成细胞内变化。仅有差异基因名单、P 值或不明方向的统计量不足以直接运行。

使用 RevPert 或准备运行包装脚本时，完整读取[RevPert方法与执行契约](references/RevPert.md)。核对两种不同的覆盖：用于计算相似性的表达特征是否覆盖；待评价基因是否属于候选扰动目录。目录之外的基因标记为无法评价，不能补上推测分数。

记录 gallery（扰动响应参考库）的物种、细胞背景、对照、表达尺度、实测/预测来源及扰动定义。模型必须对应其训练时的特征轴和候选目录。跨背景应用只有在明确说明外推理由后才执行，且结果保留外推标记。

## 执行与验证

本地脚本支持输入检查、有符号 Pearson 双方向基线、固定版本 RevPert Gallery-Dual Essential checkpoint 的推理。它不自动训练模型，也不提供通用跨背景预训练权重。论文已有表格复核、重新训练和 GWPS 模型有不同前提，按 reference 单独处理，不能当作本脚本已支持的推理模式。

从 Skill 目录执行，配置和输出路径按项目实际位置替换：

```bash
python scripts/run_revpert.py --mode check --config project/run.json --out-dir project/check-01
python scripts/run_revpert.py --mode pearson --config project/run.json --out-dir project/pearson-01
python scripts/run_revpert.py --mode revpert --config project/run.json --out-dir project/revpert-01
```

先运行 `check`，核验覆盖、签名变异、数据方向和资源关联。检查不加载 checkpoint；`revpert` 还会验证模型结构及参数。使用独立的新输出目录，保留失败诊断；不覆盖已有结果。用户只要求分析可行性时停在检查模式。

模型模式同时导出 Pearson 比较。保留整个候选目录，分别记录正反向评分，不在评分前按感兴趣基因缩小目录；融合中的标准化依赖候选集合。权重、模型和预处理预先确定，不能为提升指定基因排名而反复调参。对两个方向分别运行学习模型，不能把一侧融合分数直接取负作为另一侧。

正式生物学分析中，按供体重采样、合理的预处理敏感性或独立对比检查短名单稳定性；这些需额外数据，单次脚本运行不生成置信区间。有已知干预身份的独立留出数据才报告恢复指标，并检查正向库、PCA、反向模型各阶段的泄漏。文献锚点靠前和同一实测向量检索自身不是独立发现验证。

## 解读与交付

交付 `ranking.tsv` 全目录双方向结果、`shortlist.tsv` 两臂前列候选、`coverage.json` 覆盖和排除记录、`run_manifest.json` 版本/参数/资源指纹，以及 `report.md` 运行摘要。检查模式只交付覆盖、运行清单和检查摘要，不产生排名。

在摘要基础上结合本次问题解释候选、效应方向、Pearson 与学习模型差异及验证优先级。分数是相对排序依据，不是因果概率；接近零或整体相似性弱时，即使排第一也不作强解释。将计算假设、独立复现与实验确认分开，药物和临床推断需相应证据及专业复核。

本 Skill 独立调用，不给公共数据研究 Skill 添加固定步骤。用户确实需要汇总本次推断结果时，可把已产生的文件作为报告证据。
