# 离子迁移率与CCS分析

## 校准条件

取得仪器类型、漂移/到达时间、漂移气体与温压、校准物及参考 CCS、电荷、adduct、m/z、离子模式和 QC。不同技术平台的校准方程不能互换。

## 计算与匹配

1. 分离不同电荷和加合物，选择覆盖待测 m/z、迁移率和化学空间的校准物。
2. 按 DTIMS、TWIMS 或 TIMS 的物理/经验模型拟合，报告参数、残差和适用范围。
3. 将校准物参考值与气体、温度及 CCS 定义对应，传播参考和拟合不确定性。
4. 对超出校准范围的样本标记外推，不给虚假精度。
5. 库匹配必须使用相同离子模式、电荷、adduct 和兼容平台条件；CCS 只作为正交证据。

## 质量判断

检查校准残差、批次漂移、峰分离、同分异构体重叠和 QC 重现性。小于方法不确定性的 CCS 差异不能用于排除候选。

## 交付

提供校准模型、CCS、置信区间、残差图、库匹配和适用范围，不以单一 CCS 值确认结构。
