# 细胞状态与周期评分

## 定义状态而非标签

需要合适的归一化表达、物种匹配的基因集、细胞类型、供体、条件和批次。先检查基因集覆盖和方向，明确分数代表激活、抑制还是相对排序。

## 评分与比较

1. 在主要细胞类型内部计算模块分数或 S/G2M 周期分数，使用表达量匹配的背景基因。
2. 保留连续分数；只有阈值有独立依据时才转为阳性/阴性标签。
3. 比较多个已发表或数据驱动基因集，识别应激、干扰素和细胞周期间的重叠。
4. 条件差异在供体层建模，控制细胞组成、批次和必要协变量。
5. 需要回归周期/状态时，同时保留未回归结果，确认真实生物信号没有被删除。

## 解释边界

高分可能来自测序深度、特定细胞类型或相关程序。交付分数、基因集版本、供体效应、敏感性和冲突状态；状态分数不能直接当作新的细胞类型或功能实验证据。
