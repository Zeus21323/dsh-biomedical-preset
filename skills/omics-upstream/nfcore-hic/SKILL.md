# Hi-C接触矩阵与质量控制（nf-core/hic）

## 识别数据与研究目标

从交付文件与报告中识别 Hi-C reads、限制性酶或无酶建库信息、参考和分辨率目标；区分技术重复与独立文库。

## 方法选择

按该版本的比对、有效接触过滤和矩阵生成路径运行，核对 bin、平衡/归一化及可用下游分析。

先核对 [版本约定](references/流程约定.json)。

| 核对项 | 固定范围 |
|---|---|
| 上游版本 | `2.1.0`；`fe4ac656317d24c37e81e7940a526ed9ea812f8e` |
| 上游维护 | 未归档；使用这里固定的源码，不自动跟随新版本 |
| 本地运行 | 未进行真实分析运行；不能据本 Skill 文件声称实跑通过 |
| 引擎声明 | `!>=22.10.1`；还需核验 Java、容器和 profile |

## 根据数据确定参数

从酶切方案、有效接触数和距离衰减选择过滤、矩阵分辨率与平衡条件；稀疏矩阵降低可解释分辨率，不通过细分 bin 假造精度。

| 决策与配置 | 处理要求 |
|---|---|
| 事实与缺口 | 先读现有文件和报告；不能据文件名猜实验类型、参考或样本关系；只补问无法核实且会改变分析的背景 |
| 参数来源 | 区分协议必需设置、数据估计、方法默认和研究选择；说明实际取值及理由，不要求用户填写专业参数 |
| 可执行配置 | 仅把已支持的选择映射为当前版本的原生字段；不支持的步骤另行交接，不虚构开关 |
| 阈值复核 | 默认值先评估适用性；依据质控、对照及敏感性检查调整，不能按显著结果数量调参 |

| 资料 | 使用时机 |
|---|---|
| [参数模式.json](references/参数模式.json) | 编写 params.json 时核对字段、类型、枚举及条件约束 |
| [输入模式-1.json](references/输入模式-1.json) | 准备 input 对应的样本表或输入文件时读取 |

仅在已授权且配置齐备时运行。

```bash
nextflow run nf-core/hic -r fe4ac656317d24c37e81e7940a526ed9ea812f8e -params-file params.json
```

模式文件的许可见 [LICENSE](LICENSE)。

## 质控与解释

报告有效配对、cis/trans、距离衰减、重复与矩阵稀疏程度；分辨率应由深度和质量支撑。

交付接触矩阵、相关轨道和 QC；接触富集不直接证明功能调控，不能承诺未实现的 loop/TAD 结果。
