# 扩增子功能组成预测

1. 输入应为去噪后的ASV序列与丰度表，确认序列方向、标记区域和样本对应关系。
2. 使用PICRUSt2或等价方法完成参考树放置、拷贝数校正、基因家族预测和通路推断，保留各步日志。
3. 检查NSTI分布；参考覆盖差或NSTI高的样本必须单独标记或剔除。
4. 差异检验同时报告预测不确定性、效应量与FDR，不把小差异包装成机制证据。
5. 输出预测基因家族、通路表、NSTI质控和限制说明。

必须明确标注“由扩增子推测”，不能把预测结果写成真实宏基因组测量值。

## PICRUSt2 执行契约

执行前检查 `picrust2_pipeline.py`、参考数据库和线程资源；ASV FASTA 的序列 ID 必须与丰度表特征 ID 一致。可使用 `scripts/run_picrust2.py` 调用完整流程并保存输入哈希、命令、工具版本和退出状态。保存放置失败序列、NSTI、EC/KO 或基因家族表、通路丰度表和参数。若大批序列无法放入参考树或 NSTI 显著偏高，应停止生物学解释并建议使用宏基因组测序。
