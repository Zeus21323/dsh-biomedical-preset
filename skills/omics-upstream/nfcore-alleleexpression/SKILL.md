# 等位基因特异表达（nf-core/alleleexpression）

## 识别数据与研究目标

从交付文件与报告中识别 RNA-seq、匹配基因型/分相信息、参考和注释，明确杂合位点集合及样本对应。

## 方法选择

核对 STAR-WASP、UMI 和 phaser 等实际路径，控制参考等位基因比对偏倚并保留单倍型关系。

先核对 [版本约定](references/流程约定.json)。

| 核对项 | 固定范围 |
|---|---|
| 上游版本 | `dev`；`88c14b1de6f6734cc66e64b7ca4e8dfd1425d820` |
| 上游维护 | 开发版本；按当前代码实际实现的范围使用 |
| 本地运行 | 未进行真实分析运行；不能据本 Skill 文件声称实跑通过 |
| 引擎声明 | `!>=23.04.0`；还需核验 Java、容器和 profile |

## 根据数据确定参数

从杂合位点覆盖、比对偏倚和分相置信确定计数条件；结合过度离散与重复检查不平衡，低覆盖零计数不能直接判为单等位表达。

| 决策与配置 | 处理要求 |
|---|---|
| 事实与缺口 | 先读现有文件和报告；不能据文件名猜实验类型、参考或样本关系；只补问无法核实且会改变分析的背景 |
| 参数来源 | 区分协议必需设置、数据估计、方法默认和研究选择；说明实际取值及理由，不要求用户填写专业参数 |
| 可执行配置 | 仅把已支持的选择映射为当前版本的原生字段；不支持的步骤另行交接，不虚构开关 |
| 阈值复核 | 默认值先评估适用性；依据质控、对照及敏感性检查调整，不能按显著结果数量调参 |

| 资料 | 使用时机 |
|---|---|
| [参数模式.json](references/参数模式.json) | 编写 params.json 时核对字段、类型、枚举及条件约束 |
| [输入模式-1.json](references/输入模式-1.json) | 准备 input 对应的样本表或输入文件时读取 |

仅在已授权且配置齐备时运行。

```bash
nextflow run nf-core/alleleexpression -r 88c14b1de6f6734cc66e64b7ca4e8dfd1425d820 -params-file params.json
```

模式文件的许可见 [LICENSE](LICENSE)。

## 质控与解释

检查有效杂合位点覆盖、等位基因计数、mapping bias、低表达和重复，按检验单位处理多重比较。

交付 ASE 计数与单倍型表达证据；等位失衡还可能源于拷贝数、印记和技术偏倚，不能直接归因为某个调控变异。
