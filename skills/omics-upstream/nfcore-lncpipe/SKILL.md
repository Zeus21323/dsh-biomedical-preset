# 长非编码RNA候选分析（nf-core/lncpipe）

## 识别数据与研究目标

从交付文件与报告中识别 RNA-seq、参考与注释、链特异性和物种信息，明确发现新 lncRNA 还是定量已有注释。

## 方法选择

核对当前开发版本实际支持的组装、长度/结构过滤和编码潜能分析，保存每一步候选变化。

先核对 [版本约定](references/流程约定.json)。

| 核对项 | 固定范围 |
|---|---|
| 上游版本 | `dev`；`ff1b23f5fb89cf49106aab24d1ec111f22720d87` |
| 上游维护 | 开发版本；按当前代码实际实现的范围使用 |
| 本地运行 | 未进行真实分析运行；不能据本 Skill 文件声称实跑通过 |
| 引擎声明 | `!>=24.04.2`；还需核验 Java、容器和 profile |

## 根据数据确定参数

依据物种注释质量、转录本结构与表达支持选择候选筛选；长度和编码潜能阈值说明来源并检查边界候选，多外显子偏好不能无条件排除单外显子生物学目标。

| 决策与配置 | 处理要求 |
|---|---|
| 事实与缺口 | 先读现有文件和报告；不能据文件名猜实验类型、参考或样本关系；只补问无法核实且会改变分析的背景 |
| 参数来源 | 区分协议必需设置、数据估计、方法默认和研究选择；说明实际取值及理由，不要求用户填写专业参数 |
| 可执行配置 | 仅把已支持的选择映射为当前版本的原生字段；不支持的步骤另行交接，不虚构开关 |
| 阈值复核 | 默认值先评估适用性；依据质控、对照及敏感性检查调整，不能按显著结果数量调参 |

| 资料 | 使用时机 |
|---|---|
| [参数模式.json](references/参数模式.json) | 编写 params.json 时核对字段、类型、枚举及条件约束 |
| [输入模式-1.json](references/输入模式-1.json) | 准备 input 对应的样本表或输入文件时读取 |

```bash
nextflow run nf-core/lncpipe -r ff1b23f5fb89cf49106aab24d1ec111f22720d87 -params-file params.json
```

模式文件的许可见 [LICENSE](LICENSE)。

## 质控与解释

检查低表达、不完整转录本、编码基因片段、重复区域与链方向，避免用单一预测分数判定非编码。

交付 lncRNA 候选、表达支持与筛选依据；非编码预测不证明分子功能，开发中未实现环节需如实说明。
