# 空间结论稳健性（SpatialRobust方向）

## 触发

“细胞真的挨着吗”“换半径结论就变了”“分割影响结果吗”及重要邻接结论时，检查坐标单位、分割、切片与供体。无坐标不运行，spot不能冒充细胞。

## 真实邻域重算

python scripts/audit_spatial_robustness.py --config /外部目录/spatial.json --out-dir /外部目录/spatial-001

配置：table，labels（两个目标标签），coordinate_unit，radii（2–30个不同正半径），max_edges（1–2000000），bootstraps（100–10000），seed。半径依据细胞尺寸、平台和问题预设，不按显著性选择；像素转物理单位须有比例来源。

表列donor,slice,cell,x,y,label；供体×切片×细胞唯一，坐标有限。不跨切片连边。先预计边数保护内存，再生成最大半径KD树无向边，逐半径统计A–B边/全部A/A、A/B、B/B目标标签边。目标缺失或没有边为NA，不填零。重合坐标不同细胞会形成零距离边，必须先查分割重复。

先供体内切片等权、再供体等权；至少3名可用供体才有供体bootstrap百分位95%区间。不同尺度可用供体不同，必须报告分母；正式比较优先固定共同供体。区间不是尺度差异的正式检验。

## 完整工作流与边界

脚本实际实现邻域尺度敏感性。分割、标签或去卷积版本由原平台流程真实生成，再按固定网格独立运行，匹配供体和组织区域比较。所有尝试版本均保留，不挑稳定结果。本适配器不生成替代分割，不做破坏空间自相关的简单标签置换，也不证明通讯富集。

回查原组织图、方向、掩膜、边界和丰度。比例受丰度影响，稳定邻近不等于通讯。图默认首张切片不是最佳证据；论文应有依据选择代表切片并补充全切片图集。

依据：[SciPy cKDTree.query_pairs](https://docs.scipy.org/doc/scipy/reference/generated/scipy.spatial.cKDTree.query_pairs.html)、[SciPy bootstrap](https://docs.scipy.org/doc/scipy/reference/generated/scipy.stats.bootstrap.html)。不是已部署的全平台SpatialRobust服务。

## 代理负责准备、执行和复核

用户不需要写JSON或命令。先读取文件与元数据，确认问题、独立统计单位、对比和出处；只用普通话补问确实无法核实且改变设计的事实。只有疾病/基因/毕业愿望时先回公共研究设计；缺输入交付缺口清单，不用模拟数据冒充结果。

代理在用户指定的仓库外目录创建配置。所有配置必填question（实际问题）、parameter_reason（参数与设计依据）、evidence_notes（来源、已核验事实与不确定性）；可选font为覆盖图中文字的已安装字体。参数不得由显著性倒推。路径相对配置文件解析。CSV/TSV为UTF-8、唯一表头，TSV以.tsv结尾；保留原始数据，不自行覆盖。每次指定新输出目录。

Python 3.11+，依赖numpy、pandas、scipy、matplotlib。代理在隔离环境准备并记录版本，不要求新手安装。各适配器自包含，无跨Skill脚本依赖，不需要根目录packages。输入1GB保护上限不等于内存保证；失败非零退出，已有输出目录则留下失败记录，不把残留产物视作成功。

交付完整TSV、summary.json、run_record.json、report.md、可编辑PDF/SVG、400 dpi PNG和图注。作图数据来自对应完整结果表；图的截取规则必须说明。配置、输入/输出哈希、版本和状态均留痕。脚本摘要不等于科学论文：代理需据真实数字补写观察、样本量、效应/区间、阴性/冲突、替代解释、证据等级和下一步，关联具体表行和图件。描述性模式不能声称显著。

打开PNG或渲染PDF，按最终版面检查缺字、截断、图例、颜色、单位、比例、方向和区间；重要发现回查输入。分辨率不是论文质量保证。原始记录保持“需视觉与科学复核”状态；复核可另存review.md，不篡改运行记录。结果、缓存、测试数据和日志只放仓库外。本地适配器不代表后台数据库或未实现的论文方法已完成。
