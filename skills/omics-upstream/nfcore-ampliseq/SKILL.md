# 扩增子微生物群落分析（nf-core/ampliseq）

## 识别数据与研究目标

明确 16S/ITS 等标记、引物、平台、单双端、样本与阴性对照，核对参考分类库及扩增区。

## 方法选择

按版本支持的 DADA2/QIIME2 路径进行引物去除、去噪、嵌合过滤与分类，长度截断应由真实质量和重叠决定。

先核对 [版本约定](references/流程约定.json)。

| 核对项 | 固定范围 |
|---|---|
| 上游版本 | `2.18.0`；`2723d4c298d48321594920d0324697e14d73ee94` |
| 上游维护 | 未归档；使用这里固定的源码，不自动跟随新版本 |
| 本地运行 | 未进行真实分析运行；不能据本 Skill 文件声称实跑通过 |
| 引擎声明 | `!>=25.10.4`；还需核验 Java、容器和 profile |

## 根据数据确定参数

先确认扩增区域和引物，依据每批真实质量曲线、去引物后长度和预期重叠决定截断；ITS 长度变异与阴性对照另行考虑，不能给所有样本套统一截断长度。

| 决策与配置 | 处理要求 |
|---|---|
| 事实与缺口 | 先读现有文件和报告；不能据文件名猜实验类型、参考或样本关系；只补问无法核实且会改变分析的背景 |
| 参数来源 | 区分协议必需设置、数据估计、方法默认和研究选择；说明实际取值及理由，不要求用户填写专业参数 |
| 可执行配置 | 仅把已支持的选择映射为当前版本的原生字段；不支持的步骤另行交接，不虚构开关 |
| 阈值复核 | 默认值先评估适用性；依据质控、对照及敏感性检查调整，不能按显著结果数量调参 |

| 资料 | 使用时机 |
|---|---|
| [参数模式.json](references/参数模式.json) | 编写 params.json 时核对字段、类型、枚举及条件约束 |
| [输入模式-1.json](references/输入模式-1.json) | 准备 input 对应的样本表或输入文件时读取 |
| [输入模式-2.json](references/输入模式-2.json) | 准备 multiregion 对应的样本表或输入文件时读取 |
| [输入模式-3.json](references/输入模式-3.json) | 准备 pplace_sheet 对应的样本表或输入文件时读取 |

仅在已授权且配置齐备时运行。

```bash
nextflow run nf-core/ampliseq -r 2723d4c298d48321594920d0324697e14d73ee94 -params-file params.json
```

模式文件的许可见 [LICENSE](LICENSE)。

## 质控与解释

检查每步保留率、污染、ASV 支持及测序深度，比较组别前明确组成性和采样设计。

交付 ASV/分类表、代表序列和群落 QC；标记基因相对丰度不能直接等同细胞数量或全基因组功能。
