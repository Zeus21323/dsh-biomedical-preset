# 蛋白质结构域与功能注释

## 输入要求

蛋白 FASTA、稳定序列 ID、物种或分类背景、序列来源、目标注释类型及数据库版本。先检查空序列、异常字符、极短片段、重复 ID 和低复杂度区。

## 注释策略

1. 用 InterProScan 等识别结构域、家族和功能位点，保留每个数据库的命中坐标与显著性。
2. 用 eggNOG-mapper 或经过阈值控制的同源比对补充 GO、通路和功能描述。
3. 区分“直接结构域命中”“同源转移”“计算预测”和“人工确认”；多个来源冲突时并列保留。
4. 对多结构域蛋白按区域解释，不能把单个短域的功能扩展到整条蛋白。
5. 汇总未注释比例，并单独检查截短、低复杂度和可能的错误基因模型。

## 质量门槛

记录数据库和软件版本、E-value/覆盖阈值、域边界与物种适用性。功能名称过于笼统或只由远缘同源支持时降低证据等级。

## 交付

输出蛋白—结构域—功能表、坐标、证据来源、GO/通路、冲突和未注释清单；不把预测功能写成实验验证事实。
