# 非靶向病毒基因组重建与宿主体内变异（nf-core/viralmetagenome）

## 识别数据与研究目标

从交付文件与报告中识别非靶向宏基因组 reads、样本信息和候选病毒资源，明确 DNA/RNA 与建库类型。

## 方法选择

按流程执行病毒识别、重建和支持的 iSNV 分析，保留未知/混合病毒及参考选择的依据。

先核对 [版本约定](references/流程约定.json)。

| 核对项 | 固定范围 |
|---|---|
| 上游版本 | `1.1.3`；`3d36a809a9b6f9617d686eb799feb49a598467e6` |
| 上游维护 | 未归档；使用这里固定的源码，不自动跟随新版本 |
| 本地运行 | 未进行真实分析运行；不能据本 Skill 文件声称实跑通过 |
| 引擎声明 | `!>=25.10.4`；还需核验 Java、容器和 profile |

## 根据数据确定参数

依据测序类型、病毒候选覆盖和混合感染情况选择参考与组装，iSNV 过滤结合深度和错误背景；局部低覆盖不通过降低阈值伪造完整基因组。

| 决策与配置 | 处理要求 |
|---|---|
| 事实与缺口 | 先读现有文件和报告；不能据文件名猜实验类型、参考或样本关系；只补问无法核实且会改变分析的背景 |
| 参数来源 | 区分协议必需设置、数据估计、方法默认和研究选择；说明实际取值及理由，不要求用户填写专业参数 |
| 可执行配置 | 仅把已支持的选择映射为当前版本的原生字段；不支持的步骤另行交接，不虚构开关 |
| 阈值复核 | 默认值先评估适用性；依据质控、对照及敏感性检查调整，不能按显著结果数量调参 |

## 质控与解释

检查病毒覆盖、组装嵌合、交叉污染、重复和低频错误，对不同病毒分别报告可调用范围。

交付病毒序列、iSNV 候选与 QC；低丰度片段匹配不等同完整病毒或活性感染。
