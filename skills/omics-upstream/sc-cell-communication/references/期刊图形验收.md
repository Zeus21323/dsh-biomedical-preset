# 期刊图形验收

## 使用 Nature 样式的实际含义

绘图默认加载仓库内的 [communication-nature.mplstyle](../assets/communication-nature.mplstyle)，并按物理尺寸布局。它是本项目按官方图形指南实现的参数配置，不是 Nature 官方认证，也不是独立分析方法。若运行环境已有 `scientific-visualization` 或用户指定的 Nature figure skill，先发现并读取其指导；缺少外部 skill 不阻塞本仓库自带规范。不得声称已加载不存在或未读取的 skill。

期刊投稿时核对目标期刊、文章类型和投稿阶段的最新要求。当前本地配置参考 Nature 图形指南：单栏89 mm，双栏183 mm；以170 mm为高度上限给图注留空间；正文标签5–7 pt，面板字母可8 pt加粗。英文优先 Arial/Helvetica，中文标签需完整字体支持。PDF/SVG 保持文字和线条可编辑，PNG仅作为600 dpi检查/预览版本。

配置与来源核验日期：2026-09-07。
- [Nature figure guide：尺寸、面板与字体](https://research-figure-guide.nature.com/figures/building-and-exporting-figure-panels/)
- [Nature figure guide：可编辑矢量输出](https://research-figure-guide.nature.com/figures/preparing-figures-our-specifications/)

## 不把成功出文件当作论文质量合格

程序将 `generated` 与 `technical_quality`、`visual_review` 分开。技术检查核对物理尺寸、字号、缺字和文字是否超出画布；失败标记 `needs_revision`，保留文件用于诊断并使进程返回非零。自动技术检查不能证明科学正确性、标签互不遮挡或已达到投稿水准。

Agent 必须逐类打开图片；按最终89/183 mm尺寸检查，而不是放大后觉得清楚。完成检查后在 manifest 的 `visual_review` 记录实际审查者/时间、图类、发现的问题及修正证据。没有检查不能写 `passed`；稀疏合成数据只能验收样式和执行，不可验收真实网络复杂度和分子解释。

## 图类的可读性要求

- 网络：节点与标签有间隔，箭头可辨，边宽有数值图例；只保留本面板问题需要的范围。大网络分面或在补充图中使用编号加标签表，不把节点标签缩到5 pt以下。颜色按细胞类型全图固定，不能用红绿区分且无冗余标签。
- 弦图：优先用 CellChat/circlize 的原生结果与多层扇区布局。通用弦图仅展示已导出的发送群|通路→接收群；必须让标签读者能区分发送、通路和接收，窄扇区用引导线、编号或拆面板，不能用多块宽色带掩盖细节。相对宽度须可追溯到源表，不随美化修改权重。
- 气泡：依候选数自适应高度；面积和色标图例独立且紧凑；明确空白格含义，长标签用换行/分页。配体、受体和复合体 ID 不能为省空间改成不明缩写。
- 计数/统计：多发送群按发送群分面或分块排列，点保留独立样本；只有适用统计结果才画误差和显著性，不为了符合样例补星号。
- 热图与角色图：灰色缺失与零值可区分，角色图重叠标签用引导线或分面；同条件对比共用图例和尺度。
- 主图：数据集标识、软件版本和长方法说明放图注/报告，图内保留必要标题、标签及量纲。按科学问题组合面板，导出矢量整版；禁止把独立 PNG 缩小拼成主图后声称文字仍可编辑。内容不足时减少面板，不增加虚构数据来填版。

默认样式不能替代原生方法的专业图形布局；复杂弦图或多个条件的主图在通用图验收不通过时，应转用原生函数并继续输出适用图集，而非宣称“已用 Nature 样式，所以可直接发表”。

默认背景主次网格关闭。单图、组合图与补充图均须PNG/SVG/PDF；新增delivery记录包含文件摘要/尺寸，目视审图保持独立。组合PDF用PyMuPDF直接拼接原始矢量PDF面板并渲染核查，依赖不足则报告失败，不省略格式。
