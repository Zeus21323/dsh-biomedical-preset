# 分析、特异性与图集规范

## 先核验再复用

已有 CellChat/RDS、LIANA/AnnData、CellPhoneDB 结果时先检查数据库和软件版本、组织/物种、样本、细胞亚群、表达层、统计和过滤参数。保留原对象，只对副本做兼容升级。对象缺少某个派生结果时只补所需步骤。没有推断结果才从表达与元数据开始；运行结束必须继续进入图集生成。

常规 CellChat 的依赖关系是表达/注释 → 过表达候选 → `computeCommunProb` → 低细胞数过滤 → `computeCommunProbPathway` → `aggregateNet`。角色分析需相应 centrality 结果。遵循实际安装版本的教程，不跨版本照搬槽位。保存完整对象和可检验范围，`subsetCommunication()` 的显著边表不能单独证明一个未出现的细胞对已检验且没有信号。

记录表达汇总方式、表达比例阈值、最小细胞数、复合体亚基、置换次数、随机种子、是否考虑细胞比例、数据库校验和。做低细胞数/组成敏感性分析，不能只在讨论里提到它们。对多条件设计，区分组内特异性置换 P 值与组间差异 P 值；“一组显著另一组不显著”不是差异显著。

## 本数据集的重点从哪里来

1. 保留问题相关亚群，例如已验证的 CAF 亚型、肿瘤状态和治疗组；不能从示意图照抄标签。marker 高低分组须说明表达阈值、掉零影响和每供体细胞数。药敏标签须来自实际实验/临床数据或明确标为预测的方法，不能由通讯分数反推。
2. 先报告所有通过质量过滤的边，再确定本数据的焦点。用户指定发送群、接收群或分子时保留该焦点，即使结果不支持也如实显示；无指定时用本数据的发送/接收排名形成探索性候选。
3. 常规候选记录：发送群、接收群、LR/复合体、通路、原始分数和方向、检验含义、支持/可检验供体数、表达比例、群体细胞数、跨方法支持、接收端响应及空间支持。没有证据的列留缺失，不补零或伪造。
4. 有足够独立样本及可比较设计时，重点优先来自供体级效应、方向一致性、适用的 FDR 和稳定性；有配对样本保留配对。多重检验作用于预先定义的候选集合，不能先取漂亮的 top 10 再计算校正。供体不足时仅用描述性排名并写明；不能报告可靠差异分子。
5. 没有差异统计时，按供体支持比例、平均已支持分数等透明规则排名，只称“本数据优先候选”。通用程序默认按焦点发送者的支持比例、平均过滤后分数排序，选前 3 条通路、前 20 条 LR；这些是可配置展示上限，不是显著性阈值，不证明疾病特异性。
6. 对比多个数据集时同时报告共同候选与各自候选、可检验范围和不一致原因。细胞缺失/低覆盖不是“特异缺失”；数据库和细胞组成差异可能改变排名。不能人为降低阈值、删除共同通路或把未检测值当零来制造差异。
7. 将被选与未选候选、排序字段及焦点理由写入选择表和图注。泛 ECM/高表达通路可作为全局背景，但机制叙述需要落实到具体发送→LR→接收及支持证据。

## 默认图集与参考图的对应

| 图类 | 参考面板类型 | 数据与绘图要求 |
|---|---|---|
| 总体、焦点发送者 circle | I、M | 分别绘制唯一 LR 数量和权重；节点/颜色含义稳定，边有方向；数量不可标成强度 |
| 通路与 LR 弦图 | J、O | 用真实通路/复合体映射；按数据选择重点，标明带宽和方向；仅画有支持的联系 |
| LR 数量柱图 | N | 每样本每细胞对去重后计数，供体等权汇总并显示样本点；池化计数不画虚假误差线 |
| 发送–接收热图 | 补充核心图 | 明确行发送、列接收，未检验用缺失色；跨条件统一范围 |
| LR 气泡图 | 补充核心图 | 保留 LR 复合体；颜色/大小写明实际分数与支持含义，不能把 rank 当概率 |
| 角色散点图 | 补充核心图 | 说明入向/出向分数计算；通用求和与 CellChat centrality 不能混名 |
| UMAP 状态定位 | L | 使用现有 embedding 和可追踪状态标签；没有 embedding 可在合适预处理后计算，记录参数；不是通讯算法直接输出 |
| 功能评分与箱线/点图 | K、P | 需要明确基因集来源、背景、评分方法及供体；每细胞分数可展示分布，推断须匹配独立样本单位；不能直接用通讯强度充当 collagen score |
| 药敏相关散点与响应热图 | G、H | 需要匹配样本的药敏/临床结局及亚群丰度或特征；说明相关方法、协变量、样本量及多重检验；不能用图形相似来代替这些数据 |

原生 CellChat 可用 `netVisual_circle`、`netVisual_heatmap`、`netVisual_bubble`、`netVisual_aggregate`、`netVisual_chord_gene` 和 `netAnalysis_signalingRole_scatter`，以当前版本文档为准。模式河流图需先完成模式模型与模式数选择，不能直接从 LR 列表伪造。

条件图通过主入口及原生执行契约按实际输入继续完成；它支持供体比较、已有坐标、已定义的样本功能评分和供体级连续结局关联。评分计算、药敏分类模型或更复杂设计仍需合适方法，不能由通讯分数臆造。通用 renderer 只负责核心描述性图集。条件图状态写入 `figure_manifest.json` 的 `conditional_panels`；重复测量/供体不足、无坐标、无评分或无临床资料分别解释，不再询问是否绘制现有数据支持的图。

## 论文交付

主图围绕一个问题组织：总体背景 → 特定细胞对 → 特定分子/通路 → 重复支持 → 下游或外部证据。逐个打开 PNG/PDF 在最终尺寸检查字体、标签裁切和颜色区分。大网络分面、标注重点，其余放补充表；弦图按固定上限拆分而不是缩到不可读。跨图共享细胞颜色，比较图共享节点顺序、边尺度、气泡色标，保留所有数据集候选并集的比较视图。

至少交付源对象、边表、样本/可检验范围表、排名/筛选表、图源数据、PNG 与 PDF/SVG、可重运行代码、参数与软件/数据库记录、每图图注、生成/不适用/失败清单。HTML/交互图只能作为附加，静态产物必须可直接查看。流程成功不等于因果验证或已达到某期刊录用标准。
