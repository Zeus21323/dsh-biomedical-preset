# 多方法连续执行

## 选择与状态

[方法与执行契约.json](方法与执行契约.json) 是执行器实际读取的唯一注册表，包含方法、工作流与资源的身份、来源、执行入口和版本。先按研究问题、输入、统计单位和已安装环境选择，再执行适用方法；“收录”不等于“原生实现已完成”。`documented` 项不能自动替换成另一算法或当成已成功运行。历史方法没有可取得的实现时保留具体缺口。

常规 LR 网络优先 CellChat；多方法排序用 LIANA+，其框架中的 CellPhoneDB/CellChat 实现不等同独立软件全部功能；需 CellPhoneDB v5 原生统计时使用其独立适配器。FastCCC 的统计分数与 CellChat 概率不可相加。Tensor-cell2cell 输入跨样本可比的非负候选张量，保留缺失掩码。响应程序使用 NicheNet，空间关联使用 SpatialDM，空间竞争运输使用 COMMOT。空间关联和模型运输分别解释，不以模型复杂程度排列因果证据。

数据库是资源，不是独立推断方法。固定资源文件摘要、物种和版本；小鼠不得静默套人类资源。多亚基复合物按原生定义检查，不以一个检测到的亚基代替完整复合物。

CellPhoneDB/FastCCC 从所用数据库解析 HGNC 符号和完整复合物，保留原生编号；非蛋白配体的酶表达代理使用独立身份，不与代理基因的蛋白通讯合并。CellPhoneDB 的未通过表达门槛候选也可能有原生 P=1，检验资格必须读取原生未舍入掩码。LIANA 共识在原生合格候选上计算后才补回未检验记录，避免把未检验候选纳入排名分母。

## 入口

运行 `run_communication.py --config 配置.json --out 仓库外的新目录 --rscript 已安装Rscript`。配置包含 `methods` 时进入 `run_method_workflow.py`，逐个执行已登记适配器，生成静态 `index.html`、汇总 manifest 和每方法的 PNG/PDF/SVG、源表、图注；单个方法失败保留其他方法产物，整体返回非零。配置与输出不得位于 Git 中，输出已存在时拒绝覆盖。

```json
{
  "dataset": "本次数据集的稳定名称",
  "research_question": "患者亚群之间哪些发送端与接收端候选值得进一步验证",
  "defaults": {
    "input": "annotated.h5ad",
    "species": "human",
    "layer": "X",
    "expression_scale": "log_normalized"
  },
  "methods": [{"method": "LIANA+", "config": {"min_cells": 10}}]
}
```

这里是接口示意，不能把默认阈值当作任何数据的科学选择。h5ad 必须有唯一基因/细胞 ID，以及 `sample/donor/condition/cell_type`；可通过相应 `*_key` 映射真实字段。一个样本只能对应一个供体和条件。缺少身份时读取原始 metadata，不虚构重复；只有单标本的空间资料明确标注标本单位。

`python` 指定实际科学运行环境；每方法可覆盖。`renderer_python` 指定现代绘图环境，适用于 COMMOT 旧版依赖或 R 方法输出结果包后自动绘图。依赖按脚本头部固定版本配置在仓库外，不把全部算法强装进同一 Python 环境。R 跨 skill 执行按稳定组件 ID 定位；独立安装时通过 `skill_roots` 提供组件 ID 到实际目录的映射。

已有结果包时在 method 项提供 `bundle` 路径：检查数据集、方法、文件摘要与语义后直接重绘，不重跑推断或表达矩阵。单独重绘用 `render_result_bundle.py --bundle bundle.json --out 新图目录`。CellChat RDS 复用仍走原生执行契约的 `reuse` 模式。

## 原生方法的额外输入

| 执行器 | 额外输入及输出语义 |
|---|---|
| `run_liana.py` | 原生共识资源或显式 `resource_file`；`magnitude_rank/specificity_rank` 是排序，不是 P 值；保留检测比例和完整复合物检测支持。 |
| `run_cellphonedb.py` | `database` 为官方 ZIP，`database_version` 明确；可传微环境/活性 TF 文件；原生交互方向无法唯一解释时保留原始表，不擅定方向。 |
| `run_fastccc.py` | 官方 CellPhoneDB 展开表目录及版本；保留原始 P 值、可检验掩码；仅允许 1e-12 内浮点越界归一化，并记录发生数。 |
| `run_tensor.py` | 候选 TSV、每样本 `provenance_files`、明确 `score_definition`；必须同版本、数据库、参数。原生秩诊断与重启拟合、完整载荷及样本模式输出；不能把排名直接当强度。 |
| 分泌蛋白活性 skill 的 `run_nichenet.R` | 基因×细胞 RDS、发送/接收群、独立定义响应基因集及背景、版本化 LR 与 ligand-target 先验；导出 corrected AUPR、配体–靶基因与 LR 先验关联；不声称推断出完整 TF 路径。 |
| `run_spatialdm.py` | 实际二维坐标、`coordinate_unit=um`、转换来源、`bandwidth_um`；输出原生全局/局部 FDR 与热点；没有运输方向含义。 |
| `run_commot.py` | 实际二维坐标及来源、`distance_um`；输出原生运输矩阵和发送/接收向量。`analysis_pathways` 限定建模资源时，记录范围内竞争，不冒充全库建模。 |
| `run_mebocost.py` | MEBOCOST 1.2.2固定源码提交；原生配置中的HMDB、enzyme/metabolite、sensor资源为绝对路径，明确版本。代谢物为酶表达代理，不声称测得代谢浓度或加入了通量约束。 |
| `run_neuronchat.R` | NeuronChat 1.0.0固定源码提交、真实RDS表达与metadata、human/mouse原生DB；必要贡献基因组与替代成员遵循原生规则，保留完整推断对象及置换结果。 |
| 分泌蛋白活性 skill 的 `run_multinichenet.R` | multinichenetr 2.1.0、真实count SingleCellExperiment与版本化LR/ligand-target先验；样本pseudobulk、edgeR及原生配体活性优先级。明确供体、条件、协变量与批次；设计满秩且有残差自由度。适配器完成状态另按注册表核验。 |
| 空间 skill 的 `run_spatalk.R` | SpaTalk 1.0 固定提交，单细胞空间counts与真实坐标/注释；原生LR、TF和路径。非物理标定坐标仅作原生近邻判断；原生保留候选不补零、不冒充全家族FDR。 |
| `run_flowsig.py` | FlowSig 0.5.5 独立环境；两个真实条件、control、原生CellChat表、明确GEM来源或native_nmf。cellchat_condition_map可显式对齐上游条件键；不复用历史flow网络。变异/数值资格检查、共享缩放、原生细胞bootstrap；频率不等于P，未定向模块边不画双向因果箭头。 |

## 语义结果包

`communication_inputs.py` 检查表达数据；`communication_contract.py` 检查结果包。`schema_version=2` 包含 `dataset/method/method_version/implementation/provenance/tables`。每张表有唯一安全 ID、类型、相对路径、SHA256、数值定义及必要单位。表头即字段契约；空结果也保留表头。

| 类型 | 必需字段 | 自动图形 |
|---|---|---|
| lr_edges | sample, source, target, ligand, receptor, score, tested, supported | LR 气泡、支持数量网络；明确可加分数时增加强度网络 |
| metabolite_edges | sample, source, target, metabolite, sensor, score, tested, supported | 代谢物–sensor气泡与数量网络，不冒称蛋白配体–受体 |
| matrix | row, column, value | 同尺度分页热图 |
| activities | ligand, value | 配体活性排序，保留负值 |
| molecular_links | source, target, source_type, target_type, value | 层次关联网络、焦点弦图，保留分子类型 |
| patterns | factor, dimension, entity, value | 因子载荷分页热图 |
| effects | sample, donor, condition, feature, value | 供体散点；样本数足够时附箱线，绘图不重新计算显著性 |
| effect_summary | feature, value, p_value, q_value, n_reference, n_comparison | 条件效应与全候选火山图；明确contrast/statistical_unit/test_definition，已有区间才附区间 |
| enrichment | term, group, value, q_value, overlap, set_size, background_size | 富集点图及原生数值热图；必须有background_definition和gene_set_provenance |
| spatial_points | sample, cell, x, y, value | 真实组织坐标上的数值分布 |
| spatial_vectors | sample, cell, x, y, dx, dy | 原生方向箭头；记录向量定义与显示缩放 |
| spatial_edges | sample, source_cell, target_cell, value | 真实空间端点连接；必须有配套坐标表 |
| time_series | sample, donor, feature, time, value | 逐供体动态曲线，明确实测时间/伪时间/速度模型 |
| network | source, target, value | 明确可加度量的层次网络与焦点弦图 |

`tested=false` 是未检验，`tested=true,supported=false` 是检验未支持，真实零分数保留零；缺失不补零。支持的边必须有可检验状态和分数。P/q 校验范围，不对排序套显著性阈值。不同 interaction ID 的同名 LR 分开显示。图中只显示可读子集，完整源表、选择规则、共享尺度始终保留。

## 条件与富集的连续后处理

`run_bundle_contrasts.py` 的配置包含 bundle、table（默认lr_edges）、conditions（参考/比较顺序）、paired、min_donors（至少3）、statistical_unit=donor、design_provenance。结果表须自带逐样本donor/condition及原生数据库摘要和参数。配置有covariates时拒绝简单置换。多方法入口的每个method项可提供comparison对象（除bundle外的上述参数），执行器在该方法出图后自动运行并将比较图纳入同一图集。

供体比较先检验完整候选、计算BH，再按q/绝对效应选展示项。删一供体图只重新计算所选候选效应，配对设计同时删除两个条件；它不代表重做候选选择后的稳定性，也不是独立验证。已知共同的高表达通路可以仍然居前；无显著差异须原样展示。缺少协变量调整、独立重复或可检验候选时不能承诺疾病特异性。

`run_gene_set_enrichment.py` 读取selected_genes（group/gene TSV）、background（逐行基因）、gmt，以及dataset/species/gene_set_version/selection_provenance/background_provenance。输出超几何右尾检验、完整组×集合BH、重叠基因、fold enrichment及自动点图/热图。min_size/max_size在背景内计算，默认10/500，须按设计事先决定。它是结果解释的过度代表分析，不替代NicheNet或GSEA的原生推断。

`compare_method_support.py` 输入同一真实数据摘要的多个bundle，只在共同可检验候选中逐样本比较支持集合Jaccard和方向协调后的Spearman。保留各方法支持定义、候选覆盖和空集不可估计状态，不混加分数。

## 图形与完成判断

CellChat 继续生成数量/强度圆网、热图、重点发送者/通路弦图、LR 气泡/贡献、角色散点；条件适用时加入原生 hierarchy、NMF incoming/outgoing river/dot 及秩诊断。NMF 模式数来自诊断或研究者事先指定，不能固定成好看的数量。

自动图集包含单图和可编辑合并 PDF。通用图形采用固定物理尺寸、6–8 pt 文字、600 dpi PNG 和矢量 PDF/SVG，分页和焦点选择防止拥挤。组织图允许有来源的组织栅格底图，但数据和标注仍须保持可编辑。静态 HTML 不依赖 JavaScript，可供受限预览环境查看。

技术通过标记为 `generated_pending_visual_review`，必须实际打开最终导出图核验重叠、裁切、颜色、箭头、单位及数据一致性；名称含 nature 的样式不表示启用了外部 Nature skill。找不到外部 skill 时使用本仓库规范并如实记录。不能把仅有注册条目、单次脚本退出成功或局部真实数据跑通称为全方法完成。


CellCall 与 scConnect 按单个真实样本执行，不能把细胞标签置换或regulon筛选解释为供体条件差异。`scripts/run_cellcall.R` 接收含 expression/metadata 的 RDS，明确 source=UMI/TPM/CPM 与对应表达尺度；原生对象、TF富集、LR–TF关系和评分随结果保存。`extended=true` 仅选择 CellCall 自带扩展资源，不能冒充独立 CellCallEXT。`reuse_directory` 仅接受输入、资源和科学参数指纹相同且原生对象校验通过的既有目录；绘图焦点可调整。独立 CellCallEXT 的执行状态由唯一方法契约决定。

`scripts/run_scconnect.py` 在独立 Python 3.10 环境运行，固定源码与 setuptools 80.9.0。显式使用 AnnData 表达层与原生 GtoPdb 2020-5，保留递质代理所需基因覆盖、两端原生 q、置换分布和原生分数。缺代理基因或任一端置换方差为零不算支持；原生特异性分数不标为P值。旧依赖环境只负责推断，统一入口自动调用现代绘图环境，无需用户再次要求画图。

有明确单一通路标签且分数可加时，结果绘图器自动调用 `scripts/communication_sankey.py`，同时生成发送者→通路→接收者桑基图和细胞/通路分组双环Circos。每条LR权重只归入实际标签一次，显示子图、覆盖总量、同尺度权重表随图输出；缺通路映射不能猜测。机制层级中的不同单位边不使用该守恒权重图替代。


独立 CellCallEXT 使用 `scripts/run_cellcallext.R`，仅核验固定源码的 human counts、真实双条件与原生 pooled_cells 分支。配置 r_library 指向专用 R 库，case/control 为元数据已有值；expression_direction=UP/DOWN/BOTH 按原生语义，后两者的正载荷不等同正调控，原始带符号GSEA另存。`scripts/install_cellcallext.py` 的固定归档、NAMESPACE/依赖补丁和原生R源码摘要可审计；它只修复 plot_grid 提供者，不改评分。原生LR2TF辅助函数读取了另一包的数据库，适配器不调用该不匹配分支，而从本次实际Reactome资源及已保留LR/TF导出关系，并记录来源。既有bundle通过统一入口复用重绘。


NATMI 的 `scripts/run_natmi.py` 需要 native_root 指向固定提交的实际源码，脚本核验 ExtractEdges.py 摘要；原生human connectomeDB2020资源留在该外部目录。归一化定义必须明确，log_normalized在适配器内expm1还原线性单位。使用原生展示规则的严格 detection/expression/specificity 阈值，候选筛选不是P/FDR。表达与特异性表分开；跨方法比较时 bundles 条目可写成 {"bundle":".../bundle.json","table_id":"specificity_edges"}。同一方法有多个评分表时必须选定一种，不能静默相加或当重复证据。

SingleCellSignalR 的 `scripts/run_singlecellsignalr.R` 目前核验v1.18 human实际counts。每样本独立原生准备并按ID重新对齐低复杂度过滤后的细胞；临时原生细胞ID与原始ID保留映射，防止R改写条码。单样本cluster marker edgeR只用于原生specific分类，不能解释为供体差异。LRscore以原生0阈值保存正分候选，再按明确s_score严格筛选；完全相同的重复候选仅在标准表去重，原生表/对象保留。不同分数或身份矛盾不自动合并。

原生流形或其他真实嵌入使用 `latent_points`：每行 `entity/domain/x/y/z`，同域实体唯一，三个坐标均为实际算法输出；声明 `coordinate_unit: latent` 和 `space_definition`。绘图器连续生成二维投影与三维嵌入，轴名为潜在维度，不将基因流形假称UMAP、组织三维坐标或轨迹。原生矩阵的 `display_top_rows/display_top_columns` 必须为正整数，仅限制展示并记录选择，完整源表不删减。

细胞已有二维降维坐标使用 `embedding_points`：sample/cell/x/y，加连续value或类别label；明确embedding_method与embedding_provenance。同一样本的细胞不能重复，缺坐标失败，缺分数保留灰点；负分数使用以零对称的色标。不会重新生成表达矩阵或将t-SNE改叫UMAP。RNA-Magnet的可选embedding_file为完整细胞×2坐标RDS，搭配实际方法和来源后，统一流程自动生成逐锚群specificity、adhesiveness及偏好分类图。

矩阵 `display_style: lollipop` 仅改变单列展示方式，不改变节点值、得分或科学分类；多列矩阵仍保留完整矩阵图。`figure_role`必须表述结果实际角色，表达派生节点值不冒充中心性。

矩阵可提供 row_order/column_order，必须唯一且覆盖完整观测标签，不允许借顺序列表暗删证据。对称矩阵两轴使用相同顺序；CV 折次按真实数值顺序。spatial_points 的 title 应包含目标特征或类型及尺度，样本身份在多样本情况下同时显示。
