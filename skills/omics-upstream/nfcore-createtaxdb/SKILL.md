# 微生物分类数据库构建（nf-core/createtaxdb）

## 识别数据与研究目标

从任务与样本背景判断分类工具、数据库来源、物种范围、taxonomy 版本和资源预算，明确是否包含宿主和污染对照。

## 方法选择

按各工具原生构库方式整理序列与分类映射，固定下载来源和构建参数，避免同名数据库混用版本。

先核对 [版本约定](references/流程约定.json)。

| 核对项 | 固定范围 |
|---|---|
| 上游版本 | `3.1.0`；`b01a0f8ed96a5990d15470828dfa92a22cf08bba` |
| 上游维护 | 未归档；使用这里固定的源码，不自动跟随新版本 |
| 本地运行 | 未进行真实分析运行；不能据本 Skill 文件声称实跑通过 |
| 引擎声明 | `!>=25.10.4`；还需核验 Java、容器和 profile |

## 根据数据确定参数

按目标群落、宿主与污染来源决定序列范围，结合工具要求设置构库参数；覆盖不足与资源限制分别说明，不能为缩小体积隐去重要近缘物种。

| 决策与配置 | 处理要求 |
|---|---|
| 事实与缺口 | 先读现有文件和报告；不能据文件名猜实验类型、参考或样本关系；只补问无法核实且会改变分析的背景 |
| 参数来源 | 区分协议必需设置、数据估计、方法默认和研究选择；说明实际取值及理由，不要求用户填写专业参数 |
| 可执行配置 | 仅把已支持的选择映射为当前版本的原生字段；不支持的步骤另行交接，不虚构开关 |
| 阈值复核 | 默认值先评估适用性；依据质控、对照及敏感性检查调整，不能按显著结果数量调参 |

| 资料 | 使用时机 |
|---|---|
| [参数模式.json](references/参数模式.json) | 编写 params.json 时核对字段、类型、枚举及条件约束 |
| [输入模式-1.json](references/输入模式-1.json) | 准备 input 对应的样本表或输入文件时读取 |

仅在已授权且配置齐备时运行。

```bash
nextflow run nf-core/createtaxdb -r b01a0f8ed96a5990d15470828dfa92a22cf08bba -params-file params.json
```

模式文件的许可见 [LICENSE](LICENSE)。

## 质控与解释

检查序列/taxid 一致性、污染、重复、覆盖范围及索引可读性，保存构库工具版本。

交付分类数据库与可复现构建说明；数据库缺失物种会限制分类，不能仅以库体积代表质量。
