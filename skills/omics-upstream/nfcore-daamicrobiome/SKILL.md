# 微生物差异丰度多方法比较（nf-core/daamicrobiome）

## 识别数据与研究目标

从交付文件与报告中识别微生物计数/丰度表、分类信息、分组与协变量，明确重复测量、零值和样本排除标准。

## 方法选择

按版本支持的方法运行差异丰度并形成共识，保持过滤和比较设计一致；各方法的尺度及假设单独记录。

先核对 [版本约定](references/流程约定.json)。

| 核对项 | 固定范围 |
|---|---|
| 上游版本 | `dev`；`de1ab09c7c7ebb763e59a721533b70445eb7ad0a` |
| 上游维护 | 开发版本；按当前代码实际实现的范围使用 |
| 本地运行 | 未进行真实分析运行；不能据本 Skill 文件声称实跑通过 |
| 引擎声明 | `!>=25.10.4`；还需核验 Java、容器和 profile |

## 根据数据确定参数

根据零值、组成性、样本量和重复测量选择模型及预过滤；使用一致比较与多重检验口径，方法间一致不自动消除共同偏差。

| 决策与配置 | 处理要求 |
|---|---|
| 事实与缺口 | 先读现有文件和报告；不能据文件名猜实验类型、参考或样本关系；只补问无法核实且会改变分析的背景 |
| 参数来源 | 区分协议必需设置、数据估计、方法默认和研究选择；说明实际取值及理由，不要求用户填写专业参数 |
| 可执行配置 | 仅把已支持的选择映射为当前版本的原生字段；不支持的步骤另行交接，不虚构开关 |
| 阈值复核 | 默认值先评估适用性；依据质控、对照及敏感性检查调整，不能按显著结果数量调参 |

| 资料 | 使用时机 |
|---|---|
| [参数模式.json](references/参数模式.json) | 编写 params.json 时核对字段、类型、枚举及条件约束 |

仅在已授权且配置齐备时运行。

```bash
nextflow run nf-core/daamicrobiome -r de1ab09c7c7ebb763e59a721533b70445eb7ad0a -params-file params.json
```

模式文件的许可见 [LICENSE](LICENSE)。

## 质控与解释

检查组成性、稀疏性、库大小、离群值和多重检验，分析方法间冲突而非只取交集。

交付各方法效应、共识与敏感性结果；相对丰度变化不等同绝对数量改变，共识也不能消除共同偏差。
