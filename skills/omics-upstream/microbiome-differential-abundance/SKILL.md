# 微生物差异丰度分析

1. 明确计数还是相对丰度、样本配对关系、批次、药物和临床混杂因素。
2. 过滤极低检出率特征但记录规则；避免先按组别筛特征造成信息泄漏。
3. 根据数据与设计选择ANCOM-BC、ALDEx2、MaAsLin2或计数模型，不把多种方法的最小P值拼接为结论。
4. 同时报告方向、效应量、置信区间、检出率和FDR；对零膨胀与敏感阈值做稳健性检查。
5. 对显著结果回看污染、测序深度和批次，并区分探索性发现与预设假设。

输出可审计的模型公式、特征结果表和关键图；组成数据的相对变化不能自动解释为绝对丰度增加或减少。

## ALDEx2 路线

两组或简单设计且需要显式处理组成不确定性时可使用 ALDEx2，输入必须是非负整数计数并保持样本与元数据严格对齐。记录 Monte Carlo 实例数、分母策略、检验类型、组别参考方向和随机种子；输出效应量、组内/组间差异、原始与校正 P 值。可使用 `scripts/run_aldex2.R` 执行两组 Welch 路线。存在复杂协变量或重复测量时优先 ANCOM-BC2、MaAsLin2 或匹配设计的模型，不强行使用 ALDEx2。
