# SAMMY-seq染色质状态分析（nf-core/sammyseq）

## 识别数据与研究目标

核对交付包中的连续提取组分、样本配对、参考和测序数据，明确不同溶解性组分对应的实验条件。

## 方法选择

按本版本支持的比对、信号整理与染色质状态分析处理，保持组分标签和同一样本关系。

先核对 [版本约定](references/流程约定.json)。

## 根据数据确定参数

根据同一样本的组分对应、测序深度和信号尺度选择归一化与比较区间；先排查组分错配和批次，再判断状态变化。

| 决策与配置 | 处理要求 |
|---|---|
| 事实与缺口 | 先读现有文件和报告；不能据文件名猜实验类型、参考或样本关系；只补问无法核实且会改变分析的背景 |
| 参数来源 | 区分协议必需设置、数据估计、方法默认和研究选择；说明实际取值及理由，不要求用户填写专业参数 |
| 可执行配置 | 仅把已支持的选择映射为当前版本的原生字段；不支持的步骤另行交接，不虚构开关 |
| 阈值复核 | 默认值先评估适用性；依据质控、对照及敏感性检查调整，不能按显著结果数量调参 |

## 质控与解释

检查组分回收差异、覆盖、重复及批次，避免把提取效率差异当作染色质状态改变。

交付各组分信号与可支持的状态结果；生化分级反映特定实验条件下的可提取性，不能替代直接结合或接触测量。
