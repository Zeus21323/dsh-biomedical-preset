# 单细胞公共数据检索

## 把需求变成检索条件

明确物种、组织、疾病、assay、细胞类型、供体特征、所需数据层和用途。用于参考映射时重视标签与组织匹配；用于差异分析时必须有足够独立供体和条件元数据。

## 检索与筛选

1. 先查 collection，再核对具体 dataset 的版本、细胞数、供体数和处理流程。
2. 使用受控词表处理组织、疾病和细胞类型同义词，避免只按标题搜索。
3. 下载前确认 X/层中是原始计数还是归一化值，并检查条形码、基因 ID 和供体字段。
4. 对同一研究的重复发布或不同处理版本去重，记录更新时间和许可。
5. 核对数据是否经过子集化、是否缺少低质量或未注释细胞，以及这些选择会不会影响目标问题。

## 复用判定与交付

提供数据集标识、筛选条件、供体和细胞组成、可用数据层、许可及下载方式。若只有细胞级标签而缺少供体/条件，不得建议做组间推断统计；应明确其仅适合探索或参考注释。
