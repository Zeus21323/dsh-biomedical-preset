# 代谢组公共数据库检索

## 先区分查询对象

查询可以是化合物身份、参考 MS/MS 谱图，或公开研究数据。分别收集名称/稳定 ID/结构、m/z 与 adduct/碰撞能，或物种、基质、平台和实验条件。

## 检索步骤

1. 规范化名称、分子式、InChIKey、SMILES 及 HMDB/KEGG/ChEBI 等 ID，保留盐型和立体化学差异。
2. 化合物检索核对结构与同义词；谱图检索匹配极性、adduct、仪器和碰撞条件。
3. 研究检索核对样本数、对照、原始文件、元数据、处理方式和许可，而非只看摘要。
4. 记录数据库、版本或查询日期、过滤条件和所有稳定标识。
5. 对重复项目、同一队列和来自预测的谱图单独标注。

## 交付标准

返回候选化合物/谱图/项目、直接匹配依据、冲突、许可、下载内容及缺失信息。数据库条目是证据来源，不自动提升实验注释等级。
