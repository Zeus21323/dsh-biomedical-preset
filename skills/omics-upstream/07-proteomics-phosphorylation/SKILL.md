# 蛋白质翻译后修饰分析

## 实验信息不可缺

取得富集与未富集数据、修饰类型、酶切和衍生化、FASTA、可变修饰设置、定位概率、样本设计、批次及总蛋白结果。不同修饰类型应分开搜索和解释。

## 位点分析

1. 控制可变修饰数和搜索空间，先通过鉴定 FDR，再评估修饰位点定位。
2. 设定并报告 localization probability 或 site probability 阈值；定位不唯一时保留位点组。
3. 以修饰肽段为定量单位处理缺失和批次，必要时汇总到蛋白或功能位点。
4. 有总蛋白数据时区分“修饰占有变化”和“蛋白总量变化”；没有时明确无法分离。
5. 在合适背景上进行 motif、激酶/酶和通路分析，并回看关键谱图。

## 质控重点

检查富集特异性、修饰肽段数、定位分布、搜索空间膨胀、批次、缺失及不同肽段的一致性。单个低质量谱图不能支持机制结论。

## 交付

提供修饰肽段、位点或位点组、定位证据、差异效应、总蛋白校正、功能分析和待验证位点。
