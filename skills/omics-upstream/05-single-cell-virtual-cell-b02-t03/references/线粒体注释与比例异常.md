# 线粒体注释与比例异常
常规比例为线粒体基因组编码基因计数/每细胞总计数，不包括全部核编码线粒体功能基因。先核物种、基因ID、注释版本与集合来源；前缀只在物种和符号已确认时用，Ensembl需版本匹配。
记录匹配基因数、分母、零分母、缺失与真实零值；零匹配不能视为所有细胞比例为零。0–1和0–100按计算来源核验，最大值小于1不证明单位为fraction。
高值可能是组织生理、疾病/处理、细胞状态或损伤；结合计数、检测基因、marker和污染证据。5/10/20%不是通用阈值，不因绘图或发表自动过滤。
有真实比例表时复用[QC契约](../../scRNA-seq预处理/references/QC数据与空图处理.md)，显式选择mitochondrial_percent面板。缺少计数/注释时保留未核实结论，不填零。不另建重复绘图器；按实际安装文件核验依赖。
