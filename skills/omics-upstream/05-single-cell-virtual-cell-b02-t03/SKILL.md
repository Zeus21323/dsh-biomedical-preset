# 线粒体比例质控

## 核验实际含义

读取[线粒体注释与比例异常](references/线粒体注释与比例异常.md)，先检查已提供对象的物种、基因ID、计数层、样本、组织和运行记录。常规线粒体比例针对线粒体基因组编码的基因，不将所有核编码线粒体功能基因计入。

核验基因集合、匹配数量、每细胞分母和比例单位。基因符号前缀仅在确认物种与命名后使用；Ensembl等ID需按匹配版本注释。没有可靠注释不能把零匹配解释为真实零比例。总计数为零、比例缺失和实际零比例分别记录。

不能仅因最大值小于1就把百分数再乘100。已有比例字段优先核查计算来源，不无故重复计算或静默覆盖。

## 阈值与生物学判断

- 分样本查看比例分布，以及它与总计数、检测基因、复杂度和应激的关系。
- 根据分布、稳健统计和组织知识识别异常尾部，不把5%、10%或20%作为通用界线。
- 生理高线粒体转录群体与濒死细胞分开核查；疾病或处理也可能改变比例。
- 在输入与任务支持时，检查阈值附近细胞的marker、双细胞/环境RNA证据，并比较不同合理阈值下群体组成与结论。
- 只要求解释现有图时先解释和核查，不自行重新过滤整个对象。需要改变过滤规则时记录依据和影响，不为发表调结果。

## 图件与交付

已有完整比例表直接绘制；需要复用当前Plugin中的QC提取与绘图器时，先核验[QC数据与空图处理](../scRNA-seq预处理/references/QC数据与空图处理.md)及脚本存在，再按已验证字段选择适用面板。调用失败不能以临时假数据补图。

默认无背景主次网格，保留有依据的阈值及必要参照；全零或常数使用适用表示，不生成空框或虚构密度。每张正式图默认同时交付PNG、SVG、PDF、作图数据、图注和计算记录；核验编辑性、比例单位、样本量和布局并提供文件链接。

报告每细胞比例、分层规则、剔除理由、敏感性和受影响群体。高线粒体比例是质量线索，不是死亡证明，也不能单独决定细胞去留。
