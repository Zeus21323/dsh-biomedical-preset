# 单细胞调控网络分析

## 先确定可支持的边

RNA 只能提供共变证据；ATAC 可增加 motif 和增强子可及性；Perturb-seq 等扰动才提供更接近因果的方向信息。需要表达/可及性矩阵、细胞类型、供体、物种、motif/调控数据库和可选扰动数据。

## 网络构建

1. 在相关细胞类型或状态内推断 TF—靶基因候选，避免由细胞类型混合产生相关边。
2. 使用 SCENIC/pySCENIC 等时区分共表达模块、motif 剪枝和 regulon 活性三个阶段。
3. 多组学数据用峰—基因链接和 motif 支持过滤；保留距离、相关和先验证据。
4. 在供体重采样、细胞下采样和不同参数下计算边与 regulon 稳定性。
5. 用独立 ChIP、扰动或已知靶标验证优先边，并标记仅由相关性支持的连接。

## 交付

提供网络边、regulon、每细胞/样本活性、证据类型、稳定性和待验证 TF。motif 命中不等于该 TF 已结合，共表达也不证明调控方向。
