# ICP-MS离子组与金属组分析

## 必要实验信息

原始计数或强度、元素和同位素、调谐/反应气模式、内标、标准曲线、方法空白、加标回收、QC、样本质量或体积、稀释倍数和批次。

## 定量路线

1. 核对质量轴、内标覆盖和标准曲线范围，检查高浓度样本是否超量程。
2. 扣除匹配基质的空白，应用内标、稀释和样本质量/体积校正。
3. 对多原子与同量异位干扰说明使用的碰撞/反应气、数学修正或替代同位素，不能只靠峰质量猜测。
4. 由空白和低浓度标准估计检出限与定量限；低于范围的结果保留状态标记。
5. 汇总批内、批间精密度和加标/标准物质回收率。

## 质量和边界

检查内标漂移、carryover、容器或试剂污染、校准残差及单位换算。ICP-MS 测得的是元素/同位素信号，通常不能直接说明其化学形态或代谢物来源。

## 交付

输出元素浓度矩阵、单位、校准与 QC、干扰处理、LOD/LOQ 标记、失败样本和批次信息。
