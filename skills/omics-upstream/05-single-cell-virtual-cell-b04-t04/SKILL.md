# 单细胞类型注释与参考映射

## 注释前提

需要质控对象、物种和组织、供体、候选谱系、参考数据及版本、marker 证据和期望粒度。参考必须与组织、疾病和技术尽量接近；不匹配时只能提供辅助证据。

## 分层注释

1. 先用广谱 marker 和排除性 marker 判断主要谱系，同时标记双细胞和低质量群。
2. 在每个谱系内部再细分亚型或状态，避免一次分类到过细标签。
3. 使用 SingleR、CellTypist、Azimuth 等时保存预测分数、次优标签和参考类别，不只保留最终名称。
4. 比较参考预测、簇 marker、已知解剖和供体复现性；冲突时降低粒度或标为未知。
5. 对每个标签建立最小证据集，并检查其是否只出现在一个批次或供体。

## 质控与交付

已有参考注释而用户要求检查、出现marker矛盾、疾病/健康背景不一致或异常群时，读取[scDiagnostics复核](references/scDiagnostics.md)。输入足够时用 `scripts/run_scdiagnostics.R` 计算真实诊断；只有标签而无表达或reference时先收集证据，不凭标签名猜正确性。诊断是注释流程的一部分，不要求用户知道该软件。

交付每细胞和簇级标签、置信度、正负 marker、参考版本、未知及冲突群。聚类编号、最高分类分数或单个 marker 都不能独立证明细胞身份；状态标签不得冒充稳定细胞类型。

交付reference–query距离分布、关键marker对照、按供体分层的异常比例与降维定位。细胞层异常分数不提供患者层显著性；异常可能是疾病状态、参考缺失或技术问题，保持原标签另加复核字段。图中标注所用表达层、抽样规则与细胞数，按reference要求输出可编辑图、高清预览和作图数据。
