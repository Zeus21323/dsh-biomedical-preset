# 单细胞批次整合

## 先判断能否校正

列出供体、批次、平台、条件、组织和共享细胞类型。条件与批次完全重合时，算法无法区分技术和生物效应；此时应分层分析或补数据，而不是强行混合。

## 选择与评估

1. 明确整合只用于可视化/聚类、标签迁移还是下游统计，避免一套校正值承担所有用途。
2. 根据数据规模和计数层选择 Seurat anchors、Harmony、BBKNN、scVI 等，并保留未整合表达。
3. 用已知同类细胞检查批次混合，同时用 marker、条件响应和稀有群检查生物信号保留。
4. 分供体查看邻域组成；一个供体被拆散或稀有群消失通常提示过校正。
5. 比较至少一个简单基线与候选方法，记录参数和随机种子。

## 交付边界

提供整合表示、未整合层、批次混合和生物保留指标、失败群及适用下游。整合嵌入不应直接用于把所有细胞当独立重复做差异表达。
