# 历史单细胞矩阵分析流程（nf-core/scflow）

## 识别数据与研究目标

检查已有历史 scflow 接受的表达对象、样本元数据与参考注释，确认复现目标和原分析参数。

## 方法选择

按归档 revision 核对 QC、归一化、降维和整合接口，迁移到 scdownstream 前先比较对象和方法语义。

先核对 [版本约定](references/流程约定.json)。

| 核对项 | 固定范围 |
|---|---|
| 上游版本 | `dev`；`c2c97284e609b116b857949efa256cccf308420b` |
| 上游维护 | 已归档；用于明确的历史分析或复现审查 |
| 本地运行 | 未进行真实分析运行；不能据本 Skill 文件声称实跑通过 |
| 引擎声明 | `>=21.04.2`；还需核验 Java、容器和 profile |

## 根据数据确定参数

依据对象中的原始计数、已有变换和原报告恢复 QC 与整合设置；新分析按样本分布重新评估，不把历史默认值自动升级为当前样本的最佳选择。

| 决策与配置 | 处理要求 |
|---|---|
| 事实与缺口 | 先读现有文件和报告；不能据文件名猜实验类型、参考或样本关系；只补问无法核实且会改变分析的背景 |
| 参数来源 | 区分协议必需设置、数据估计、方法默认和研究选择；说明实际取值及理由，不要求用户填写专业参数 |
| 可执行配置 | 仅把已支持的选择映射为当前版本的原生字段；不支持的步骤另行交接，不虚构开关 |
| 阈值复核 | 默认值先评估适用性；依据质控、对照及敏感性检查调整，不能按显著结果数量调参 |

| 资料 | 使用时机 |
|---|---|
| [参数模式.json](references/参数模式.json) | 编写 params.json 时核对字段、类型、枚举及条件约束 |

仅在已授权且配置齐备时运行。

```bash
nextflow run nf-core/scflow -r c2c97284e609b116b857949efa256cccf308420b -params-file params.json
```

模式文件的许可见 [LICENSE](LICENSE)。

## 质控与解释

检查细胞筛选、批次校正、聚类和注释是否依赖旧软件版本，保留中间对象和身份映射。

交付能够重现的单细胞结果与版本限制；不能以新流程得到相似 UMAP 就宣称旧分析完全复现。
