# 宏基因组组装与分箱（nf-core/mag）

## 识别数据与研究目标

从交付文件与报告中识别宏基因组 reads、样本/coassembly 分组、测序类型及宿主过滤需求，核对资源规模。

## 方法选择

按实际模式进行质量处理、组装、分箱和 bin 评估，保留每个 MAG 的来源及多样本覆盖信息。

先核对 [版本约定](references/流程约定.json)。

| 核对项 | 固定范围 |
|---|---|
| 上游版本 | `5.5.0`；`56abab5b023ce953c9c43fe21090d156ad0e18af` |
| 上游维护 | 未归档；使用这里固定的源码，不自动跟随新版本 |
| 本地运行 | 未进行真实分析运行；不能据本 Skill 文件声称实跑通过 |
| 引擎声明 | `!>=26.04.0`；还需核验 Java、容器和 profile |

## 根据数据确定参数

根据群落复杂度、样本关系和覆盖互补性决定单样本或联合组装，按 bin 完整性、污染及菌株混合评估筛选；不同研究目标说明保留等级，不能只追求 MAG 数量。

| 决策与配置 | 处理要求 |
|---|---|
| 事实与缺口 | 先读现有文件和报告；不能据文件名猜实验类型、参考或样本关系；只补问无法核实且会改变分析的背景 |
| 参数来源 | 区分协议必需设置、数据估计、方法默认和研究选择；说明实际取值及理由，不要求用户填写专业参数 |
| 可执行配置 | 仅把已支持的选择映射为当前版本的原生字段；不支持的步骤另行交接，不虚构开关 |
| 阈值复核 | 默认值先评估适用性；依据质控、对照及敏感性检查调整，不能按显著结果数量调参 |

## 质控与解释

检查组装质量、bin 完整性/污染、菌株混杂和低覆盖，避免把多分箱器结果简单重复计数。

交付组装、MAG、分类及 QC；MAG 是重建的群体基因组表示，不自动等同纯培养菌株或完整闭合基因组。
