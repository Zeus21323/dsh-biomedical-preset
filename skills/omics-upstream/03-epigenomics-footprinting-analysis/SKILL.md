# 转录因子基序与足迹分析

## 开始前

准备统一版本的峰或开放区域、参考序列、物种匹配的motif库、样本分组和切割位点。明确问题是集合富集、单个位点扫描还是足迹差异，这三类结果不能互换。

## 执行流程

1. 为富集分析构建GC、长度、可比对性和开放程度匹配的背景；记录区域去重及重复基因组处理规则。
2. 使用HOMER、MEME或等价方法报告富集效应、多重校正和背景定义；扫描位点时保存阈值、链方向和所有候选位置。
3. 将高度相似的motif家族合并解释，不能仅凭一个motif命中指定具体家族成员。
4. 足迹分析用TOBIAS、HINT等校正Tn5或DNase序列偏好，要求足够切割深度，并在样本层面评估重复一致性。
5. 差异足迹使用可比的开放区域与深度，检查结果是否只是总体可及性变化；结合TF表达、ChIP或扰动证据给候选TF排序。

## 交付与解释

交付富集motif、扫描位点或足迹分数、背景与偏好校正、候选TF家族和可视化。基序存在不代表结合，足迹也可能受核小体、切割偏好和局部可及性影响。
