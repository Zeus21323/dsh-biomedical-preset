# 蛋白质质谱数据处理

## 处理目标

先说明是格式转换、谱图检查、色谱峰提取还是为后续搜索准备数据。需要原始或 mzML 文件、仪器与采集模式、profile/centroid 状态、样本表、运行顺序和期望输出。

## 安全处理顺序

1. 对文件计算校验和并验证扫描数、MS 层级、极性、离子淌度和元数据能否读取。
2. 只有在下游确实需要时才转换格式或质心化；保留未处理原始文件和转换日志。
3. 依据校准物和 QC 检查质量误差、保留时间与信号中断，再决定去噪、峰检测或特征链接参数。
4. 使用 PyOpenMS 或同类工具时，将每个步骤、软件版本和参数写入可重算记录。
5. 抽查原始谱图与提取峰，确认处理未删除低丰度真实信号或制造重复特征。

## 失败判据

扫描缺失、元数据不一致、profile 被重复质心化、质量误差突然跳变或运行顺序出现喷雾中断时，应停止批量处理并标记文件。

## 交付

交付处理后 mzML/featureXML 或表格、文件对应关系、参数、校验和、运行级 QC 和失败清单；不把未搜索的谱峰称为已鉴定肽段。
