# 宿主与病原双RNA测序分析（nf-core/dualrnaseq）

## 识别数据与研究目标

从交付文件与报告中识别共测定 RNA-seq、宿主和病原参考、链特异性及感染设计，核对两套注释的标识冲突。

## 方法选择

按流程支持的分配/比对路径区分宿主与病原信号，保存多重比对和无法归属读段的处理。

先核对 [版本约定](references/流程约定.json)。

| 核对项 | 固定范围 |

| 上游版本 | `1.0.0`；`d8dcd8acfa6f1c2de933294bc73344d6258ebb42` |
| 上游维护 | 未归档；使用这里固定的源码，不自动跟随新版本 |
| 本地运行 | 未进行真实分析运行；不能据本 Skill 文件声称实跑通过 |

| 语法兼容 | 原生入口含历史 process/channel 写法；先核验匹配的 Nextflow 版本 |

## 根据数据确定参数

从两套参考的相似区域和读段归属比例选择多重匹配处理，分别评估宿主及病原的有效深度；比例变化不直接等同单个系统的表达变化。

| 决策与配置 | 处理要求 |
|---|---|
| 事实与缺口 | 先读现有文件和报告；不能据文件名猜实验类型、参考或样本关系；只补问无法核实且会改变分析的背景 |
| 参数来源 | 区分协议必需设置、数据估计、方法默认和研究选择；说明实际取值及理由，不要求用户填写专业参数 |
| 可执行配置 | 仅把已支持的选择映射为当前版本的原生字段；不支持的步骤另行交接，不虚构开关 |
| 阈值复核 | 默认值先评估适用性；依据质控、对照及敏感性检查调整，不能按显著结果数量调参 |

| 资料 | 使用时机 |
|---|---|
| [参数模式.json](references/参数模式.json) | 编写 params.json 时核对字段、类型、枚举及条件约束 |

仅在已授权且配置齐备时运行。

```bash
nextflow run nf-core/dualrnaseq -r d8dcd8acfa6f1c2de933294bc73344d6258ebb42 -params-file params.json
```

模式文件的许可见 [LICENSE](LICENSE)。

## 质控与解释

评估跨物种错配、RNA 比例变化、低丰度病原覆盖和批次，对两种生物分别检查样本质量。

交付双物种表达与 QC；宿主病原表达相关不代表直接调控，归一化需考虑两方组成比例变化。
