# 菌株追踪与传播分析

1. 确认目标物种、样本时间、宿主关系、测序深度和可能的批次或污染来源。
2. 选择核心SNP、基因组ANI或菌株标记方法，并统一参考基因组与可比较区域。
3. 过滤混合定植和低覆盖样本，报告可调用位点比例，不用缺失值制造近似。
4. 用时间、地点和流行病学关系解释遗传距离，设置来自同队列的经验阈值。
5. 输出距离矩阵、聚类或系统树、时间线和证据等级。

遗传近似只能支持潜在关联，不能单独证明传播方向或排除未采样中间宿主。
