# 核糖体足迹与翻译组分析（nf-core/riboseq）

## 识别数据与研究目标

从交付文件与报告中识别 Ribo-seq、建库与核酸酶信息、参考注释及可用的匹配 RNA-seq，明确翻译效率或足迹定位目标。

## 方法选择

根据片段长度和本版本方法处理 rRNA、比对及 P-site 偏移，保留 ORF 注释与计数策略。

## 根据数据确定参数

按读长分层检查三核苷酸周期并估计 P-site 偏移，据此选择足迹范围；翻译效率需核验匹配 RNA 与重复设计，不预设统一的足迹长度窗口。

| 决策与配置 | 处理要求 |
|---|---|
| 事实与缺口 | 先读现有文件和报告；不能据文件名猜实验类型、参考或样本关系；只补问无法核实且会改变分析的背景 |
| 参数来源 | 区分协议必需设置、数据估计、方法默认和研究选择；说明实际取值及理由，不要求用户填写专业参数 |
| 可执行配置 | 仅把已支持的选择映射为当前版本的原生字段；不支持的步骤另行交接，不虚构开关 |
| 阈值复核 | 默认值先评估适用性；依据质控、对照及敏感性检查调整，不能按显著结果数量调参 |

## 质控与解释

检查三核苷酸周期、CDS 富集、起止区域和长度特异偏移，RNA 与 Ribo 样本设计须匹配。

交付足迹、计数和可支持的翻译结果；没有匹配表达与合适模型时不能将足迹变化直接解释为翻译效率变化。
