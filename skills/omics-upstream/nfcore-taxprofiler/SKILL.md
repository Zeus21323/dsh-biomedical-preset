# 宏基因组多方法分类与丰度估计（nf-core/taxprofiler）

## 识别数据与研究目标

从交付文件与报告中识别 shotgun 短/长 reads、样本与数据库表，明确所需分类工具和分类层级，核对宿主过滤目标。

## 方法选择

选取本版本支持的 profiler 与对应数据库，分别保存各方法结果，整合时协调 taxid 和丰度定义。

先核对 [版本约定](references/流程约定.json)。

| 核对项 | 固定范围 |

| 本地运行 | 未进行真实分析运行；不能据本 Skill 文件声称实跑通过 |
| 引擎声明 | `!>=25.10.4`；还需核验 Java、容器和 profile |

## 根据数据确定参数

根据读段类型、目标分类层级和数据库覆盖选择分类器，结合阴性对照与支持量判断低丰度信号；粪便样本身份本身不足以区分扩增子与 shotgun。

| 决策与配置 | 处理要求 |
|---|---|
| 事实与缺口 | 先读现有文件和报告；不能据文件名猜实验类型、参考或样本关系；只补问无法核实且会改变分析的背景 |
| 参数来源 | 区分协议必需设置、数据估计、方法默认和研究选择；说明实际取值及理由，不要求用户填写专业参数 |
| 可执行配置 | 仅把已支持的选择映射为当前版本的原生字段；不支持的步骤另行交接，不虚构开关 |
| 阈值复核 | 默认值先评估适用性；依据质控、对照及敏感性检查调整，不能按显著结果数量调参 |

| 资料 | 使用时机 |
|---|---|
| [参数模式.json](references/参数模式.json) | 编写 params.json 时核对字段、类型、枚举及条件约束 |
| [输入模式-1.json](references/输入模式-1.json) | 准备 databases 对应的样本表或输入文件时读取 |
| [输入模式-2.json](references/输入模式-2.json) | 准备 input 对应的样本表或输入文件时读取 |

仅在已授权且配置齐备时运行。

```bash
nextflow run nf-core/taxprofiler -r 70ecc15e49b4f1fcf79d876643b5d14b65c66178 -params-file params.json
```

模式文件的许可见 [LICENSE](LICENSE)。

## 质控与解释

检查污染、未分类比例、低丰度假阳性和工具分歧，评估参考库构成及近缘物种歧义。

交付分类谱、丰度和 QC；不同工具的读数/丰度不可直接相加，检出病原相关序列不自动证明感染。
