# 稳定同位素示踪与代谢流分析

## 先设计示踪问题

明确要区分的通路、示踪底物与富集度、稳态或动态实验、采样时间、细胞/组织、池大小、重复和候选网络。时间点必须覆盖标记进入和接近平衡的阶段。

## 数据处理

1. 对每个代谢物确认分子式、碳/氮数、峰边界和 isotopologue 覆盖。
2. 校正天然同位素丰度、示踪物纯度及已知杂质，保留校正前后 MID。
3. 检查相邻峰、同位素串扰和质量分辨率；总 MID 与理论碳数不一致时停止解释。
4. 稳态 MFA 只用于已满足同位素稳态的设计；动态数据使用非稳态模型并包含池大小或相应假设。
5. 用重复、残差和置信区间评估通量，标记无法由当前示踪区分的反应。

## 解释边界

标记比例变化既受流量也受池大小和稀释影响。单个代谢物 MID 不能直接等同某条通路通量。

## 交付

交付校正 MID、时间曲线、模型与原子映射、通量和区间、拟合残差、假设及不可识别通量。
