# 宏基因组组装与 MAG 重建

1. 依据样本数量和研究目标选择单样本或联合组装，质控并去除宿主与明显污染读段。
2. 组装后评估N50、总长度、短contig比例与回贴率；不能只凭N50判断质量。
3. 联合覆盖、序列组成和多种分箱器生成候选bin，再进行精炼。
4. 用完整度、污染度、rRNA/tRNA和嵌合信号评价MAG，按明确标准分级。
5. 去冗余、分类并计算平均核苷酸一致性，输出MAG、丰度、分类和质量清单。

所有结论应可追溯到样本和组装版本；低质量MAG不得用于物种命名或精细代谢结论。
