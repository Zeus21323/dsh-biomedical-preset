# 染色质区室与TAD分析

## 开始前

准备同一参考版本、同一bin大小的接触矩阵和重复，记录矩阵平衡方法、有效接触数及辅助活性轨道。若样本深度差异很大，先制定降采样或稳健性检查。

## 执行流程

1. 按染色体计算观察/期望矩阵及相关矩阵，用主成分识别区室；依据GC、基因密度、H3K27ac或表达给PC定向，不能把PC符号本身当A/B标签。
2. 用insulation score、方向性指数或适配工具识别TAD与边界，固定窗口大小、分辨率和边界合并容差。
3. 评估矩阵稀疏度、染色体臂效应、距离衰减、重复相关和边界重现性；低覆盖bin或着丝粒周围单独标记。
4. 条件比较使用共同bin和边界全集，比较连续的区室强度或绝缘强度；只有超过重复波动且方向稳定时才报告区室转换或边界变化。
5. 用不同分辨率、归一化和参数做敏感性分析，并与表达或表观轨道对照但不据此补造边界。

## 交付与解释

交付区室分数与标签、TAD/边界区间、差异强度、重复与参数稳定性。TAD边界依赖分辨率和算法，样本间标签不一致不一定代表真实结构重塑。
