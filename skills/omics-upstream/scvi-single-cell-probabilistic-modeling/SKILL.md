# scVI单细胞概率建模

## 选择正确模型

- 无标签 RNA 计数表征与批次建模使用 scVI。
- 有部分可信标签并需要半监督注释时考虑 scANVI。
- CITE-seq RNA 与蛋白联合建模使用 totalVI。

需要原始整数计数、batch_key、供体、条件、标签和技术协变量；条件不能误填为要消除的批次。

## 训练和验证

1. 检查类别字段、稀有批次和计数层，划分训练与验证细胞，并避免供体泄漏到外部性能评估。
2. 固定软件、架构、随机种子和训练停止规则；保存模型而不只保存潜空间。
3. 查看训练/验证 ELBO、后验和批次混合，同时检查已知细胞类型、稀有群及条件信号是否保留。
4. 比较不同种子或潜变量维数；潜空间变化较大时不要依赖单次 UMAP。
5. 下游差异使用模型支持的方法并在供体层验证，不能直接把细胞后验当独立重复。

## 交付与边界

交付模型、潜变量、所用数据层、分类字段、训练诊断和适用域。生成或去噪表达是模型估计，不等于重新测得的分子数。
