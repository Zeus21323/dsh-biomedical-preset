# 靶向代谢组定量

## 定量资料

取得目标物和 transition、保留时间、定量/定性离子、同位素内标、标准曲线、QC、空白、稀释倍数、样本体积或质量、批次和单位。

## 从峰到浓度

1. 核对定量离子、定性离子比例和保留时间，逐批复核自动积分边界。
2. 评估空白、carryover 和内标峰；峰形或离子比不合格的结果先标记。
3. 根据残差选择线性或非线性及 1/x、1/x² 等权重，保存曲线、回算值和接受标准。
4. 应用内标、稀释及样本量校正；低于 LLOQ、介于 LOD/LLOQ 或高于 ULOQ 分别编码，不向范围外外推。
5. 用低中高 QC 评估准确度、精密度和批内/批间稳定性。

## 交付

输出浓度、单位、积分证据、曲线与残差、QC、内标回收和范围状态。没有标准曲线和合适内标时只能报告相对信号，不能称为绝对定量。

## 缺失与变换边界

半最小值、中位数或 KNN 插补只适用于明确的下游探索矩阵，不能修改用于 LOD/LLOQ 判定和正式浓度报告的原始定量结果。任何 TIC、中位数或对数变换都应产生独立衍生表，并记录输入表、处理顺序、因子和零值规则，避免把相对信号处理误写成绝对定量。
