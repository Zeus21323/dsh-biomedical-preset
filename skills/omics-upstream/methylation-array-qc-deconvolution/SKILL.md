# 甲基化芯片预处理与细胞组成校正

先确认芯片平台、IDAT 是否齐全、样本表、组织类型、参考基因组、性别信息和实验板布局。不能从已经丢失探针与控制信息的汇总表假装完成原始芯片质控。

从检测 P 值、珠子数、控制探针、强度分布、性别一致性和遗传指纹检查样本；处理交叉反应探针、SNP 影响探针和性染色体探针时必须根据研究问题记录规则。归一化方法应与组织、平台和下游目标匹配，不能为了消除批次而消除真实生物分组。

细胞组成估计必须选择与组织和年龄相符的参考。需要具体过滤、M/B 值使用和去卷积时读取[芯片质控与校正规范](references/芯片质控与校正规范.md)。如运行环境具备 R、EpiDISH 和相应参考数据，可运行 `scripts/cell_deconvolution.R`；维护时按脚本内置合成数据自检。

交付样本和探针排除表、归一化前后诊断、批次评估、细胞比例及其不确定性。EWAS 模型中细胞比例和技术协变量的处理必须预先说明，不能只报告校正后的显著位点。
