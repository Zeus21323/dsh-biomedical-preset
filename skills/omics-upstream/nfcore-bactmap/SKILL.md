# 细菌参考比对与系统发育（nf-core/bactmap）

## 识别数据与研究目标

从交付文件与报告中识别细菌全基因组 reads、参考及样本信息，评估参考与待比较菌株的距离。

## 方法选择

按映射式流程获得可比位点并建立该版本支持的系统发育结果，明确重复/重组及缺失区域处理。

先核对 [版本约定](references/流程约定.json)。

| 核对项 | 固定范围 |
|---|---|
| 上游版本 | `1.0.0`；`834642d8ac150ca10d705833223e7bcf15efc210` |
| 上游维护 | 未归档；使用这里固定的源码，不自动跟随新版本 |
| 本地运行 | 未进行真实分析运行；不能据本 Skill 文件声称实跑通过 |
| 引擎声明 | `!>=21.04.0`；还需核验 Java、容器和 profile |

## 根据数据确定参数

根据参考距离与共同可调用区域设定位点质量和缺失过滤；重组与重复区域分别评估，参考过远造成的差异不能当作真实菌株距离。

| 决策与配置 | 处理要求 |
|---|---|
| 事实与缺口 | 先读现有文件和报告；不能据文件名猜实验类型、参考或样本关系；只补问无法核实且会改变分析的背景 |
| 参数来源 | 区分协议必需设置、数据估计、方法默认和研究选择；说明实际取值及理由，不要求用户填写专业参数 |
| 可执行配置 | 仅把已支持的选择映射为当前版本的原生字段；不支持的步骤另行交接，不虚构开关 |
| 阈值复核 | 默认值先评估适用性；依据质控、对照及敏感性检查调整，不能按显著结果数量调参 |

| 资料 | 使用时机 |
|---|---|
| [参数模式.json](references/参数模式.json) | 编写 params.json 时核对字段、类型、枚举及条件约束 |

仅在已授权且配置齐备时运行。

```bash
nextflow run nf-core/bactmap -r 834642d8ac150ca10d705833223e7bcf15efc210 -params-file params.json
```

模式文件的许可见 [LICENSE](LICENSE)。

## 质控与解释

检查覆盖、混样、参考偏倚和核心位点数量，评估低质量样本对树形的影响。

交付比对、变异/比对矩阵与树及 QC；近缘聚类不单独证明直接传播，需要流行病学和采样证据。
