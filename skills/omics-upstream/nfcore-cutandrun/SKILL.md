# CUT&RUN与CUT&Tag染色质定位（nf-core/cutandrun）

## 识别数据与研究目标

记录 CUT&RUN/CUT&Tag 类型、靶标、IgG、spike-in、重复和参考，区分不同实验的背景与片段结构。

## 方法选择

选择适用的比对、片段处理和 peak caller，按真实 spike-in 来源确定归一化；不能仅因有外源 reads 就假定可做绝对比较。

## 根据数据确定参数

根据实验化学、靶标、片段与 IgG 背景选择过滤和峰调用；只有设计和观测支持时使用 spike-in 校正，局部低信号不能一律用更宽松阈值补偿。

| 决策与配置 | 处理要求 |
|---|---|
| 事实与缺口 | 先读现有文件和报告；不能据文件名猜实验类型、参考或样本关系；只补问无法核实且会改变分析的背景 |
| 参数来源 | 区分协议必需设置、数据估计、方法默认和研究选择；说明实际取值及理由，不要求用户填写专业参数 |
| 可执行配置 | 仅把已支持的选择映射为当前版本的原生字段；不支持的步骤另行交接，不虚构开关 |
| 阈值复核 | 默认值先评估适用性；依据质控、对照及敏感性检查调整，不能按显著结果数量调参 |

| 资料 | 使用时机 |

## 质控与解释

核验片段大小、靶标富集、对照背景、spike-in 稳定性与重复一致性。

交付峰、轨道和 QC 及归一化依据；低背景技术仍可能产生非特异富集，差异结论受重复和对照质量限制。
