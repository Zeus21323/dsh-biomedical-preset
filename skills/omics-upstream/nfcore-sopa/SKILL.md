# 空间组学图像与分子数据分析（nf-core/sopa）

## 识别数据与研究目标

明确空间技术、图像、分子/计数数据、像素/物理坐标和样本组织信息，检查 Sopa 支持的数据格式。

## 方法选择

按本版本的分割、聚合和空间分析组件处理，保留跨图像层和表达层的坐标转换。

先核对 [版本约定](references/流程约定.json)。

| 核对项 | 固定范围 |
|---|---|
| 上游版本 | `1.0.1`；`0b959963a3984ff78725209113d9ecdb78cef0b6` |
| 上游维护 | 未归档；使用这里固定的源码，不自动跟随新版本 |
| 本地运行 | 未进行真实分析运行；不能据本 Skill 文件声称实跑通过 |
| 引擎声明 | `!>=25.10.4`；还需核验 Java、容器和 profile |

## 根据数据确定参数

按空间平台、组织形态、像素尺度与分子密度选择切块、分割和聚合设置；代表性区域校准后保留坐标变换，避免不同层的尺度误配。

| 决策与配置 | 处理要求 |
|---|---|
| 事实与缺口 | 先读现有文件和报告；不能据文件名猜实验类型、参考或样本关系；只补问无法核实且会改变分析的背景 |
| 参数来源 | 区分协议必需设置、数据估计、方法默认和研究选择；说明实际取值及理由，不要求用户填写专业参数 |
| 可执行配置 | 仅把已支持的选择映射为当前版本的原生字段；不支持的步骤另行交接，不虚构开关 |
| 阈值复核 | 默认值先评估适用性；依据质控、对照及敏感性检查调整，不能按显著结果数量调参 |

| 资料 | 使用时机 |
|---|---|
| [参数模式.json](references/参数模式.json) | 编写 params.json 时核对字段、类型、枚举及条件约束 |
| [输入模式-1.json](references/输入模式-1.json) | 准备 input 对应的样本表或输入文件时读取 |

仅在已授权且配置齐备时运行。

```bash
nextflow run nf-core/sopa -r 0b959963a3984ff78725209113d9ecdb78cef0b6 -params-file params.json
```

模式文件的许可见 [LICENSE](LICENSE)。

## 质控与解释

验证分割边界、分子归属、组织外背景和分块边缘，检查不同区域结果是否一致。

交付空间分析对象、细胞/区域特征与 QC；计算分割和聚合结果需要在原始图像上核验，不直接认定细胞互作。
