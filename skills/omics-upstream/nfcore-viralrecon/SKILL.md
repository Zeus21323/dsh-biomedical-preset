# 病毒共识组装与变异分析（nf-core/viralrecon）

## 识别数据与研究目标

确认病毒、平台、扩增子或非靶向策略、引物方案和参考，核对样本与对照。

## 方法选择

按支持的实验模式进行 reads 处理、引物修剪、共识与变异调用，固定 primer scheme 和数据库版本。

## 根据数据确定参数

先核验平台、扩增子或非靶向模式与引物方案，再按覆盖和错误特征选择共识及变异条件；缺覆盖区域保留未知，不能以参考碱基补成确定结果。

| 决策与配置 | 处理要求 |
|---|---|
| 事实与缺口 | 先读现有文件和报告；不能据文件名猜实验类型、参考或样本关系；只补问无法核实且会改变分析的背景 |
| 参数来源 | 区分协议必需设置、数据估计、方法默认和研究选择；说明实际取值及理由，不要求用户填写专业参数 |
| 可执行配置 | 仅把已支持的选择映射为当前版本的原生字段；不支持的步骤另行交接，不虚构开关 |
| 阈值复核 | 默认值先评估适用性；依据质控、对照及敏感性检查调整，不能按显著结果数量调参 |

| 资料 | 使用时机 |

```bash
nextflow run nf-core/viralrecon -r 395079f1d24dce731ac22e03d7a5e71f110103fc -params-file params.json
```

## 质控与解释

检查扩增子 dropout、深度、污染、混合感染与链偏倚，掩蔽不足覆盖区域而非填充参考碱基。

交付共识序列、变异、覆盖和 QC；序列质量不直接证明感染性，谱系/传播解释需额外证据。
