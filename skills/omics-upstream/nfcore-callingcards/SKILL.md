# Calling Cards转录调控记录分析（nf-core/callingcards）

## 识别数据与研究目标

核对 calling cards 技术、插入位点数据、参考、实验/对照和条形码设计，明确记录目标及生物学重复。

## 方法选择

依据本版本支持的读段处理和插入分析方法组织数据，区分技术插入热点与目标蛋白相关富集。

先核对 [版本约定](references/流程约定.json)。

| 核对项 | 固定范围 |
|---|---|
| 上游版本 | `1.0.0`；`20b66e785a822028eaa125583aad0747d55bba61` |
| 上游维护 | 未归档；使用这里固定的源码，不自动跟随新版本 |
| 本地运行 | 未进行真实分析运行；不能据本 Skill 文件声称实跑通过 |
| 引擎声明 | `!>=23.04.0`；还需核验 Java、容器和 profile |

## 根据数据确定参数

根据条形码设计、背景插入与重复一致性选择插入合并和富集条件；对照缺失时收窄证据解释，不把所有插入热点作为靶蛋白结合。

| 决策与配置 | 处理要求 |
|---|---|
| 事实与缺口 | 先读现有文件和报告；不能据文件名猜实验类型、参考或样本关系；只补问无法核实且会改变分析的背景 |
| 参数来源 | 区分协议必需设置、数据估计、方法默认和研究选择；说明实际取值及理由，不要求用户填写专业参数 |
| 可执行配置 | 仅把已支持的选择映射为当前版本的原生字段；不支持的步骤另行交接，不虚构开关 |
| 阈值复核 | 默认值先评估适用性；依据质控、对照及敏感性检查调整，不能按显著结果数量调参 |

| 资料 | 使用时机 |
|---|---|
| [参数模式.json](references/参数模式.json) | 编写 params.json 时核对字段、类型、枚举及条件约束 |
| [输入模式-1.json](references/输入模式-1.json) | 准备 input 对应的样本表或输入文件时读取 |

仅在已授权且配置齐备时运行。

```bash
nextflow run nf-core/callingcards -r 20b66e785a822028eaa125583aad0747d55bba61 -params-file params.json
```

模式文件的许可见 [LICENSE](LICENSE)。

## 质控与解释

检查插入复杂度、位置偏倚、对照背景和重复一致性，考虑转座偏好与读段重复。

输出插入/富集结果和实验记录；长时间累积的插入证据不能简单解释为瞬时 ChIP-seq 占据。
