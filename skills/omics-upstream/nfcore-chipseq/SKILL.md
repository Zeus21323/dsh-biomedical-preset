# ChIP-seq富集区域与差异分析（nf-core/chipseq）

## 识别数据与研究目标

明确转录因子或组蛋白标记、input/IgG 对照、重复、单双端与参考；据目标选择窄峰或宽峰分析。

## 方法选择

按本版本执行比对、过滤、peak calling 与已支持的差异步骤，保留实验对照关系和统一峰集合的生成方式。

先核对 [版本约定](references/流程约定.json)。

| 核对项 | 固定范围 |
|---|---|
| 上游版本 | `2.1.0`；`76e2382b6d443db4dc2396e6831d1243256d80b0` |
| 上游维护 | 未归档；使用这里固定的源码，不自动跟随新版本 |
| 本地运行 | 未进行真实分析运行；不能据本 Skill 文件声称实跑通过 |
| 引擎声明 | `!>=23.04.0`；还需核验 Java、容器和 profile |

## 根据数据确定参数

由靶标生物学、片段分布、对照质量与重复决定宽窄峰和背景模型；结合富集与重复一致性评估峰阈值，不能以得到更多峰作为调参目标。

| 决策与配置 | 处理要求 |
|---|---|
| 事实与缺口 | 先读现有文件和报告；不能据文件名猜实验类型、参考或样本关系；只补问无法核实且会改变分析的背景 |
| 参数来源 | 区分协议必需设置、数据估计、方法默认和研究选择；说明实际取值及理由，不要求用户填写专业参数 |
| 可执行配置 | 仅把已支持的选择映射为当前版本的原生字段；不支持的步骤另行交接，不虚构开关 |
| 阈值复核 | 默认值先评估适用性；依据质控、对照及敏感性检查调整，不能按显著结果数量调参 |

| 资料 | 使用时机 |
|---|---|
| [参数模式.json](references/参数模式.json) | 编写 params.json 时核对字段、类型、枚举及条件约束 |
| [输入模式-1.json](references/输入模式-1.json) | 准备 input 对应的样本表或输入文件时读取 |

仅在已授权且配置齐备时运行。

```bash
nextflow run nf-core/chipseq -r 76e2382b6d443db4dc2396e6831d1243256d80b0 -params-file params.json
```

模式文件的许可见 [LICENSE](LICENSE)。

## 质控与解释

检查富集、FRiP、片段分布、重复率及样本一致性，避免把测序深度差异当作结合变化。

交付峰、信号和适用的差异结果；结合或修饰富集不能单独证明对邻近基因的调控因果。
