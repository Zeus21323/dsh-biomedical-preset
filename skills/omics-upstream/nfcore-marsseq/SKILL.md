# MARS-seq文库预处理与计数（nf-core/marsseq）

## 识别数据与研究目标

从交付文件与报告中识别 MARS-seq v2 读段结构、well/plate 条形码、UMI、参考和样本映射，核对文库拆分阶段。

## 方法选择

根据实际协议处理样本条形码与分子标签，按本版本生成表达和可用 velocity 输入，避免套用 10x 的 read structure。

先核对 [版本约定](references/流程约定.json)。

| 核对项 | 固定范围 |
|---|---|
| 上游版本 | `1.0.3`；`b02ede773092f8a8a5999400acda6894d51b4d26` |
| 上游维护 | 未归档；使用这里固定的源码，不自动跟随新版本 |
| 本地运行 | 未进行真实分析运行；不能据本 Skill 文件声称实跑通过 |
| 引擎声明 | `!>=23.04.0`；还需核验 Java、容器和 profile |

## 根据数据确定参数

从实际 v2 协议核对条形码与 UMI 结构，再以孔位背景和分子复杂度选择过滤；低分子数先排查空孔，不能套用液滴式预期细胞数。

| 决策与配置 | 处理要求 |
|---|---|
| 事实与缺口 | 先读现有文件和报告；不能据文件名猜实验类型、参考或样本关系；只补问无法核实且会改变分析的背景 |
| 参数来源 | 区分协议必需设置、数据估计、方法默认和研究选择；说明实际取值及理由，不要求用户填写专业参数 |
| 可执行配置 | 仅把已支持的选择映射为当前版本的原生字段；不支持的步骤另行交接，不虚构开关 |
| 阈值复核 | 默认值先评估适用性；依据质控、对照及敏感性检查调整，不能按显著结果数量调参 |

| 资料 | 使用时机 |
|---|---|
| [参数模式.json](references/参数模式.json) | 编写 params.json 时核对字段、类型、枚举及条件约束 |

仅在已授权且配置齐备时运行。

```bash
nextflow run nf-core/marsseq -r b02ede773092f8a8a5999400acda6894d51b4d26 -params-file params.json
```

模式文件的许可见 [LICENSE](LICENSE)。

## 质控与解释

检查孔间污染、UMI 饱和、基因检出、重复和 spliced/unspliced 计数支持。

交付细胞/孔级计数及 QC；生成 velocity 所需计数不代表已推断可靠的细胞命运方向。
