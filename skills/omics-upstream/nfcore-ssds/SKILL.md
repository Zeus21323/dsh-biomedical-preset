# 历史单链DNA测序富集分析（nf-core/ssds）

## 识别数据与研究目标

从交付文件与报告中识别历史 SSDS 数据、实验靶标、参考和对照，核查特殊读段结构及固定版本。

## 方法选择

依据归档代码确认单链 DNA 信号处理步骤与过滤选项，避免误用普通 DNA-seq 的默认比对解释。

先核对 [版本约定](references/流程约定.json)。

| 核对项 | 固定范围 |
|---|---|
| 上游版本 | `dev`；`0cc3ee6ac2d3d8ed309b74e4ae61bad4006362cc` |
| 上游维护 | 已归档；用于明确的历史分析或复现审查 |
| 本地运行 | 未进行真实分析运行；不能据本 Skill 文件声称实跑通过 |
| 引擎声明 | `!>=21.10.3`；还需核验 Java、容器和 profile |

## 根据数据确定参数

由原实验读段结构与靶标确定过滤和峰证据要求；对照特殊信号与归档代码核验结果，不把普通 DNA 覆盖的默认判据套用到单链富集。

| 决策与配置 | 处理要求 |
|---|---|
| 事实与缺口 | 先读现有文件和报告；不能据文件名猜实验类型、参考或样本关系；只补问无法核实且会改变分析的背景 |
| 参数来源 | 区分协议必需设置、数据估计、方法默认和研究选择；说明实际取值及理由，不要求用户填写专业参数 |
| 可执行配置 | 仅把已支持的选择映射为当前版本的原生字段；不支持的步骤另行交接，不虚构开关 |
| 阈值复核 | 默认值先评估适用性；依据质控、对照及敏感性检查调整，不能按显著结果数量调参 |

| 资料 | 使用时机 |
|---|---|
| [参数模式.json](references/参数模式.json) | 编写 params.json 时核对字段、类型、枚举及条件约束 |
| [输入模式-1.json](references/输入模式-1.json) | 准备 input 对应的样本表或输入文件时读取 |

仅在已授权且配置齐备时运行。

```bash
nextflow run nf-core/ssds -r 0cc3ee6ac2d3d8ed309b74e4ae61bad4006362cc -params-file params.json
```

模式文件的许可见 [LICENSE](LICENSE)。

## 质控与解释

评估目标富集、链偏倚、重复和对照背景，检查热点是否受低复杂度或比对歧义影响。

交付该历史版本可产生的富集结果及复现记录；SSDS 热点不能在缺少实验背景时直接解释为所有类型的 DNA 损伤。
