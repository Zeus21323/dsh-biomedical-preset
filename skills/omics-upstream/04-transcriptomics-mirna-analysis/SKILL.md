# 非编码RNA分析

## 开始前

先确认建库捕获的是小RNA、poly(A) RNA、总RNA还是RNase R处理样本，并核对链特异性、读长、参考与非编码RNA注释。不同RNA类别必须使用各自可观测的证据。

## 执行流程

1. miRNA数据先精确去除3'接头，按成熟体、前体和isomiR规则比对计数，检查读长峰与多重比对。
2. lncRNA使用链特异表达或转录本组装，过滤明显蛋白编码潜能时保留所用证据与阈值，避免删除已知双功能转录本。
3. circRNA要求跨反向剪接连接的高质量读段，结合线性转录本背景、RNase R或多调用器支持；单个junction读段不能作强证据。
4. 每一类别分别建立计数矩阵和低表达过滤规则，再按样本设计做差异分析，不混用miRNA、基因和circRNA的归一化假设。
5. 靶标或ceRNA关系整合序列预测、负相关、结合数据与扰动证据，明确哪些只是计算候选。

## 交付与解释

交付分RNA类别的表达或事件表、差异结果、结构与读段证据、候选靶标和质量限制。建库方式未捕获某类RNA时，缺少信号不能解释为生物学缺失。
