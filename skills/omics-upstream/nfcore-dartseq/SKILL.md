# DART-seq RNA m6A候选检测（nf-core/dartseq）

## 识别数据与研究目标

从交付文件与报告中识别 DART-seq 或本版本支持的 RNA 数据、编辑体系、对照、参考和样本关系，确认需要的突变/表达对照。

## 方法选择

按实际实现检测与修饰相关的编辑信号，区分序列变异、RNA editing、比对错误和实验诱导信号。

先核对 [版本约定](references/流程约定.json)。

| 核对项 | 固定范围 |
|---|---|
| 上游版本 | `dev`；`bad48a26b500363959f09afb804d0dd09d2a1431` |
| 上游维护 | 开发版本；按当前代码实际实现的范围使用 |
| 本地运行 | 未进行真实分析运行；不能据本 Skill 文件声称实跑通过 |
| 引擎声明 | `!>=25.04.0`；还需核验 Java、容器和 profile |

## 根据数据确定参数

根据未处理或体系对照估计背景编辑和错误，再设置位点覆盖与差异证据；基因组变异及比对伪影先排查，避免使用统一编辑比例宣称修饰。

| 决策与配置 | 处理要求 |
|---|---|
| 事实与缺口 | 先读现有文件和报告；不能据文件名猜实验类型、参考或样本关系；只补问无法核实且会改变分析的背景 |
| 参数来源 | 区分协议必需设置、数据估计、方法默认和研究选择；说明实际取值及理由，不要求用户填写专业参数 |
| 可执行配置 | 仅把已支持的选择映射为当前版本的原生字段；不支持的步骤另行交接，不虚构开关 |
| 阈值复核 | 默认值先评估适用性；依据质控、对照及敏感性检查调整，不能按显著结果数量调参 |

| 资料 | 使用时机 |
|---|---|
| [参数模式.json](references/参数模式.json) | 编写 params.json 时核对字段、类型、枚举及条件约束 |
| [输入模式-1.json](references/输入模式-1.json) | 准备 input 对应的样本表或输入文件时读取 |

仅在已授权且配置齐备时运行。

```bash
nextflow run nf-core/dartseq -r bad48a26b500363959f09afb804d0dd09d2a1431 -params-file params.json
```

模式文件的许可见 [LICENSE](LICENSE)。

## 质控与解释

检查覆盖、编辑比例、链偏倚、表达变化与背景位点，控制低覆盖产生的高比例假象。

交付候选位点、编辑证据和 QC；编辑信号是 m6A 的间接读出，不能作为每个位点绝对修饰率。
