# 单细胞跨队列整合与元分析

跨队列任务不是把全部细胞合并后做一次批次校正。先为每个研究记录供者、组织、平台、疾病定义、处理、细胞注释和原始质控差异，建立可比较的共同终点。细胞是观测单位，供者和研究才是主要重复层级。

整合表示可用于统一注释和可视化，但效应估计应尽量在研究内完成，再在研究层进行固定效应、随机效应或分层模型汇总。细胞类型缺失、注释粒度不一致和病例定义差异应作为结构性缺失处理，不能简单填零。

需要制定 harmonization、效应汇总和异质性分析时读取[跨研究统计规范](references/跨研究统计规范.md)。交付队列对照表、统一细胞本体、研究内效应、合并效应、异质性、影响分析和不能合并的原因。

批次混合良好不等于生物结果可复现。任何泛化结论都应说明支持它的独立研究数，而不只是总细胞数。

已有逐研究效应/标准误，或独立定义的有序轴和供体级状态值时，读取[跨队列状态复现执行契约](references/跨队列状态复现执行契约.md)，代理配置并运行 `scripts/analyze_state_replication.py`。实际执行DL汇总或探索性阶跃扫描，不将分别扫描写成冻结阈值的外部验证。交付全表、图、日志和含冲突及限制的Markdown，并打开图件复核。
