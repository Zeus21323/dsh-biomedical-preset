# 跨队列状态复现（StateShiftAtlas方向）

## 何时进入

“换个队列还成立吗”“细胞什么时候开始变”“不同分期是否一致”“整合后结论相反”时，检查独立研究、供体、状态和有依据的时间/分期轴。整合UMAP不证明转变，组织或平台差异不能靠强行合并解决。

## 两个模式

python scripts/analyze_state_replication.py --config /外部目录/state.json --out-dir /外部目录/state-001

mode=meta：table列study,feature,effect,se,independence_source。研究×特征唯一，SE>0，每特征至少3个独立研究。需同量纲、同方向、可比较终点；不能把p当效应、SD当SE。独立性来源由代理核验。实际计算DL随机效应、Q/I²/tau²、正态近似95%区间及逐研究剔除结果。研究少时区间和异质性可能不稳，重要结论需适当稳健推断复核；这里没有实现HKSJ。完整meta_results、leave_one_out、study_effects及森林图。

mode=ordered_shift：table列study,unit,feature,axis,value，study×unit×feature唯一，同供体一个轴位置；axis_reason说明独立定义轴，min_units_per_side（2–10000）、permutations（99–10000）、seed必填。逐研究特征扫描允许的单阶跃分界，以两段均值SSE改进为统计量；每次置换重做所有候选扫描，再对全部研究×特征BH。输出分界相邻观测范围、效应和p/q；常数特征no_variation。

轴由响应数据学习、重复测量、重要混杂或不满足交换性时，不用当前置换。分界范围不是置信区间。逐队列重新扫描属于探索，不是独立阈值验证；复现需冻结发现集轴/方向/分界再验证，不能把阶段关联写成因果转变。

## 审核与边界

报告研究/供体数、方向冲突、缺失状态、异质性及剔除影响。整合表示用于展示/标注，不用全细胞一次检验代替供体推断。本脚本不建立StateShiftAtlas，不自动状态本体对齐，也不冒充新颖变点算法。

依据：[statsmodels combine_effects](https://www.statsmodels.org/stable/generated/statsmodels.stats.meta_analysis.combine_effects.html)、[SciPy permutation_test](https://docs.scipy.org/doc/scipy/reference/generated/scipy.stats.permutation_test.html)。

## 代理负责准备、执行和复核

用户不需要写JSON或命令。先读取文件与元数据，确认问题、独立统计单位、对比和出处；只用普通话补问确实无法核实且改变设计的事实。只有疾病/基因/毕业愿望时先回公共研究设计；缺输入交付缺口清单，不用模拟数据冒充结果。

代理在用户指定的仓库外目录创建配置。所有配置必填question（实际问题）、parameter_reason（参数与设计依据）、evidence_notes（来源、已核验事实与不确定性）；可选font为覆盖图中文字的已安装字体。参数不得由显著性倒推。路径相对配置文件解析。CSV/TSV为UTF-8、唯一表头，TSV以.tsv结尾；保留原始数据，不自行覆盖。每次指定新输出目录。

Python 3.11+，依赖numpy、pandas、scipy、matplotlib。代理在隔离环境准备并记录版本，不要求新手安装。各适配器自包含，无跨Skill脚本依赖，不需要根目录packages。输入1GB保护上限不等于内存保证；失败非零退出，已有输出目录则留下失败记录，不把残留产物视作成功。

交付完整TSV、summary.json、run_record.json、report.md、可编辑PDF/SVG、400 dpi PNG和图注。作图数据来自对应完整结果表；图的截取规则必须说明。配置、输入/输出哈希、版本和状态均留痕。脚本摘要不等于科学论文：代理需据真实数字补写观察、样本量、效应/区间、阴性/冲突、替代解释、证据等级和下一步，关联具体表行和图件。描述性模式不能声称显著。

打开PNG或渲染PDF，按最终版面检查缺字、截断、图例、颜色、单位、比例、方向和区间；重要发现回查输入。分辨率不是论文质量保证。原始记录保持“需视觉与科学复核”状态；复核可另存review.md，不篡改运行记录。结果、缓存、测试数据和日志只放仓库外。本地适配器不代表后台数据库或未实现的论文方法已完成。
