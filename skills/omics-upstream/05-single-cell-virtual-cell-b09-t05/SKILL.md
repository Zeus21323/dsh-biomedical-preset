# 单细胞药物响应模拟

## 问题与模型域

明确药物及结构/稳定标识、剂量、暴露时间、目标细胞类型、预期终点和可用对照。需要模型训练数据的化合物、细胞、剂量和时间覆盖，不能只提供模型名称。

## 预测流程

1. 将目标细胞状态与训练域比较，量化细胞、药物和条件的外推距离。
2. 匹配未处理/溶剂对照，区分表达变化、细胞死亡和细胞组成改变。
3. 输出每个细胞群的预测分布或不确定性，而不是只给平均差异基因。
4. 用已知靶点、通路方向、剂量关系和留出扰动验证；新药或新细胞群单独标记外推。
5. 比较简单签名匹配基线与复杂模型，确认增益不是批次或训练泄漏。

## 排序与交付

按效应、置信度、外推风险和可实验性排序药物—细胞群组合，给出候选 biomarker 和验证设计。模拟结果不等于药效、毒性或临床反应，不能替代真实剂量实验。
