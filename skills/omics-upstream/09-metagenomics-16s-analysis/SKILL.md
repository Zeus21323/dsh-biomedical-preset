# 16S 与 ITS 扩增子分析

1. 确认标记区段、引物、单双端布局、阴性对照和分组信息；不清楚时先询问，不能把16S与ITS参考库混用。
2. 检查读长质量、接头和引物残留，再依据质量曲线设定截断位置。
3. 用DADA2或同类方法学习误差、去噪、合并和去嵌合体，生成ASV表，不默认聚类成OTU。
4. 选用与扩增区域匹配的SILVA或UNITE版本进行分类注释，并记录数据库版本和置信阈值。
5. 报告各步保留率、低深度样本、阴性对照污染信号和未注释比例。

需要用 QIIME 2 处理双端扩增子时，先读取[QIIME2工件与参数](references/QIIME2工件与参数.md)，再运行 `scripts/run_qiime2_amplicon.sh`。先用 `--dry-run` 审查导入格式、DADA2 截断长度和分类器；维护脚本时运行 `scripts/test_run_qiime2_amplicon.sh`。脚本不会替用户从质量曲线猜截断参数。

输出ASV丰度表、分类表、代表序列、质控摘要及可复现参数；除非用户明确要求，不把相对丰度差异解释为绝对菌量变化。

## DADA2 与分类器分流

原生 R 环境可采用 DADA2 完成过滤、误差学习、去噪、合并与去嵌合；需要 QIIME 2 工件互操作、可视化或现成分类器时使用 QIIME 2 路线。分类器的训练区段、方向和参考版本必须匹配引物区域。每个样本输出原始、过滤、去噪、合并和非嵌合 read 数，不允许只保留最终 ASV 表。
