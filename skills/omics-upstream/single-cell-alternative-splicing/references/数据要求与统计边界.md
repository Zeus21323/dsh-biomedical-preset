# 数据要求与统计边界

## 平台能力

| 数据类型 | 适合任务 | 主要限制 |
|---|---|---|
| 3'或5'端 droplet | 剪接连接或内含子信号的有限比较 | 转录本覆盖偏斜、单细胞稀疏 |
| Smart-seq 类全长数据 | 外显子和事件级剪接 | 细胞数通常较少 |
| 长读长单细胞 | 全长异构体和新转录本 | 错误率、成本和深度限制 |
| 单核 RNA-seq | 内含子保留和核内转录 | 与全细胞数据不可直接等同 |

## 统计原则

- 先定义可检测事件集合，再做多重检验。
- 供者是生物重复；大量细胞不能替代供者数。
- 可使用 pseudobulk、分层模型或 beta-binomial 类方法处理覆盖和重复。
- 同时报告效应大小、覆盖度和显著性。
- 与基因表达变化共同检查，避免把低表达造成的缺失误认作剪接转换。
