# 单细胞可变剪接分析

先判断数据是否具有足够的读长、测序深度和比对信息。普通 3' 端 droplet 数据对全转录本剪接的覆盖有限，不能按 bulk RNA-seq 的事件检出能力承诺结果；全长单细胞和长读长数据更适合异构体分析。

使用保留剪接连接信息的比对结果，统一基因注释和参考版本。事件量化应报告覆盖读段、可检测细胞和 PSI 或等价指标；过滤极低覆盖事件，并把供者、批次、细胞类型和测序深度纳入比较。若研究细胞状态，优先在同一细胞类型内比较，避免把细胞组成变化误认为剪接变化。

选择事件、聚合层级和统计模型时读取[数据要求与统计边界](references/数据要求与统计边界.md)。交付可检测事件清单、覆盖度、差异剪接效应、供者层重复性、功能注释和无法可靠检测的事件类别。

spliced/unspliced 计数主要服务 RNA velocity，不等同于完整可变剪接分析；两者应使用不同的统计目标和解释语言。

需要把已定量事件与长读长或跨队列异构体证据衔接时，整理供体、细胞类型、来源、注释、支持量和可测性，条件性交给“转录组学”Plugin中“可变剪接分析”的异构体证据整合分支；不在此重复维护同一脚本。相关Skill未安装时说明当前不可执行范围。局部junction、全长RNA和蛋白机制不属于同一级证据。
