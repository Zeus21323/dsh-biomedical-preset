# 微生物功能与天然产物基因筛查（nf-core/funcscan）

## 识别数据与研究目标

从交付文件与报告中识别基因组/MAG 等序列、物种背景及目标功能，明确筛查天然产物、抗菌或其他基因集合的范围。

## 方法选择

按本版本支持的注释/筛查工具组合识别候选，追踪数据库、模型和 contig 上下文。

先核对 [版本约定](references/流程约定.json)。

| 核对项 | 固定范围 |
|---|---|
| 上游版本 | `4.0.0`；`aee3dc965eb0c77267435544dda30da858763913` |
| 上游维护 | 未归档；使用这里固定的源码，不自动跟随新版本 |
| 本地运行 | 未进行真实分析运行；不能据本 Skill 文件声称实跑通过 |
| 引擎声明 | `!>=25.10.4`；还需核验 Java、容器和 profile |

## 根据数据确定参数

按候选功能的模型覆盖、序列完整性与基因邻域选择筛选条件；边缘命中分级保留，不能把部分结构域命中当作完整生物合成系统。

| 决策与配置 | 处理要求 |
|---|---|
| 事实与缺口 | 先读现有文件和报告；不能据文件名猜实验类型、参考或样本关系；只补问无法核实且会改变分析的背景 |
| 参数来源 | 区分协议必需设置、数据估计、方法默认和研究选择；说明实际取值及理由，不要求用户填写专业参数 |
| 可执行配置 | 仅把已支持的选择映射为当前版本的原生字段；不支持的步骤另行交接，不虚构开关 |
| 阈值复核 | 默认值先评估适用性；依据质控、对照及敏感性检查调整，不能按显著结果数量调参 |

| 资料 | 使用时机 |
|---|---|

```bash
nextflow run nf-core/funcscan -r aee3dc965eb0c77267435544dda30da858763913 -params-file params.json
```

模式文件的许可见 [LICENSE](LICENSE)。

## 质控与解释

检查基因组完整性、片段化、预测边界及同源阈值，避免把短片段命中判作完整功能簇。

交付功能候选及序列证据；计算筛查不能证明产物被表达、化合物身份或实验抗菌活性。
