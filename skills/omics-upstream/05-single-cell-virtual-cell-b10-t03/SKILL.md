# G&T-seq基因组与转录组联合分析

G&T-seq 的关键是同一细胞 DNA 与 RNA 的可靠配对，而不是把两个独立单细胞实验事后相关。开始时核对细胞条码映射、DNA/RNA 文库关系、扩增方法、批次、双细胞和样本身份，保留失败细胞的原因。

DNA 侧评估覆盖均一性、等位基因掉落、拷贝数和可检测变异；RNA 侧评估基因数、UMI、线粒体比例、环境 RNA 和表达状态。联合分析应显式区分“检测不到”与“真实阴性”，并把 DNA 覆盖和 RNA 表达可检测性纳入模型。

需要设计配对表、过滤门槛和变异—表达关联时读取[联合分析规范](references/联合分析规范.md)。交付细胞级配对清单、双模态质控、克隆或 CNV 状态、表达状态、变异—表达关联及其覆盖度限制。

同一细胞关联可以增强时间和克隆关系解释，但仍不能自动证明某个变异直接造成表达变化。低覆盖单细胞 DNA 结果必须用区段或克隆层证据稳定化。
