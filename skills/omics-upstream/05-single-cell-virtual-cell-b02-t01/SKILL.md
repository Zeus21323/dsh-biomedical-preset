# 双细胞检测

## 先估计风险

需要每个样本的上样细胞数、平台与回收量、原始计数和初步细胞群。预期双细胞率应按样本和装载量估计，不能全项目套一个固定比例。

## 判定流程

1. 在每个捕获批次独立运行 Scrublet、scDblFinder、DoubletFinder 等，并保存连续分数。
2. 结合人工模拟双细胞、UMI/基因数、互斥谱系 marker 共表达和局部邻域判断异型双细胞。
3. 同型双细胞更难检测，检查极高计数和亚群内分数分布，不声称完全清除。
4. 对真实过渡、吞噬、细胞接触或活化群保留“不确定”标记，避免仅因混合 marker 删除。
5. 比较剔除前后的群体组成、稀有群和供体差异。

## 交付

提供每细胞分数、阈值、预计率、保留/剔除/不确定清单及方法一致性。双细胞工具输出是筛查证据，不应未经复核自动删除全部高分细胞。
