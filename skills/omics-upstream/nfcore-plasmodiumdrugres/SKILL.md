# 疟原虫耐药标记与微单倍型分析（nf-core/plasmodiumdrugres）

## 识别数据与研究目标

从交付文件与报告中识别 allele table 或 PMO 等支持的微单倍型输入、位点定义及采样群体，确认参考和氨基酸编号。

## 方法选择

按该版本将耐药位点变异转为氨基酸并计算单/多位点频率，保留分母及混合感染处理。

先核对 [版本约定](references/流程约定.json)。

| 核对项 | 固定范围 |
|---|---|
| 上游版本 | `dev`；`076642a93b9d564708af5e75137eb19899c31266` |
| 上游维护 | 开发版本；按当前代码实际实现的范围使用 |
| 本地运行 | 未进行真实分析运行；不能据本 Skill 文件声称实跑通过 |
| 引擎声明 | `!>=25.10.4`；还需核验 Java、容器和 profile |

## 根据数据确定参数

按位点覆盖、混合感染与缺失情况确定频率分母和低支持过滤；标记证据与药物反应解释分开，不能把缺失位点算成敏感型。

| 决策与配置 | 处理要求 |
|---|---|
| 事实与缺口 | 先读现有文件和报告；不能据文件名猜实验类型、参考或样本关系；只补问无法核实且会改变分析的背景 |
| 参数来源 | 区分协议必需设置、数据估计、方法默认和研究选择；说明实际取值及理由，不要求用户填写专业参数 |
| 可执行配置 | 仅把已支持的选择映射为当前版本的原生字段；不支持的步骤另行交接，不虚构开关 |
| 阈值复核 | 默认值先评估适用性；依据质控、对照及敏感性检查调整，不能按显著结果数量调参 |

## 质控与解释

检查低覆盖、缺失、位点覆盖差异和单倍型相位，区分等位基因频率与携带者比例。

交付耐药标记统计与限制；病原体基因型不直接决定个体治疗结局，也不是患者药物代谢分型。
