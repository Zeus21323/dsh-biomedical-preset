# 历史非标记蛋白质组定量（nf-core/proteomicslfq）

## 识别数据与研究目标

核对交付包中的归档 LFQ 流程支持的原始质谱、蛋白库、酶切/修饰参数和样本设计，明确复现版本。

## 方法选择

保持历史搜索、FDR、跨run 匹配和蛋白汇总规则，迁移时逐项比较而非替换工具名。

先核对 [版本约定](references/流程约定.json)。

| 核对项 | 固定范围 |
|---|---|
| 上游版本 | `1.0.0`；`43c77e50c955d7e62899e7d31e0d6f6a87ac2316` |
| 上游维护 | 已归档；用于明确的历史分析或复现审查 |
| 本地运行 | 未进行真实分析运行；不能据本 Skill 文件声称实跑通过 |
| 引擎声明 | `!>=20.01.0`；还需核验 Java、容器和 profile |
| 语法兼容 | 原生入口含历史 process/channel 写法；先核验匹配的 Nextflow 版本 |

## 根据数据确定参数

从仪器、样本批次和缺失模式评估搜索、跨 run 匹配与蛋白汇总；恢复历史设置时保留原 FDR 口径，比较条件不能把未检出一律填成零。

| 决策与配置 | 处理要求 |
|---|---|
| 事实与缺口 | 先读现有文件和报告；不能据文件名猜实验类型、参考或样本关系；只补问无法核实且会改变分析的背景 |
| 参数来源 | 区分协议必需设置、数据估计、方法默认和研究选择；说明实际取值及理由，不要求用户填写专业参数 |
| 可执行配置 | 仅把已支持的选择映射为当前版本的原生字段；不支持的步骤另行交接，不虚构开关 |
| 阈值复核 | 默认值先评估适用性；依据质控、对照及敏感性检查调整，不能按显著结果数量调参 |

| 资料 | 使用时机 |
|---|---|
| [参数模式.json](references/参数模式.json) | 编写 params.json 时核对字段、类型、枚举及条件约束 |

仅在已授权且配置齐备时运行。

```bash
nextflow run nf-core/proteomicslfq -r 43c77e50c955d7e62899e7d31e0d6f6a87ac2316 -params-file params.json
```

模式文件的许可见 [LICENSE](LICENSE)。

## 质控与解释

检查鉴定深度、定量分布、批次、缺失机制和共享肽，评估缺失填补对效应的影响。

输出可恢复的肽/蛋白定量与质量记录；LFQ 数值不能无条件作为绝对浓度或跨实验直接比较。
