# 蛋白质组数据质量控制

## 建立期望值

收集运行顺序、QC/空白、批次、仪器维护记录、搜索和定量结果，以及项目预设的质量范围。阈值应来自本项目 QC、历史同平台分布或明确规范。

## 三层检查

- **仪器层**：总离子流、MS1/MS2 数、质量误差、保留时间、峰宽、喷雾中断和 carryover。
- **鉴定层**：PSM/肽段/蛋白数、酶切效率、污染物、反向命中、仅位点鉴定和分层 FDR。
- **定量层**：LFQ/通道强度分布、QC CV、缺失率、动态范围、批次与样本相关性。

使用 MaxQuant/Perseus 结果时，明确去除 contaminants、reverse 和 only identified by site 的规则；检查 MaxLFQ 强度、M-B-R 转移率及转移蛋白是否集中在低强度区。缺失值插补前后都要展示，不能用漂亮聚类代替质量证据。

## 异常处置

逐个样本列出异常、可能原因、影响层级和建议。重跑、剔除或仅限制部分下游必须有预设或敏感性分析支持，不能只因 PCA 离群自动删除。

## 交付

提供样本/运行质量表、关键诊断图、阈值来源、异常证据、保留或重跑建议，以及处理前后结论稳定性。
