# 基因组集合映射与微生物基因定量（nf-core/magmap）

## 识别数据与研究目标

从交付文件与报告中识别宏基因组/宏转录组 reads、候选参考基因组集合及注释，评估群落是否符合流程主要面向的原核生物范围。

## 方法选择

按版本步骤筛选参考、补充缺失注释并映射定量，保持 gene ID、contig 和 genome 之间的关系。

先核对 [版本约定](references/流程约定.json)。

| 核对项 | 固定范围 |
|---|---|
| 上游版本 | `1.2.0`；`20c6dda92b52ad9788dfcc7eebc6330ac48f2fcd` |
| 上游维护 | 未归档；使用这里固定的源码，不自动跟随新版本 |
| 本地运行 | 未进行真实分析运行；不能据本 Skill 文件声称实跑通过 |
| 引擎声明 | `!>=26.04.0`；还需核验 Java、容器和 profile |

## 根据数据确定参数

由参考冗余、群落差异与多重匹配情况选择映射条件，保留可比的基因标识及长度定义；缺少参考的成员不能按零丰度解释。

| 决策与配置 | 处理要求 |
|---|---|
| 事实与缺口 | 先读现有文件和报告；不能据文件名猜实验类型、参考或样本关系；只补问无法核实且会改变分析的背景 |
| 参数来源 | 区分协议必需设置、数据估计、方法默认和研究选择；说明实际取值及理由，不要求用户填写专业参数 |
| 可执行配置 | 仅把已支持的选择映射为当前版本的原生字段；不支持的步骤另行交接，不虚构开关 |
| 阈值复核 | 默认值先评估适用性；依据质控、对照及敏感性检查调整，不能按显著结果数量调参 |

| 资料 | 使用时机 |
|---|---|
| [参数模式.json](references/参数模式.json) | 编写 params.json 时核对字段、类型、枚举及条件约束 |
| [输入模式-1.json](references/输入模式-1.json) | 准备 genomeinfo 对应的样本表或输入文件时读取 |
| [输入模式-2.json](references/输入模式-2.json) | 准备 input 对应的样本表或输入文件时读取 |

仅在已授权且配置齐备时运行。

```bash
nextflow run nf-core/magmap -r 20c6dda92b52ad9788dfcc7eebc6330ac48f2fcd -params-file params.json
```

模式文件的许可见 [LICENSE](LICENSE)。

## 质控与解释

检查参考选择、近缘基因组多重比对、覆盖与未映射比例，区分数据库缺失和真实低丰度。

交付基因/基因组特征定量及 QC；相似菌株间分配具有不确定性，下游差异模型需匹配 DNA 或 RNA 数据语义。
