# Molecular Cartography空间转录处理（nf-core/molkart）

## 识别数据与研究目标

从交付文件与报告中识别 Resolve Molecular Cartography 图像/分子数据、panel、坐标尺度和样本信息，核对处理阶段与必要分割通道。

## 方法选择

依据本版本支持的分子定位、细胞分割和表达组织方法处理，保留原始分子到细胞的分配关系。

先核对 [版本约定](references/流程约定.json)。

| 核对项 | 固定范围 |
|---|---|
| 上游版本 | `1.2.0`；`4ec0790d80cf77f2428d33b1a8571ccb498e2170` |
| 上游维护 | 未归档；使用这里固定的源码，不自动跟随新版本 |
| 本地运行 | 未进行真实分析运行；不能据本 Skill 文件声称实跑通过 |
| 引擎声明 | `!>=25.04.0`；还需核验 Java、容器和 profile |

## 根据数据确定参数

从实际分割通道、像素尺度及分子背景确定分配半径和过滤条件；比较细胞边界附近分子的归属变化，防止为增加计数过度扩张细胞。

| 决策与配置 | 处理要求 |
|---|---|
| 事实与缺口 | 先读现有文件和报告；不能据文件名猜实验类型、参考或样本关系；只补问无法核实且会改变分析的背景 |
| 参数来源 | 区分协议必需设置、数据估计、方法默认和研究选择；说明实际取值及理由，不要求用户填写专业参数 |
| 可执行配置 | 仅把已支持的选择映射为当前版本的原生字段；不支持的步骤另行交接，不虚构开关 |
| 阈值复核 | 默认值先评估适用性；依据质控、对照及敏感性检查调整，不能按显著结果数量调参 |

| 资料 | 使用时机 |
|---|---|
| [参数模式.json](references/参数模式.json) | 编写 params.json 时核对字段、类型、枚举及条件约束 |
| [输入模式-1.json](references/输入模式-1.json) | 准备 input 对应的样本表或输入文件时读取 |

仅在已授权且配置齐备时运行。

```bash
nextflow run nf-core/molkart -r 4ec0790d80cf77f2428d33b1a8571ccb498e2170 -params-file params.json
```

模式文件的许可见 [LICENSE](LICENSE)。

## 质控与解释

检查背景探针、定位质量、每细胞转录本数、边界与未分配分子，评估组织密度影响。

交付空间分子/细胞表达和 QC；靶向 panel 的缺失信号不能解释为全转录组不表达。
