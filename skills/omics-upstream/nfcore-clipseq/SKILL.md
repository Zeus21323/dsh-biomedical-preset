# CLIP-seq RNA结合蛋白定位（nf-core/clipseq）

## 识别数据与研究目标

确认 CLIP/iCLIP/eCLIP 等协议、UMI、对照、reads 结构、参考和重复，避免混用截断与交联位点定义。

## 方法选择

按本版本选择 pre-mapping、比对、UMI 去重和 peak caller，保留协议相关的交联/富集解释。

先核对 [版本约定](references/流程约定.json)。

| 核对项 | 固定范围 |
|---|---|
| 上游版本 | `1.0.0`；`45ae3c0b9b16206b687f4a645e1643c85b3f1ab4` |
| 上游维护 | 未归档；使用这里固定的源码，不自动跟随新版本 |
| 本地运行 | 未进行真实分析运行；不能据本 Skill 文件声称实跑通过 |
| 引擎声明 | `>=20.04.0`；还需核验 Java、容器和 profile |
| 语法兼容 | 原生入口含历史 process/channel 写法；先核验匹配的 Nextflow 版本 |

## 根据数据确定参数

从交联协议、UMI 与对照设计确定去重和位点定义；峰阈值结合局部背景及重复，不能将不同协议的截断和富集坐标直接合并。

| 决策与配置 | 处理要求 |
|---|---|
| 事实与缺口 | 先读现有文件和报告；不能据文件名猜实验类型、参考或样本关系；只补问无法核实且会改变分析的背景 |
| 参数来源 | 区分协议必需设置、数据估计、方法默认和研究选择；说明实际取值及理由，不要求用户填写专业参数 |
| 可执行配置 | 仅把已支持的选择映射为当前版本的原生字段；不支持的步骤另行交接，不虚构开关 |
| 阈值复核 | 默认值先评估适用性；依据质控、对照及敏感性检查调整，不能按显著结果数量调参 |

| 资料 | 使用时机 |
|---|---|
| [参数模式.json](references/参数模式.json) | 编写 params.json 时核对字段、类型、枚举及条件约束 |

仅在已授权且配置齐备时运行。

```bash
nextflow run nf-core/clipseq -r 45ae3c0b9b16206b687f4a645e1643c85b3f1ab4 -params-file params.json
```

模式文件的许可见 [LICENSE](LICENSE)。

## 质控与解释

检查 rRNA、重复、UMI 家族、对照背景与重复一致性，评估高表达 RNA 导致的非特异富集。

交付结合候选区域和支持证据；结合信号不自动说明剪接、稳定性或翻译调控效应。
