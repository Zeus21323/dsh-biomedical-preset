# 代谢组质量控制归一化与批次校正

原始数据还没有形成稳定峰表，或需要处理保留时间偏移时，先读取[色谱峰对齐与漂移处理](references/色谱峰对齐与漂移处理.md)；不要在峰表形成前直接进入批次校正。

## 所需信息

峰表、样本类型、注射顺序、批次、空白、pooled QC、稀释 QC、内标、样本量或体积和缺失值。没有运行顺序时不能可靠做顺序漂移校正。

## 处理次序

1. 先依据方法空白和检出频率去除污染或极不稳定特征。
2. 用 pooled QC 沿运行顺序拟合漂移；样本较少或 QC 稀疏时避免高自由度曲线。
3. 检查稀释线性和 QC CV，再决定保留阈值；阈值按平台和项目设定。
4. 依据采样设计选择内标、样本量、PQN 或稳健总信号归一化，不默认总信号恒定。
5. 批次校正时保留条件、组织和其他真实协变量；完全混杂时报告不可辨识。
6. 按缺失机制选择删除、模型或插补，并保存原始缺失掩膜。

## 校正是否成功

比较校正前后的 QC CV、漂移曲线、PCA、内标和生物对照；若 QC 变紧但已知生物梯度消失，应降低校正强度。

## 交付

交付清洁矩阵、每项过滤与校正规则、QC 图、缺失处理、批次诊断和被剔除特征清单。

## 参数记录

每一步输出特征数和样本数变化，记录空白比、检出率、QC CV、漂移模型、归一化因子、批次变量和缺失掩膜。TIC、中位数、PQN、内标或 QC-RLSC 只能在数据假设成立时使用；若多种处理路线均合理，保留未处理矩阵并报告敏感性差异，不按组间分离程度挑选归一化方法。
