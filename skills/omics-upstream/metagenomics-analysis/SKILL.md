# 宏基因组端到端分析

1. 先定义研究问题、对照、重复、批次、主要终点和允许的推断边界。
2. 完成原始质控、宿主去除、污染审计与样本排除记录，再并行规划读段分类和组装路线。
3. 物种谱、功能谱、MAG和耐药分析分别保留数据库版本与中间质量指标。
4. 统计模型纳入组成性、批次、协变量和重复测量，多重比较统一校正。
5. 交叉核对不同路线的一致结果，并把数据库缺口、低深度和污染风险写入结论。

输出数据流图、样本质控表、结果矩阵、统计模型和可复现参数；任何机制性结论均需外部或实验验证。
