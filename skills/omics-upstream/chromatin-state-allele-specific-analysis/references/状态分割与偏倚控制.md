# 状态分割与偏倚控制

## 染色质状态

- 输入轨道使用同一基因组版本、染色体命名和分箱大小。
- 每个样本的标记缺失必须显式处理，不能用全零代替失败实验。
- 状态数通过可解释性、重现性和下游用途选择，不以更大为更好。
- 使用启动子、增强子、转录、异染色质和重复区域等外部注释解释状态。
- 跨模型比较应按发射模式和基因组重叠匹配，不能直接对齐状态编号。

## 等位基因特异分析

- 基因型和相位需与样本一致；
- 采用 WASP、个体化基因组或等价策略评估参考偏倚；
- 只在有足够总覆盖和双等位基因支持的位置检验；
- 控制多个位点和多个标记的检验数量；
- 结合输入对照、CNV、印记区域和克隆性解释。

## 运行接口

`run_chromatin_states.sh` 只编排 ChromHMM 的 BinarizeBam 与 LearnModel。调用者仍需提供已安装的 Java、ChromHMM JAR、染色体长度和经过质控的 BAM 清单。
