# 染色质状态与等位基因特异分析

先确定任务是多标记染色质状态分割、等位基因特异信号，还是二者联合。状态分割要求各标记在相同样本、参考版本和可比较分箱上处理；等位基因分析要求可靠基因型、相位和等位基因映射偏倚控制。

染色质状态模型需要记录输入标记、分箱、状态数、训练方式和状态命名依据。状态编号本身没有跨模型生物意义，必须根据发射概率和外部注释重新解释。等位基因特异分析应使用个体化或变异感知比对策略，过滤低覆盖、重复和可能的参考等位基因偏倚。

需要设计 ChromHMM 类流程或等位基因计数时读取[状态分割与偏倚控制](references/状态分割与偏倚控制.md)。如果运行环境已有 ChromHMM，可用 `scripts/run_chromatin_states.sh --dry-run` 生成并检查命令；维护脚本时运行 `scripts/test_run_chromatin_states.sh`。

交付状态发射矩阵、状态注释、区段文件、富集结果、等位基因计数、偏倚过滤和跨样本一致性。低覆盖下的等位基因不平衡不能单独解释为印记或顺式调控。
