# RNA测序融合转录本检测（nf-core/rnafusion）

## 识别数据与研究目标

从交付文件与报告中识别 RNA-seq、建库、参考与注释、样本信息，明确筛查范围及可用 DNA 验证证据。

## 方法选择

按本版本支持的融合调用器组织检测和结果整合，保留各工具原始支持及过滤原因，避免机械合并不兼容的断点表示。

先核对 [版本约定](references/流程约定.json)。

| 核对项 | 固定范围 |
|---|---|
| 上游版本 | `4.1.3`；`76ad76e7c39b2ba9edc35aa3602e3dc454d842ec` |
| 上游维护 | 未归档；使用这里固定的源码，不自动跟随新版本 |
| 本地运行 | 未进行真实分析运行；不能据本 Skill 文件声称实跑通过 |
| 引擎声明 | `!>=25.10.4`；还需核验 Java、容器和 profile |

## 根据数据确定参数

结合读长、表达量、split/spanning 支持和重复区域决定调用与复核条件；对低表达目标报告检测限制，不能只降低支持读数换取更多融合候选。

| 决策与配置 | 处理要求 |
|---|---|
| 事实与缺口 | 先读现有文件和报告；不能据文件名猜实验类型、参考或样本关系；只补问无法核实且会改变分析的背景 |
| 参数来源 | 区分协议必需设置、数据估计、方法默认和研究选择；说明实际取值及理由，不要求用户填写专业参数 |
| 可执行配置 | 仅把已支持的选择映射为当前版本的原生字段；不支持的步骤另行交接，不虚构开关 |
| 阈值复核 | 默认值先评估适用性；依据质控、对照及敏感性检查调整，不能按显著结果数量调参 |

| 资料 | 使用时机 |
|---|---|
| [参数模式.json](references/参数模式.json) | 编写 params.json 时核对字段、类型、枚举及条件约束 |
| [输入模式-1.json](references/输入模式-1.json) | 准备 input 对应的样本表或输入文件时读取 |

仅在已授权且配置齐备时运行。

```bash
nextflow run nf-core/rnafusion -r 76ad76e7c39b2ba9edc35aa3602e3dc454d842ec -params-file params.json
```

模式文件的许可见 [LICENSE](LICENSE)。

## 质控与解释

检查 split/spanning reads、比对唯一性、read-through、同源基因与背景事件，评估低支持候选。

交付融合候选、断点和读段证据；融合转录本不一定对应 DNA 重排或驱动事件，临床用途需专业复核。
