# 蛋白家族构建与增量更新（nf-core/proteinfamilies）

## 识别数据与研究目标

从交付文件与报告中识别蛋白 FASTA；更新家族时同时提供一一对应的 HMM 与 MSA 文件，明确旧家族标识的保留规则。

## 方法选择

依据 MMseqs2、MSA 与 HMM 构建链路聚类和扩展家族，记录修剪、合并与新成员招募的阈值。

按序列分化、长度和功能粒度选择相似度与覆盖规则；增量更新检查家族合并及边界成员，不用单一 identity 门槛定义所有家族。

## 质控与解释

检查家族覆盖、序列长度、冗余、远缘混入和 MSA 质量，防止过度合并损失功能亚家族。

交付家族成员、比对与 HMM 及变更说明；家族成员身份不能直接证明完全相同的生物功能。
