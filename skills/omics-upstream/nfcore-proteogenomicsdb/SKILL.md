# 蛋白基因组学搜索数据库构建（nf-core/proteogenomicsdb）

## 根据数据确定参数

按研究目标限制变异、转录本和翻译范围，结合冗余与 decoy 设计检查搜索空间；更大的库增加统计负担，不能仅以候选序列数评价质量。

| 决策与配置 | 处理要求 |

| 参数来源 | 区分协议必需设置、数据估计、方法默认和研究选择；说明实际取值及理由，不要求用户填写专业参数 |

| 阈值复核 | 默认值先评估适用性；依据质控、对照及敏感性检查调整，不能按显著结果数量调参 |

## 质控与解释

检查非法翻译、冗余、参考不一致及过大搜索空间，估计新候选库对鉴定错误控制的影响。

交付可用于搜索的数据库与来源映射；构库中的候选蛋白不代表在质谱或生物样本中已被检出。
