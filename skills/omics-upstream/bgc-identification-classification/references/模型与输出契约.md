# BGC-Prophet 模型与输出契约

## 关键参数

- `threshold`：基因级 BGC 判定阈值，改变时同时报告候选簇数量变化。
- `max_gap`：一个候选簇内允许的最大非 BGC 基因间隔。
- `min_count`：形成候选簇所需的最少预测基因数。
- `classifier_threshold`：类别判断阈值；低于阈值时保留为未分类。

这些值必须随模型版本一起记录，不能跨 checkpoint 直接比较分数。

## 最小输出

保留样本、contig、蛋白 ID、基因顺序、预测分数、簇 ID、簇起止、簇内基因数、分类及分类分数。运行元数据至少包含输入文件清单和哈希、检测与分类 checkpoint 哈希、完整参数、设备、工具版本、开始结束时间和退出状态。

## 停止条件

输入为核酸、无法恢复基因顺序、模型缺失或不兼容、GPU 请求不可满足、外部命令失败时停止。不得用空模型路径、演示 checkpoint 或随机结果继续。
