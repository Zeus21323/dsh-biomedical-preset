# 微生物生物合成基因簇识别与分类

## 输入门槛

输入为按基因组或 contig 组织的氨基酸 FASTA，并保留能够恢复基因顺序的稳定标识。先验证不是核酸 FASTA、序列字符合法、文件之间样本名不冲突。若只有核酸序列，先使用适合该基因组类型的基因预测流程。

运行需要 BGC-Prophet CLI、检测模型 checkpoint 和可选分类模型 checkpoint。模型文件不随本 Skill 分发，使用前核对来源、许可证、版本和 SHA-256。

## 分析

1. 组织蛋白序列并验证基因顺序。
2. 提取 ESM 表征或复用与模型版本兼容的缓存。
3. 以预先记录的检测阈值、最大基因间隔和最小基因数识别候选 BGC。
4. 有兼容分类器时进行类别预测，同时保留原始分数和未分类候选。
5. 回到 contig 边界、基因数量和功能注释复核重点簇。

可使用 `scripts/run_bgc_prophet.py` 调用外部 BGC-Prophet。参数和输出定义见[模型与输出契约](references/模型与输出契约.md)。

## 输出与解释

交付基因级预测、簇区间、类别分数、输入和 checkpoint 哈希、完整命令、工具版本及运行状态。BGC 预测只说明存在潜在生物合成区域，不等于产物结构、表达或活性已经确认。
