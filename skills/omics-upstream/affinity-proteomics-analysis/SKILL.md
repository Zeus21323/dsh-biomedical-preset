# 亲和蛋白质组分析

## 平台信息决定处理方式

确认平台、panel/试剂版本、输出尺度、板布局、桥接样本、平台 QC 标记和 LOD 规则。NPX 与 RFU 不是可直接互换的浓度，不能套用质谱搜索或蛋白推断流程。

## 数据整理

1. 校验样本—板—孔映射，排查重复、换板和失败样本。
2. 按厂商定义解释 QC 和标准化结果；如需追加板校正，先确认条件与板不完全混杂。
3. 保留探针 ID 作为分析单位，再映射到蛋白；多个探针对同一蛋白的结果分别报告。
4. 在样本层建立差异或关联模型，纳入必要的批次和临床协变量。
5. 对低于 LOD 的值按平台尺度和问题处理，避免一律填成零或最小值。

## 质量判断

检查桥接样本、板内/板间漂移、低于 LOD 比例、溶血或采样质量、重复一致性和探针注释更新。显著结果若只来自单个探针，应标记特异性风险。

## 交付

提供清洁探针矩阵、样本 QC、板校正说明、差异效应与 FDR、蛋白映射冲突和检测范围边界。
