# 噬菌体序列识别与注释（nf-core/phageannotator）

## 识别数据与研究目标

从交付文件与报告中识别基因组/宏基因组序列与定量所需数据，明确噬菌体或前噬菌体识别目标及数据库版本。

## 方法选择

按流程识别病毒候选、注释并在支持时定量，保留候选边界和宿主 contig 上下文。

先核对 [版本约定](references/流程约定.json)。

| 核对项 | 固定范围 |
|---|---|
| 上游版本 | `dev`；`30d09bd9e4b3538ae3394a91e6ffb44ad9d33183` |
| 上游维护 | 开发版本；按当前代码实际实现的范围使用 |
| 本地运行 | 未进行真实分析运行；不能据本 Skill 文件声称实跑通过 |
| 引擎声明 | `!>=23.04.0`；还需核验 Java、容器和 profile |

## 根据数据确定参数

依据候选长度、完整性、病毒特征和宿主边界选择报告条件；碎片与完整基因组分开，定量时评估多重映射与共享区域。

| 决策与配置 | 处理要求 |
|---|---|
| 事实与缺口 | 先读现有文件和报告；不能据文件名猜实验类型、参考或样本关系；只补问无法核实且会改变分析的背景 |
| 参数来源 | 区分协议必需设置、数据估计、方法默认和研究选择；说明实际取值及理由，不要求用户填写专业参数 |
| 可执行配置 | 仅把已支持的选择映射为当前版本的原生字段；不支持的步骤另行交接，不虚构开关 |
| 阈值复核 | 默认值先评估适用性；依据质控、对照及敏感性检查调整，不能按显著结果数量调参 |

| 资料 | 使用时机 |
|---|---|
| [参数模式.json](references/参数模式.json) | 编写 params.json 时核对字段、类型、枚举及条件约束 |
| [输入模式-1.json](references/输入模式-1.json) | 准备 input 对应的样本表或输入文件时读取 |

仅在已授权且配置齐备时运行。

```bash
nextflow run nf-core/phageannotator -r 30d09bd9e4b3538ae3394a91e6ffb44ad9d33183 -params-file params.json
```

模式文件的许可见 [LICENSE](LICENSE)。

## 质控与解释

检查序列完整性、宿主污染、基因特征及边界不确定性，避免把所有病毒样信号视为完整噬菌体。

交付噬菌体候选、注释和可用丰度；宿主预测与裂解/溶原性质仍需具体证据验证。
