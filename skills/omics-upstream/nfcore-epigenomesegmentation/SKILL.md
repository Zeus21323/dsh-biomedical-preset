# 表观信号染色质状态分段（nf-core/epigenomesegmentation）

## 识别数据与研究目标

从交付文件与报告中识别组蛋白、开放染色质或甲基化信号、统一基因组分箱和样本对应，确认平台与信号尺度。

## 方法选择

按 EpiSegMix/Meth 等本版本支持的模型设置状态数、分布与持续时间假设，比较不同初始化和模型复杂度。

先核对 [版本约定](references/流程约定.json)。

| 核对项 | 固定范围 |
|---|---|
| 上游版本 | `dev`；`2fbdaf179be7c0bbcd18028c45c1af5798752e90` |
| 上游维护 | 开发版本；按当前代码实际实现的范围使用 |
| 本地运行 | 未进行真实分析运行；不能据本 Skill 文件声称实跑通过 |
| 引擎声明 | `!>=25.04.0`；还需核验 Java、容器和 profile |

## 根据数据确定参数

依据轨道尺度、覆盖和研究分辨率确定分箱与状态数；比较不同初始化的稳定性及留出数据表现，状态解释依据信号组合而不是状态编号。

## 质控与解释

检查训练收敛、状态稳定性、信号缺失和批次影响；状态名称需要通过富集特征解释。

交付状态分段、参数和生物学注释依据；隐状态是模型总结，不能直接当作固定的细胞类型或功能事实。
